# 颐和轩至景祺阁穿廊局部实施计划

基线：9e68601aa473bb58459dc6936047c068b5c8d160。保留旧分支/main，不部署。

## 依据与选择
官文236516/236480确认北向三间穿廊，中央东西开门。2025年第1期《紫禁城》108页平面确认颐和轩后口；《“迷楼”—符望阁》19页下图可见穿廊侧立面的低瓦顶、红色窗门。精确尺寸、三间分配、颜色、屋顶交接与现时开放未核。

相比只补外壳或只去掉后门，本次选择一处真实连通的有限主体：两个既有台基之间增加低檐穿廊、中央两侧开口与实体台阶，保留其他入口和东西绕行；不改地图目标/通用物理，不补小院园石、家具或原彩画。

## 重点风险
后门目标不得误认；只读宿主和分配中途失败不能产生部分替换；旧景祺南阶/落点被新地面覆盖不能造成困住；两侧入口必须实体可走；正常销毁不能误释放共享材质。完整World、GPU、浏览器、手机均不在本轮可验范围。
