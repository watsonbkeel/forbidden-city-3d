# R257 大佛堂东墙六框：有限组件候选

## 来源与建模边界

王家鹏，2015年，印刷页306图22《大佛堂东墙罗汉立面图》直接支持东墙中央四幅高框、南北两端各一较矮框及其在九罗汉长台后方的关系。
来源：https://img.dpm.org.cn/Uploads/File/2020/02/26/u5e56176b64d88.pdf

这不是西墙镜像推断、完整历史内装或现今博物馆复原。所有绝对坐标、尺寸、木框截面、深度、背板和颜色均为 MODEL_FIT_NOT_SURVEY。未制作擦擦小像或罗汉；正文2188总数不分摊到墙面或框内，素底不表示历史为空。源图未作为产品素材上传。

复核图22后纠正了未执行初稿的过低下缘和过窄整体跨度：中央框下缘应接近罗汉头肩，而不是紧贴台面。最终中央底2.90/顶6.50，两端底2.70/顶4.95；端中心z=-3.75、+4.95，中央中心z=-1.23、-.01、1.21、2.43。中央各宽1.16、端各宽.90，整体宽9.60，对比旧拟合平台长9.00；图中木框外线、格面及被遮挡部分不够明确，不能把像素比例当测绘。

背板x=-9.65、厚.04；前框x=-9.60、深.10。静态源码范围比较：距旧平台顶1.60至少1.10；距隔墙内表面约.05286；距侧门开口北端z=-5.0约.80；框顶距已存最低梁面7.90约1.40。以上是静态拟合包络比较，不是实际宿主碰撞验收。

## 实现与验证

新增独立DafotangEastCabinets组件，30网格、360三角、25,200B索引几何，两个专有材质桶；每网格有真实三角碰撞owner。只在RemainingOuterHalls的大佛堂分支增加一个import和一次调用。照片登记只读写元数据，不捕获几何，因此东框在其后安装。保留旧西框、三佛、韦陀、双木塔、照片登记、房间和walkables。

组件/合成installer/组件合批/静态接线检查6/6通过，涵盖顶点范围、所有权、嵌套双塔宿主形状约束、重复/变更拒绝、部分发布回滚、构造失败清理及旧源码hash保护。峰值73.33MiB，user+sys CPU .341123s，子进程reaped墙钟 .231558s，stderr为空且清理完成。仅缺失模块与接线的静态RED先观测到两项预期失败；不把后续行为测试描述成逐项已执行RED。

从仓库根目录复现已存在的六项测试：

```sh
node --max-old-space-size=128 --max-semi-space-size=8 --test --test-isolation=none --test-concurrency=1 --test-reporter=tap tests/current-state/dafotang-east-cabinets.test.mjs
```

该命令只重跑组件测试，不自行实施外部RSS/CPU/墙钟监督，也不是整个项目测试命令。

另一次独立有界CPU诊断1/1生成正面256×160和斜面192×160两图，共73,696B；峰值62.48MiB，CPU .211708s，reaped墙钟 .150365s。亲看两图可辨四高两矮、分离端框、抬高悬挂及整体跨度。蓝色虚线仅是y1.60平台顶的静态二维参考线，绝非真实host几何；原框顶点未改。低分辨率RGB332不能验证精细框深、真实光照、GPU、浏览器或手机表现。这项一次性诊断不是上方六项测试的一部分，也不冒充仓库已有可运行的视觉测试命令。
