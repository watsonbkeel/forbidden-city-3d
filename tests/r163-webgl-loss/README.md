# R163：WebGL图形中断反馈

基于远端 `a17de47abf021828d4254da71a64b6328a0b66e3` 的完整累计树。目的是图形中断时不再无提示地继续游览，不是确认修复储秀宫根因或保证GPU恢复。

## 行为范围

- 主循环准备启动时，直接在renderer的canvas绑定webglcontextlost。确认当前上下文已经丢失时，不启动第一帧；返回可见时也检查状态，覆盖后台遗漏事件但仍处于丢失的情况。
- 上下文丢失不必抛JavaScript异常。统一故障入口现在先真正dispose主帧调度，再沿用a17的设置／飞行输入所有权清理和可访问的重新加载入口。图形文案明确“图形显示已中断”，说明刷新回到起点。
- 首个错误和原因保留。反复lost/restored、切标签、切帧率模式或再次start，不自动重启终止态，不无限重试。restored事件不被解释为画面或全部资源已恢复。
- 不移除／截断Three自身的上下文事件处理，保留其恢复许可；没有新增应用级GPU资源重建，也不会自动刷新。即便底层原本能短暂自行恢复，游览仍需用户明确重新加载，这是避免不可见移动的取舍。
- 页面dispose会移除应用自己的canvas监听；晚到回调不会再弹出窗口。正常后台暂停、首帧dt=0、30帧／流畅节奏、渲染管线、画质、地图目标及玩家物理不改。
- 监听在游览准备开始时建立，不宣称覆盖初始化早期所有失败或浏览器进程／主线程无响应。也没有通用“黑屏检测”。
