## 测试过程与边界

首次7组件红测证明新模块/挂接不存在；实现后修正牌匾Mesh不可JSON序列化的测试投影，原牌匾几何/文字保护仍在。冻结源码导入器曾误匹配函数内from字符串，已改为严格行首import匹配，失败在构造前，不是产品异常。
