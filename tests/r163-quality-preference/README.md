## 行为边界

- 设置中明确点击高／低画质后，尝试写入独立的 `fc3d-quality-v1`；刷新时只恢复 `high` 或 `low`。
- 无记录、非法值、读取被禁或存储不可用时，仍为原来的桌面高画质、手机低画质。不猜测 MacBook Air 型号，不自动降低默认画质。
- 存储写入失败不阻止本次切换；没有可用记录时，下次刷新仍回到平台默认。
- 启动、打开／关闭设置、程序调用画质切换都不保存默认值。只在真实设置按钮回调成功应用所选画质后保存。
- 不读取或迁移其他旧键，不改30帧调度、节能DPR上限、具体高低画质参数、地图、人物或物理。此前选择的流畅模式仍独立保留。
- 低画质的既有边界不变：部分细节在分区重载后应用，桌面贴图库不自动重建为手机SD。
