# E45 single-candidate eight-zone entry, proposed

Not executed on actual eight production zones. Runtime is byte-identical to checkpoint04. This directory adds only read-only verification. `run.mjs` has no arguments, requires E45_INPUT_MANIFEST and its separately supplied E45_INPUT_SHA256, and otherwise exits78 without invoking any builder. The supervisor controls actual approval, identity admission and process limits; supplying a JSON file does not itself constitute approval.

Input fields consumed: schema `e45-input/v1`, candidateCommit, candidateTree, sourceInventorySha256 (the exact bytes of tests/r169-current-source/delta.json), fonts[{path,sha256,family,coverageRanges,coverageEvidence}]. The supervisor verifies actual checkout commit/tree and lock/tool/native identities, rather than accepting values asserted by a caller. The child verifies every current1012 runtime file/mode/hash and complete path set, all eight pinned configurations and their actual registered order. No H17 dependency or dual root.

Readonly asset paths are public/textures/hd/manifest.json and its exact hd texture filenames; original production TextureLibrary.load/configure/material/ownership code runs. Only fetch/loadAsync transport is adapted to local bytes and @napi-rs/canvas loadImage, then full decoded pixels on real Canvas. No network, placeholder pixels, canvas no-op methods or swallowed asset failures. Node24.22.1, Three0.162.0, @napi-rs/canvas0.1.100 and its actual platform native binary must be fixed by the parent, not just package-lock. DISABLE_SYSTEM_FONTS_LOAD=1 precedes module import. Font file identities/families are passed by the controlled parent and verified before explicit registration. No child package install, permission or cache-setting changes.

JavaScript persistent writers: none. Normal production console output is forwarded to stderr, not suppressed or truncated. stdout has one final JSON result, <=1MiB checked after serialization (not a1MiB allocation guarantee). The supervisor budgets both streams, metadata and audit files together under the reviewed16MiB ceiling with terminal reserve. Native-library internal OS reads/writes are not claimed proven absent by a JS writer declaration. The supervisor environment must fix Node/native shared libraries and fonts, redirect writable HOME/TMP/cache paths into its budgeted area, and reject unexplained files. No glyph-face reflection or browser/native rendering equivalence is claimed.

Real entry: all eight original configs and ZoneBase constructors, original ZoneManager.init with all eight prebuilt, default32MiB/two-entry/120s cache, original rivers/moats and all source-bound hooks. The dynamic eight-zone helper test instead uses eight TEST_ONLY tiny boxes; it proves the helper's logic only and cannot be substituted by the entry.

Collision audit visits every loaded owner's collider/support occurrence in order, checks original source reference identity and shapes/rescue/ramp metadata against original CollisionManager admission, and rejects unknown/unloaded tags and missing/duplicate/reordered occurrences. It is an ownership/registration oracle, not a new collision algorithm. Complete ordered records are length-prefixed and hashed in memory. Triangle template vertices/normals/bounds are fully hashed once per shared template per state, with repeated instance/template identities preserved.

13 fixed probes perform exact ensure requests then real update/queue draining. The dedicated natural far and return use update only, and tiny tests install an ensure function that throws to prove they do not call it. Default cache ownership/cost determines retain versus disposal. Retired test strong references are nulled before a normal setImmediate yield; no GC, cache alteration or synthetic eviction. E45 final buffer attributes/index/groups/transform/material values and all76 collider/2 support records are compared after return. Only the exact verified generated source UUID suffix is removed from the E45 physical identity; role and occurrence remain.

Routes: initial16 new gate +16 old neighbor +16 approach +2 required closed-E46 non-arrivals =50. Return repeats16 new gate routes. Original endpoints, native physical-waypoint driver, rates10/30/60/144, walk/sprint and two-second stop are unchanged. Each real controller update also calls manager.update. The existing QA clock controls route simulation only; natural manager phases use restored native time. Complete frame/result sequences are hashed without truncation. Failed old routes are reported, not moved to another endpoint.

Static scope: 景运门 and the relevant east axis wall actually belong to axis-courts items4/6; E46 belongs to east-six. They are NOT double-added. The entry additionally uses the exact static PalaceBuilder.buildGate for original 乾清门 and original Enclosure.buildOuterWalls; all their actual colliders/supports are tagged and registered. It does not construct other PalaceBuilder palaces/gates or GardenBuilder/characters/GLB, and cannot claim full World collision closure. Rivers/moats remain the original CollisionManager lists. The supervisor must judge whether any additional static generator is an actual path dependency before release; this is an explicit remaining scope review, not a fabricated all-static PASS.

Result schema: `e45-eight-zone-result/v1`, PASS/FAIL/INCOMPLETE; completed/cleanup_complete; candidate_commit/tree/input_manifest_sha256; ordered stages/assertionGroups; runtime/environment/configuration/startup/staticScope;13 pointStates;16 physical state receipts; initial/returned route receipts; ownerBranch; resource summary/build ownership; errors/cleanupErrors. `result.mjs` is the pure supervisor-importable validator. The pure validator requires exact keys/types and cross-field counts/identities. RESULT-SHAPES.json defines the fixed nested shapes; SYNTHETIC-PASS.json is only a complete synthetic parsing fixture, never a production receipt. No actual production entry launch is authorized by this draft.


Native observation records the ordered actual fillText/strokeText calls, font request strings and finite codepoints, controlled available font families/styles, and complete row-chunk pixel hashes of every final consumed texture occurrence. Shared texture/source/image IDs preserve aliases; repeated references remain in the sequence. Readback requests sRGB through this pinned native API, not arbitrary hidden internal color profiles. Glyph coverage is checked against actual supervisor fc-query charset ranges for the registered SC font files. This proves controlled available coverage, not which face the native engine selected. Font discovery is disabled before importing the module; the fresh registry must be empty before the explicitly hashed registrations. The exact installed JS/type/binary pins and source lines are in NATIVE-SOURCE-EVIDENCE.json.

Pixel and frame streams retain every occurrence and complete ordered content through byte counts and hashes, not sampled rows/frames. The entry keeps no per-pixel or full per-frame persistent output. The single bounded result includes exact44 asset-read records, eight pinned configuration hashes,13 point states,16 physics stream receipts,50 initial and16 returned native route streams, owner/cache branch and complete resource-event stream. Tiny tests use fixtures solely to test acceptance/refusal, including missing/unknown fields, changed pixels, uncovered glyphs, ownership drift, reversed/duplicate/missing physical occurrences and fresh UUID normalization.

The startup observer invokes the original ZoneBase build/dispose and native canvas text methods without replacing geometry, source guards, cache policy or clipping behavior. Texture transport is the only local file adapter. The existing route QA clock restores after each route; the natural far/return phase uses the ordinary clock, normal event-loop yields and no ensure call or forced GC. Natural eviction/rebuild still has to be measured in the future admitted process.

Remaining execution gates: exact public candidate/tool/dependency/font provenance, independent entry and resource review, fresh cgroup quota/headroom admission and a single bounded actual-eight-zone attempt. Local tiny success, complete result schema and the prior product04 review do not grant those gates. The inherited portable UI matrix remains regression coverage only; an E45-specific browser assertion may be separately supplied by the CI author.
