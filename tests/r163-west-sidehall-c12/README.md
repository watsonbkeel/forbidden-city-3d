## 边界与回滚

这是单区 CPU 和绑定证明，不是397项或整栋完成率。完整 World 曾在旧工作区运行被 SIGKILL，本轮不重复，不将原因断言为已证实 OOM；静态全城、跨区流式加载、动态人群、全路线、GPU/PBR外观、浏览器／手机／Mac温度没有本轮通过结论。用户重点旧修复仍由累计分支保留，未扩大本次验收范围。

保留 c12 开发分支及 main。必要时继续使用 c12，或只回退此新增组件及 ZoneBase 两行挂接。是否纳入早上最终版本由集成人决定。没有创建 PR、合并 main 或部署 Pages。
