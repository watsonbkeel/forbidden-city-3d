## 行为与边界

- 主游览帧的同步未捕获异常进入终止状态：取消后续帧、移除后台切换监听、保留首个错误并记录控制台。切标签、切帧率模式、重复调用start不会自动重试部分完成的世界更新。
- 清除按住的移动／飞行输入并解锁鼠标，显示“游览已暂停”。真实重新加载按钮、alertdialog、标签与说明、初始焦点、Tab／Shift+Tab焦点限制、背景inert和输入隔离均有CPU DOM检查。重复触发不叠加窗口，成功发出一次重新加载请求后不会再次发出；重载API抛错时显示浏览器刷新提示，允许用户再试。
- 重新加载会回到起点，画质与既有运行设置仍遵循各自保存规则。没有当前位置保存、自动恢复执行或无限重试。
- 地图传送保留原几何、加载、落点判定、移动及更新顺序，只在外围捕获异常。失败前后比较真实相机位置／朝向；相机未变、已变化、无法可靠读取三种提示分别处理，不回滚，也不保证部分加载的世界已还原。失败返回null，地图继续打开；下一次明确操作可重试其他地点，恢复正常状态提示。失败消息持续显示，下一次操作或重新加载才替换；没有定时自动尝试。
- 没有异常但安全落点受阻时，继续使用原受阻提示，不把它当崩溃。错误详情不注入HTML，只留在控制台／内部错误字段。
- 不改默认画质、节能30帧、正常移动／碰撞、地图目标、NPC接触或地面容差。不处理初始化失败、没有JavaScript异常的WebGL上下文丢失、浏览器进程崩溃、主线程长任务或内存耗尽。
