This adds only three tiny side/back normal-perturbation grooves on the existing continuous head base. It does not add shells, discs, rim geometry, texture pixels, UV changes or source artwork changes. Radius .014m, depth .0008m; locally orthonormal spherical frames provide a physical tangent-space metric. Center singularity returns zero before atan, exterior height and slope fade to zero. Three centers remain nonoverlapping. There is no raised button dome or independent bright circular border.

Height is multiplied by source-contour mask, indexed-body eligibility and art/gold common-border falloff before differentiation. Art material0 shader remains unchanged by the groove addition; only material1 normals are perturbed after the ordinary normal-map chunk. Raw view-position derivatives preserve world-space height scale. Degenerate determinant returns the original normal. This is an engineering scratch/groove experiment, not a claim to recover Buddha hair form.

Local tests bound finite depth and sampled slope (<1), orthonormal frames/spacing/front exclusion, and normal sign/unit length under known scalar gradients.
