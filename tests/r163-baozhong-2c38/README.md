## 来源与拟合

[故宫重华宫介绍](https://www.dpm.org.cn/explore/building/236506.html)明确中院东配殿葆中殿为三间一进深、黄琉璃瓦硬山顶；“古香斋”为殿内额。[李燮平《从乾隆朝养心殿的改造看明清紫禁城硬山建筑的变化》](https://www.dpm.org.cn/Uploads/File/2020/11/12/u5facb56c07c8f.pdf#page=3)，载《故宫博物院院刊》2020年第10期，印刷135页明确列葆中殿为不出墀头硬山，136页图九确认院落位置。图八并非可确认的完整葆中正立面。

模型中心(99.15,496.5)、9.8×4.6m主体、10.8×7m平台、0.45m高和两级0.15m高／0.65m踏面为工程拟合。门窗分格、彩画、隐面、具体山墙细节、尺寸、真实阶数和近景正立面仍未核，不把浴德镜像当官源。未知室内封闭，不新增地图、传送、房间、家具、外匾或现实开放声明。
