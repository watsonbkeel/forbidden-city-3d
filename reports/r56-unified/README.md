# R56 累积人物版本

基于已交付 R55（远端 ec032ce22565c581491d944bcf5b085d1a50782f），不包含未接受的景运门实验，不修改 main 或部署 Pages。

## 本轮变化

- 逻辑人数 93 → 101。寿康宫、慈宁宫、寿安宫各新增一位侍立宫女和一位短线缓步太监；养心殿内院新增两位匿名太监，一位侍立、一位缓步。全部使用已有确认模板，无新服饰/模型形制。
- 原93角色记录、17条路线、Kit及195项世界输入保持原样。新增4条3.5米短线，路线总数21。
- 修复了实际复现的显示预算问题：远处 core 角色曾抢占名额，令镜头前旧守卫不显示。保留 essential 优先，其他角色按已有滞回的几何LOD距离层，再按身份、距离和ID排序。Manager另保留预算LOD字段，低档的渲染降级不会丢失近距离排序信息。**因此并非全部运行时代码不变。**
- 高档64、低档32、复杂近景2上限不变；低档太和12官员及固定19宫廷角色的身份选择不变。101是注册总数，不是同屏人数。

## 当前验证

- 56项适用专项通过，含128逻辑容量、队列取消与进展、默认开关、分代缓存、间距负测，以及高/低档局部可见排序、小抖动和LOD滞回。
- 一次最终实际世界集成通过：101人分别在B、真实养心S与真实坤宁S加载状态中逐一提交并通过实际三角可见性，280组观察无失败；21路线575支承样点；区域卸载、重载、关闭/重开和S返回B均用新代次绑定。
- 新8人额外28组高低档/重载观察，4条路线各2完整周期，合计1820个实际提交动作帧。新人与全体共772对、836段全相位间距检查，最小16米（门槛1.2米）。所有8人有实际身体范围、足底/摆步支承检查。
- 3项生产入口及真实根路径/子路径构建测试通过。实际main→设置→System→Manager→renderer非零实例与默认开启、关闭、夜间计划一致。CPU壳替代浏览器/GPU部分，不能据此称实机验收。
- 最终世界观察上界：高档64实例 / 45,470三角 / 21批 / 近2；低档32 / 14,228 / 11批 / 近0。只代表这些相机与状态的实际提交计数，不是任意镜头最高负载、GPU帧率或手机性能证明。
- 夜间只有原18名全天守卫符合日程；本批8人白天出现。初次准备帧数来自不按墙钟节奏运行的CPU测试，不换算成用户实际加载秒数。

## 证据与未过范围

RESULTS.json为摘要；ACTUAL-ROSTER.json为101个实际绑定地点，不是同屏承诺。大型世界报告与图像几何通过 reports/r56-transport/ARCHIVES.json 无损分片保存。运行 `node scripts/r56-restore-report-archives.mjs` 只校验；加一个输出目录可恢复原文件字节。PNG、小报告和日志直接保留。图像复绘用 tests/r56-render-staff.py，输入恢复后的 geometry/*.json.gz。

原失败日志保留：首次世界显示预算失败、低档几何排序失败均有修后对照；既有 p3c 固定38/96人数及旧路线缓存测试仍历史不适用，未改断言，不算通过。focused-filter-before.tap记录首次名称筛选未排除旧用例，最终使用明确 skip-pattern，56仅是适用项。旧全库不是全绿，本轮没有重跑或宣称全库绿。

GPU/WebGL画面与帧时、实体手机、完整史实验收仍未完成。人物默认可见不等于整体验收通过。BUILD-PACKAGE.json记录最终构建 R56-2119bbfe3973、134个包文件逐项哈希、135项ZIP完整性及本地HTTP检查。R55与所有旧版本保持回滚。
