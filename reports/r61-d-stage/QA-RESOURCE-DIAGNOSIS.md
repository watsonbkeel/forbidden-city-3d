# R61 QA resource diagnosis

The original single B attempt and the first five-stage B-current attempt were terminated by SIGKILL. The external cause is unknown. These are failed attempts, not passed world checks. The process memory measurements are QA-process observations, not browser/GPU/phone performance evidence.

The last B-current checkpoint preceded the retained R57 physical/body/motion proof. An isolated 100,000-triangle merged-mesh probe found one avoidable QA allocation: the historical raster exporter retains every transformed vertex, all kept triangle objects, a complete JSON string and gzip buffers simultaneously. With the same synthetic input, legacy peak RSS was 454,580 KiB; bounded export peak RSS was 75,664 KiB. Wall duration was 580 ms versus 482 ms. Gzip became 146,987 versus 241,941 bytes because bounded gzip members trade compression ratio for memory. These observations do not establish the previous termination's cause.

A new QA-only exporter writes individual triangle JSON records to a private temporary spool and compresses at most 65,536 source bytes per member. It retains the same arithmetic, draw range, visibility, frustum/far tests, triangle order, metadata and complete geometry. It does not alter production or texture policy. The historical exporter remains unchanged. Tests require exact decompressed JSON bytes, not approximate geometry, including actual CharacterRenderer buffers across all three LODs. Exceptions propagate and temporary files are removed; an existing destination is not replaced by failed traversal.

The R61 harness injects this serializer into the unchanged assertion scope of the R57 proof, and adds QA checkpoints after physical scanning, each body envelope and each export. No route, actor, phase, body radius, culling range or assertion was reduced. The static census checks every old assertion invocation (163 byte-exact plus one phase-enumeration guard) and all 17 route collectors. Five serial fresh complete worlds are still required; this is not one-world cumulative acceptance. Any further failure is reported rather than automatically subdividing again.
