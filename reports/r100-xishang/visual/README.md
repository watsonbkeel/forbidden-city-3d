# R100 actual-model CPU diagnostic images

export-visual.mjs exports the actual Xishang builder at the same entry/rail cameras; render-cpu.py rasterizes shared triangle data, fixed colors/light. Before is R99 inherited geometry; final after is the accepted continuous-top R100 candidate. Base/vertex-color CPU images are not textured GPU/mobile screenshots. They demonstrate filled stone-panel form, not exact bamboo relief or projecting post heads. Private official reference photographs are not included.

Rejected-first-proportions and rejected-raised-posts images/source remain separate negative evidence. Raised posts introduced 12 new physical failures; their picture is not the final candidate. All PNG files here and in the rejected directories are generated by this project's CPU script, not copied official images or user screenshots.
