# R49B 牌匾挂位纠正候选

## 结论与分母

**本轮修复局部已查实的问题，不宣称故宫全部牌匾已按实景验收。** R49 曾把“文字无遮挡”优先于真实门头/额枋关系，导致永和等牌落入门框范围，这是本轮明确纠正的错误。

- 157 条逐项对象台账 = 77 命名分区厅殿 + 74 命名门/历史门址 + 6 中轴主殿。不是 157 块实体匾。门类含 2 已拆门址；一个殿也可能有多个牌面。
- 31 个对象按目标照片改具体牌位/方向：其中 26 是已检查 CPU 约束的源图引导候选，另 5 个只纠正挂层、深度或轴线，窗带比例仍未解，不能计为完整修好。
- 58 个普通门的牌面与自有背框成组退出墙体，分别修复 5cm/7cm 的嵌墙。仅是几何修复，不是 58 处实景高度和朝向认证。
- 太和殿、保和殿、中和殿、乾清宫、交泰殿的现有层位保留，有官方像素及最终几何复核。
- 其余 63 条已登记证据、缺口和待办，但没有完整候选验收结论。见 [157 条台账](inventory-157.json)、[具名未完成清单](UNFINISHED.md)。不能将登记数计入修复通过率。

## 永和、重华：真实门头关系优先

| 模型量（米，非实测） | 永和 R49 → R49B | 重华 R49 → R49B |
|---|---:|---:|
| 牌面中心高度 | 4.5316 → 6.22088 | 3.907 → 5.40996 |
| 牌面宽×高 | 1.05×1.50 → 不变 | 1.05×1.50 → 0.945×1.35 |
| 完整模型框底 | 3.7216 → 5.41088 | 3.097 → 4.67496 |
| 真实生成门扇上框高度 | 5.33088，不变 | 4.61496，不变 |
| 完整框底相对门扇头 | −1.60928 → +0.08 | −1.51796 → +0.06 |
| 抱厦梁/檐参考高度 | 5.8416 → 6.9168 | 5.142 → 6.45 |

根因不是“再往前移/再缩一点”即可解决：旧抱厦高度压缩了正殿门头净空。两处使用获准局部抱厦高度拟合；主殿屋面、主柱、门扇、台基、柱脚平面、院距均未改。重华仅一次 10% 同比例牌面拟合，旧尺寸也不是实测硬约束。牌仍在**正殿门头、前方抱厦梁之后**；不删真实柱梁，正常斜侧遮挡保留。

抱厦后部按原主殿实际瓦面三角包络做隐蔽收边，10mm 接缝重叠明确是工程拟合，不是历史节点测绘。实际裁片保留 UV/法线和材质，追加封口在原屋面厚度内；独立检查不宣称每个构件网格均为数学封闭流形。

## 其他具体修正

- 景仁、承乾、钟粹、景阳、永寿、翊坤、储秀、太极、长春、咸福：按各自照片把完整框移到真实门扇上框以上、彩画额枋/斗栱前；不统一塞进梁下，不缩原牌。
- 养心：保持主殿头墙外深度和 1.32×2.2 牌面，仅中心高度 6.847→7.304；完整框底高出实际门扇头 8cm。
- 皇极、慈宁、坤宁、太和门：纠正到两檐夹层。皇极、慈宁保留原尺寸；坤宁、太和门的单次模型框比例拟合分别为 79.43% 和 76.51%。70% 只是一道工程防失控下限，绝不是历史比例正确的证据。完整旧新框值见 [静态前值](static-before.json)、[静态后值](static-after.json)，完整官方像素、相对柱间/夹层比及不确定性见 [双檐照片比例复核](double-eave-photo-ratios.md)。
- 古华、遂初、畅音、阅是、咸若：真实横排纹理和从右向左的字序，不拉扁竖匾贴图；咸若采用蓝底，其余四处深底。仍为系统字体和简化框，非书法/雕框复刻。
- 文华门、武英门：完整牌组回到内退红门头前，不挂到外檐柱面。
- 颐和：回到抱厦后的正殿门头。倦勤：回到东五间中心。文渊、宁寿、乐寿、梵华和倦勤的未解窗带比例必须继续修复，不以本轮部分纠正冒充完成。

[31 个变更对象的前后实际值](changed-mounts-31.json) 包含各位置、尺寸和多视点记录。屋檐自然遮挡没有被抹掉：例如皇极、慈宁的近院视点仍受下檐遮挡，远侧局部视点可见；高位诊断相机不是可行走人物视点。

## 验证、隔离和回滚

- 原九个新增针对性入口检查 44/44：完整背框、门扇上框、不入实际三角体积、双檐层位、横匾字序、裁片边界保面积、普通门框退墙与轻量 fixture 命名兼容。
- 两处静态双檐完整框另经实际场景全部结构三角相交检查，0 相交，不仅是几条射线。
- 独立两抱厦审查：70,389 表面探针零缺面、8 切面无主梁柱穿越、553 封口采样全隐蔽。旧裁片丢面缺陷曾被发现并修复，保留红证据。
- 独立总审：145 个分区对象、136 组注册牌面/背框；两获准抱厦以外所有非牌几何逐字节不变，牌数不变。五种横匾每种两次 finish/dispose，合并后顶点/UV、材质 UUID 分桶和新 atlas 释放通过。
- 29 个分区对象各 6 视点、9 面内样点，记录真实局部生产合并网格；不等于全城遮挡、GPU 或每条行走路线通过。
- 完整同口径回归：复用 SHA 校验一致的 R49 337 入口基线，候选运行同 337 + 本次 9 = 346 入口。最终原始 TAP、实际退出码、失败逐项归因在 `../final-validation/`。旧错误挂位测试不因“以前通过”而视为历史正确，也未改写旧测试来刷绿。
- 原 346 入口全套的真实结果是 5265 tests、5085 pass、180 fail、exit 1：158 为 R49 已有失败，22 为新增失败。明确保留红结果，不宣称全库通过。旧 R49 身体入口因原源码守卫拒绝新源 hash，在注册 57 项前退出；新增独立守卫适配补跑真实候选世界，57/57、exit 0，原身体路线/三角/断言逐字保留。另补两抱厦实际站立/跳跃和四柱阻挡检查 2/2、exit 0。三组结果分开记录，见 [验证报告](../final-validation/README.md)。

## 明确边界

没有 GPU/浏览器验收；此前受限路径未重试或绕过。没有 R50 人物验收。原始门、殿、匾尺寸多为既有模型拟合，本次只按官方照片层位/相对关系修正，不能称测绘还原。旧图/文字、导览标签和真实实物匾分别记录；敬思等导览标签不被计作真实匾复制通过。所有无目标照片、朝向未定和建筑根因未解项均保留待办，不增造牌来掩盖缺口。

主要官方证据：[永和宫](https://www.dpm.org.cn/explore/building/236518.html)、[重华宫](https://www.dpm.org.cn/explore/building/236506.html)、[坤宁宫](https://www.dpm.org.cn/explore/building/236487.html)。完整图片 URL、像素审查结论和 SHA 在 audit-sources/ 及台账中；URL 路径日期不当作照片拍摄日期。

交付插图使用高质量 JPEG 有损压缩以缩减上传体积。场景几何与相机构图未改，但像素/文件字节与原 PNG 不同；原 PNG 在本地留存，原图与交付图 hash 对照在 visual-encoding-provenance.json。独立审查中的原 PNG hash 仍保留，切面线图仍为 PNG。官方整图没有批量作为素材上传，只在两张必要挂位对比版中缩小展示并署名，完整证据优先引用官方链接。
