# R54 acceptance scope

This is a cumulative successor to R53, not a separate set of patches the user must assemble. Previous releases remain frozen. The local candidate is not a Pages deployment.

## Candidate changes

- Eight unnamed courtyard staff in Chuxiu, Yikun, Yongshou and Chengqian, using previously accepted maid/eunuch templates. All85 remain required. Exact staff counts, paths and times are interpretation, not historical or modern-exhibition staffing claims.
- Changchun east north-kang frame/curtain/plain rear fields, retaining its kang, west counterpart, central screens and room paths.
- Jiaotai source-bounded central display change, including only source-supported visible arrangement; unobserved seal contents and inventory are not reconstructed.
- Runtime character code and Kit unchanged from R53. Default-on, ordinary off, night guards, high64/low32/near2 and 128 synthetic registration capacity are retained. Formal acceptance remains separate and false.

## Required final checks

1. Exact original77 actor/binding/Kit records and prior coverage; eight explicit IDs, no demotion/count padding.
2. New190-source cumulative world provenance, original188 source manifest retained, changed/new paths explicitly bounded. R28 source bytes and any authorized runtime lower-screen extension are reported separately.
3. One actual current static/all-zone world: all85 current ready bindings, all13 paths, every ID individually submitted and visible through actual deformed-triangle rays. Ready alone is insufficient.
4. New8 real body/sole support, five two-cycle paths, stationary/turn/walk contact, high/low views, and analytic full-path pair clearance against all retained77 and one another, independent of phase. Repeat after real west/east unload, pending-job cancellation and reload.
5. Changed Changchun/Jiaotai actual collisions, legal player routes and map landings. No changed generic collision, teleport or below-floor rescue.
6. Genuine Yangxin GLB load/unload with existing InteriorLoader, all85 rebind and per-ID visibility in the changed world. Changchun/Jiaotai have no new GLB or invented S-layer acceptance.
7. Actual compiled production main wiring and root/subpath HTML/JS/manifest identity. Fresh source-fingerprinted root package and local no-cache response.

## Boundaries

CPU geometry/ray/instance/index checks do not establish GPU frame time, WebGL visual parity, texture/shadow appearance or physical-phone performance. Previous whole-repository suites were not green; they are not counted as newly passed. Historical source-freeze snapshots that intentionally pin earlier geometry/counts remain unchanged and are not relabeled green.

This checklist is a scope definition, not a pass certificate. Final README and report indexes give the actual results.
