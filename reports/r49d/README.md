# R49D 本仁殿：仅整牌/框的前后深度小修

2026-10-22。直接从冻结 R49B `95db2af664ff9cb6ea405d0ba389ef428dfd7d6c` 新建分支 `feat/r49d-benren-plaque-depth-20261022`。独立小修代码提交 `ad64a922a8e2885fb42e1a6c64806ba8646a3b8c`。

## 范围与结论

仅将本仁殿登记的牌面及其自己的完整框同步向外移动 **0.05 模型米**。保留原高度、尺寸、朝向、字样、材质、所有建筑三角、平台、门扇、柱、碰撞及导航。没有导入 R49C 景运屋顶或未接受的门头实验，没有人物改动。

修正的是实证穿梁：旧完整框穿入前彩画梁约 0.035 m，命中 3 个结构三角。新框背距梁前约 0.015 m，与全部其它结构三角相交为 0。5 cm 是旧模型下的可逆净空拟合，不是照片测量值。

**只关闭本仁穿梁及“牌在梁前”的深度关系，不代表本仁整殿实景验收。** 当前 Y、牌/完整框比例、门头竖向关系和实物固定件形制仍未验证；不因本次小修增加“整殿实景完成”计数。十二项未完成大项也未因此关闭。
