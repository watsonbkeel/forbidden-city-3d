# R99 局部真实几何 CPU 图

使用 scripts/r99-interface/export-visual.mjs 从冻结原基线 R98（运行等R96）与 R99 两处位置修正后的实际构造器导出，同一组 above/side/ground 相机；render-cpu.py 对真实三角做CPU z-buffer。三角共享gzip避免按相机重复存世界。before/after没有改变照明参数。

仅包含东北角墩、梵华、佛日、景福局部对象，不包含完整北/东墙、地表或人物；不是游戏截图/GPU/手机实测。全部为项目自生成诊断，无用户截图/官网照片。2.25m为工程拟合，0.34m不是新通道。上方局部图也不能证明历史建筑外连梯已完成。
