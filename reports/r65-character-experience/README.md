# R65 人物体验专项，累计至 R64

## 本版变化

- 保留 108 个逻辑人物、24 条路线、已确认 Kit、全部建筑/陈列/资源与此前 A–G 阶段成果。108 是逻辑总数，不是同时画面人数；高/低档上限仍为 64/32，复杂近景 2，低档官员 12。
- 增加玩家与人物双向阻挡。碰撞按站/坐/跪形态及真实垂直范围独立计算，不把人物注入建筑支承或飞行包络。玩家走、冲刺、跳跃、落下不能穿体；巡逻队遇玩家停止，在已有安全路线有限后退让路，远离后继续。不引入任意横向绕路或推人。
- 新就绪、质量切换、预算恢复、后台恢复若与玩家重叠，暂缓该角色的显示与实体激活，不删注册项。近处可阻挡角色同步进入可见候选；低档排除角色不留隐形碰撞。开关、离区、后台与释放会清理动态实体。
- 修复傍晚调度：原 `daylight > .12` 在北京 2026-10-23 的 17:24:48 附近把 90 个非守卫隐藏，剩 18 守卫仍有资格，并非 108 个记录消失。现在所有人物全天具备展示资格，仍受真实绑定、区域加载、距离与数量预算限制。这是全天游览演绎，不代表历史作息。
- 夜间增加平滑的虚拟月光与适量半球/补光，正午光照不变，不提高全局曝光。月光是游览辅助，不是天文月相模拟；最终夜间画面舒适度尚需浏览器与设备检查。
- 用户指定的原右下设置/来源按钮显示两行：`作者` 与 `陈华山&陈诺`。保持原点击打开设置、Esc、触控行为，研究说明仍在设置里，不作其它作者身份替换。

## 验证结果与证据

- 新专项集中 105/105；另新增注册实体 128 成功、129 原子拒绝的边界 1 项通过。该文件复验 8/8，不与集中结果重复计数：新唯一断言用例总计 106。
- 独立只读代码复核无新的阻断项；其轻量身体/相互阻挡复验 21/21。曾发现并修复擦边穿体、后退停滞、朝向与实际移动样本不一致、质量/后台恢复重叠，原红日志保留。
- `FINAL-WORLD-SUMMARY.json`：4 个独立完整世界，程序 B、真实养心 S、真实坤宁 S、真实皇极 S，均用相同运行源指纹和同一测试字节。每段重新绑定全部 108 人及 24 路线，S 段有真实配置 GLB 加载、淡入、返回 B/卸载与清理。不是一次浏览器会话中累计切换所有内景的验证。
- B 段实际检查 108 人的夜间变形三角可见性、接触、24 路线双周期与遇玩家停止/让行/恢复。S 段各有 108 个 S 与 108 个回 B 的逐角色观察；没有移动皇帝出殿或在现代展陈内新放人物。
- PC 控制覆盖 W/S/A/D、10/60 Hz、走/冲刺、真实鼠标方向、跳跃/落下、不同楼层、初始交叠逃离、镜头呼吸、直升机三视角与真实退出候选。三个内景有各自的加载与碰撞证据，不拿其它 S 代替。
- `RETAINED-INPUTS.json`：445 个运行文件与 R64 逐字节相同，包括人物/路线/Kit、全部建筑、区域数据、128 个 public 文件（31 GLB）、飞行模块、依赖与 Vite 配置。生产接线/共享碰撞确有本报告所列变化，不能据保留数据宣称所有运行代码未变。
- `PRODUCTION-VERIFICATION.json`：根路径与 `/forbidden-city-3d/` 实际编译身份一致性、各 132 内容文件的真实 HTTP 字节、全部 public/GLB 相同；可运行根路径包 134 文件，另带校验清单。包不是部署。

## 限制与原红

没有新的浏览器 WebGL、真实 GPU 或实体手机验收，也没有把 CPU 几何/逻辑测试冒充截图或帧率通过。没有重跑旧全库并宣称全绿。

保留同口径历史对照：R64 26 项中 25 过/1 原有 R34 源哈希守卫失败；R65 同 26 项 21 过/5 失败，其中共同旧守卫 1 项，新增失效预期为“不得新建灯光”1 项及原夜间隐藏行为 3 项。另原署名按钮标题断言 1 项因用户明确改文案不再适用。旧测试不删除、不篡改通过。

`FINAL-METRICS.json` 给出完整功能 CPU 统计。B 样本 p95 1.252 ms、最大 94.134 ms；养心最大 6.733 ms、坤宁 28.148 ms、皇极 7.449 ms。包含实际准备/提交，来自共享 QA 主机，不是隔离设备性能或 GPU 帧率，尾部尖峰仍需真机评估，不以平均值掩盖。完整世界 QA 峰值 RSS 约 1.10 GiB，不等于游戏浏览器内存结论。

夜间补光的实机色彩、帧尾、触控舒适度与长会话仍待人工验证。精确路径上的有限后退不是通用导航避让，用户持续占据狭道时人物会等候；不会强穿玩家。A–G 所有未闭合来源、工程与视觉项继续保留。
