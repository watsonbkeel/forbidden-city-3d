## Reproduction

Use a clean R51 checkout, with its node dependencies and the original frozen R50 oracle checkout available. `P3C_FROZEN_WORLD` may identify the frozen oracle if it is not `../r50-character-system`.

Run these heavyweight steps serially:

```sh
node scripts/p3c-r51-world-bindings.mjs
node scripts/p3c-r51-character-sightlines.mjs . reports/r51-unified/world-sightlines-r49e.json.gz
PROBE_COMMIT=$(git rev-parse HEAD) R49_INHERITED_WORLD_REPORT=reports/r51-unified/world-body-57.json node --test --test-concurrency=1 tests/r49b-inherited-world-body.test.mjs
node --test --test-concurrency=1 tests/r49b-canopy-player-clearance.test.mjs
```

The original body JSON was losslessly gzipped after capture. `world-joint-summary.json` links the exact artifacts and commands. Commit labels record HEAD at capture; actual source hashes and frozen Git blobs identify inputs. The lightweight budget test can consume the new exact world evidence with `R50_FRESH_BINDINGS=reports/r51-unified/world-bindings-38-148.json.gz`; it must not use the prior Benren inheritance path for this R49E world.
