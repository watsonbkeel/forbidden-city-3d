## 角度如何使用照片，而非按不相交倒选

侧照牌两边人工主边读数约为 `(805,575)→(835,603)` 和 `(847,573)→(869,600)`；相邻窗竖边在几十像素高度内仅横移约 0–3 px。长边像面 dx/dy 约 0.81–1.07，取边受雕饰和低分辨率影响，这不是统计区间。

同幅较直窗头向右略升、右山墙横梁向右略降。用局部弱透视、近零横滚、横纵等像素尺度及正交墙面作条件灵敏度分析：相机方位约 35°、视线略低于匾约 3.2°这一代表假设，可使上述斜率对应约 56–64°俯倾。因此采用 **60°作为可逆工程中心**；约 55–65°附近有照片相容性支撑，但不是测得的置信区间，也未排除 70°。40°在这一中等偏侧条件下支持较弱。没有拿旧模型尺寸当实物尺，也未从碰撞成功反向宣称照片证明 60°。

相机姿态/内参、完整雕饰、固定点、真实尺寸和绝对标高仍未标定。不同照片未保证同日同状态。模型敏感度探针与照片角度判断分开记录在 `pitch-probes.json`；这些探针不是多个已接受方案：在相同下缘/窗头前后拟合规则下，55°仍碰 2 个原檐底三角，60°与65°才未碰。因此不能把整段照片相容角范围称为均已通过物理检验；60°的图像理由来自独立的照片灵敏度，不用碰撞结果反证照片。
