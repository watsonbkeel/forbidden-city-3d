# R49 独立优先修正版

本版只处理用户报告的五类问题及同类巡查，不包含人物系统或新的内饰扩建。开发分支为 `feat/r49-reported-regressions-20261022`。此报告证明本地修复与限定范围检查，不证明 GitHub Pages 已更新。

## 修复内容

| 问题 | 根因与本版处理 | 明确保留的限制 |
|---|---|---|
| 太极殿、永和宫匾被挡 | 太极御座平移误选同金色匾框，改为四个御座组件的精确语义身份；永和通用牌穿入抱厦梁檩，改成梁下拟合挂位 | 不修改柱墙、屋顶或庭院间距来人为露出匾 |
| 东西六宫地图名字缺失 | 地图画布缩放同时改变字宽、标签层级和避让。改为屏幕像素绘字、宫名先于门名布局，并提示放大查看更多 | 300px 测试画布默认200%显示6宫；400%全部12宫，避免硬塞重叠文字 |
| 钦安殿不能进入 | 旧版主动封闭两侧面板；仅将两侧既有台阶相接的皮层拆成虚拟侧门，原路返回 | 门扇为模型通行拟合，非现状开放承诺；无北门、无新增祭祀陈设，原地面传送点保留 |
| 主敬、敬思牌被挡 | 后殿高牌进入连廊顶面；将完整牌面及自身框置于顶面以下 | 不扩大殿间距。主敬挂位有官方全景支持；敬思保留为模型名称标识，不冒称实景匾复原 |
| 乾清门缺牌 | 专用建模没有生成名称牌；按官方照片在后檐中央门头补“乾清門” | 仅有核实的汉字语义，不编造满文；不是外檐凭空增加横匾 |

同类实体穿插另修景祺阁、文渊阁、养心殿、重华宫。文渊真实中柱保留，养心及景祺只校正注册牌面与自身框相对于墙面的挂位，重华缩为梁下拟合牌。

有清晰官方图片依据的遗漏另补钦安殿、吉云楼、弘义阁、宝蕴楼。宝蕴只给原有浅石色、绿边框内加汉字，不另造金边牌。吉云按上层正面横额处理。

钦安详情卡与保真说明也同步说明虚拟侧门、原路返回及非现场开放许可；旧R48研究与实施记录作为历史保留。

## 证据边界与覆盖分母

- 77处命名 zone 厅殿逐一采用实际 TextureLibrary 构造并执行生产 finish。71个登记名牌覆盖70殿，另3个专用字面，共74个命名面覆盖73/77殿；景福的“五福五代堂”使同殿存在第二牌面。
- 尚无本版名称面的4处：体仁阁、延禧宫遗址、宝相楼、慈荫楼。体仁挂位仍缺已核实图像；延禧为未竣工遗址，不凭空补常规宫殿匾；宝相、慈荫文献证明有匾，但本轮资料未充分解决完整正面挂位，属于已知未补，不是声称原本没有。
- 门楼另外扫描74个命名 gate/cityGate：储秀门、长春门为已拆历史点；72个模型实体中71个有名称面。皇极门没有已核实挂位，不杜撰；神武门“故宫博物院”牌与完整双语门名牌不是同一物件。
- 122处厅殿物理差分：110处全部物理几何未变，121处导航未变；只有钦安殿改变通行。12处外观差异均在本轮修复名单，门楼另验。
- 71登记牌共639条射线，637条到达对应字面点，误差需小于1cm，不能只命中另一块同材质牌。畅音阁、咸若馆各保留一条极近仰视的自然檐口遮挡。其它建筑正常柱子或前殿的远处遮挡也不消除。
- 独立全场景接近检查覆盖主敬/敬思及四处同类牌；合法常规接近视线与局部可达路线另见 `independent-nameboard-review.md`，并不声称任意角度都无遮挡。
- 钦安16种方向/帧率/行走模式路线共5,736帧，对真实finish后三角面做全身体积检查。另有继承原台阶证据的全场景57项检查，56条路线变体共44,180帧、58,648个接受子步；这些是限定路线，不代表全宫全部行走路线验收。
- 没有真实GPU、浏览器鼠标锁定、真实手机或完整游览路线验收。官方照片用于事实和构图依据，所用可逆挂位尺寸均为模型拟合，不是测绘。
