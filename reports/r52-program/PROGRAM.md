# 故宫 3D：全项目逐栋滚动精修计划

规划基线：R51 `fac791cf956d852e32cc9594ce537b22bca82308`。

目标是持续逐栋精修整个已命名模型清单，而不是选两座建筑后结束。每批交付范围明确、能够单独检查的改进；不为尚无充分资料的全宫精度虚报最终日期。

## 一、范围与现状

- **89 个已命名模型建筑身份**：每栋分别跟踪内饰、外观、院落、材质与昼夜、游览体验。这不是故宫全部实体建筑的普查。
- **159 个地图地点**：其中83个对应上述建筑；其他76个为73个门/城门地点、乾东五所复合标签、御花园区域和九龙壁。159不能称为宫殿数。
- 恒寿斋、浮碧亭、澄瑞亭、万春亭、千秋亭、御景亭在89个建筑身份中，却不在159地点目录中。两个清单的并集也不能称为165座建筑。本计划不新增或改写地点目录。
- 内饰现状：71个专用但局部、14个通用占位、3个留白、1个共享亭模板。外观现状：86个专用但局部、3个通用占位。89个身份均未达到整栋完整验收。
- 保留已交付的建筑、牌匾和人物成果，尤其本仁匾厚度、文渊整匾俯角，以及人物默认开启和设置开关。未验收的景运门试验不纳入。

这里的“局部”不等于没有做，也不等于整栋完成。逐栋清单保留已有成果，下一批只处理确有证据且尚未完成的部分。

## 二、每栋持续推进的五条工作线

1. **内饰**：先明确现状或指定历史时期，再逐件核家具、隔断、梁顶与陈列。现代展柜和历史宫廷陈设不能混为一套原状。
2. **外观**：分别检查屋面、门窗、台基和柱网，不用通用模型或镜像复制替代本栋资料。
3. **院落**：核对院墙、门洞、台阶、甬路、树位及跨院连接，兼顾完整空间和实际通行。
4. **材质与昼夜**：以同机位、固定曝光区分石、木、墙、瓦、玻璃，先做局部对照，再推广。渲染参数始终标为拟合，不冒充文物材料测量。
5. **游览体验**：检查入口、内部或观览边界、返回及跨区路线，同时复查人物开关、昼夜变化、区块加载、触控和直升机退出。CPU、WebGL与实体手机证据分开记录。

## 四、首批具体范围

### A：武英、敬思四件器物的下一层细化

处理已定位的d111、d112、59、61四件器物，只新增原图支持的口、肩、耳、盖、足等局部。保留已经完成的d102、60细化，以及全部16柜的组织、位置和通路。

证据采用故宫官方2021开馆全景，并逐件保留来源。不能把2021记录说成2026逐件库存，也不能由模糊轮廓发明器名、藏品编号或背面纹样。

预计12–20专项工时。首四小时目标是可核的原图对照、可实施/留白边界和第一件候选，而非宣布两殿整体完成。

### B：武英南月台与院落接口

补充官方全景独立支持的南月台回折、东/西侧阶口和中央甬道。保留现有西山墙中段白石栏，不以未知全圈栏杆封住阶口或通路，不从左右对称推定未见细部。

预计10–18专项工时。首四小时目标是来源约束、候选边界和第一条有支撑的通路。树木遮挡下不能精读的阶数、柱距和尺度仍标为可逆模型拟合。

### C：连续路线、预算与后续实机验收准备

先检查午门至太和、协和至文华/主敬、熙和至武英/敬思，以及跨院返回的自动几何路线。记录受影响的实际几何、材质、纹理和资源释放情况，并建立固定昼、暮、夜机位及文华/武英材质来源对照。

CPU准备预计4–6专项工时。后续材料试点预计8–14工时，真实环境路线和手机检查预计6–10工时，均从相应条件具备时计算。当前真实WebGL、GPU帧时和实体手机验收仍有缺口，不能承诺首批全部通过，也不能用CPU画面或模拟触控替代。

这些数值是独立片段的工作量估计，不是全宫期限，也不是墙钟时间相加。每四小时给出可见成果、尚存缺口和下一片；已完成成果不必等待检查点才交付。

## 五、验收与证据边界

- 优先使用故宫博物院的具名文字、照片、全景和研究资料。来源链接存在，不等于它证明了整栋几何。
- 真实拍摄日期未知就保持未知；网页发布日期、服务器路径日期、历史时期、设计值、模型拟合和实测值分别记录。
- 不把“1单位等于1米”或模型与导航坐标一致称为全场景测绘级1:1。
- 每个改动片段需有前后差量、来源对应、实际测试和明确限制；片段完成不自动把整栋标为完整验收。
- 人物扩量单独记录数量与状态。建筑改动后重新检查所有受影响人物的表面、座位和路线，不以旧38人结果代替新世界或新数量的验证。
- 保留原有测试与原始报告。R51当前态测试有已记录的历史失败，新批次须区分旧失败与新增失败，不重写旧预期制造全绿。
- CPU离线图须明确标注；它不证明WebGL像素表现、GPU性能或实体手机体验。没有运行的平台测试保持“未验收”。
- 每批保留可回滚版本。只在必要检查后交付对应候选；本计划不要求修改或合并main，不改变账号权限或凭据。
