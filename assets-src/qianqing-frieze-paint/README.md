# Original five-dragon illustrative frieze

This sample follows only the visible five-dragon category and red/gold field of
https://img.dpm.org.cn/Uploads/Picture/dc/2568%5B1024%5D.jpg . The central dragon faces front;
two lateral dragons lie on each side. The official photo is undated and does
not supply dimensions. The associated scene reference is
https://img.dpm.org.cn/Uploads/Picture/dc/1523%5B1024%5D.jpg and building context is
https://www.dpm.org.cn/explore/building/236472.html .

The image is an original AI-assisted approximation. Dragon anatomy, posture,
clouds, shading, surface colors and wear are invented. No inscriptions or seals
have been guessed. It is not a photograph, tracing, conservation measurement or
artifact facsimile. The official image is reference-only, not a shipped texture.

The first generation produced seven heads and was rejected. A single correction
produced exactly five identifiable heads/bodies. The corrected original PNG is
archived unchanged; engineering resize/WebP encoding creates a1024x409 texture.
The original lower white canvas margin remains in the file, but a registered
source rectangle [0,0,1024,358] excludes it during drawImage. This changes only
private atlas cell2 [512,0,256,256]. All other atlas pixels, response textures,
meshes, lighting and collision stay unchanged. There is no additional GPU texture.

The retained model frieze is7.16x.85m, still an unregistered relative fit. The
art is horizontally fitted to it; the image does not validate this aspect ratio
or correct the outstanding structural registration. Near/oblique/reduced-size
visual review is required before accepting the sample.
