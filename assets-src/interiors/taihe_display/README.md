# Bounded Taihe display authoring

`approved/mesh_kernel.py`, `approved/taihe_display_pairs.py` and `approved/integration_geometry.py` are exact frozen R2 source copies. `approved/artifacts` retains the approved source manifest, final receipt and both JSON geometry exports. Source notes and historical implementation notes preserve the original uncertainty and rejected-predecessor context; their original status/path statements are historical provenance, not current execution requirements.

`blender_display.py` appends expanded flat faces into the original eight architectural material-batch frames without changing the shared authoring helpers. It does not render. `generate_fallback.py` creates the compact checked-in runtime module from the same pure source; no runtime fetch or external asset is needed.

All executable paths are repository-relative. The original standalone verifier and its absolute-workspace tests are not executable dependencies in this repository. The portable production-output guard is `tests/lib/taihe-display-geometry-guards.py`; its derivative changes are repository-root binding and recognition of the exact explicit gold/dark-gold DoubleSide assignments that replace the retired caisson tier calls. The material-side set remains unchanged and is also checked against actual fallback objects. See `docs/current-state/taihe-v17-display/INTEGRATION.md` for exact counts, approximation limits, CPU results, index-order nondeterminism and the blocked runtime gate.
