# 故宫 3D 虚拟游览 v1.0.0 发布说明

**发布日期**：2026-10-13　**标签**：`v1.0.0`（基于 `p2s-done`）

## 这一版有什么

- **全宫格局 1:1 复刻**：中轴线（午门 → 神武门）、东西六宫、外东路（文华殿、文渊阁、奉先殿、箭亭）、外西路（武英殿、慈宁宫、寿康宫等）、宁寿宫区，加上城墙、角楼、护城河。坐标按实测锚点校准，113 个锚点偏差全部在容差内。
- **6 座高保真内景**：太和殿、乾清宫、皇极殿、养心殿、坤宁宫、慈宁宫。走近自动加载，离开自动卸载；加载失败会回退到简化内景，不影响游览。
- **可进入的殿宇**：大多数殿宇、宫门可以走进去，台阶、台基按真实高度行走。
- **交互**：桌面 WASD + 鼠标；移动端虚拟摇杆；M 键小地图；左上角实时显示所在位置；Esc 设置菜单可切换画质。

## 已知限制（不影响游览）

1. 普通殿宇只有简化内景；zone 数据里的 A 档内景配置（`"interior": "A:..."`）尚未生效。
2. 太和殿、乾清宫宝座台上的陈设比例偏小；陈设在宝座台上，只能从台下观看。
3. 慈宁宫内景原状已不存，按文献推断复原，置信度低。
4. 文渊阁院南入口为临时开口，计划按史料补方池石桥。
5. 首次加载约 8~10 秒（贴图 10 MB）；移动端建议默认低画质。
6. 自动路线测试的已知问题登记表目前不生效（表为空，不影响本次结果）。
