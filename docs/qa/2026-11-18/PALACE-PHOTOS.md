# 跨区目检补记｜2026-11-18
在先前仅直接目检一幅太和门历史照片的基础上，现补充下列**实际打开并观察的馆方图像像素**。项目侧取自 8de5c83 实现、区域数据与原始名录的 FC 编号；所述关系都不等于同机位渲染配准。参考图片仅链接，不随报告分发。

|区域、对象与名录号|图中所见 → 对照与边界|
|---|---|
|外朝太和殿 FC-A478209231|[馆方正面照片](https://img.dpm.org.cn/Uploads/Picture/2020/04/17/s5e9926e6ea567.jpg)中轴对准石栏围出的中央上行路径，两边另有阶道；高台上是横向铺展的两层黄瓦屋面。项目 PalaceBuilder 的十一间重檐庑殿与共台、taiheFrontPorch 多阶组合支持总轮廓。不能用斜面透视量坡度、栏距，也不能由正面图验证背面。|
|中和殿 FC-5FAA15AE5C、保和殿 FC-58A3300503|[馆刊图版，印刷页028，右侧图3、4](https://www.dpm.org.cn/Uploads/File/pdf/6a/7c/bc/6a7cbcd5a792ef683777997c41083d88.pdf)：上幅见较小的独尖集中屋面和环台石栏，下幅是较宽的双檐横向殿体、中央长石阶。与 REAL 中 pavilion/1、xieshan/2 相容。积雪遮挡花纹，不核兽数。左图1、2分别是太和殿和乾清宫内景，不可混为同一室。|
|御花园堆秀山 FC-A1FFC2BC33、御景亭 FC-4D1D69857E|[纪中锐《御花园的堆秀山》，印刷页91图一](https://img.dpm.org.cn/Uploads/pdf/1603/T00091_00.pdf)：几乎没入树丛的高亭屋顶、参差透空的石堆，前下方有嵌入山体的拱口而非平地孤亭。项目 DuixiuMountain.js 把山体与山顶平台关联，位置在园内东北（负X、正Z），明确为照片约束下的工程拟合。树石轮廓、攀登步数及后方未逐处核实。|
|宁寿宫区皇极门 FC-ECB2C6B896、宁寿门 FC-1E971B3E74、皇极殿 FC-B607AA467B、宁寿宫 FC-E66DFE768F、九龙壁 FC-FF99BC5DC0|[学刊《乾隆太上皇宫寿宫营建考》图二，印刷页126右上](https://www.dpm.org.cn/Uploads/File/2019/12/15/u5df60cf540978.pdf)：实际读图，右图前路沿一轴串联，后路分成平行院落；左图是改建前历史图，不能互换。ningshou.json 的南北顺序为壁123、两门154.1/224、殿287.7、宫319.1。[实景下图，印刷页31](https://img.dpm.org.cn/Uploads/File/2021/08/24/u6124c80fa86f5.pdf)见九龙壁横长、彩釉纹带、黄瓦盖顶、灰基。模型有专用 nineDragonWall；未以远照确认每龙姿势、砖数或高度。|
|东六宫景仁宫 FC-6AF6DCFC02|[同刊图版，印刷页33左上](https://img.dpm.org.cn/Uploads/File/2021/08/24/u6124c80fa86f5.pdf)：一座浅灰、实心矩形影壁立于石座，两侧红墙和宫门构成背景。该图是**院内照壁**，绝非景仁宫正殿立面。项目 east-six.json 的正殿记录和 JingrenGateStoneFrame 均不能据此自动验收为这座影壁；影壁本体、定位和石纹未通过本轮比对。|
|西六宫储秀宫 FC-B0A68A4270|[馆方正面照片](https://img.dpm.org.cn/Uploads/Picture/2020/04/17/s5e99869751add.jpg)可见较低的横向黄瓦顶、红柱和密格门窗，台前深色动物造像与浅色方座成对配置；前景树木遮挡左右端部。模型 west-six.json 使用专设 chuxiu-household，ChuxiuFrontEnsemble 标注为立面组合拟合。只支持从整面尺度、门窗节奏开展比对，不据此确认铜像数量、画面之外的后院和家具。|
|城垣角楼 FC-E8C2F3E267；城墙对象 FC-95FE4AAEE9|[馆方角楼与水面照片](https://img.dpm.org.cn/Uploads/Picture/2020/04/20/s5e9d3ef250ba9.jpg)：角楼多层屋面坐于转角处，灰色城墙向两侧延伸，墙外还有窄岸再到水面；不是红色宫墙直接泡在水中。项目 Enclosure 独立墙身取 wall_brick，设角楼与外侧水带。只核关系，不把单一透视视角推广到四个城角，不由此测宽。972/961米差异、南部通道仍在。|
|外西路大佛堂 FC-6CAE88B6A2|[馆方外景原图](https://img.dpm.org.cn/Uploads/Picture/dc/8035.jpg)树冠明显遮蔽屋顶，仍见前沿黄瓦、连续红色开间与低阶。项目 outer-west.json 把大佛堂放在慈宁宫之后。外照不支持认定神像。[馆藏研究，印刷页308图26、27](https://img.dpm.org.cn/Uploads/File/2020/02/26/u5e56176b64d88.pdf)：本轮目检的是两尊**分别题注**的历史黑白坐像，不能拼作大佛堂三尊同机位全景。档案图、历史陈设、当前展陈和私有预览是不同对象；未认可任何新造像、纹理或八层莲座上线。|

以上为有对象编号的限定字段复核，不是覆盖全宫的逐项实景验收。宁寿宫分区平面图是本轮直接观察的地图；全宫导览仅作索引，没有以地图像素量取几何。
