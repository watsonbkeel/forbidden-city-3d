# R379 开发分支核查｜不建议直接合并发布

基线为 `8de5c83d25a669a014575a1489429f064a464496`。本次没有修改 main 或部署 Pages。本页区分代码检查、模型对照与设备验收。通过其中一项不代表其他项通过。

## 本分支改了什么

1. 小地图原先将南北方向乘以 0.82，等长的东西、南北两段在截图坐标中会变为约 200 和 164 像素。已取消这项压缩；步行/飞行制图范围都使用同一米制比例，屏幕仍独立裁切、滚动与缩放。没有缩放整个三维宫城或搬动建筑。
2. 中和殿和保和殿的公开布局元数据已分别改为单檐攒尖、重檐歇山。真正建模时原本即使用正确的专有配置，因此不是“重建了两座屋顶”。
3. 三佛只在显式 `?triad=texture-first` 下使用本地试玩版本的三幅原创画；[版本身份与回退](TRIAD.md)。默认入殿不替换旧像。原图、浅浮雕几何缓冲区与试玩包逐字节核对，非完整圆雕。
4. [397 项独立维护目录](../../../data/architecture/ledger-397/README.md)保留原编号、固定出处、所属院落、候选位置、未证实的字段和分项验收。独立文件按稳定 ID 命名。对全部条目校验名称、ID、原文、现存模型指针和工程坐标，不以复用模型或目录卡片替代物理实体。
5. 入场测试夹具改用真实合并、材质和构造时的碰撞所有者；保留原行为断言，修复错误的资源释放方式。新增回归覆盖地图、屋顶、登记项和三佛。

## 建筑与地形证据

[馆方资料与地形参数对照](PALACE-PLAN.md) · [跨区官方平面图／照片实际目检](PALACE-PHOTOS.md) · [397 项覆盖统计](coverage.json)。工程坐标系以太和殿为原点，+Z 北、−X 东。154 项有同名布局/分区的位置或范围，238 项有源码稳定 ID，159 项有同名目录卡；三组重叠。43 项的旧位置指针指向无名或异名声明，79 项既无同名模型声明也无源码 ID 字面命中；不能由此断言模型缺失，更不能据此签收。

模型端点算得宫城南北 972 米；馆方总览列 961 米但未给测量端点。两种口径相差 11 米，不能据此认定北墙实测错位 11 米。北墙牵连城角支座、北侧房舍、门洞、道路和碰撞；护城河南边 200 米干通道也是游戏拟合，不是考证所得的桥。照壁不等于同院正殿；档案图不是当前开放或展陈证明。

## 合并前还缺什么

- 在具备项目内存门禁的环境里，从正式游戏入口做桌面与触屏浏览器复测：午门起步、小地图缩放与点选、大佛堂逐尊可见性，切换区域后再返回。此环境在 Chromium 启动前被项目门禁阻止；未绕过。没有当前整宫 GPU 截图、手机帧率或点击路线的实测证明。
- 保留并区分 325 项继承失败（冻结历史源码指纹、夹具及行为断言等），不是“一律过时”。R379 特有校验也未全绿，不能删除断言或更换冻结哈希来宣称通过。
- 要签收“全宫复原”，仍须按 397 个独立对象逐项核实实体、同一构件的视角、年代和尺寸基准。图像抽核不是 397 座的多角度目检，更不是测绘级 1:1。

回退：这个开发分支不需要更改 main；基线 SHA 仍可检出。测试、项目文档和登记表可独立评阅。
