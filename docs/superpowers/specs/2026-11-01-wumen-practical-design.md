# 午门五项实用版设计

用户当前目标：R157 37项24小时内按视觉接近、正常通行优先推进；≤0.3m且不影响通行不修。该组覆盖午门、东/西雁翅、钟鼓亭、四角方亭5原ID。保留旧精细复原账，不虚称测绘或展厅复原。

采用既有来源配准的整组可见候选：四亭约19m外轴、南北中心间距约84m、两翼13跨、完整U台及双折返马道。主楼与五门图元保留，北洞口随新台北边统一迁移。旧主楼-link约0.175m缝与不影响通行的Float32残差不修。

方案比较：只拉屋顶会使柱/台/物理不同步，拒绝；继续精确owner/provider工程会挤占24h实用交付，拒绝；选用对象专属生产组装模块及现有CollisionManager普通有限box/ramp，复用经过复核的可见几何算法。不得导入scripts/tests到生产；不加依赖、不改共享控制器。

当前实际午门＋Enclosure默认CM实验64路线组合均到达；2下坡组合有各1帧逻辑体接触，爬坡相机平滑脚下滞后最大0.287m，不能写零穿。真正全World/实际贴图/GPU另验。

物理：仅替换本次buildWumen新增的colliders/walkables区间；保主楼原碰撞，平台采用真实187有限顶面与12坡，无旧整floor或receiver试块。新闭亭/翼、柱、横连采用可见实体相应有限体，未知内饰不造。空间身份保持旧world anchor −419.6，不混入未集成的新全城坐标。

共享接线由集成者持有：buildWumen入口记录两个起始索引，在旧组装完成后调用一个专属installer；其他分支不改。新增对象化模块、目标tests、source/acceptance记录由本分支持有。
