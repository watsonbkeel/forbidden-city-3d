# R162 四座既有街门的照片正向门簪局部

用户已授权连续推进原397项十版计划，有根据的工程拟合须内部明示，0.3m内不碍通行的误差无需纠结；未知不可凭空造。前端只用正式名称，不暴露开发备注。main由用户合并，不自行部署。

本项属于R162/G29的4个已有通用门：琼苑东门/西门（items26/27）、长康左门/右门（30/31）。联合策展《华彩故宫》目录把各自带清楚匾名的本体照片逐项映射。每门所见前额均有4枚凸出门簪，红面、金黄边；琼苑高清图可辨六角，长康轮廓按粗六棱工程拟合，不宣精确角数。原始照片只本地研究，不入仓库/runtime。

## 方案与决定
- 不新增整门或重造通用门体：原位置、转角、开口、屋顶、台座、匾额、地图和物理流都保留，只新增这4枚真实薄实体装饰。完整立面/琉璃花饰/精细雕刻留账。
- 不双面镜像猜补：琼苑照片语境为园内看街，拟用各自local+Z，作为语境推断而非实测方位。长康摄向经反证未定，照片特征仅迁用至既有前额local−Z，内部明确PHOTO_FRONT_TRANSFER和CARDINAL_FACE_UNKNOWN，不称北/南立面。
- 整门重建会无据扩大尺寸、隐藏面及通路变化；因未知面而完全停止会放弃已有本体照片明确支持的可逆局部。选择上述最窄内部标明工程迁用，保留低成本独立回滚。

## 实施边界
独立`GardenStreetGatePins.js`仅认garden精确4项及其默认wall gate宿主。原生几何/材质/变换、colliders、walkables、rooms、map/regions/牌匾流逐项保全；新增几何高于门洞，非低身碰撞修改，不声称修复旧高层墙体碰撞。采用局部X[-1.5,-.5,.5,1.5]、Y4.70、半径≤.14m、外凸≤.22m的工程尺寸；不得与原牌匾相交。错对象无操作、宿主漂移在突变前拒绝、重复不可叠加，资源正常finish/dispose。仅内部metadata加入sourceObjectId、范围和不确定性，wholeObjectAccepted:false。

独立作者先测试红绿、模块、资源/字节保护与CPU图；集成者后加正常唯一hook，去注入地核实际World旧路/物理流与4项正常记录、独立审查、干净生产构建、远端完整回读。历史全套失败、GPU/手机/全流式及整项验收缺口保留。局部门簪绝不关闭R162/G29。
