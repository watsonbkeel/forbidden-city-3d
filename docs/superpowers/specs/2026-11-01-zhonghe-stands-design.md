# 中和殿两件前置陈设的限定候选

父任务已明确选择：基于5b83065f独立实现两件错误巨大通用鼎→本体官图可辨细腿陈设，保护主要通行及既有座屏，不猜雕刻，组件/定向检查后交独立Astra，最终只由整合人发布。本实施为detached worktree，不改共享树或main/远端branch。

唯一采用的路线是专属可见轮廓替换，而不是缩小旧巨鼎（仍错型）或全面补齐内景陈设（超出单图证据与本轮范围）。官方1569图已亲看：两件目标细腿、浅托盘与上方小型陈设；其准确器名、年代、腿数、尺寸及反面不确知，不能借其他殿器物补纹样。

工程选择：原中心不动；原1.2×1.2×2m碰撞包络内作低细节比例拟合，细腿、浅圆台和小件保持真实通空。三根素弯腿是小候选的稳定支承拟合，不称原物腿数。小件只有朴素几何体量，不添加火焰、龙凤、铭文或不可见器具。逐闭合可见件精确triangleSupport，不留旧整盒穿过空气，不增救援walkables。低平台、椅屏、四门、四柱/外廊和其它殿均不改。

验证：先记录5b原殿非目标几何/碰撞/support；红测目标API及细腿空隙→组件；逐件几何/碰撞/合批/dispose；原真实四门路线10/60Hz、走跑/后退/斜向与低台路线；CPU同机位新旧只作形体诊断。全局构建与审查仍由整合负责人安排。
