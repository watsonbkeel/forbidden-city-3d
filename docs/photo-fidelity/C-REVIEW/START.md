## First actual comparison

The official Wuying south-gate image has two outer windows with diamond lattice.
The frozen local gate instead has two solid red end walls. The first experimental
window patch preserves those walls' old mid-depth placement. It passes six
geometry/retention tests but **fails visibility**: only 2 of the eight field
centres are visible from the frontal probe. Columns/dividers hide the others.
`reports/r60-c-stage/windows-01/` is therefore a rejected positioning prototype,
not a completed correction or acceptance. The red probe is retained.

Next correction is bounded to these two walls and their two exact collision
boxes, bringing them behind the south front columns. Portal bodies, six original
ramps, columns, roof, plaque and other gate remain unchanged. Exact depth is a
reversible photo-constrained fit, not a surveyed dimension. The obscured lower
wall is not reconstructed as a guessed pale skirt. A separate south railing
scope follows the three existing stair gaps; no unverified sculptural heads.

The Yude interior has real hollow masonry, pointed opening, squinches and open
oculus; only the observed dome brick courses are currently missing. Its rear
visitor access stays closed. The Hengshou paper's Fig.13 shows a separate
under-purlin swallowtail block but does not identify which gable, so placement
is not inferred by copying it to every end. Fig.14 is a different building.

All images here are actual model CPU previews, not GPU/browser acceptance.
Reference photo/PDF bytes are kept outside this repository. Official links and
hashes may be published. Interior inventory dates remain separate from current
visitor access. All 108 characters and 24 routes retain their prior data.

## Corrected window positioning checkpoint

`windows-02` moves each existing end wall and its exact unique proxy by -8.4 m
in local Z, leaving its front face 0.25 m behind the south column axes. This is
an explicitly fitted depth, not a measured facade location. All eight field
centres now hit actual window geometry from the same frontal probe (previously
only two did). Seven dedicated checks pass, including exact inverse-delta
retention, proxy bounds, negative identities/geometries/proxies, real merging
and resource disposal. Twelve inherited gate/bridge/window/plaque checks passed
on the same production source; their combined run retained one QA observation
failure at y=7.1 where the retained front beam correctly hides the moved wall.
The final wall-margin probe is y=6.72, below that beam, while the independent
all-eight-field visibility assertion is unchanged. The raw failed logs remain.

This does not correct the inherited uniform bay grid, stair proportions, open
walk-through door pose, or full roof/caihua detailing. The photograph's projected
bay widths are not used as a metric survey. The added coarse diamond lattice
uses fitted spacing, not an asserted exact repeat count. Total local gate cost
is 4,994 triangles versus 2,702 before, +2 private materials, no new textures.
The two facade proxies move; all supports, portals, steps and other navigation
remain byte-equivalent under the recorded two-box inverse transform.
