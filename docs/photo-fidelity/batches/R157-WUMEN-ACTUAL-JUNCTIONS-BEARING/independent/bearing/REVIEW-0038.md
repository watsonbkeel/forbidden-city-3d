## 3. 精确足迹减并集

作者按所有实际矩形边界划分单元，对未被矩形完整包含的单元裁剪凸足迹；面积在局部平移基准下计算，不以远原点大数相减，不加 epsilon。

独立 Python `Fraction` 从 JSON 中每个 binary64 数的**精确二进制有理数**出发，重新：

1. 验证 187 实际双三角和矩形分割；
2. 对 180 足迹建立精确坐标分区；
3. 用精确有理数中点判断并集，再作精确半平面 clipping 与面积求和（有理数中点不会发生浮点贴边舍入）；
4. 与作者每个足迹结果逐项比较。

结果：

| 项目 | 独立结果 |
|---|---:|
| 足迹 / 实际台面片 | 180 / 187 |
| 严格正缺口 | 16 |
| 主楼 / 外围翼柱 / 横连 | 8 / 4 / 4 |
| 超过 `1e-8㎡` | 6 |
| 最大正缺口面积 | `4.557104996895375e-8㎡` |
| 作者浮点面积与精确结果最大绝对差 | `1.6212740006039342e-22㎡` |
| 正/零分类差异 | 0 |

因此这些正缺口**不是 polygon area 抵消噪声**。典型未覆盖单元窄边：横连约 `1.067357349171516e-7m`，翼柱约 `2.2776077912567416e-8m`，主楼约 `9.536743306171047e-8m`。面积来自足迹与该窄条的真实交集，不能直接拿矩形全长乘窄宽替代。

这里的“精确”只针对已经存储的实际几何坐标，不意味着历史测绘、曲面连续体、材料变形或现实建造精度。历史 188 柱的 34 正缺口 / 20 阈值项 / 330 边账仍属另一对象集合，不能机械继承为本轮分母或期望值。

## 4. Y 误差单独分账

全部 187 实际 slab 顶 Y = `12.300000005960465`（12.15 平移 + Float32 0.15）。实际柱底：

| 类别 | 根数 | 实际底 Y |
|---|---:|---:|
| 主楼 | 52 | 12.300000029429995 |
| 四亭外围 | 56 | 12.300000047683717 |
| 两翼外围 | 48 | 12.300000104904175 |
| 两横连 | 24 | 12.300000047683715 |

逐实际矩阵与 Float32 半高可复现；**全部柱底略高于 slab**，垂直残差范围约 `+2.3469530319175647e-8` 至 `+9.894371011398562e-8m`。这与水平窄缝是两项不同事实，不能用光线命中或名义 Y=12.3 合并成精确接触。

独立实变 slab 下移 .01m，extractor 如实记录新 Y、XZ 不变；删去两顶面会拒绝，不产生名义支承。没有补面、改脚高、吸附或容差扩张。几何微误差可归因于独立 Float32 半尺寸加双精度平移；是否后续以统一共享顶点修正，需要另立可见几何及物理合同，不能在本轮诊断中悄补。

## 5. 一 ULP 与其他负控

作者真实首红 `ulp-red.tap` 是面积 `0` 对预期 `Number.EPSILON` 的数学断言红。旧浮点分区中点在 `[1.5,1.5+EPS]` 会舍入为 1.5，被误判属于左侧已覆盖矩形。终版用分区**完整端点包含**，返回 `2.220446049250313e-16㎡`。

独立确认该精确算术，并以最终 helper SHA 锁定 loader 仅恢复旧 midpoint 判定，选这一条测试：**1 项真实 `ERR_ASSERTION` 红，actual 0 / expected EPS**；不是加载失败。见 `midpoint-regression.tap` 与 `negative-audit.json`。

重要口径：这一项是 **binary64 纯 footprint 算法的一 ULP 合成负控**，不是声称实际 Float32 网格中生成了 EPS 宽建筑缝。真实模型微缝另由原顶点和 Fraction 全量复算确认。

独立负控启动过程另有两项未接受故障：首轮外置 loader 路径写错，随后 nextLoad 链重复变换触发 SHA mismatch；均保存原日志，不算数学负控。最终采用每次读取已锁原文件并 shortCircuit 的 loader，才得到上述有效断言红。

现 8 项还保留缺一上三角、隐藏、倾斜、全缺支承、重叠矩形、稀疏/非有限/非凸/溢出输入、柱实际移位 200m 等范围。缺 module 的初始文件失败、`actual-red` 缺 export 和后续真正断言红均按原日志分别记账，不能混算为八项全部执行红。
