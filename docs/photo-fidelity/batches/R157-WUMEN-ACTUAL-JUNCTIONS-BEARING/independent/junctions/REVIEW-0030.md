## 全分母和独立第二算法

九个显式实体：主楼、四亭、两翼、两横连；合计 521 mesh、36,172 实际绘制三角。平台和八个非柱 LineSegments 标记不属于上层八对三角诊断。主楼保留 84 个退化三角，它们未从原分母删除。

独立 Python 从完整原 NDJSON 重新计算每个三角的三顶点 AABB，验证三角 ID 唯一、原始坐标/矩阵导出结果与逐对引用一致，并以分块笛卡尔比较重新枚举所有严格不分离的 AABB。集合不是只比数量：**7,348 个候选 pair 的两端 ID 集合逐项相等**。

| 分账 | 数量 |
|---|---:|
| 八对完整笛卡尔分母 | 63,912,112 |
| 严格 AABB 分离 | 63,904,764 |
| 进入窄相并保存完整参数 | 7,348 |
| 稳定穿交 | 1,820 |
| 候选中稳定分离 | 5,403 |
| 数值边界未决 | 125 |

`63,904,764 + 7,348 = 63,912,112`，`1,820 + 5,403 + 125 = 7,348`。原主楼退化三角对每个 link 产生 `84 × 812 = 68,208` 交叉统计；两侧 136,416 不能再加入上述互斥分区。

作者窄相保留 Three ray 原 bool、独立 segment-plane/barycentric 原值与分类，1e-10 为无量纲参数边界、64*EPS 为相对分母诊断界，不是米制“可接触”容差。独立复核另写 **三角与另一平面的截线区间** 算法，不调用作者分类器、Three Ray 或原 barycentric 路径：1,820 穿交及 5,403 分离全部一致；125 对仍原样保留未决，不因第二次运算推定通过。

共面裁剪的面积/线/点、反向 winding、退化/非有限输入有单位测试；本轮实际 7,348 对中没有把共面正面积诊断当承托。旧退化面也不是被自动修补。

## 主楼—横连距离：全局下界与实际见证

两主楼—link 对分别有 **13,498,688** 三角组合，全部实际三角 AABB 严格分离，无窄相接触候选。作者对所有组合施加 AABB 距离下界剪枝，保留真实 vertex-triangle / edge-edge 最短见证，不把实体中心距或单一 bbox 缝当最短距离。

独立对全部实际三角对重新计算 AABB 平方距离下界，两侧最小均为：

`0.030624870658057902 m²`

它恰等于实际见证点平方距离，对应：

`0.1749996304512038 m`

东侧原见证的主楼点在实际三角内部、横连点是原三角顶点。西侧原最近点求解有约 2e-16 的重心舍入；独立改用**同一原 link 三角的另一既存顶点**和主楼平面投影，不改几何，得严格非负二进制有理数重心坐标及同一距离。以存储坐标作为精确二进制数，两侧距离为 `24629008452813 / 140737488355328`。详见 `exact-witness.json`。

这比仅复跑作者最近点函数更强，但仍限定当前记录几何及数值下界复算；不是现场测量，也不把整个算法升级为通用认证区间。**应报告约 17.5 cm 实际面间隔，不能写“主楼与横连已接通”。**
