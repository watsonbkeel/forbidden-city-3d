北口±48位于条件46–50族；x内翼±40.6给横段中心长7.4。侧z=-16.5、净宽3.8，其北边=-14.6，与主台南面-13.3相距1.3；北向中心段35.1。都相容最小L连通，不跨到南正立面造第四/第五口。端部外余墙60-(48+1.9)=10.1，几何上足够，不要求扩大台体。

2. 旧门叶按旧width布置且注册包围盒。旧门叶/门体碰撞必须一起去除并重新匹配，避免新空口留旧叶、旧head、不可见堵墙。侧口门扇开闭是另一个未核实状态，不可靠整块翼台阻塞伪装关门。
3. L形相交空域要贯通；主台南界与翼台北界共面处易残留端盖/基座带。真实网格射线应穿过横段、折角、主翼接缝、北头，且邻近实体负例仍封闭。不要只用metadata中心线测试。
4. 全高墙碰撞是正确方向；三角体需与渲染实体同坐标变换/同面，不能把弧头包围盒当实心，也不能只注册上表面导致下方穿透。急转角测试需要实际身体半径/高速多段，不能仅点射线。
5. 对洞顶与12m台顶分别测向上碰头、向下落地，保持台顶/马道支承；不可在洞下无实体处造12m“楼板”落地支承。边界y等值须测，防旧3m墙代理残留。
6. 测试五口是五个独立连通口，而不是同一外部空域误数；南三口、侧二口各有法向与所在墙面断言。既有三路线按新轴迁移并保留旧失败日志。
