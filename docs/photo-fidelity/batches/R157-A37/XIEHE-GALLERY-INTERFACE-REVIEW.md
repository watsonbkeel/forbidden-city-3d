# 协和门—南北庑房整项接口审查（未实施）

关联原清单三项：FC-9E59B14A3C协和门、FC-3489F3B25A南庑房、FC-2D6DB6F0EC北庑房。不是新增范围，不扩分母。

## 已证明的模型缺口
- axis-courts/items26、27分别是南北相邻庑房：平面长101m、63.9m；前版仅将端点裁到协和门宽/2+.6m。
- CourtKit.corridor固定ph=.45m；协和门平台ph=2.62m。端点平面接齐不等于真实高程相连。
- SideGate把门台当独立矩形，在local x=±14.2、z=-6..6各放一条完整侧栏；这两条的存在没有本体图独立支持。
- 自身7-f/b以及6/8视点可见庑廊/外台面延续到门两侧。不能将未经证实的完整横栏仅换上精细外观，更不能删除物理栏而留下2.17m断差冒称连通。
- 自身0-f/b/l和7-f/b/r共同显示东西两面檐下廊地高于外平台的一次低台沿；黑双条与黄警示条位于同一踏面，不是多级阶梯。原模型把两面内外皆设同高也未闭合。

## 必须联合核验后才能实施
1. 官文两侧各11间与另13间记载的来源、期别/计数对象；当前101/63.9m通用廊长度是否对应同一原对象。
2. 庑房的前廊/房体、与门侧接头、平台外缘及四条return终点；两条旧整侧栏是否存在、哪些段应归庑廊。
3. 2.62m测量完成面、厅内外单台沿相对高差、庑廊地面、慢道顶与栏脚的关联高程。
4. 整条庑廊的柱门窗、屋面和未见内景，不能仅抬高通用廊就称完成。
5. 以真实支承和全程往返验证门—两庑—慢道，不用救援面或传送消化断差。

## 当前处置
不执行剩余8段栏组整组换型；不抬廊、缩河、变更台基高程或删除侧栏碰撞。已独立验证的西厅两端间候选不包含这些调整。继续获取已知公开全景组4/5/6/8完整源面以定位连接；新视点比例不当米制测绘。整项仍0/37。

## 后续完整近景明确的拓扑（2026-10-30）
补齐6/8视点六向后，6-r与8-r分别显示门端低台沿转折/结束、庑房檐柱站在较低的相邻面。6-b/8-f沿庑前廊向远端通畅；6-l/8-l真正白石转角在外平台/慢道边，不是建筑端墙跨全进深的横栏。因此现两条全深侧栏不只是证据缺失，而与可见接口冲突。**外平台连续不等于门内与庑内同高**；不能用整廊抬至2.62m代替真实低级差。
