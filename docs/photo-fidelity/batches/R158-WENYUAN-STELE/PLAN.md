# 文渊阁碑亭：有限工程拟合计划

## 依据与目标
原41项 FC-F23B7824D4。基线 acc36（本地 d1c66 同树）无对应模型。故宫文渊阁官文236513记阁东黄瓦盔顶碑亭、碑一通；官刊011页第8图已本人查看，可见灰石脚、红围护、南门、四角上翘的盔顶与宝顶。不是空敞四柱亭。原照片/PDF留本地，不随代码上传。

## 方案与约束
采用独立小实体模块+ZoneBase一次调用，不改阁、桥、水域、院墙/数据、全局控制器。拟中心(-212.5,-132.8)、身宽约6m、檐宽不超8.5m；尺寸/坐标/内部碑尺度是工程拟合，不是测绘。已在真实基线World核8.5m方形、y.02..10的预留0旧collider、身位网格无水/阻挡。z=-145为原水池，不能从池面径直引路；沿原桥北岸进入亭前。

不采用通用开放亭（不符实墙图）；不增加猜测碑文、雕龙精细纹样或无图北侧门。碑面仅素面，说明身份与文字来源而非伪造可读碑刻。
