# Wumen joint wings / platform / ascent / south-wall candidate

## Intent and decision
Parent approved a bounded candidate using source plan topology and explicitly engineering-fitted heights, before any production hook. The purpose is to correct the major joint footprint error, not add another ornamental patch or declare Wumen complete.

## Approaches
1. Move only WUMEN_Z / enlarge pavilions: rejected; silently disables anchor-guarded refinements and breaks physical wall/ascent/route contacts.
2. Keep origin and stretch wings alone: rejected; perpetuates the whole-U bbox mistake and apparent Que-gate/boundary conflict.
3. Joint, isolated candidate: selected. Register the actual main wood part, both differently traced source sides, four upper pavilions and long wings; reconstruct real visible supporting surfaces and folded ascents together with the southern wall interface. Verify before considering a production hook.

## Architecture and phase boundary
A new plain-data candidate profile and validator live under scripts/photo-fidelity/batches/wumen-joint-layout (not imported by src). The profile distinguishes SOURCE_COORDINATE, NOMINAL_REGISTRATION, ENGINEERING_FIT and UNKNOWN for each group. It supplies one geometry contract for later actual candidate solids and actual collider/support generation, not separate invisible route floors.

First deliverable: source-registered profile plus failing-then-passing validation tests. It MUST fail validation if an unresolved field is promoted to measured, a source wall bbox becomes a constant-Z wall, Que anchors are changed, an ascent contact has a gap, or a route is claimed accepted without real support/physical evidence. Initial profile may be structurally valid but routeAcceptance=false; this is not completion.

Second deliverable (separate gate): candidate closed solids, visible top faces and collision providers sharing authored vertices; separate south wall/side-wall/corner seams; lower five openings preserved in topology but individually registered; actual raw controller route tests. No production connection until source/geometry/physics review and cumulative gates.

## Acceptance gates
1. Reproducible source/pixel registration and tag uncertainty; exact current production capture/rollback.
2. Actual closed geometry, finite normals/UV, no orphan columns / unsupported pavilion floor, no hidden filling. Both source sides separately checked.
3. Real support contacts, seam clearance and body sweep through each folded ascent/neck and all five lower routes; walk/run10/60Hz and edge/drop/jump negative probes. A source-common node alone is not contact evidence.
4. Same-camera complete-face A/B, honest CPU-only labels; independent review.
5. Only after those gates: proposed production hook, non-target preservation, full/batch/3base and backup. Inherited213 full failures,10 missing-history failures/38 unexecuted remain disclosed.

## Non-goals
No whole-object completion, GPU acceptance, historical high-column reconstruction, unobserved carvings/door leaves, hidden-vault dimensions, or public release.
