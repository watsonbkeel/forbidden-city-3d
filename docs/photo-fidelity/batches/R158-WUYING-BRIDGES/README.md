三桥各自六面均显示：栏下有连续低石基座，南北卷云端板下有向端头伸出的浅石足。R157 已有的花口、单中鼓腹短承、浅框、尖叶瓣柱帽和卷云形状不重做；其 **23,352 个源三角形状逐个保留，仅整套栏杆实体向上平移 0.10m 坐于新石座**。现版严格验证 `Float32(oldY+0.10)`，不再声称旧绝对坐标不变。新增六条低基座、十二端足，共 126 个闭合浅实体 / 3,480 三角，拼入原有 126 个三角接触 owner，不加悬空 walkable、不加 broadphase 代替真实接触面。

## 尺寸与安全边界

高度 0.10m、栏格宽 0.23m、柱心基座局部宽 0.32m（接缝回到 0.29m）、干岸端足宽 0.40m、端距桥心 9.04m 是**保守照片拟合，不是测绘**。原柱/栏格离散数和基座分段数也不是石材块数验收。完整图能辨类型与连续性，但不能据透视像素宣称精确横断面。

曾试将湿跨段统一拟为 0.40m 宽，真实竖直扫掠发现：身体半宽 0.5m 会挂在低外唇，圆脚支承半径 0.3m 不落脚，旧水界会阻止退出。该形状已撤销，不通过放宽水界或补救援地板掩盖。当前湿跨基座投影在原扶手/柱冠实体之下；逐顶点向上射线与故意恢复宽原型的红测均验证此约束。独审随后发现原柱与新基座侧面同面/内埋，已保留红例并整体升栏 0.10m：柱座使用水平实座承柱，低肩独立露出；60 柱在四个低高度的实际第一可见表面与不同实体表面分离验证通过。只有已在干岸的端足保留明显外展。原栏顶向内恢复函数体原字节保留（仅改私有函数名）；单独的尖冠权限与残余上升防护接入真实控件后通过轻量负控，最终 CPU 完整 World 结果见末节；不通过放宽共享水界掩盖问题。

- 真实非圆脚支承的尖冠 body-impact、静止有限竖速、当帧原始 `targetForward/targetRight`（不是残留平滑速度）、显式 jump 输入缺一不可。
