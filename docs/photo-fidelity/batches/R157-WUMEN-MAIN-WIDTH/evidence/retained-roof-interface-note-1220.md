# Retained roof interface — read-only check

PalaceBuilder builds the same Wumen roof from retained dm.width/depth and body.topY. RoofBuilder.addBrackets uses a continuous prism band, not separate column-axis-specific brackets. This change does not leave discrete old equal-axis bracket meshes behind, but neither the continuous textured band nor existing roof is a full timber-frame reconstruction. Through-columns, real bracket ownership and upper structural joinery remain unverified; no roof production bytes changed.
