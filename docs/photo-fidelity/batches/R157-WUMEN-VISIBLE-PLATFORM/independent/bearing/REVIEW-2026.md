## 2. 承托和射线结果的精确含义

- 旧3块实际slab并集：188脚缺失投影面积0；2444个中心/底多边形顶点射线全命中。
- 新187块实际slab并集：同2444射线全命中，最大脚底/实际顶面竖向残差 **9.894371011398562e−8m**。脚底实际Y范围12.300000029429995～12.300000104904175；不能写成逐比特正好等于12.3。
- 新顶面有 **34个脚**存在严格正的微条带缺口，其中 **20个 >1e−8m²**。作者summary的20是报告阈值分组，不是只有20脚非零；另外14个不能改报实零。
- 作者double鞋带/裁剪最大面积2.5243366508220788e−8m²。独立使用实际二进制坐标的精确有理数裁剪，最大为 **2.5243432798302876e−8m²**；两最大值相差6.63e−14m²，所有188项的最大double舍入差5.01e−13m²。结论和20/34分组相同，**不存在靠1e−5容差或面积阈值抹平米/厘米缺口的问题**。
- 独立核187顶面各为2个实际朝上三角，4个轴对齐角、同平面；有理数三角面积和精确等于对应矩形面积，故本轮用矩形并集并非拿任意bbox替有洞三角。
- 用同一188个真实脚底多边形，但将矩形换为builder authored cell界，无epsilon裁剪得到 **188脚缺口面积全部严格0**。它证明“拟定分区没有切穿这些旧脚”，不证明实际Float32面严丝合缝，也不证明将来搬动的脚。

中心和顶点射线全部命中并不排除穿过脚底内部的窄裂条，本轮正是全多边形并集补出了它。不可单用射线全绿写“全脚零缺口”。这也是可视几何接触检查，不是木结构承载能力、榫卯或真实修缮结论。

## 3. 330边的误差推导成立，但范围要限定

对每个slab的轴区间[a,b]，当前builder用中心 `c=(a+b)/2` 和宽度 `b−a` 建BoxGeometry；其局部半宽存Float32，mesh平移存double。因此实际左右边为：

`left = c + Float32(−(b−a)/2)`

`right = c + Float32((b−a)/2)`

对 authored 共有同一边的两个cell，各自半宽舍入不同，实际gap就是右cell实际左边减左cell实际右边。作者330项预测与实际Box3边逐位相同；独立从**实际顶面顶点**取边、用Python二进制Float32重建，所有187cell边及330邻接gap亦逐值相同。

| 共享边统计 | 结果 |
|---|---:|
| 正缝 | 202 |
| 正面积重叠方向 | 110 |
| 精确相等 | 18 |
| 最大正缝 | 7.867813138773272e−7m，即0.786781μm |
| 最大重叠宽 | 1.00360800558974e−7m，即0.100361μm |

最大正缝例：cell0与cell11在 authored Z=−18.4 相邻；实际边分别−18.400000762939456、−18.399999976158142。物理 authored 域无缝，但绘制面有上述数值缝。它是已被公式精确解释的有限表示差，不是修复，也不是把现有物理反录成合格。

**330仅是本轮187 slab的正长度 authored 相邻边对**，不是所有建筑界面或完整候选最大缝隙上界；不含坡—平台、亭翼—横连、屋顶、周边城墙等全体接缝。若后继合同要求实际顶面严格无缝，应在另行冻结/TDD的公共顶点生成方案中解决，不能只加容差、扩大footprint/支承、补隐形平面后宣称旧证据已修。
