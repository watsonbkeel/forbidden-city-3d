## 本轮实际变化

体仁阁南/北与弘义阁南/北四个侧端，原平台与廊存在 2.35m 高差，至廊轴横距约11.64/12.15m。四处新增**可见实心石接坡、转角台、低接道及相配护栏/碰撞**，从原侧阶落台通向附近既有廊前门；不穿闭山墙，不把廊当无限通厅。

实际几何为2.4m宽通道：从原2.8m落台沿外侧Z方向首坡**8m**下降至**1.45m**转台，再横向缓降到原廊0.45m台面，以短低接道进入已有开门。首稿6m/1.8m是设计初值，不是最终实装。阁和廊本身的台明/屋顶/柱墙/正门/原前阶、右翼门和廊端点均保持；只把原侧端封栏中央2.4m改为新实体连接开口，并保余段及完整新周边栏。

这是为现有游戏布局做的**外露U形工程适配，不是历史连接形态或实测坐标复刻**。新取官方两阁照片可证高台、栏、侧邻廊关系，但不能给出本游戏这组折线坐标；照片只保私有研究原件，仓库仅记URL/SHA。原建筑尺度/细部简化不因本轮变成已验收。
