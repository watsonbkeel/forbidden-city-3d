# Astra P2 修正：朝向与完整底面贴脊

前一候选 `f6fe81d4` 的18项专项只证明了四个底角接触，没有证明底面；独审发现底面中部穿脊及全部头部朝内。该版本不应按原通过项直接集成。

## 红测与根因
- 新增实际几何朝向检测：身、头真实包围盒中心差对实际角脊曲线檐端的水平方向。旧72头最小点积约-1，全部朝内。角脊正向本来就是向檐，旧头部位移符号取反。
- 每身底面7×6网格共3024点，向上射线测身底，向下射线测实际脊面；旧最大偏差 **0.058821618 m**。四角贴在凸脊上，但四角之间的平面弦穿入了凸起脊面。
- 三条新增测试首次全部红；没有把旧底面平面接触当作已经通过。

## 只限乾清宫的实现
- 新 `QianqingBeastSeat.js` 将每个真实、朝上的原角脊Float32三角面裁剪到原兽身矩形足印内；裁剪出的整个面反向作为兽身底面，轮廓边接侧面和原平顶。不是再抬高四角或填入一个隐形平面。
- 沿原角脊距离/尺度取样，头沿正切正向偏移，向檐端；数量、72个原脚印位置、8仙人、屋面/斗栱/大吻和通路不改。
- 共享 `HallWalkingBeasts.js` 只多一个import和一个**以乾清宫profile对象严格相等**的转发；太和、保和、中和全部继续原实现路径，不顺手修它们的几何。

## 修正后证据
- **22/22**：既有18专项与新增4专项合跑通过。72头最小水平向檐点积 **0.9999999999804436**。
- 3024身底射线最大绝对误差 **0.00000107521 m**（Float32量级），不是0.0588 m。
- **680个实际身底三角面**逐面证明：三个顶点均处于同一个原脊三角面内部；凸三角面的整个区域因此受支承，最大包含误差 **0.00000109135 m**。逐个同绕序三角面保留于最终合批，不仅测试元数据或散点。
- 几何负控：实际反转头位置使方向验证失败；保留4个真实底角和全部元数据、只把身底内部顶点压低3 cm，实际底面射线验证失败。
- 三旧殿高/低档完整指纹、所有非走兽网格、低档省略、资源释放、乾清宫非屋顶与全部碰撞/行走记录仍通过。
- 真实最终屋顶 **15,948 triangles / 1,531,008属性字节 / 6材质批**。相对493a13c7无profile屋顶净增 **2,984 triangles / 286,464 B**；相对首候选额外 **2,024 triangles / 194,304 B**，不再沿用旧+960结论。无新增材质批/纹理。
