https://www.cactch.org.cn/webfile/upload/2021/02-09/09-55-430520991296728.pdf
原PDF与两页研究图片仅本地保全，累计仓库保留URL/SHA（RESEARCH-SOURCES.json），不分发像素；madao-6.jpg对应461页、madao-7.jpg对应462页。作者现场勘察测绘；第6节和图1/2分别标南、北马道，图7为全平面。两条均为两跑折返，中间缓台，实体砖构；上跑宽约8m、下跑宽约6m，12°/13°。下跑护墙南1.17m、北1.665m，上跑.925m。摘要写“东西两侧”，与具体章节/图注冲突，本候选依有标注的南北平面，记录冲突而不隐瞒。论文明确西华门马道已拆；本改动不外推西华门。
