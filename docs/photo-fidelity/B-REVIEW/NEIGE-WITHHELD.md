# 内阁大堂试壳暂不合入

来源存在：官方[内阁页](https://www.dpm.org.cn/explore/building/236523.html)及[8036南外景](https://img.dpm.org.cn/Uploads/Picture/dc/8036.jpg)。本项不是全部缺源。独立原型 bfe6923bd94bd97b5fd433cf69d7cb6bb6fff1f5 有三间粗立面，但尺寸/位置为 FIT、细窗未完成、下部被前门遮挡。没有进入当前生产树或地图。

局部真实 FlightTour 试验从正常出生点飞入、下降，停于机底约9.6m，最低允许约9.411m；空中退出被拒绝。南侧地面降落后正常下机到脚底0。12次四向低位接近被实际飞行包络拦住。这些正常路径通过，不应写作正常下机必穿屋顶。

另设定“外部注入空中步行状态”的明确负测试，10/60Hz 从脚底12m落下会穿过屋面、站在5.2m实体盒顶；从西侧脚底6/7/8m冲刺也能跨入上部。原5碰撞盒未覆盖屋面上部；零登记 walkables 不代表没有盒顶隐式支承。22项诊断断言包括复现这些失败，不是22项安全通过。

因此本批暂不合，并保留原型及原红。后续需位置/周边可达性核查和有界实体包络方案，不能塞一个超大挡箱、改真实壳或把来源工程问题写成缺照片。当前共享物理、角色和旧建筑完全不因该候选改变。浏览器未验收。
