# R59-B 全范围特征审查结论

## 结论与范围

本轮完成的是 B 全量审查，不是 B 全量实现或验收。41 个原始 FC 对象的 577 条既有必需特征逐条覆盖：外部331条、内部246条。另覆盖6个 AUX 声明的两类 facet，并以84条角色适用性记录说明其外部/内部义务；AUX 原来没有 canonical feature 数组，不能把这些审查行冒充新增任务或六栋建筑。全部原始 ID、feature ID、状态、acceptedScope 和接受历史均保留，没有新的 ACCEPTED。

`R59-B-REQUIRED-FEATURE-MATRIX.json` 是完整机器可读矩阵，逐对象保留原 feature 定义和证据/差异/审查动作；同名 Markdown 是完整人读版，CSV 是577条原 FC 特征的可筛选导出。源码锚点含文件/行/函数或声明 JSON Pointer，来源目录含链接、可用哈希和实际阅读层级。代码基线799390a，最终元数据快照记录在 JSON 中。17个引用源码/声明文件的字节哈希均与799390a相同。

审查结果不是“缺壳清单”：103条已有实现待实际浏览器比较；7条来源支持有界实现；158条来源存在但身份、实例、时代或登记仍需处理；268条只在该特征/视角仍缺证；14条属已证不存的历史对象；18条属于汇总/不适用；9条保留本轮有限修改但视觉待验。一个 feature 可含已知与未知部分，分类不把有官方照片/论文的整栋建筑变成 BLOCKED_SOURCE。

1. 文华殿、主敬殿和穿廊已经通过 `ZoneBase.js:146–156` 进入专用实现。`SouthCourtHalls.js:7–68` 与 `SouthGalleryDisplays.js:17–107` 已有连续工字形地面、真实单个圆门、前殿主展柜/北低柜、穿廊双侧展柜/斜支撑/挡唇、后殿不可穿越圆形展柜。`RemainingOuterHalls.js:1427–1470` 已有主敬殿藻井、灯轨和门姿拟合。不得回退为通用壳或把镜中圆门复制成第二个实体。展品身份仍受2026年9月第一期陈列时点限制，不能宣称10月第二期展品全部吻合。
2. 文渊阁实际三层地面、三开间挑空、偏置入口轴、两段西梯、绿色柱、灰山墙、各层柜架，以及底层/三层分别引用照片的家具，已在 `RemainingOuterHalls.js:1158–1239` 生效。旧 `WenyuanPavilion.js:5` 的“未建楼层/楼梯/无柜架”文字不是最终运行结果，不能依它重建或移除现成果。
3. 三项首轮局部改动和六声明家具策略完整保留。南三所只是六个既有声明各撤8件无据通用道具及其碰撞，共48件；不是发现六间历史空屋，也没有解决九座主殿身份。源码入口见 `NansansuoInventoryPolicy.js:12–17`、`ZoneBase.js:234` 与 `palace/kit.js:475–480`。
4. 穿廊原 FC 和 AUX 同体关系、池桥现有子系统绑定、满本堂历史不存政策已经进入 canonical。不得把它们再列成“待首次绑定/待首次纠正”，不得增加第二条穿廊或第二座池桥。
5. 已读取并保留 `reports/r59-b-batch1/SUMMARY.json` 的完成累计功能检查：108角色实际观察、24条双循环路径、6次生命周期、48次新入口往返；24710碰撞体与1125支撑；222份源码冻结。早期红记录未抹去。本审查没有重跑世界，也不把 CPU 场景、代码、计数或中间图转写成浏览器/GPU/手机视觉通过。

## 需要完整方案而非小修的工作

- **传心殿组**：来源并不缺。官方正文支持约100×25米院落和南北序列；[论文p21](https://img.dpm.org.cn/Uploads/pdf/3718/T00021_00.pdf)支持治牲所5×3硬山、景行门3间悬山、正殿5×3硬山、后三房3/3/5。当前足迹与水系/边墙的关系未落定。论文井亭图是四柱双坡，不是盔顶；[p22](https://img.dpm.org.cn/Uploads/pdf/3718/T00022_00.pdf)有明确“东琉璃门”题注，不能套给景行门。先做现代位置、时期/屋面冲突登记，后分实体施工。祭祀文字不等于现代家具清单。
- **南三所完整九主殿和附属群**：现六声明的三进映射没有定，不能把两个中所后殿/撷芳任务先合并，也不能因此再加第四座“缺失”殿。官方三所各前3间、中后5间，另有三所琉璃门、各进配殿、井亭、耳房、顺山房、值/膳/净房、黑瓦后罩房；必须按 EXPAND-04逐实例展开。现共用门是 wall 变体，与三间绿瓦歇山门殿不同，但门坐标/通行与分院门关系先行。
- **内阁办公室群**：多条方位/间数文字可用，缺的是当代存续、物理边界、场景定位与内部图证，不是全部缺来源。典籍厅/满票签档子房边界未明。满本堂已有明确不存政策，历史位置仍可研究，不能建当代壳。
- **文渊阁碑亭**：南立面官方照片右侧可见东侧碑亭局部及黄色盔顶，父页有东侧定位。它不是完全无图的对象，但完整轮廓、尺寸、碑身/室内和独立空间绑定仍需补足，不能因这张局部照直接施工全亭。
- **室内与时代**：本仁/集义院落立面有自身2022全景来源，不能误说无外观资料；它们的室内仍缺。书画展柜、文渊固定装修/座具与未见库存须逐条区别；48个南三所删除项不授权把未知房间当空房验收。

本审查实际查看10份图像/论文页渲染的像素；另读官方缓存正文、已存在的来源报告和源码中的全景链接。目录逐条标明 `PIXELS_VIEWED`、`PDF_PAGE_RENDER_PIXELS_VIEWED`、文本读取、报告读取或仅源码绑定读取，不把既往查看归给本轮。照片拍摄日期未给出时一律未知。没有把官方照片/PDF副本放入本交付物，只有链接、哈希和必要转述。
