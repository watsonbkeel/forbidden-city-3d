## 4. 优化手段详解

### 4.1 SSAO 深度重建法线
✅ **效果：最显著**

**改进**：
- P0c：SSAO 对整个场景重新光栅化以重建法线 → 382 calls（占整帧 51%）
- P1-R：改用深度纹理重建法线 → 19 calls（仅 SSAO 的 4 个 pass）
- **收益**：−95% 后期 pass 开销

**权衡**：
- 法线重建精度略低于全场景重新绘制
- 实测视觉上无明显差异
- 保留了 SSAO 32 样本、模糊、Bloom、FXAA 等效果

### 4.2 BatchedMesh 跨组合批
✅ **效果：次显著**

**改进**：
- P0c：同材质网格在各顶层 group 内单独渲染 → 多余的 draw call
- P1-R：跨 group 同材质合并为 BatchedMesh → 减少材质切换
- **样本**：太和殿前 165 calls（vs P0c 238 主 pass calls）

**实现细节**：
- 按材质、属性布局、索引类型和接收阴影分桶
- 透明/ShaderMaterial/noMerge/实例池保留原渲染
- 阴影回调按源 castShadow 过滤并调用原生 BatchedMesh 阴影视锥处理

**遗留问题**：
- 首次流式加载复用启动预合并
- 卸载重建和跨组批次重建可能超 8ms 预算（已在 REQUESTS 申请优化权限）

### 4.3 120 m 阴影范围限制
✅ **效果：阴影 pass 优化**

**改进**：
- P0c：阴影投射物 = 整个场景 → 阴影 pass 126 calls
- P1-R：阴影投射物 = 玩家 120 m 内 → 阴影 pass ~66 calls
- **收益**：−47.6% 阴影 pass

**实现**：阴影相机跟随玩家，半径 120 m，动态剔除超范围物体

### 4.4 远景屋面轮廓壳
✅ **效果：远处卸载时保留天际线**

**改进**：
- P0c：远处区块卸载后天际线消失
- P1-R：生成每区无投影屋面壳，远景渲染
- **开销**：极低（无投影、每区 1 个 mesh）

**效果**：保持视觉连贯性，无额外性能代价

## 5. 瓶颈分析

### 5.1 主 pass（238 → 165 calls）
⚠️ **仍有优化空间**

**瓶颈**：
- 各顶层 group 的 mesh 数 ≈ 材质数（13−37 材质/组）
- 御花园 37 个材质 / 三台 29 / 后三宫 28 / axis-courts 20 居前

**优化方向**（Phase 2）**：
1. 进一步跨 group 同材质合并（目前限制在单 group 内）
2. 材质合并：相同颜色的瓦片合并 UV（减少材质种类）
3. LOD 策略：远处物体降级着色

### 5.2 阴影 pass（126 → 66 calls）
⚠️ **仍有优化空间**

**瓶颈**：阴影 pass = 主 pass 的 50%（目标 ≤ 40%）

**优化方向**（Phase 2）：
1. 阴影级联（Cascaded Shadow Map）以减少单 pass 复杂度
2. 动态批处理：阴影 pass 专用合批
3. 阴影深度预通道优化

### 5.3 后期 pass（382 → 19 calls）
✅ **已大幅优化**

法线重建后已降至瓶颈下方。

## 7. 已知问题与遗留项

### 7.1 批处理启动延迟
⚠️ **首次加载时间**

- 启动时 dry-build 全部区（预合并）：实测 ~2 秒
- 分帧构建：目标 8 ms/frame，实测复杂区可能超预算
- **影响**：切入游戏时首帧可能有轻微卡顿

**建议**：Phase 2 进一步优化构建管线

### 7.2 stepwalk 路径失败
⚠️ **15 条路线不可达**

- 御花园小路：堆秀山碰撞体阻挡（11 条）
- 文渊阁夹道：宽度不足（4 条）

**性能影响**：无。这是碰撞体几何问题，不是渲染性能问题。

**建议**：Phase 2 调整碰撞体，扩宽夹道

## 9. Phase 2 优化建议（不需实现，仅供参考）

### 9.1 优先级 1（可直接收益 10−20% calls）
1. **材质合并**：相同颜色瓦片合并，减少材质种类
2. **深度预通道**：先绘深度，减少后续 overdraw
3. **LOD 替身**：远处 (>200m) 殿宇简化着色或使用柱状替身

### 9.2 优先级 2（可收益 5−15% calls）
1. **遮挡剔除改进**：宫墙遮挡细粒度改进
2. **实例化扩展**：栏杆、柱网改为实例化（目前部分已做）
3. **纹理流送**：远处降级纹理分辨率

### 9.3 优先级 3（体验优化，性能收益小）
1. **阴影级联**：级联阴影贴图减少单 pass 复杂度
2. **批处理启动优化**：预合并分阶段加载
3. **移动端适配**：自动降级渲染参数
