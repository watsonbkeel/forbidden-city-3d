## 3. 数据覆盖说明

- **来源优先级执行**：142 个 dpm 建筑页全部抓取并解析（面阔/进深间数、形制、彩画、陈设、官方米数如太和殿 63.96×37.17×26.92、养心殿 36×12、九龙壁 29.4×3.5、奉先殿 1225 m²）；傅熹年院落模数（三台 130×232、后寝院 118×218 等）用于校核；OSM 501 条 way 量算提供全部建筑的中心坐标与外包尺寸（标"量算"）。
- **置信度口径**："高" = 官方数值或间数/形制；"中" = OSM 量算定位（±2–5 m）或由面积/间数推算的米数；"低" = 估算。多数行为复合标注（如"高（间数）/中（尺寸）"），统计时按首字计。
- **室内文档**：每份含 柱网 / 地面 / 门窗 / 宝座-匾额-藻井 / 陈设位置 / 彩画色彩 / 光照建议 / 图片 / P0-P2 优先级 / 未知字段 十节。官方正文可直接支撑的字段标"高"，照片可辨认的标"中"，估算标"低"。

## 4. 系统性未知字段（待后续补充）

1. **檩高/脊高、台基高**：dpm 仅对太和殿、午门、太和门、保和殿、神武门、角楼给出；其余约 85% 建筑"未查到"。dimensions.md §8 给出《清式营造则例》比例法（柱高 ≈ 面阔明间 × 0.8；举高按 五举/七举/九举）供建模方按间数推算。
2. **各间精确面阔**：仅太和殿明间 8.44 m 有文献值；其余按通面阔均分或估算（低）。
