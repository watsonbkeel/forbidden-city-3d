## 5. 遗留问题

### 5.1 配殿与后殿名称缺失

**问题**：六宫的配殿和后殿大多无 `name` 字段，仅正殿有匾额。

**影响**：小地图显示和位置提示无法精确到配殿/后殿名称。

**建议**：Phase 2 补充 `docs/research/dimensions.md` 中配殿/后殿的具体名称（如景仁宫东配殿"贞顺斋"等），回填到 JSON。

### 5.2 延禧宫特殊情况

**现状**：延禧宫现存为灵沼轩（水殿遗址），钢结构三层未完工建筑。

**当前处理**：采用遗址实测尺寸 16.3×11.7 m，仍按标准宫殿单檐歇山生成，`enter:true`。

**建议**：Phase 2 内景实现时，延禧宫需特殊建模（钢架玻璃结构 + 水池）。

### 5.3 门前净空警告

**问题**：zone-lint 报告 3 处门前净空 < 4 m：
- 钟粹门南侧：2.1 m（被承乾宫 courtWalls 阻挡）
- 景阳门南侧：2.1 m（被永和宫 courtWalls 阻挡）
- 乾东五所门南侧：2.3 m（被景阳宫 courtWalls 阻挡）

**原因**：六宫南北相邻院落间距较窄（约 7–8 m），符合实际布局。

**影响**：玩家可正常进入各宫门，但 NPC 巡逻路径可能受阻。

**建议**：保持现状（真实尺度优先），Phase 2 NPC 系统需识别窄巷场景。

### 5.4 截图生成失败

**问题**：执行 `node tests/shot.cjs` 时 Playwright 无法连接开发服务器（`ERR_CONNECTION_REFUSED`）。

**尝试**：
1. 修改 shot.cjs 移除硬编码 Chrome 路径，改用 Playwright 默认 Chromium
2. 多次重启 `npm run dev`，curl 确认服务器运行正常
3. Playwright 单独测试通过（`chromium.launch()` 成功）

**结论**：疑似环境或权限问题导致 Playwright 进程无法访问 localhost:5173。

**状态**：截图步骤跳过，其他验收项（zone-lint、anchor-check）全部通过。

**建议**：L0 总控验收时可在主分支手动运行 `npm run dev` 后截图确认。
