# Three-hall exterior nameboard mounting candidate

Official photographs confirm the south-facing Taihe, Baohe and Qianqing nameboards are centered between the double roof tiers. The preceding shared implementation instead placed all three over the below-eave doorway. Correct only these three transforms after each unchanged roof is built. Interior plaques and all other halls are outside this change.

Keep existing board geometry, dimensions, material, text, texture and insertion order. Use the generated upper-wall depth and actual lower ridge / upper soffit envelope; sample lower tile and upper rafter surfaces at both board faces and three horizontal stations. The retained board must fit with 0.03m model clearance; failure must not shrink it, increase stand-off or change the roof. The 0.12m wall gap is a bounded model fit, not a measured bracket projection. All geometry, global light, collision and walkables remain unchanged.

This is a mounting correction, not full plaque reconstruction. Existing rectangular gold frames, system-font lettering and assumed sizes remain simplified. Qianqing's actual plaque has Manchu and Han columns; the existing Han-only rendering is explicitly unresolved. No museum photograph becomes a runtime texture. Photo service dates are not verified capture dates. See REVIEW.md for exact primary sources and perspective limitations.

Acceptance: same-camera before/after front view of each hall, actual roof clearance and readability inspected, unchanged complete navigation and unrelated meshes/materials bound in CPU tests, original total-scene performance budget retained. No new native long-route or physical-device claim solely from fixed-camera or CPU checks.
