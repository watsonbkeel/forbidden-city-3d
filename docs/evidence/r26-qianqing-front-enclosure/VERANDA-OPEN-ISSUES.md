# 乾清宫前廊、尽间穿堂：注册条件复核

日期：2026-10-19。只读 R26 产品代码、复用既有资料并读取限定官方来源；未改产品/测试，未开浏览器，未运行产品或发布。

## 结论

**目前仍不足以把前廊退距与东西穿堂作为“已注册的准确几何”一并实现。** 新核到的官方穿堂视图补齐了南口—通道内部—北口的拓扑证据，但没有可校准的尺度和完整墙体平面。不能把现有等宽九间、25m 进深切成五等份便称为实测，也不能仅删除前后端板便称穿堂完成。

**下一项更成熟的单一修正：乾清宫南面重檐间外露木身区的分格彩画。** 保留现有屋顶几何及匾额挂点，在经照片明确覆盖的南面范围，以青绿/蓝底、金色线饰的分格彩画替换通长朱红材质。具体纹样、分格尺寸及颜色仍属照片拟合。不要顺带改背面/两山或把整圈木身统一涂成相同纹样。

- 复用官方《后三宫》资料及第8页“后三宫平面图”（本地 `后三宫-p08.pdf/png`）：能读到乾清宫两端独立南北通道与中间围护区的布局，但图上没有单体尺寸/比例尺，线图较粗，也未给测绘时间与测量方法。分类为**官方出版的无尺示意平面**，不能升级为现状实测图。

## 2. 已知拓扑与仍未知的几何

已知：南面9间对应1穿堂＋2窗＋3门＋2窗＋1穿堂；两条穿堂均沿南北向贯通，侧边有实体界面；前廊柱与七间围护不共面。

尚未闭合，须取得带尺度平/剖面或可校准多视点后再定：
1. 九间各轴距及五进深间的六条轴线；前檐柱轴至门窗框轴/墙面的真实退距、后廊深度。
2. 东西穿堂内侧纵墙的轴位、厚度、全长和南北收头；它们不能由现有边柱间宽直接替代。
3. 两端门洞净宽、净高、门框/门槛厚度，是否与檐柱轴或退后围护轴相齐。
4. 内侧小门的位置、尺寸、开向与门后空间；仅看一条通道前视图不能封定其完整墙面。
5. 北端出廊后的侧向转接、台面高差和与后院地面的连续界面；不能将现有中央后门继续开放当成史实。
6. 墙身与前廊天花、横梁、地面和碰撞的统一收口。摄影透视、阴影和240px缩略图不足以关闭这些条件。

## 3. 当前 R26 的实际落点

`src/config/constants.js:92–97`：w=46、d=25；`Layout.js:142–155`：x0=0，z0=316.8。这些是现模型参数，不是新实测值。

`PalaceBuilder.js:654–710`：乾清宫没有专属平面网格；面阔9等分，bayW=46/9≈5.1111；`Math.max(3, round(25/7.4)|1)`给3进深间，4排柱轴为局部z=−12.5、−4.1667、4.1667、12.5。不能只把nd改5而保留dBay=25/3，否则最后柱排会越界。

`PalaceBuilder.js:733–770`：前/后围护及门槛仍在全局z=304.3/329.3，与外柱轴共面。R26仅南面bay1、2、6、7改窗＋下墙，bay3、4、5为虚拟打开的门，bay0、8仍为通用闭合整板。每端两侧长条碰撞覆盖x=[−23,−7.6667]及[7.6667,23]，也堵住尽间。

`PalaceBuilder.js:774–784`：两山墙在x=±23、贯穿25m，墙宽0.9、下碱宽1.0；不存在穿堂与室内之间的专属纵墙/小门。现有地面虽贯通，却不代表穿堂边界已建成。

## 4. 重檐间分格彩画候选：准确对应代码

- `PalaceBuilder.js:814–829` 调用通用buildRoof，width=46.6、depth=25.6，无乾清宫外露木身专属配置。
- `RoofBuilder.js:37–39` 的木身材质是 `wood_column`；红带**不是** `wall_red`。
- `RoofBuilder.js:622–628`：inset=3.072，Wi=40.456、Di=19.456；627行整圈棱柱 `sk.y0 → bodyTop-cb` 使用 `ctx.mat.wood`。628行只有顶部窄带用 `caihua_beam`，所以其下仍显朱红。
- 对应南面木身平面为局部z=−9.728；这是模型坐标定位，不能作为真实尺寸。
- 官方全正面照片清楚显示重檐之间连续的暗青绿/蓝色分格装饰，外匾近照进一步显示匾下、两旁均有金色线饰和青绿/蓝底。照片支持“该可见面不是整条纯红”；不支持用泛用材质精确复原全部金龙和玺构图。
- 若执行此候选，应限定乾清宫、南面外露木身，保留红色柱/竖分隔的可见节奏，避免涂满匾额或檐椽。分格数和比例需再对原图逐段注册；本报告没有编造面板数量。
