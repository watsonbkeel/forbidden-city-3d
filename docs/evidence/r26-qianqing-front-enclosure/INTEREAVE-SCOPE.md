# 可并入 R26：乾清宫南面重檐间分格彩画

## 可执行的证据范围

**南面可以确认；本次只做南面。** 官方完整正面图覆盖从左端到右端的重檐间外露带，带内可辨重复的青绿/蓝底分格。官方匾额近照提供同一部位的近距离确认：匾下及两侧有金线轮廓与纹饰，外露装饰一直下接黄色瓦/围脊交接处；上方为额枋、斗栱和上檐构件。不是一整条裸露朱红木板。

左前斜照在左端仅显露很短的西面转折，且重阴影。它能确认装饰不是独立悬浮牌，不足以注册整幅西面分格；没有本次已核清晰东、北面证据。因此不将整圈外皮换色，不声称四面同样。

## 与 R26 代码的精确接口

- `RoofBuilder.js:627` 是通长红带的来源：上层木身四面棱柱，材质 `ctx.mat.wood` → `wood_column`。628行已有顶部 `caihua_beam` 窄带。
- 仅处理**乾清宫**该棱柱**南向面**。原面在局部z=−Di/2、x∈[−Wi/2,+Wi/2]，其几何保持原样。
- 露出腰檐之上的保守目标区：下界 `sk.ridgeTopY`（下层围脊顶），上界 `bodyTop−cb`（现有上层彩画额枋下沿）。下界实际可见性仍由保留的瓦、围脊遮挡决定；不要把贴面伸到瓦面之前。
- `doubleEaveMountingBand.upperY` 到上层椽底，包含斗栱等间隙；它是挂匾清空范围，**不等于**本次围板顶边。
- 保留原来的顶部额枋彩画、上下檐瓦与围脊、斗栱、椽头、匾额挂点/尺寸；不改屋顶曲线、形制、透视比例。
- 可用暗青绿/蓝底、有限金线和分格表现替换裸红带；红褐细分隔应保留可见节奏。照片没有允许我们宣称精确纹样、准确分格宽度或实测颜料值。不要声称现有通用彩画纹样就是乾清宫真实原样。

## 验收建议

只需在原 R26 正面/斜面截图补查：没有通长裸红带；彩画面与下层瓦/围脊相接，上方没有覆盖斗栱；匾额不穿插、不下移；两山和背面没有被连带替换。最终文案称“南面重檐间彩画分区修正，纹样与颜色为简化拟合”。
