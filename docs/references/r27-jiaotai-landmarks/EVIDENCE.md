# 交泰殿两件大型计时陈设：限定证据包

核查日期：2026-10-19。结论：足以做一个“西大自鸣钟＋东铜壶滴漏楼亭”的可辨认轮廓包，尺寸和站位必须标为来源约束下的照片拟合。没有闭合现状测绘尺寸、墙距或完整室内。未改产品、未测试、未开浏览器、未上传发布。官方照片仅研究，不应作为项目贴图或随发布包再分发。

## 先用哪些图

1. `交泰殿内景基础影像-1.jpg`：官方全景的1365×1720内景原图。自南向北看，左钟右漏，中央宝座、红屏风和两根对联柱共同提供方位锚点。建筑页 `building-interior.jpg` 是同一照片的较小版本，不能算第二独立机位。
2. `交泰殿自鸣钟-0.jpg`：官方全景收录的1314×1718大钟近照，完整柜体、底座、钟盘、两层围廊、顶部雕花冠及尖柱。背景南面红色槛窗和相邻宝玺罩架保留在画面里。
3. `video-clepsydra-250.jpg`：故宫官方《交泰殿_中文版》视频第250秒。左侧静态照片显示当前彩色正面滴漏全貌：双檐楼亭、器壶、台座与前伸的阶形底部。只约204×262有效照片像素，不能读出精细雕饰。原视频和出处已保存。`inspection-current-clepsydra-crop.png`仅裁切，无补画。
4. `historical-clepsydra.png/pdf`：故宫《紫禁城》160期第118页，明确标1900年、小川一真摄影。正面清楚显示三只方形敛底壶、双檐亭、前伸台座；只作历史轮廓校核，不冒充今日照片。1981年傅振伦文配图为另一个旧视角，`clepsydra-article-1981.png`。
5. `inspection-clock-side-crop.png`、`inspection-clepsydra-side-crop.png`：第1图两个侧边的纯裁切，便于判断与北屏风的透视关系。它们不是额外机位。

## 位置与朝向

- 建筑官方文字直接支持“西次间钟、东次间漏”。以南门向北的游客视角，钟在左、漏在右；以宝座朝南视角，左右相反。不能不说明视角就写“左钟”。
- 多照片方位推断：**西侧大钟钟盘朝东，东侧滴漏的器壶正面朝西，均面向殿中**。中央正面照可见两件正面的水平檐/栏沿景深斜收，与北屏风的横向边不同；两件各自近正面照片背后分别保留南面红色槛窗，滴漏照片左方见北侧“恒久…”对联柱。这组证据支持相向陈设，不能把两件都朝南摆成平行于北屏风的正面。
- 两件均在中央北屏风与对联柱的南前方，分列中央宝座陈列区两侧，落在殿地面而非中央宝座白色台沿上。宝玺罩架分布在其旁侧和更北处。中央照片两边黑色双扇柜面不能直接当东西外门或可通行门洞。
- **没有确定**距北墙、侧墙/侧门的米数；没有足够证据把两者的底座中线注册到东西侧门轴。勿为“对齐侧门”而改门、移后墙或宣称路线符合现状。
- `SquareHalls.js` 当前代码以 east 为负X、west为正X，north为正Z。若沿用这套标签：钟在正X且正面朝负X；滴漏在负X且正面朝正X。必须以实际模型坐标复核，不能套用通常的“东=正X”。

## 大钟：官方旧量制尺寸已核，米制未闭合

出处：刘月芳《交泰殿的自鸣钟》，官方《紫禁城》后三宫特辑第20页：
https://img.dpm.org.cn/Uploads/pdf/2201/T00020_00.pdf
对应官网：https://www.dpm.org.cn/clocks/talk/206646.html

实际读过渲染页 `clock-article.png`，非只读OCR。该文明确采用清尺：
- 通高17.4尺；底座横6.9尺、宽5.55尺。
- 下/中/上层高8.4、5.4、3.6尺；下层柜身横4.35尺、宽3尺；圆钟盘直径3尺。
- 后有8级上弦梯，高8.4尺；该背面细节有文字但本次没有当前背面照片。

安全可用的无量纲比：底宽/总高0.39655、底深/总高0.31897；三层高比0.48276/0.31034/0.20690；盘径/总高0.17241。不要把“清尺”静默当现代市尺，或把通行的5.8m百科数字当本次已核官方米制值。本文没有交代测量时间或尺的换算常数。

实物识别点：黑漆深色木柜、金色番莲雕饰，粗壮下柜、四角雕柱，中层大圆盘和罗马数字、两针、突出的围廊栏杆；上层是雕花冠和高尖柱、宝顶状构件，不是滴漏那样的双檐瓦屋顶。金饰须节制，不能做成整块亮金柜。照片中顶部接近侧部天花/梁枋，门窗上缘明显低于冠顶；这只是照片比例，不是6.2m柱高的反证或标尺。

## 滴漏：整亭形态可做，总高尚不能写成精确米数

1900年照片页引用《清宫述闻》：亭通高一丈八尺余。它支持与大钟同为高大、近天花量级，不能强制推出当前确切米制总高。小幅当前视频照片和大幅内景侧面共同支持：
- 红木色/彩绘、青绿暗色的**双檐**楼亭；上檐小于下檐，檐角上挑，顶部有小圆柱/壶形构件。
- 大面积雕饰台座，上方四角柱、开敞中段与小栏杆；前方沿纵深逐级向下排列的方形敛底铜壶、前伸的窄台座。
- 官方视频250秒字幕明确说由五只铜质壶组成。三只主要壶在正面自上而下可辨；不能为了“展示五只”把所有壶挤成五只同形直线堆叠。隐藏后部和小管路此次不精细重建。
- 当前红/青绿配色可参考原内景侧面；灰白壶体受低分辨率、光照影响，不应直接定为抛光银材质。

**排除的易混物件**：https://www.dpm.org.cn/collection/clock/232497.html 的“故00199158”高591cm、底座458×259cm，正文明确原存皇极殿、嘉庆四年。其两张照片也不是交泰殿。`clepsydra-collection.html`和`collection-clepsydra-*.jpg`只作排除证据，不可把它们的尺寸/照片当交泰殿实物。

## 年代与现在陈列的边界

- 大钟1983官方文章明确现件为嘉庆三年（1798）造办处制作，并记1797年火灾毁掉前件。不可称当前大钟为利玛窦原送之钟。
- 滴漏官方旧文/照片引文写乾隆，而[2020王子林署名文](https://big5.visitbeijing.com.cn/article/47QkJHdHt63)指出旧钟漏1797毁、新造钟漏1798陈列；本次不把存在年代冲突的材料写成确定文物断代。原状陈列的可见形态与制作年代是两项不同问题。
- 当前图与1900图中的布罩、宝玺盒、摆放和遮挡有差异。保留今天照片所证的主体形态，勿照搬历史图所有附属物；没有把网页文件路径中的2026年月当拍摄时间。
- 官方2023视频约150秒说明二十五宝玺已收藏于他处。因此宝玺罩架应理解为陈列外观，不能根据布罩就宣称每只珍宝原物仍在该处。

## 建议的最小实现与验收范围

1. 仅为交泰殿加两件各自独立的主体模型；保留现建筑壳、中心宝座、天花、匾额和光照。藻井及大屏风虽显著缺失，另立任务，不夹带。
2. 先用上述钟的无量纲结构比建形，再按现有6.2m壳的可见照片比例拟合总高；滴漏保持近似同高量级并明确标估。没有足够依据给精确新米数，本包不建议冒充实测。
3. 在侧次间摆放、两正面朝向殿中。位置只按中央照片的柱/屏风/地面关系拟合；不封定侧门轴。物体落地、所有基座与突出围栏/台阶须有一致碰撞，不以穿模获得通行。
4. 以南门向北总览、殿内分别面向东西两物的正面、斜侧和通行净空截图验证；不能只给南向北一张图就称两件已验收。
5. 钟面/壶体/屋檐必须分别可辨，柜顶不可混成中国亭屋顶，滴漏不可混成第二座机械钟。无需动态指针、报时声或流水，没有给这类新增表现的史实与玩法依据。
