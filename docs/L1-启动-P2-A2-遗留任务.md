### R1：Collision.js 金水桥桥位改读 river.js

**当前代码**（`src/utils/Collision.js` L67-L79）：
```javascript
isOnBridge(x, z) {
  const bridges = [
    { x: 0, z: -324.5, r: 8.9 },
    { x: -21.8, z: -324.5, r: 5.1 },
    { x: 21.8, z: -324.5, r: 5.1 },
    { x: -43.9, z: -324.5, r: 5.1 },
    { x: 43.9, z: -324.5, r: 5.1 },
  ];
  return bridges.some(b => Math.abs(z - b.z) < 8 && Math.abs(x - b.x) < b.r);
}
```

**需改为**：
```javascript
import { bridges } from '../data/river.js';

isOnBridge(x, z) {
  return bridges.some(b => Math.abs(z - b.z) < 8 && Math.abs(x - b.x) < b.r);
}
```

**修改步骤**：
1. 检查 `src/data/river.js` 是否已导出 `bridges`
2. 修改 `src/utils/Collision.js` import 和 `isOnBridge` 方法
3. 运行 `npm run test:gate` 中的 regression 步骤验证（24 条回归截图）
4. 提交：`fix(collision): 金水桥桥位改读 river.js`
