# 临溪亭桥池 Implementation Plan

> Sole product writer uses executing-plans; parent explicitly directs immediate autonomous implementation of researched package.

**Goal:** 从0aa1f79b累计，补临溪亭矩形池、单孔砖石券桥、汉白玉池栏为一个真实有孔的桥池单元，保亭身和南北可行通路。
**Architecture:** 独立 `LinxiBridgePool.js` 精确校验目标并替换唯一矩形砖台体；保原石顶板、所有亭身、台阶和旧物理。新池底/岸/石栏及同形碰撞，Environment仅加本池有界开孔，避免地下桥被全城地面遮挡。现有Three.js/材质库，不改通用殿或屋顶。
**Spec:** FC-00B009500F；官方236537已读，linxi0.jpg、linxi1.jpg像素已看。矩形池、单孔砖石券、东西临水与池畔汉白玉望柱栏板、南北阶为事实；全部新增尺寸/水位/券线/雕饰细节标拟合；拍摄日期/现时水态未知。

## Alternatives and boundaries
- 选专属有孔桥台加地面矩形孔；只贴深色池面会保留实心砖台和挡孔地面，不满足对象结构。
- 不重建整座亭、不改既有门窗/屋顶/台阶，不用旧原图作生产贴图；不扩大到慈宁全园花木/花坛。
- 池栏采用源图可辨的望柱、柱帽、压顶、下栏板、上部镂空，浅轮廓拟合不假装石雕细纹。
- 保所有原碰撞/行走数据，新增碰撞仅与新增实物一致；无隐形地板、无新增通池路线。水是静态表达而非现场当前水态，明确未知。
- 回退开关仅供可追溯对比。不得main/push/deploy；无GPU或手机性能宣称。
