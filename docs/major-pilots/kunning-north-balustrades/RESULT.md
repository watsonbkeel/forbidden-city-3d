# R152 坤宁门北面双水平矮栏：有界局部开发

## 来源与范围

原文对象 FC-60FCD2B8CC。故宫[坤宁门官方页](https://www.dpm.org.cn/explore/building/236582.html)的[第三幅北面照片](https://img.dpm.org.cn/Uploads/Picture/2020/04/20/s5e9d4d9c2b146.jpg)支持黄绿水平矮栏与白石基座。已人工查看原图并由独立核对者确认方位；缓存与官图字节 SHA256 为 `19369d55a125661e9375b1a3cd3638676cda83d5f6822282eacd8f04662e896f`。第一幅带方格窗的照片是南/后面，不用作北面造型来源。URL 日期不是拍摄日期。

本次仅新增**北侧成对完整水平段和浅色基座**。官图斜降帽面与白色端足可见，但其下墙身不充分：不猜实墙、开放栏或白色填板，斜降墙身及帽面一并延期。这不是整组北栏、整门或原文全部完成。八字琉璃影壁是另一实体，不冒认本栏；现代黑色游览围栏、树支架、标牌及花盆不加入。

canonical garden/items29、坐标 `(1.1,422.7)`、frame rotation π、既有门体/平台/阶陛/通路保持。双栏各宽 6m，最高 2.25m，三排八列黄绿色块及三层近似圆帽的阶带均为照片拟合，不是测绘尺寸、精确砖数或雕花复原。基脚向既有平台北缘外突出 8cm，不能声称新实体完全不出原足迹。采用既有石材与两个自有无贴图釉色材质；不增加外部图片资产。

## 实现与接触

独立 `KunningNorthBalustrades.js` 加一处门体 hook。先校验 canonical 身份、既有非索引几何属性/姿态、平台支承边界和 no-rescue 标记；随后原子暂存新增件。重复调用无副作用，分配/挂接/物理注册后故障均回滚新资源，不处置旧材质。旧网格属性、材质、变换、支承、碰撞器前缀、rooms/maps/regions 均有保全检查。

60 个闭合 Box 构件，碰撞边界与变换后 Float32 顶点一致；无全高度假墙、额外 walkable 或公共控制器适配。真实控制器 8m 高落后立于栏顶，向北可下至地面。原守门房和柱体会阻挡栏顶向内/向端部及该 Z 的直接横移；安全父独立证明该阻挡原已存在，不移动旧柱或绕过碰撞。最初要求这些方向穿柱通过的测试属错误要求，保留诊断证据并改为正确阻挡及北向退出；曾试验的局部 scope 未解决真实柱体阻挡，已从产品完全撤除。

- 实际材质合批父 3,724→候选 4,444 三角（+720），顶点属性 357,504→426,624 字节（+69,120），11→14 网格（+3）。无新纹理。
- 实际几何 CPU 前后对照已查看，独立审阅无重要实现问题；仅平色软件光栅，不冒称官图同机位或 GPU 实机图。
- 三 base `/`、`/forbidden-city-3d/`、`/gugong/` Vite 内存编译及 HTML/JS/build-info 身份核对通过；write:false、publicDir:false，无产物复制、HTTP/浏览器或可部署包声明。运行源码指纹 `624d2b713fa1eb9853ccd0717686e1b614cba506d89a06b0600bc708dbe40402`。
- 整世界 6/6：两侧 8m 真高落及北向地面退出，10/60Hz 双阶道全门往返。60 步实测约 9–44ms、360 步约 16–28ms，仅 Node 诊断，不是帧预算或实机 FPS；该短测在父套收尾时运行，不作为独占性能基准。
- 标准安全父/候选最终均 1331 项：1113 通过、218 失败；逐条有序测试名称＋状态 0 差异，失败名称相同，不仅比较总数。两套串行，约 458/460 秒；不宣全绿。
