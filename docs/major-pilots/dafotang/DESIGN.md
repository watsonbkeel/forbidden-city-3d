# 大佛堂正面闭合门叶：照片关系拟合

依据：原需求清单K、故宫建筑页236533、外景8035.jpg。照片400×279支持七开间、红色槅扇、上部细密格/下部板面，不支持精确纹样种类、格数、雕绘或背衬材质。全部比例、网格密度仍为模型拟合；原拍摄日期未知。

方案选择：不添加悬空外贴条、不扩大旧闭合叶碰撞盒、不改共享物理。只在24个既有闭合门叶厚度内，改为后置实背板、红色完整框、内嵌斜向细格和两层矩形下板框；斜格及两层分格为明确拟合，不声称精准菱花。保留闭合门叶原有不透明拓扑，不指定纸/玻璃等未经照片证实材料。实际装配外包围盒保持原门叶范围；原稀格和外凸纸面删除。中央4个打开叶、中央净开口、门楣/柱、过门/暖阁隔断、屋顶/台基/台阶、全部collider/walkable/导航与室内契约不变。

替代方案：新增外凸实体格条需新的细薄接触安全证明，当前没有必要；贴整张照片会引入透视/伪门，拒绝；重造整个佛堂或恢复旧佛龛会混淆历史调查与现代展陈，拒绝。

先验红测：默认构造应具24个来源标记闭合叶，基线缺失；四叶打开姿态与全部旧物理/导航不变。实现后逐组件检查几何在旧实体边界内、装配外包围盒相同；最终合并材质/网格不丢失。10/60Hz真实控制器在完整World验证中央进出、暖阁过门；局部CollisionManager验证闭叶方向走/跑/跳输入的新旧逐帧等价，另断言实际起跳及不能穿过闭叶。没有独立前廊路线。 independent review。只小文件与增量记录，不构建、不复制资产、不推送。

碰撞精度边界：保留的闭叶AABB仍是保守代理，不是新凹格的逐面精确碰撞；凹入空隙仍可能被原代理挡住。此步不新增阻挡/可站立面，也不宣称整体建筑验收。24闭叶/中央4开叶是继承模型姿态，不是照片验证的现代门叶开放清单。

装配实现使用原门叶Float32外坐标建立完整四边框；后半厚度保持不透明背板。专项红测先发现暗色上部背衬与背板的2mm间隙，随后改为2mm交叠；格条均与背板相接。最终合并顶点逐个存在于实际合并输出，所有新增部件位于原门叶合并包络，装配外边界完全相同。
