# 佛日楼前小院—月洞门—低阶区域

原对象FC-2318B5F73B，原文708。官方236573明文楼前虎皮石饰墙小院/月洞门，fori-0可见门洞、饰石墙及入楼阶道。当前模型已有两层三间佛堂却无前小院。本包选择补整个中央入院—入楼关系，非添单个装饰门圈；比重造室内更有证据，也不碰未核东梯接点。

现有Three.js专用ForiForecourt模块、kit.foriForecourt=false回滚。真挤出带圆弧凹口墙、分段实体边界、石门圈、程序性不规则饰石提示、两侧低深度回墙和中央低阶/坡道。门洞圆心稍低于半径、地下弧截于地面，保证真实玩家净空；半径/墙高/墙退距/回墙均为旧地块约束拟合而非测量。墙背未知，素面不伪造同款贴石；不模拟无据石山、树木或原每块石位置。

保留既有楼体全部几何/物理、三间分隔与供台轮廓，不新增佛像。东侧通梵华楼石梯有文字但当前接口/标高未核，不假接或解锁上层。需测试院外中心及两侧过月门入楼回环、旧楼路径、物理墙阻挡、邻楼非目标精确保留、合并生命周期；累计专项/全量父子失败名、CPU实材质、三基址缓存与独立复核后本地提交。
