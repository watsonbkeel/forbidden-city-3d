# 澄瑞亭完整亭桥单元 Implementation Plan

> 唯一产品写手按 executing-plans 实施；用户/父任务已明确要求自行选定有据整包并执行，不再重复方案审批。

**Goal:** 在 707e9bad 累计版本上处理澄瑞主亭/南抱厦连续屋面、宝顶与对应承托、可见井口天花层次，同时保持亭桥全部原通路和周边实体。
**Architecture:** 独立 `ChengruiWholeEnvelope.js` 校验规范宿主后构造有界替换；原 `RemainingGardenPavilions.js` 末端一次调用。默认启用、false 为历史对比回退。亭桥非目标网格和所有原物理行逐一保持。主/抱厦屋面采用同一连续闭合高度壳，避免两片屋顶互穿；既有尺度下曲线、瓦列、宝顶剖面均标照片拟合。
**Tech Stack:** 既有 Three.js / GardenBuilder，无新增依赖或图片纹理。
**Spec:** 原需求 FC-4610835E3D、全对象试点SELECTION-20261028、官方236443（2026-10-28读取）及自身正/斜外景、3962天花、7906藻井图（已看像素）。

## 决策/约束
- 选统一连续闭合屋壳，而非继续两套交叠三角片或重建通用 RoofBuilder；最小影响且屋面相交一次处理。
- 不用原照片贴生产纹理；不生成伪龙雕或把现代陈列/上传年份当原状日期。
- 不增可走屋顶、隐形碰撞或复原已拆护墙板/斗坛。未核项保持 UNKNOWN/BLOCKED，accepted=false。
- 保所有此前寿康/交泰与人物系统；不 main/push/deploy。

## 接续决策与评审修复
- 源图红色抱厦山端板有明确形体支持，纳入同一屋面包；双端对称标拟合，细雕未知。
- 评审测得解析承托与实际三角化屋底最大约19.36mm间隙/2.62mm穿入。红测试后改为实际Float32屋底逐三角裁切，15mm有限内嵌；顶面顶点和重心均验证，而非只测四角。
- 评审测得天花组件12.5mm悬空。改真环框接天花、蓝底凹于框、金边接框；补八边形真实裁切的中央部分格子，金龙/双龙仍明确未复原。
- 早期24k新增几何预算扩到30k：实际接触裁切、环框/孔边完整格子与红板要求增加面数；成本显式记录，不称性能收益。最终全园+28,220三角、+3合批网格。
- 原R142历史“只换两凳”的比较明确关闭新屋面，仅隔离旧改动；其他原R142通路/落地在新整包运行。缺报告目录由测试准备创建，不作为产品问题掩盖。
- 全套结果1115/1331通过、216失败，与707e9bad完整低并发基线失败名相同；不修无关历史缺件/旧源hash来凑全绿。
