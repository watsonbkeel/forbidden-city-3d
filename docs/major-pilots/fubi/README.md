# 浮碧亭：主亭—南抱厦连续屋面与自身天花层次

**原对象FC-DE4C06C5F7，G区第619行，累计父版本40ea708。** 原397必需对象与7展开组分母不变；不把该整包改进说成浮碧亭、百花绘画或全园验收完成。

## 本包实做

1. 主亭与南抱厦从两套直坡相交壳替换为一个闭合连续曲面外壳，同步实几何瓦条、黄剪边、鼓腹金色琉璃宝顶、两端红色曲边山端板。
2. 16处承托由实际Float32屋底三角逐片裁切，嵌入120mm屋壳15mm；保所有柱梁及原净高，不用不同采样的解析曲线假装接触。
3. 浮碧自身照片的红格网、绿色方框/底、蓝色金边圆心做实几何层次，圆心与底板接触、井口真实裁切。**圆心仍素面，无花卉绘画；双龙戏珠精雕未做。** 16边圆心和6mm色域浮层是可见性拟合，不是石/木雕史实。
4. 既有八方井轮廓保留：没有把澄瑞独立照片的阶进藻井复制给浮碧。抱厦天花为形体延续拟合，未声称有本次独立抱厦内景。
5. 真实高位跨池红测试复现旧1.6m池域障碍可被跳过并落在默认y=0的漏洞。追加仅覆盖本池水面的非游泳通行策略，按身体半径保留主桥、南抱厦及2.4m宽北桥；不加隐形墙/地板，不改原碰撞体和行走面。

## 自身来源与未闭项

依据[故宫博物院浮碧亭页面](https://www.dpm.org.cn/explore/building/236498.html)，本亭外观、百花天花及桥部细图均已看像素，SHA见`SOURCE-MANIFEST.json`。官方说明支持方亭三开间、南抱厦、绿瓦黄剪边、琉璃宝顶、百花天花及八方双龙井等型制；原照片不进入生产资源。

- **全部拟合而非测绘：** 屋坡曲率、瓦条数量、鼓腹宝顶尺寸、山端板厚度/两端对称、8×8格子排布、颜色、圆心数量/直径、承托及连接方法。文献约8m与既有7.6m柱网分列，不冒充同一实测量。
- **保留并核验：** 全部原桥/池/台阶/座凳/柱梁，原2034个花园碰撞体与31行走面、树木实例，已完成澄瑞所有几何及其独立来源记录，以及此前宫殿累计修改。
- **未闭：** 花卉和双龙原画/精雕、苏式彩画、真实斗栱木作、脊兽、浮碧曲背凳细节、桥栏雕刻/池口细部、牌匾字形/挂位独立验收、摄影日期/现场开放/当前水况。保留池桥不重算为本次新建完成。
- `FubiWholeEnvelope.js`独立启用/回退；复用已验证的数学方法，不扩宽澄瑞对象选择或改其产品几何。八项外部/六项内部要素逐项见`COVERAGE-MATRIX.json`，旧账完整保留。
