# 禊赏亭：正面三开间通透槛窗及高坠安全

官方建筑页：<https://www.dpm.org.cn/explore/building/236514.html>。两幅官方照片见 `SAFETY-PLAN.md`。本次仅拟合照片可辨认的矩形回纹通透木构分格，不声称精确榫卯、分格数、细部雕绘或完整建筑复原。

## 实做与不变项

- 三个原正面开间增加 63 个真实木条，孔隙不填面。沿用原模型局部正面及旋转（世界负 X 方向），本次不擅改场地朝向。原石栏、流杯渠、台基、背屏、梁柱、天花、屋顶几何及两块既有 walkable 保留。
- 78 个原屋面网格和新木条共 8,760 个源三角；12 个严格零面积面记录并省略，其余 8,748 面进入原有精确接触机制。
- 每面按最终 MergeUtils 的 Float32 烘焙语义生成，并逐面匹配实际 `kit.finish()` 合并渲染，避免双精度注册与真实渲染的微小错位。
- 只新增一个真实源面碰撞 owner；碰撞体 41→42，walkable 仍为 2，合并网格仍为 13，渲染三角 13,986→14,742（+756）。没有新隐形地板或代理屋面。
- 本亭玩家脚高域接入已有精确方形脚底/连续扫掠/权威脚高路径；共享 SAT、扫掠和步行算法不改。原柱身份、唯一性和更新不可降级；NPC/无显式玩家脚高调用不选择新域。
- 地面只来自两个实时原有 walkable 或当前安装、可见、变换/源面有效的真实 Environment 地面；不设置 `groundY:0` 回退。来源撤销、变形、隐藏及跨 CM 不能继续借用。

## 安全证据

先保留并复现旧候选的 10/60Hz 9m 高坠悬空。仅把圆脚底改方脚底的假设仍穿透，明确否决；采用局部既有精确路径。诊断是历史调查，不能代替生产验证。

生产专项覆盖：真实合并渲染源面；原几何/地板不变；身份/重复/更新/卸载与重载；816 个阈值、边角、最大速度例；三开间重复跳跃；站/坐 NPC 不成为可落地跳跃支撑，人物撤销与姿态更换；全 World 36 个 9m 高坠→屋顶落地→六方向离开→域外停止落地路径，逐帧独立三角穿透检查。

旧 R100 石栏冻结快照显式关闭后来新增槛窗，只验证其历史增量，不修改黄金快照。R100 运动测试仍直接构建默认开启的完整 World：10/30/60Hz 十二条落栏、沿栏行走及停止路径，验证新旧同时存在。当前开启态另有全几何保留测试。

独立复核指出并修复了域外扩地面见证覆盖、Float32 渲染一致性、无效输入及锚点降级/重复更新缺口。最终测试清单与源指纹见 reports；不得把早期并行 SIGKILL 运行当通过。
