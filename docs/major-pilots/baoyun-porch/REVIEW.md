# 独立复核摘要

只读复核由另一代理完成，产品单一写手。先复核完整父版（含R48增饰）和官方主立面图，再复核候选源/物理、CPU整院与门廊相机。

已发现并关闭：
1. 最初调用位置过早，漏掉完整R48低饰带。改至完整增饰后替换七件，并严格守护原源。
2. mesh分配后异常可能留部分新体。提前登记分配并事务回滚；独立注入第15次碰撞push后抛错，16分配/16释放，原children/物理/walkables恢复。
3. 隐藏顶面裁剪的主体来源缺身份守护。三主体名称、几何hash、姿态、完整drawRange和材质状态现均严格验证。
4. 普通箱体+逻辑顶面不能可靠走出高檐。取消新增walkable，改用原有TriangleSupport的16个完整闭合源箱体；逐三角对齐最终Float32流，非顶面代理。
5. 旧横穿起点被真实高石础占据；原始证据保留且明确非法，新增净空起点。测试控制器出生后补一次静止支撑更新，避免尚未建立onSupport的伪卡死。

最终只读复核：12项当时定向测试通过，后产品写手加入晚期异常及重复销毁后为14项。北墙内supportContact的数值查询不是合法站位：脚印半径0.3触及隐藏后缘需中心z≥7.7，而身体半径0.5在中心z>7.5已被原主体阻挡；非法出生明确拒绝，北缘高坠/移动未穿墙。未为此削掉箱体顶面、添加救援面、移动题名或修改公共控制器。

所有结论限于源几何、CPU/控制器和显式用例；没有实机GPU、手机帧耗或整院史实验收结论。
