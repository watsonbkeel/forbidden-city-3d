# 独立复核摘要

只读来源研究与代码审查均由独立执行者完成，不让产品作者用自己的判读代替全部复核。

## 发现及修复证据
1. 全景areaId最初写109，属千秋；改为108，与MASTER/官方API万春vp3348一致。
2. 早期rest几何分配后第二次clone抛错，尚未入pending，泄漏1个克隆。独立注入复现`allocated1/disposed0`；新增红测试后，改为每次分配立即记录，故障下释放全部新几何/材料，原始面和所有权集合不变。
3. source几何守卫补上drawRange和morphAttributes；非默认可渲染状态红→绿拒绝。
4. 真实GardenBuilder使用临时garden_static，最初夹具根假设导致正式运行拒绝；明确传入原构建root、严格限制根形态，并测试合批后保留范围metadata。不是移除身份守卫以消除失败。

最终独审再次运行定向10项，10/10通过；未发现新的阻断项。四向取面、开启叶朝通道侧、千秋隔离、资源析构和纹样非精确声明合理。

独立实看CPU南北内视/正面及槛墙纹理：红下裙/深上棂、浅底窗、绿黄龟背分区生效，无明显倒置或重复贴面。**只能支持局部材料分区**；旧平顶、外门层、原门姿/比例和完整实机状态未验。最终渲染指纹及广泛回归见RESULT.md，不把这些CPU图提升为GPU或整亭实景通过。
