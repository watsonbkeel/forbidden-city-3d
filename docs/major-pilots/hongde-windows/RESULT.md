- 初版横向同心靶形及贯通十字被官图/CPU独审否定，已撤回；红绿覆盖改为纵长空内核与端桥，不能将初版图当作最终图。
- 上下明度初拟顶点色在真实合批中被旧规范丢弃，实际最终合批 RED 捕获；改用两个私有中性材质，不改共享 MergeUtils，诚实增加一个材质网格。
- 独审射线发现 12 个端桥与中横档的同距共面区域，已用真实射线 RED→GREEN 将桥端裁到横档内边缘；保持环形尺寸，接触而非覆盖。
