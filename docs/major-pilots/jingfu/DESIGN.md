# 景福宫南前廊整包

原文 FC-7616C3B4B6，706行；官方236571文字明确五间见方、周廊、南明间门及其余槛窗。自有7411照片仅可见前廊的柱列、分格顶、槛窗与朴素色彩关系。

采用现有Three.js/CourtKit单独南廊模块，`kit.jingfuSouthGallery=false`可回滚。南门保留旧实际净宽及门户元数据；窗扇细分为照片可辨的矩形嵌套格，尺寸/数量为拟合。南柱仅用独立已有竹木色拟合，不对侧后颜色作推论；柱础加朴素肩圈，绝不宣称雕出覆莲。廊顶增加内外边梁、分格顶板、跨廊梁，均在净空上方。苏式彩画不另造人物山水画心。

不改三卷屋顶、任何阶梯/平台、后东门、侧后墙、原内顶/柱/匾及所有行走面。照片没有完整室内，不能当成五福五代堂内景。前廊可通行性用真实控制器沿横向及前后门户验证；新增装饰不创作上层可行走区。

与“重建整栋”相比，这一原区域包证据边界清楚；与仅改颜色相比，覆盖门窗—柱列—廊顶的空间关系。实现方式由实施者选定，继续执行已授权范围，不再请求额外确认。
