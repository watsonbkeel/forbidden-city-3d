## 实现

`ShoukangSouthEnclosureCandidate.js` 在规范寿康正殿默认生效；`kit.shoukangSouthEnclosureCandidate=false` 可明确回到旧南叶用于对比。显式 token 仅用于测试选择，错误 token/重复应用/错误构件一律失败。

先验证规范宿主、5 间轴线、20 叶原始 BoxGeometry 顶点/索引/尺寸/位置/材质、每叶唯一旧碰撞体与独占几何；全部新几何和真实三角碰撞源构造成功后才替换。移除 20 个旧整板和 128 个南侧假菱格；加入 40 个可见实体网格及其一一对应真实三角所有者。格孔不填不透明面板，也不以 broadphase 大盒充当实体。

保留：所有其他可见网格/矩阵/材质、旧碰撞行、楼面与行走面、房间/区域/地图、三条南入口、东暖阁、后门、后窗、南三组阶、屋顶与上部檐下构件、其他宫殿及此前交泰修改。屋顶和上部红色简化构件仍是既有拟合，不能把本包称作完整立面还原。

合批后的 `architecture` 中保存 `structure.southEnclosure`，不会丢失来源、拟合边界、20 叶/40 物理所有者或非当前陈列声明。
