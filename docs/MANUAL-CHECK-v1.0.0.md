# v1.0.0 手动走查清单

> 自动门禁已覆盖碰撞、路线、构建和资源加载。下面这些只有真人在真浏览器里才看得出来，约 20 分钟。
> 打开方式：`npm run dev` 后访问 http://localhost:5173 ；或部署后的线上地址。每项打 ✅ / ❌，❌ 写一句现象。

## B. 6 座高保真内景（10 分钟）——本版重点

每座殿：走到殿门口 → 进殿 → 看宝座区 → 从侧面绕到宝座后 → 出殿。

| # | 殿 | 怎么去 | 要看什么 | 结果 |
|---|---|---|---|---|
| B1 | 太和殿 | 午门北行，过太和门 | 进门时内景出现是否突兀；踏跺能走上几级；宝座台上的象、甪端、鹤、香亭；两侧能绕到殿后 | |
| B2 | 乾清宫 | 过乾清门 | 同上；两侧绕行不卡 | |
| B3 | 坤宁宫 | 乾清宫北，过交泰殿 | 内景与外观是否对得上（门窗位置、墙） | |
| B4 | 养心殿 | 西六宫南侧，遵义门进 | 宝座、「中正仁和」匾、东暖阁；隔断门洞能走过 | |
| B5 | 皇极殿 | 宁寿宫区，过皇极门 | 金龙柱、藻井、宝座 | |
| B6 | 慈宁宫 | 外西路，慈宁门进 | 内景完整，无穿模 | |
| B7 | 任意一座：进殿后迅速退出 50 m 再进 | 内景卸载后能重新加载，不重复、不残留 | |

**重点留意**：内景出现时的闪烁/跳变；地面高度不一致（脚陷进地里或悬空）；墙/柱穿模；走到某处突然被看不见的东西挡住。
