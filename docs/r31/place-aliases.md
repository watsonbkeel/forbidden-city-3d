# Explicit source-backed historical name search

Six historical names are now searchable from four existing cards, using their already-cited official source text: 玄武门→神武门; 奉天殿/皇极殿→太和殿; 思顺斋→储秀宫后殿; 未央宫/启祥宫→太极殿. Search results retain current card names, IDs, coordinates and independent destinations. 皇极殿 returns both that current hall and Taihe's historical-name match; it is not a one-to-one redirect.

Every alias has an explicit source ID and must appear in the same card's source-backed summary/timeline. The 159-card coverage, two demolished historical-gate labels and seven uncertain identity/history labels remain unchanged. Search does not silently index neighbouring-place mentions from all description text.

25 new CPU cases exercise actual input/filter events, collisions between names, canonical aliases, empty queries, historical-site status and return/search/focus state. 94 related behavior checks passed. Ordinary browser/mobile-device acceptance is separately pending.
