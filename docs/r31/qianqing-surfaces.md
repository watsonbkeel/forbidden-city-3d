# R31 Qianqing entrance and connected surface trial

Primary appearance reference: Palace Museum photograph [1523](https://img.dpm.org.cn/Uploads/Picture/dc/1523%5B1024%5D.jpg), locally inspected. Its date and temporary display configuration are not independently dated. No external photograph is redistributed in production.

The old optional incense pavilions were solid gold boxes with two pointed roofs and large pale bases. The official view instead shows blue enamel framed compartments, one broad curved roof and a dark stepped base. A hall-local 8-sided interpretation replaces only those two objects. Other halls' shared ornament generator is unchanged. Decorative flowers and sculpted feet remain simplified. The 1.6 m height and 1 m maximum width are photo-relative trial proportions inside the old envelope, not measured object dimensions.

Important unresolved layout: the photo places these objects outside the throne platform; the inherited model centres (+/-2.5, local z2.1) and elevation .70 remain unchanged because no registered dimensional placement supports moving them without revisiting circulation. This is not a complete restoration.

The indoor square-brick module stays .64 m, but the illustrated joint narrows from .05 to .008 m and tile shading narrows from .82–1.18 to .96–1.04. Dark palette/roughness are visual trial parameters. The permanent fallback uses the same module and half-tile X origin. One existing front-court terrace deck receives a private pale, low-contrast stone material; no floating surface, height change, new collider or global texture mutation is introduced. Door thresholds, outdoor ground and indoor bricks remain distinct. The outdoor module inherits the old six-metre texture scale, not a new survey claim.

Costs before final whole-scene measurement: optional layer 8240 → 9024 visible triangles (+784), 7 → 8 material batches (+1). Permanent material split adds two batches without adding geometry, and two 256² RGBA textures with mipmaps consume about 0.667 MiB. All additional resident geometry/materials/textures count against the existing whole-scene baseline. Original R29 asset retained byte-for-byte. Lights, exposure, anchors and all 27 optional navigation proxies stay unchanged.

CPU: asset/source/profile hashes; exact mesh signatures; unchanged red columns and bases; exact old 27 proxy bounds; upward floor normals; unique private disposable textures; malformed identity rejection. Actual same-camera image comparison and final combined budget/route checks are separate gates, pending at implementation time.
