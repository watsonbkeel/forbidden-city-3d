# R23 保和殿前立面候选

## 可见变化
依据故宫博物院正面照片与1941年立面，外侧四个窗区增加灰色下墙；前门及窗区改为专用红框暗棂图集，去除误用的金色纹理。中央四分门叶、柱联与全部通道保持。下墙比例0.22、厚度/投影、色值和纹样均为照片估计；灰色下墙材质未确认，不称精确测绘或装饰摹本。

## 实际画面
外部R22/R23各一张、R23入口一张均保存并查看。外部及入口分别核对同机位、视口、70度FOV与正午条件，图集无明显翻面或缺面。外部机位经未变地面支撑由请求y10.7落至9.7，两版相同。两次冷浏览器32.71秒与50.76秒结束、清理通过、0资源错误。它们是受控定点照片，没有据此新增原生通行声明。图集仍有平贴感，屋架、天花重复、后亮窗和宝座仍有简化。

## 程序及通行证据
针对性首批142项中141通过；唯一失败为新历史测试误以为旧libBox几何带索引，修正测试计数后该文件25/25通过。117项已有/当前受影响检查通过，原15项定点检查也通过，各批重叠不相加。历史适配仅反向还原精确源字节/几何身份，负向覆盖未知、缺失、重复和局部还原，不改变产品或路线驱动器。

2487碰撞体、120步面和七个其他分组与独立冻结R22逐项一致。保留R22的368组受控路线及三处前门原生往返证据，没有重跑无变化的完整矩阵，也不把旧记录改称R23新实测。北侧原生长路线与真机手机缺口仍在。

## 总场景与性能
常驻163网格、188075三角形、18296468几何缓冲字节，含两档LOD；相对R22增加1网格、4三角形、384字节、1材质和1纹理。新图集1024×512，GPU总内存未实测。只剔除了完全被地面/下墙遮住的底面，外露侧面、顶面、阴影包围和碰撞保留。

原六机位×60帧、原历史基线及10% calls/tris阈值未改，结构预算通过。太和机位961348三角形，原阈值961607.9，余量259.9。SwiftShader平均0.97–1.47 FPS，6点有流畅度警告。历史非同时基线、正午与原固定光照差异及其他管理空白浏览器均披露，不承诺真机流畅。
