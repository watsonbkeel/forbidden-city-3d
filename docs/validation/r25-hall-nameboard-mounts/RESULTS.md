# R25 三殿外匾挂位修正候选

故宫官方照片显示，太和殿、保和殿、乾清宫南向殿名匾位于重檐之间。原通用实现将三匾放在下檐内的门头处。本轮仅按既有屋面实际包络修正三块外匾的挂位；殿内匾、牌匾尺寸、字体、材质、屋面和通行保持。

## 实际画面
三处均保留R24与R25同机位、同1180×757画幅、70°FOV、北京正午的前后实图，共六张。两次冷启动分别76.63秒和71.63秒，0资源/页面错误，清理确认通过。三匾已从门头移到重檐间，图中无可见屋瓦穿插。保和与乾清可观察正面整体；太和前景御阶遮住低处，只认可上部外匾挂位，不把此图称为完整正面或原生游览验收。

当前专项6/6、严格保留性9/9通过。74文件受影响图谱首轮1237项中1221通过，16项历史全场景断言仍期待旧匾位；11处消费者改用锁源字节的便携R24夹具后，相关130项通过。旧断言、未知/重复/局部还原等反例保留，102个既有夹具文件原字节不变。各批重叠，不能相加宣称新增覆盖数。

初版8571在浏览器启动前发现材质名只接受轻量测试名，未接受真实TextureLibrary的_material后缀；e383已修并补实际名与未知名反例。没有把初版启动失败改称通过，因为它未启动浏览器。

完整场景除三块匾的矩阵与挂位说明外，几何、材质、网格顺序及其他矩阵不变；2487碰撞体与120步面逐项相同。保留R22的368受控组合及三前门原生往返证据，本轮没有重跑长路线，也没有真机验收。

## 总量和性能
常驻163网格、188027三角形、18291860几何缓冲字节，包含两档LOD；新增几何、材质、纹理和导航均为零。流式场景另计入实际机位。原六机位×60帧和历史10% calls/tris门槛保持，结构预算通过。SwiftShader平均1.00–1.56FPS，6点流畅度警告，不能承诺未测试设备流畅。
