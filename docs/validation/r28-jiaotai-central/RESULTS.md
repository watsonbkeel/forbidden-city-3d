# R28 交泰殿中央内景候选

## 实际可见改动
依据故宫博物院现存照片和建筑文献，将通用平面圆盘改为一间尺度的方形、折角、多边形与圆形逐层藻井；保留中央镜与盘龙示意。屏后红色背景分为上部金饰区、下部铭文区，米色“無為”小匾置于上部区域。四角闭合并检查屋面净空。官方图可支持拓扑及相对比例，所有新增米数、雕饰与字体均为模型拟合，铭文尚未可靠转录，当前留空。宝座仍为旧通用简化形体，不能称完整实景复原。

## 实图
R27同视口同机位仰视一张、R28总览/仰视/屏风三张均已实际查看。方圆递进、镜及后部层次可辨，形体较旧版改善；盘龙仍明显是简化盘绕管状，纹样平贴，空铭文及通用座椅仍影响真实感。受控视角仅作图像比较，不计原生游览。

## 程序、通行与资源
40个受影响文件最新结果去重567项通过，非全库全测。2489碰撞体、120步面及其他分组与R27逐项一致；屋顶外表面不变，开口只修交泰殿隐藏内底面。历史适配先绑定完整源/场景身份再精确逆向还原，保留初次失败及负向测试，没有放宽门槛。
普通页面原生M打开地图、W保持5秒实际前移3.923889米，地图打开期间移动有效，随后M关闭。240秒上限终止并清理成功，0页面/资源错误；交泰卡片、当前版原生入殿及四门全绕行未完成。R27旧前门进入证据可追溯，但不冒称本版新实测。真机手机未验。
