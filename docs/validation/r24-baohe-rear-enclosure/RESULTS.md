# R24 保和殿前后立面合并候选

本候选包含此前R23的红框暗棂、外侧槛墙窗区及已有日夜/直升机等功能。本轮依据官方现代后部照片与明确标注背立面的1941图，将后面六格误套的金色门窗改为两翼连续红墙，中央三处既有开口保留。没有为照片里的闭门姿态关闭游戏通道。

## 实际画面与真实修正
保留同机位R23基线与初版54ef图。初版0.9m墙在四根锥形柱脚处有约0.01387m突出，形成实际可见黑缝。柱脚不删，采用现有1m下墙包络覆盖；修后838b同机位实际图黑缝消失。三张照片都保存，原缺陷不改称通过。三次冷浏览器约27.71/29.70/34.12秒，0资源错误，进程和端口清理通过。固定照片不作为新增原生通行证据。

## 程序和通行
修后79个受影响文件1361项中1360通过；唯一失败是新增负测把源文本1写成1.0，改测试锚点后相关66项通过。各批重叠不相加，不重跑无变化全库。便携历史夹具锁完整源字节、唯一反向片段、场景/材质/导航身份，保留未知/缺失/重复/局部还原反例；100个既有夹具原字节保留。

2487碰撞体和120步面与R23独立历史构建逐项相同。前门、六扇既有后门、屋面、侧墙及七个其他场景分组不变。R22的368受控路线及三处前门原生往返保留，不声称R24重跑；此前北侧长路线与真机缺口继续披露。

## 总量和性能
常驻163网格、188027三角形、18291860几何缓冲字节，含两档LOD；比R23少48三角/4608字节，无新网格、材质、纹理或导航。所有流式场景计入实际机位预算。原六机位×60帧与历史10% calls/tris门槛保持，结构预算通过。SwiftShader平均0.96–1.52FPS，6点流畅度警告，不承诺真机流畅。

## 证据边界
连续红墙拓扑有现代照片与历史图双重依据；1m厚度、精确色值、当前后门扇数/开角与摄影日期未核。屋架、材料、宝座仍有风格化简化。121静态文件冻结核验，相对base ./。源码独立分支，main和公开Pages未改。
