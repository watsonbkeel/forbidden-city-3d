## Implementation boundary
The permanent layer owns the new five-panel central setting; the optional S asset retains floor, six red columns and six existing ornament forms without its obsolete seven-screen/raised central platform. Its 12 rail colliders and 15 step walkables align to the new display and remain inside the inherited permanent excluded core. THE THREE STEP FLIGHTS ARE VISUAL DISPLAY DETAILS, NOT A NEW WALKABLE THRONE ROUTE. Existing two lateral loops are retained.

The actual GLB SHA256 is checked against the registry in tests. Runtime installation also binds every visible mesh's exact transform, typed attribute/index bytes and material values to a generated external manifest; marker metadata and triangle counts alone are not trusted. Equal-count vertex mutation and transform mutation must fail before registration. These lightweight fingerprints are integrity checks, not a general cryptographic authenticator for untrusted assets.

The old compressed asset is retained byte-for-byte for rollback. The new asset uses uncompressed Blender 4.3.2 export: 599,584 bytes versus 233,300 bytes (+366,284). Visible S geometry is 8,240 triangles/7 material batches versus 33,240/10 previously. Both permanent near/far LODs are counted resident (1,986/192 triangles), not hidden from the scene budget.

## Near-view rendering correction
At the ordinary close view (x=0, eyeY=3.86, z=315.999363), c450 showed a large black screen-space region. The original failed captures remain preserved. A bounded fixed-view diagnostic reproduced it with SSAO off and separately with batching off. CPU inspection identified 10 collapsed cap triangles/30 zero-normal vertices across the five perforated screen crests. f0be9fc removes only these zero-area faces. The same exact camera, time, lighting and geometry settings then produced a clear complete view in one cold capture (44.747s active, 0.119s cleanup, no recorded HTTP/application error). Both comparisons used a forced1180×757 canvas/FOV70, although outer browser windows differed. This is a local qualitative pixel check, not proof for all GPU drivers or full performance.
