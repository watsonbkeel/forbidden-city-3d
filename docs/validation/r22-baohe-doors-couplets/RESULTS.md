# R22 保和殿前门与柱联候选

## 可见改动与依据
中央三处开放前门改为四分构成：两侧外扇正置，中间两扇向内折开。十二片可见门体均有同形同位碰撞。柱联按故宫博物院官方文字及左右实物图自绘黄底黑字字库图集。官方出处与不确定项见 `docs/evidence/r22-baohe-front-and-couplets/`。

门叶厚度、90度开合姿态、柱联尺寸和柱行注册仍为估值。原通用金色门纹理明显偏离实景红框暗棂，外侧槛墙窗区仍待改；屏风宝座与标准字体也有简化，不称精确复原。

## 实际画面与通行
与R21相同的两机位、70度FOV、画幅和正午光照观察了前门及柱联，1张入口图片保存，另1张近图仅在工具结果中观察，未补拍。
三个前门均完成原生键盘往返，开地图后实际继续移动8.58m。起点为受控设置，只证明这三处局部通道；不是全园原生游览。

同一冻结产品重新完成33固定路线×4及59自动路线×4，共368受控组合，全部到达、无穿底。自动请求/favicon.ico的单个404保留，未见应用资源错误。测试路线修正不改变产品移动行为。
