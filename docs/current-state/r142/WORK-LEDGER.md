# R142 御花园：源可见的澄瑞亭南侧短凳细部

状态：产品已固定 ae1786f，目标独审/标准集合/真实资源成熟/生产构建检查完成；累计R141。只计真实落地部分，不把G区29对象或堆秀山全部宣布完成。

## 锁定对象与依据
- FC-4610835E3D 澄瑞亭；官方2020上传图 s5e98108dce16c.jpg / s5e98108dd6faa.jpg。已由实现者和独立资料审查实际看图；上传时间不等于摄影时间。
- 主亭南中口两侧短凳有红弯曲背靠条及灰石卷云轮廓端头，现代码只有平凳和矩形石板。前抱厦凳无同样背靠，必须保持。
- 新几何是照片有界拟合，尺度/条数/雕刻细线未测绘；不声称原雕复刻。不补看不清细部。

## 实施边界
1. 仅澄瑞主亭南端两短凳；浮碧亭、北端及前抱厦不变。
2. 保留凳板、中央人行口、原台/水池/阶/屋面/全部walkable。
3. 若替换旧矩形石板，旧渲染和对应碰撞一起替换，不保不可见旧墙。新轮廓实体闭合且碰撞取真实几何。
4. 通路/接触如果需新控制器例外，不直接放宽：优先源几何不侵占原门口并验证；未知则不纳入。
5. 澄瑞全亭/全G未验；堆秀山先前五失败方向不重开微调。

## 先失败后实现的必要检查
- 目标身份守卫、南两组新几何存在，北/前抱厦/浮碧逐字节不变。
- 闭体正体积/接缝边配对；实物空间中口净宽、与旧柱/凳/地面关系。
- 所有新碰撞有对应真实面，不生成虚拟支撑；旧walkables完全一致。
- 完整园区10/30/60Hz双向走/跑与局部凳前绕行、完整中央过亭通路。
- 材质几何所有权/释放一次；实际图像成熟高低质量资源账；同视角baseline/candidate图审。
- 标准失败集合、生产构建身份与源码指纹；真实GPU/手机未验保留。

## 实做与安全接口修正
- 原南两石板替换为红色曲背及带多级外鼓/内收的石端轮廓。9条/侧与两支脚间距均模型拟合，精雕未复原；旧凳板、北侧、抱厦、浮碧逐字节保留。
- 初版普通TriangleSupport圆脚支撑造成空中落曲件不能收束；保失败日志。20新曲件接入现有精确方脚印20专属ID；未改Collision/FirstPerson通用算法。
- 曾尝试将旧整台顶注册为新surface，导致中央阶回归，明确撤销，未发布。最终用ChengruiSeatSupport专属工程floor绑定：原主/抱厦所有有符号position/normal/UV/index及变换校验，实时旧walkable缺失或变形不返回支撑；只两凳附近，域外立即null，不注册整台collider、不新建walkable/救援平面。它是明确新增局部安全分派，而非宣称所有物理完全不变。
- 原旧碰撞注册除两南石板外不变，新增28实际实体注册；旧所有walkable不变。域外中央进亭运动完整帧与冻结R141一致。
- z−4.30初态触旧柱的失败已在冻结R141重现，保原负证据；不是这次修复。新石端初态z−4.45、曲条z−4.46均按真实几何避旧柱/上横木；8个10/60Hz闭环实际落稳airborne=false、走离、回旧抱厦台面，全帧原.5半径/1.7高身体独立三角clip无正深穿透。过深直冲抱厦柱的旧探针不宣称已通；最终按可见通路提早转向/停止，不改变控制器速度。
- 60全静态世界两向走跑10/30/60Hz中口及两侧前后路线通过；不是全宫/GPU验收。
