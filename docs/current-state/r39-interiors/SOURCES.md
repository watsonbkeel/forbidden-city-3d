- 长春宫官方建筑介绍：https://www.dpm.org.cn/explore/building/236436.html ，支持中央宝座、帘罩分界及北侧尽间带罩炕。
- 长春宫中央照片：https://img.dpm.org.cn/Uploads/Picture/dc/1454%5B1024%5D.jpg ，支持低深色座具、脚踏及五扇屏风的局部轮廓；拍摄日期未知。
- 长春宫西次间照片：https://img.dpm.org.cn/Uploads/Picture/dc/1456%5B1024%5D.jpg ，作为开放木框和帘幔的参考，不将镜头方向当作精确测绘。
- 翊坤宫官方建筑介绍：https://www.dpm.org.cn/explore/building/236517.html ，明确中央东侧喜鹊登梅、西侧藤萝松缠枝落地罩，次间和梢间以隔扇分开。模型只做开放木框和隔扇轮廓，不声称复现原雕刻。

两栋均保留既有模型外包与等分柱距。木材颜色、罩高、炕宽、屏高和通道宽为模型拟合；门扇开启姿态服务可进入参观。翊坤中央通用宝座形制仍待核实。长春照片不能证明整个宫殿在某个历史年份的完整库存。

太极殿来源 https://www.dpm.org.cn/explore/building/236475.html 记载两类罩，但本轮未取得足以确定其东西映射的可靠依据；不以句序推断方位，暂缓这部分几何更新。
