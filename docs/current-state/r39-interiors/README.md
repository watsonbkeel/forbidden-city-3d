# R39 逐栋内外复原：第一批与覆盖清单

目标是逐栋核对所有有名称的宫殿和房屋的内饰布局及外观，不把同一默认殿堂复制到各处。本批是这个持续计划的第一批，不是全故宫完成验收。

## 覆盖不等于完成

当前模型独立枚举出 89 个有名称的建筑身份：83 个已有地点卡片对应建筑、恒寿斋和五座花园亭。另有门、历史门址、地区标签与无名附房，不混入这 89 个分母；它也不是现实故宫全部建筑的普查数。既有 159 个地点及七项身份不确定记录保持不变。

`data/architecture/building-fidelity.json` 分别记录每栋建筑的内饰、外观、具体官方事实、尚未实现部分、尺寸拟合及验收状态。地点卡片使用原有“本版模型说明”展示简短状态，不增加新导航点。通用宝座没有因为概述未提及就被一概删除：多个宫殿确有宝座依据，但具体形制仍须逐栋核对。

## 本批实际改变

- 文华殿：前殿圆形通道屏风增加照片支持的横棂和较宽框柱，不封堵唯一通道。穿廊两侧书画承托板改为朝参观通道倾斜并带低挡边，前殿低展柜与主敬殿水平承托保持不变。仅以 2026 年 9 月第一期全景的设备为参照，不虚构第二期作品位置或画面。
- 奉先殿：移除四块通用朝会宝座几何及其碰撞。它是皇室家庙，不能用一个在位皇帝朝会宝座概括祭祀神位。祭祀内饰尚未复原，留白不是“历史空殿”。原有外壳、地面、入口和地图记录保留。
- 景仁、承乾、钟粹、永和四处后殿，以及储秀宫后殿丽景轩、咸福宫后殿同道堂：按官方说明改为五间硬山顶。不是只改枚举名称：六处独立启用齐平山墙/瓦坡端部，其余屋顶仍用原参数。原来按宽度推算的七间改为五间，因此柱网和相应碰撞有意改变；既有外包、坐标、中央入口与地点名称保持。四处东路后殿不因此变成新的地点卡片。

- 长春宫：中央与次间之间采用开放的帘罩框架，北侧两尽间加入有罩炕体；中央改为官方照片支持的低深色座具、脚踏及五扇屏风轮廓，不复制图绘或虚构寝具。
- 翊坤宫：中央东西分界采用木质落地罩框架，外侧分界采用隔扇轮廓，与长春的帘罩布局区分。官方文字记载的两种雕刻题材仅保留为依据，未声称已重建原作雕刻。中央宝座仍是有座位依据、具体形制未核的通用占位。

长春和翊坤的新分区是模型导航区，不是历史房间总数。罩口和隔扇开启位置为参观通行拟合，不代表历史门扇姿态。太极殿两种罩的东西对应尚不能可靠确定，因此本批保留原模型，不按文字顺序猜测方位。

## 证据和精度边界

- 官方文字支持“几间、哪种屋顶、哪个房间或构件关系”，不自动支持模型米数。保留外包与等分柱距均为模型拟合；长春宫论文的柱头中心距不能直接覆盖当前外墙/屋顶宽度。
- 指定照片、历史布置、原状陈列复原与当前展览不混为一个时间层。照片网址中的上传日期不是拍摄日期。
- 文渊阁新找到的照片明确属于第三层，不能移到目前可进入的底层。此批没有据此填入书柜或御榻，也未伪造第三层楼梯。
- 太和殿、乾清宫既有专属核心与储秀宫既有隔断、R38 树木及太和门南侧双梯保留。飞机上下机、附近地点菜单、地图和路线属于回归保护范围。
- 无实际 WebGL/GPU/原生手机验收。本批自动测试只能支持所列几何、路线和资源行为，不能证明摄影级或测绘级 1:1。

## 后续批次

继续按清单推进不同宫殿的前后廊、门窗、天花和家庭分间，复杂多层建筑另立通行与楼层方案。多重屋檐不等于楼层，建筑名称也不能授权凭想象填家具。R39 冻结后继续 R40，不把第一批发布视为整个任务结束。
