# R44 寿康宫正殿局部布局与陈列

本批实际改变寿康宫正殿一处建筑，不包括其后殿。通用七间厅堂改为有文献比例依据的五间柱轴，建立前廊、南面三处四叶门、北面中央四叶门和两端暖阁的简化分区；通用金色宝座替换为有匹配照片及单件尺寸依据的低木宝座和三屏风。没有为东暖阁增造佛像、供器，也没有为西暖阁增造牌位或神龛。

## 来源和时间

- 建筑说明：https://www.dpm.org.cn/explore/building/236448.html
- 2005年《故宫博物院院刊》第5期第150页修缮研究：https://www.dpm.org.cn/Uploads/File/pdf/ff/8e/7f/ff8e7f5fee79130164656141fe26d725.pdf
- 林姝《尊养兼隆——从寿康宫家具看崇庆皇太后》，《紫禁城》2018年第12期，第27至29页：https://www.dpm.org.cn/Uploads/File/2019/11/30/u5de26f7031b50.pdf
- 官方2020年陈列介绍：https://www.dpm.org.cn/classify_detail/253198.html

2018年正殿内景照片有明确图注及“慈寿凝禧”匾额匹配。相关屏风、宝座为2015年恢复原状陈列准备期间找回并重设的物件，不能说成未经改动地一直原位保存，亦不代表2026年完整陈设清单。拍摄时刻未明确；PDF上传路径不是拍摄日期。2005年图1是院落修缮范围图，不是室内隔断测绘平面。

## 已实施的关系

- 五间宽度比例13.5:13.5:15.5:13.5:13.5来自文献。归一到既有26.9米模型宽度后，约为5.225、5.225、5.999、5.225、5.225米。总宽与17.4米进深仍是模型拟合，不做历史尺制的直接米制认证。
- 前出廊采用2米拟合内退。南面明间、两次间均有可通行的四叶门，两梢间为四叶槛窗；北面明间四叶门、其余四间为窗。北侧非中央窗的叶数没有额外假定。简化菱格不等于准确复刻三交六椀做法。
- 暖阁在两梢间。东为负X，西为正X；边界由间位推定，通行开口位于局部Z−1.2、宽2.6米，是明确的游戏通行拟合，不能称为实测古代门洞或已核实隔断样式。只登记三个观览导航区，不声称全殿历史上只有三个房间。
- 原近似屋顶、台明、前阶和原有可行走面保持，后阶是新建的通行拟合。门扇打开姿态不代表现场开放许可。
- 真实人物绕行宝座、屏风两侧到北门。首轮测试发现原拟合路径撞到可见后门折扇，保留门扇和单件尺寸，调整宝座、屏风拟合位置至局部Z4.1、5.0，后侧横向通路Z6.3。此举是通行拟合，不是历史位置考证。

## 单件测量与拟合分别处理

2018年第29页刊载宝座单件高98、长117.5、宽84厘米。本模型对应木器外包尺寸0.98×1.175×0.84米，不把平台、坐垫、脚凳计入此测量。第27页给屏风高310、宽319、厚32厘米；0.32米是整件屏风厚度，不是底座单独厚度。屏风三片关系有文献和照片支持，但各片比例、阶梯外轮廓和纹样仍为简化拟合。

平台高0.12米、纯色坐垫、脚凳、物件位置及框格细部均另列拟合。没有把画面透视当房间测量，也未复制海屋添筹缂丝、嵌玉花卉或整套仪仗陈设。进深三间不等于三道内部实墙，本批没有增加这种通用隔墙。
