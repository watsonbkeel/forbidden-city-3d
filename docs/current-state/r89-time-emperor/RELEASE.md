# R89：时间设置、皇帝路线与 CPU 热点优化

## 累计版本与范围

在冻结 R88 基础上累计开发，保留 R88 的建筑、内景与既有功能。另保留用户已合并 main 的 README、llms.txt、public/llms.txt 文档修订。此记录不宣称 R89 已上线；开发分支上传、main 合并与公开部署分别核验。

## 本版变更

1. 时、分分别输入，点击应用或按 Enter 生效；只接受 00–23 和 00–59 的整数，空值、小数、越界值拒绝。保留滑杆和恢复现实时间。
2. 时间输入焦点隔离；关闭设置、Esc、继续游览、地图模式恢复均释放旧输入焦点。飞行中编辑时间清除旧按键，但不擅自下机或获取鼠标锁。
3. 皇帝使用实际玩家 `PLAYER.SPRINT_SPEED = 12 m/s`。逐路点消费位移预算，每段不超过 0.15 m，保留静态墙体与玩家碰撞、可行的贴墙滑动、阻挡等待和恢复。不是瞬移。
4. 乾清宫真实 S 内景由通用地形采样改为固定永久地面 y=2.16，消除错误 y=2.72 的 0.56 m 错位。最终进座路线在中线跨过真实栏杆后再侧移，不移除栏杆。
5. 南部复杂水域碰撞（内金水河及武英/文华支流）增加缓存的保守多边形包围盒。仅严格不相交的脚印跳过原始几何细算；边缘仍走原算法。不是外护城河简化，不减少人物、不关闭碰撞或灯光。

## 验证结果与限制

- 本版和设置联测 65/65 通过，包括真实乾清 B/S 入殿、往返、阻挡、流加载和时间反跳。
- 完整世界 B、养心 S、坤宁 S、皇极 S 四种变体全部通过：108 人物、28 个独立占用床位、21:00/06:00、跨午夜、玩家阻挡、卸载重载、低/高质量预算保留。
- 独立审查 UI 24/24；真实乾清 B/S × 60/10 Hz 往返通过。受控 CPU 路线约 32 秒单程；不能当作任意设备帧率保证。
- 水域优化测试 2/2 通过：冻结 R88 几何实现比较覆盖河岸边缘、包围盒边缘、桥缘、多种半径及随机脚印。108 次远处查询原有 2,640,384 次顶点字段访问，优化后为 0。
- 原始 `npm run test:current-state`：1290 项，1127 通过、163 失败。R88 基线 1129/161。新增两项失败是乾清 JSON 的 R32/R33 逐字节身份断言，被本版显式地面修正打破；没有改松历史断言。新增 `r89-source-contract` 绑定原件 hash 并证明只改了 floor 字段。完整失败名称与差异见 `failure-comparison-final.json`。
- 相关四个 shared-loader 文件 83 项，80 通过、3 个既有失败：Cining 旧 optional-proxy 约定、Taihe 旧资源子路径约定、其他厅纹理处置约定。未将这三个红项报告为通过。
- CPU 测量和回归不是 GPU、手机、画面或全游览路线的实机验收；间歇卡顿仍可能存在其他渲染/资源加载原因。

## 证据

专项结果在 `reports/r89-time-emperor/`。`performance-paired.json` 为同一全世界、同一 R89 路线算法下只替换旧/新水域判定的成对 CPU 测量。原始诊断与并行负载下的初次 postpatch 测量只作定位，不作为最终性能结论。独立审查见 `independent-review/`。

保留既有占用检测后的离散坐下/站起姿态转换，不声称新增连续登座动画。自动测试产生的历史报告路径副作用已另存到 R89 后恢复历史原件。

### 成对性能结果

全场景 108/108 人物已绑定，每组预热 200 次，测量 1200 次，状态复位在计时区外。60 Hz 步长 p50 11.74→3.36 ms、p95 13.63→4.21 ms、p99 16.09→5.73 ms；10 Hz 步长 p50 12.75→3.71 ms、p95 14.17→4.43 ms、p99 16.16→4.84 ms。只比较同一 R89 路线中旧/新水域算法的 CPU 耗时，不把旧版皇帝速度差异或 GPU 帧时间混入结论。单次尾延迟受 JIT/GC/主机调度影响。
