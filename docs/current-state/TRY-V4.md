# V4 体验方法：弘义阁与体仁阁

这一轮把太和殿广场两侧的弘义阁、体仁阁分别按故宫博物院公布的测绘资料重建柱网和竖向层次。两阁的下层九间、上层中央七个门区、外围24根方形廊柱，以及楼板、下檐、上檐、主脊，不再用一个通用殿堂缩放代替。

依据为2006年发表的测绘研究及博物院建筑介绍，不代表已完成2026年所有立面、细部和开放情况的核验。每阁的已测、推导、暂定尺度分别见[弘义阁建筑卡](cards/hongyi.md)和[体仁阁建筑卡](cards/tiren.md)。

## 已构建包

解压 `forbidden-city-r3-v4-playable.zip`，进入有 `site` 文件夹的目录，运行：

```sh
python3 -m http.server 8080 --bind 127.0.0.1 --directory site
```

Windows可用 `py` 替代 `python3`。打开 `http://127.0.0.1:8080`；Ctrl+C停止服务。不要双击 `site/index.html`。游戏纹理随包提供，不需要联网获取。

## 源码

在新目录克隆：

```sh
git clone --branch feat/r3-v4-surveyed-pavilions --single-branch https://github.com/watsonbkeel/forbidden-city-3d.git forbidden-city-r3-v4
cd forbidden-city-r3-v4
npm ci
npm run dev -- --host 127.0.0.1
```

打开终端显示的本地地址。合并仍由项目拥有者决定。

## 建议比较路线

按M打开地图，点击建筑文字选择目的地；WASD/方向键行走，鼠标或Q/E转向，Esc打开设置。地图传送可能落在建筑前的低层台面；先由中间石雕带旁的台阶下到广场，再从地面比较。

1. 到太和殿广场西侧的弘义阁，面向其朝东正立面。从地面观察高台、下层窗墙、腰部支承层和上层环廊。原版本的高大单层门墙已被分层结构替换。
2. 从正面中间石雕带任意一侧的32级台阶登台，再走到中门。台阶宽度、踏步进深和部分台基边界仍是有标记的工程暂定值；中间石雕带不作为玩家登台捷径。
3. 在台上回看广场，再由另一侧台阶下行。留意与侧面现有庑廊之间的高差：南侧台阶、北侧礓磋与邻廊标高尚未完成统一测量接合，暂设可见的安全阻挡。它们不是对现场栏杆或游客开放路线的复原声明。
4. 到广场东侧的体仁阁，面向朝西正立面，用同样路线比较两阁。两阁有各自的柱网和标高；体仁阁并非把弘义阁镜像后等比缩放。
5. 继续体验V3的协和门、熙和门、景运门、隆宗门三条门道及V1的中和殿、交泰殿、乾清门。此前的画质按钮修复保留。

上层环廊用于结构观察；本轮不把未核实的内部楼梯或上层区域作为实际游客路线开放。两阁原有全局中心位置未移动；小地图轮廓按实际生成的台基范围绘制。

## 限制

测绘柱心距不等于墙外皮、檐口外缘或台基尺寸。部分屋面边界、廊地外坡、栏板细节和台基接口仍为明确标注的近似；来源中弘义阁腰层正面尺寸链的矛盾未被当作确定测量使用。神武门11m定位分歧仍待统一坐标依据，见[定位核查](SHENWU-POSITION-REVIEW.md)。全宫其他对象仍需逐项复核。
