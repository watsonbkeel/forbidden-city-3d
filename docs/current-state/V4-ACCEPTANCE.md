柱心距、墙外皮、外廊柱线、平台外缘和檐口边缘分别处理；上层主体有九段柱间，其中中央七段为门区，两端封闭，不把整个上层简单缩成下层宽度的7/9。体仁阁正面4mm不对称和弘义阁前后不同柱网均保留。每阁24根外廊方柱与主体圆柱分开，楼板、廊地、栏杆、下挂琉璃带、腰层短柱和承梁分别生成。

独立核查修正了两个容易被外观遮住的问题：腰层柱下新增明确的暂定承梁传力路径；正脊按图中脊帽顶而非瓦面交点校准。实际中央射线为23.90999985/24.05999947m，瓦面峰值位于其下方。弘义阁图11的脊帽端点明确；体仁阁对应端点依据图10分离引线的对齐及同文并列图作解释，图12未另行复述该标注。当前低细节屋顶省略正吻，不能把包围盒高于瓦面的部分误称为已生成的正吻；概述中的23.8/25m仍是测量端点未明的另一组数字，没有用来硬拉模型总高。

完整来源、尺寸链和状态见[弘义阁建筑卡](cards/hongyi.md)、[体仁阁建筑卡](cards/tiren.md)。博物院照片和论文只作研究，没有放进运行包；没有生成图片冒充实景依据。

## 台基、路线和局部接合

- 两阁63.3×27.5m台基采用论文对两阁共同的约数描述；偏置、精确边角和体仁阁台面高程仍标注暂定，不冒充两份独立实测台基图。
- 正面两路实际32级台阶分别可以上下，中央约2.3m石雕带有与形体一致的斜面碰撞，不作为玩家捷径。踏步进深和单路宽度暂定。
- 南侧台阶、北侧礓磋只接到暂定2.8m平台及可见安全阻挡。与现有低位廊道的完整标高联测尚缺，未将整片廊道抬高。这些阻挡不是现场2026年栏杆的证据。
- 只切开由两阁封闭后墙实际替代的狭窄墙段，不按整个平台宽度开洞；只缩短四个直接相接的廊端。前门开启是游戏体验选择，上层没有新增未核实游客通路。
- 原51条自动路线身份保留，50条非两阁路线的完整点序列与V3一致；新增弘义阁进入路线及四条正面双路台阶往返，合计56条。原33条固定路线不变。
- 生产传送逻辑保持不变：两阁的安全落点在3.7m台面，实际下层室内地面3.8m。观察完整立面时先沿前方台阶下到广场。

## 保留结构的渲染修正

初次冻结曾真实触发两个原性能门禁失败：午门207次绘制，太和殿972,273个提交三角形。没有放宽原阈值或降低测绘结构精度，而是追踪实际主通道与阴影通道提交，定位重复隐藏面和楼板共享材质阴影责任。

- 只删除完全被另一真实、不透明封闭长方体覆盖的三角面以及退化面；不凭任意包围盒把屋顶、孔洞或透明材料当成实体。外向探针保留重合外皮，负缩放、部分覆盖和不支持几何均有独立测试。
- 两阁合计减少5,576个基础三角形；弘义阁19,084→16,374，体仁阁19,804→16,938。原构件节点、柱栏/台阶数量、剩余顶点/法线/UV、完整测绘构件边界、碰撞体、可行走面和小地图资料保持不变。
- 楼板仍为同一实体。上表面使用原砖铺地材质接收阴影；侧面和底面使用已有砖体材质承担实体投影，避免一个共享地面批次被整体设为投影。侧面/底面的材质变化单独近看核查，不称逐像素完全不变。
- 5,430条独立旧版/优化版外部射线的首交距离和存续UV一致；21项对抗性检查覆盖镜像重合、部分遮盖、旋转体、无效遮盖体和共享资源释放。最终主通道/阴影提交总量仍以原六机位浏览器实测为准。
