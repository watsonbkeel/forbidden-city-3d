## 实质问题与修复范围

ZoneBase 仍有真实中央佛单独预览入口。底层真实模型工厂清理抛错时，旧会话顺序收尾被中断，残留 READY、隐藏fallback和WeakMap占用，阻止同一宿主重新进入。这不同于R375已修的工厂内部“一个资源抛错导致其余资源未尝试释放”。

当前会话修复分别尝试自有模型detach和dispose，恢复原fallback可见性、清presentation、设置终态并释放本会话claim，保留原清理异常。重入dispose不得重复释放，旧会话迟到结果或发布回调不能改写新会话所有权。所有错误保留原始对象供诊断；某释放监听抛错不意味着其内部资源已成功释放。

真实工厂红绿测试位于 `tests/r379-central-session/session.test.mjs`。累计保留R378奉先门精确owner准入、三工厂清理与其他前版修复。当前CPU准备结果不等于已通过正式CI，最终以精确提交对应检查/制品为准。
