# 中和殿：R3 结构修订

## 依据

- [故宫博物院：中和殿](https://www.dpm.org.cn/explore/building/236464.html)，2026-10-14 核读。
- [官方正面照片](https://img.dpm.org.cn/Uploads/Picture/2020/07/03/s5eff05cd7866d.jpg)，本轮实际查看像素；拍摄日期未知。
- [Balon Greyjoy 实拍，2020-01-10，CC0](https://commons.wikimedia.org/wiki/File:20200110_Hall_of_Central_Harmony-1.jpg)，实际查看外廊和内围护关系。

文字支持内殿三间见方、四面外廊、单檐攒尖；南面十二扇隔扇，其他各面四扇；南北各三组出阶，东西各一组。正面照片与文字合读支持南面三组四扇门；这一分组为图文推断，并非实测平面。

## 本轮模型

保留世界中心 Z=65 m 和项目 25×25 m 外柱线。内部围护后退，形成可绕行的四面外廊。南面中组打开供游戏通行，两侧各四扇关闭；其他三面各有中门及两侧槛墙窗。关闭门扇仍是门，不把它记录成不存在的洞口。内殿三开间与外廊五段柱列分别表达。

南北各三道实体阶道，东西各一道。台明暂取 0.6 m，阶宽暂取 4.6 m；这是适配现有共享台面的待核尺寸，不是博物院测量值。三殿共享台基整体没有拆开。既有共同台基轮廓、各层宽度和标高仍需后续独立平面核对。

单檐攒尖屋面用显式屋身/屋顶高度，避免按整座宽度默认生成过陡尖锥。外廊深 3 m、柱高 6.6 m、屋面升高 7.8 m、内殿等分间宽均为暂定比例。内景为简化陈设，宝座后留真实步行间隙，不是原状陈列精模。

## 验证与限制

专项测试检查四个实际中门、封闭侧门/窗、二十四扇实体门扇、门扇碰撞、完整外廊环路，以及无需跳跃的侧阶/中门路线。旧斜穿南面围护的路线作为负向测试保留，正向路线经过中门后才绕宝座。

同机位浏览器截图及完整集成状态见 `../ACCEPTANCE.md`。纹理、斗栱形制、脊兽、精确标高和当日参观围栏尚未逐项放行。照片仅用于研究，没有嵌入游戏贴图。
