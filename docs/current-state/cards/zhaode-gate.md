# 昭德门：V7 高台单门证据卡

状态：证据与实施范围已定，几何、浏览器和发布验收另记，不以本卡代替完成结果。

## 独立资料及其含义

- 故宫博物院[英文建筑地图](https://intl.dpm.org.cn/explore/build_maps.html)中的独立昭德门条目及[南面原图](https://intl.dpm.org.cn/Uploads/Picture/2023/06/20/s649169917abd5.jpg)：一组中央双扇门，三段较宽门身跨度、两端较窄廊间，侧间实墙，抬高的砖石台基和宽石慢道。相邻翼房南面为实墙。照片拍摄日期未知，URL 日期不是拍摄日期。
- 王璞子《太和门的被毁和重修》，1983，第18页，[官方条目](https://www.dpm.org.cn/building/talk/223393.html)、[原页](https://img.dpm.org.cn/Uploads/pdf/2198/T00018_00.pdf)：分别提及昭德门、贞度门的面阔三间、纵深一间的门身、周围廊、九架檩单檐歇山以及尺寸。作者对重修设计和当时实物进行比较；这不是 2026 测绘。原文附图本身是比例不严的示意图，不能按其像素量高度。
- 于倬云《故宫三大殿》，1960，插图一，[官方条目](https://www.dpm.org.cn/building/talk/223358.html)、[1:1000 原平面](https://img.dpm.org.cn/Uploads/File/pdf/c7/92/ed/c792eddcdca8356377637b90520bce08.pdf)：独立标名两门、比例尺和北向，支持南北各有轴向登台构件及两侧连接关系。属于历史出版平面，不是现状地理配准测量。
- 李鹏年 1986 年文献尺寸明确引用上述王文，不能作为第二份独立测量重复计票。

照片/PDF 不放入 public 或交付 ZIP，也不做纹理。来源为故宫博物院网站，未取得研究图再分发许可。本文只提供出处和有限事实释读。

## 本轮工程拟合及未核项

维持原模型锚点 `x=-62.4,z=-214.2,rot=0`；局部南为-Z，世界东为-X，不把扫描校正角当世界朝向。模型采用台面高3.216m、台基24.4×21.0m、南北慢道约16.5/17.0m；这些参数的依据层级不同，以专用 profile 为唯一运行值来源。

逐间宽、前后廊分配、门扇线、柱高/柱径、屋面分段、栏杆形式和间距、净门宽、坡道净宽及线性坡面均为工程拟合。图上宽石慢道可见，不凭照片编造精确踏步级数。南面照片可见窄光滑边带，但本轮未据此认定现状无障碍尺寸或设计规范。

中央双扇门在游戏中可打开；北侧采用与中门相通的出口，完整北立面和是否有第二组门扇尚缺直接证据。侧间和两端廊的未知通道不作为穿行路线。不把关闭未知开口解释成历史上从未有侧门。

两条原庑房地坪约0.45m，与高台不等高；只在本轮门体边缘形成封闭接口，不凭空添侧阶/坡桥。余下整条翼房的朝向、柱网、门窗与历史连接仍未验收。
