# 乾清门：现存形制专项建模卡

## 证据与目视检查

- 故宫博物院官方建筑条目：<https://www.dpm.org.cn/explore/building/236473.html>，2026-10-14 读取。
- 官方正面照片：<https://img.dpm.org.cn/Uploads/Picture/2020/11/17/s5fb36b5c38de7.jpg>，本轮实际查看像素。
- 官方斜侧照片：<https://img.dpm.org.cn/Uploads/Picture/2020/11/17/s5fb36b5c3db52.jpg>，本轮实际查看像素。
- R2 对象卡 `axis/qianqingmen`、组团卡 `group/inner-axis`：现状缺口为直墙代替八字影壁、单道大阶、重复落地隔扇、甬路无实体高程。

官方文字支持五间面阔、三间进深、单檐歇山、后檐三门、1.5 m 石须弥座、门前三组阶道、两梢间青砖槛墙及方格窗、八字形琉璃影壁、门后高台甬路连接乾清宫月台。照片补充支持门厅前部开敞、阶道之间有栏杆、红粉色壁心配绿黄色琉璃边饰、影壁在平面上有折转。

照片拍摄日期未经确认；网址日期不当拍摄日期。参考图片只用于研究，不作为游戏贴图或再分发资产。此模型是现存形制的可玩近似，不代表逐项实测或 2026 年临时开放设施。

## 建模与可玩性

- 独立 `buildQianqingGate(builder, data)` 使用 `PalaceBuilder` 的真实构件、碰撞、可走面和按材质合并流程。
- 六条横向柱线与四条纵向柱线形成 5 × 3 间；中部三间通行，两端为墙窗。门扇仅在北侧后檐，并在可玩版本打开。
- 前阶是三组独立的可走坡道，各自有实体踏步、垂带和栏杆分隔。中阶的御路石为视觉构件，游戏步行允许通过，不代表真实参观路线授权。
- 后方三门先汇入短而宽的高台落脚区，再接 8 m 宽实体甬路；落脚区平面为可玩连接暂定值。
- 八字影壁有折线、厚度、前后表面与绿色/黄色边饰；碰撞按短段注册，避免用整块轴对齐大盒误封周边空地。
- 甬路不另造长斜坡。保留乾清宫旧前阶，接入其达到 1.5 m 的位置：`edgeZ = palaceZ - palaceDepth/2 - 6`，`run = palaceBaseHeight * 1.6`，`joinZ = edgeZ - run + 1.5 * 1.6`。目前为 Z=292.7 m。
- 台顶、甬路和宫前坡道分段有连续脚面；边界防穿、柱网和门扇共同决定实际路径，不以元数据声称可走。

## 接入契约

在 `PalaceBuilder.js` 导入专用构建函数，并在 `buildGate(data)` 进入通用 `buildComplex` 之前对名称 `乾清门` 返回 `buildQianqingGate(this, data)`。不得再为同一门调用通用门殿/台基，否则会重复楼梯、门扇和碰撞。

返回值为已加入 `builder.scene` 的按材质合并 `THREE.Group`。`userData.qianqingGate` 保留柱网、阶道、后檐门线、屏壁折线、屋顶层数、基座及甬路的审查信息。所有碰撞和可走面照旧登记到 builder 数组；自建材质登记到 builder 所有权列表。

## 验证

专项命令：`node --test tests/current-state/qianqing-gate.test.mjs`。

测试直接调用生产 builder、几何合并、射线、`CollisionManager.getValidPosition`，仅以无贴图材质替代图像加载：检查锚点/台高、24 根实际柱碰撞、三道互不合并坡道、三门无需跳跃、后檐门几何、梢间槛墙与实体窗格、单层屋顶、影壁实体厚度与两侧通行、实体甬路及接入原宫台坡道。合并前后照片匹配、全场景相邻墙体及实际漫游另作集成检查；本卡不以局部测试替代全宫验收。
