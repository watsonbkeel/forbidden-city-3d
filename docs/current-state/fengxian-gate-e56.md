# 奉先门 E56 · FC-EF18B2CEC2

旧实现把奉先门当成一座厅式门殿。R381 用独立构件替换现有南墙上的同一段，保留原有轴线、墙接点与高墙轮廓，不改全院边界、奉先殿、钟表馆和其他门的共用逻辑。

- [故宫博物院《故宫奉先殿现状调查及分析研究》](https://img.dpm.org.cn/Uploads/File/2023/02/15/u63ec3cb1a5b6d.pdf#page=5)：印刷页 83 图 8 是南立面实景，参照高墙、前凸的琉璃小屋面、红墙和浅色石脚；印刷页 85 图 11 把东、西角门与奉先门分开标注。本次不新增这两个角门。
- [《建筑学报》2023 年第 2 期图 2d](https://doi.org/10.19819/j.cnki.ISSN0529-1399.202302007)：三道圆券中间高大、两侧较小，墙垛连体，券间有带小屋顶的垂莲柱短墙。瓦件、色彩、石脚线脚和背立面作简化处理。
- 19.5 个游戏米是替换原门殿所占的旧南墙缺口（10.7 + 1.6 + 2 × 3.6），不是实测门宽；门券比例和进深为照片拟合。馆方图中门扇状态不作为现行开放规定。游戏保留原有中门可走、两侧不通的路线安排。

检查时从南侧正面看三券、小屋面与背后长墙；不跳跃穿过中门再返回，两侧门扇和墙缝都不能穿过。尺寸、现行开放方式、角门和全院布局不在本次验收范围。
