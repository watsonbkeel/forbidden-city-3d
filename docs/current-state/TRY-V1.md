# V1 体验方法

这是 `feat/r3-present-day-first-playable` 分支的第一轮结构预览。先看四座建筑的结构与行走空间；比例、彩画和屋面细节仍有暂定部分。游戏通行状态不代表故宫当天对游客开放的范围。

## 从源码启动

需要 Node.js（本轮使用 24.19.0）与 npm。在一个新目录运行，不覆盖已有工作目录：

```sh
git clone --branch feat/r3-present-day-first-playable --single-branch https://github.com/watsonbkeel/forbidden-city-3d.git forbidden-city-r3
cd forbidden-city-r3
npm ci
npm run dev -- --host 127.0.0.1
```

打开终端显示的 `http://127.0.0.1:5173`。如果端口占用，以终端实际给出的端口为准。

## 从已构建 ZIP 启动

解压 `forbidden-city-r3-v1-playable.zip`，在解压后的目录打开终端：

```sh
python3 -m http.server 8080 --bind 127.0.0.1 --directory site
```

Windows 已安装 Python 时可用 `py -m http.server 8080 --bind 127.0.0.1 --directory site`。

然后打开 `http://127.0.0.1:8080`。按 Ctrl+C 结束服务。不需要安装 npm 依赖，也不需要联网取纹理。不能直接双击 `site/index.html`：浏览器的本地文件限制会拦截模块和资源加载。若没有 Python，请用上面的源码方式。

## 建议的 10 分钟路线

进入场景后按 M 打开地图，点击建筑文字可传送到门前；地图可放大。WASD/方向键行走，鼠标转向，Q/E 也可转向，Esc 打开设置。低性能设备先选低画质。

1. 中和殿：从南面中阶走上台明，绕一圈外廊；从中门进去后绕宝座到北门。观察内殿与外廊是两层独立的柱墙关系，南北各有三道阶，东西各一道。
2. 乾清门：分别走三道前阶，注意门扇在门厅后侧。走过门后沿实体高台甬路北行，接到乾清宫原有前阶。
3. 交泰殿：比较南面的门与两侧槛窗，再绕到侧面看中央门与封闭墙面；它不套用中和殿外廊。
4. 体仁阁：地图中位于太和殿广场东侧。其正面朝西，观察真正分离的上下两层、下九间/上七间及上层外廊；可从正面中门进入下层。上层没有虚构可游览的楼梯。

体验时可优先记录“在哪里、朝哪个方向、看到/走到什么问题”，附一张截图。这比泛泛调整红墙或金瓦更有助于下一轮修正。

## 当前限制

- 首批四座结构修订，不是全宫验收；其他建筑仍可能有模板化或尺度问题。
- 神武门现有位置与锚点差 11 m；外西路一条自动慢走路线仍有既有阻挡。具体结果见 [ACCEPTANCE.md](ACCEPTANCE.md)。
- 当日围栏、预约/参观动线、临时展陈及封闭区域未核实。不要把游戏作为现场通行授权或实时导览。
- 材质、斗栱、脊兽和室内陈设仍简化；没有把生成图当成实景依据。
