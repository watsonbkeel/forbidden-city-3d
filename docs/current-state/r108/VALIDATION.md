## 重要限制：距离latch不等于流式换区立即显示
初稿把“相机移39m且同时增删场景后同一帧必有interest”当断言，实际触发安全source proof重新绑定，断言失败原日志保留。未绕过产品验证：额外用R105/累计同一真实zone.update流程重验，二者frame600均binding/interest暂空，登记108不丢；实际重新提交分别frame789/641。只是单次功能记录，非性能基准/实机等待承诺。

因此固定注册world的latch门不冒充“跨区无闪烁”；真实跨区重绑仍可能暂时隐藏人物，后续恢复/不出现近处隐形身体已验。本版没有新实现来消除这一继承限制，也不凭两次帧差称修复。
