基线：2a1dda7a284bf3a9b2947c771bc8766134104405。保留该分支、main及所有前序，不合并、不部署。

## 本轮可见范围

将现有通用单洞随墙门替换为独立石座/琉璃框式门垛/低门罩的有限拟合。保留(-272.3,518.9)旧位置、3.6米中央净口、6.4米北墙缺口与原地图矩形；附近珍妃井、倦勤斋及所有既有主体不改。移除没有实景文字依据的通用名称牌匾，地图仍正式显示“贞顺门”。

故宫官网[《从故宫珍宝馆谈起》](https://img.dpm.org.cn/Uploads/pdf/1948/T00006_00.pdf)印刷第6页的黑白旧照，明确题注“珍寶館出口貞順門”，可确认单座入口、浅色石座和框式门垛。[《宁寿宫的琉璃花门》](https://www.dpm.org.cn/building/talk/224072.html)正文也明确单座门楼。文章配图是皇极门，未移作本门依据；URL的1948目录不被当作文章出版年。

颜色、低庑殿式门罩的具体顶型、几何尺度、背面及门扇全开姿态均为游戏拟合。旧照不支持精确色彩/雕饰或当下开放状态；没有编造铭文、年代或新建筑。I29仍保留29个原ID，22项有专用局部代码、3项仍通用、其余既有分类不变，整项验收仍为0；不以这些分类计算397项完成率。
