只替换六个现有上部肩圈的几何，不更改下部鼓形柱础、其他柱础、柱子、南廊门窗和天花。保留原底缘和整体外包络，局部面向内收雕，不添加突出通道的新物理。新构件仍借用原石材，不增加材质/纹理/网格/碰撞/可行走面/地图或传送目标。旧六件480三角替换为8064三角，净增7584三角；独立CPU计数显示源属性/索引缓冲净增189696字节，局部真实合批缓冲净增728064字节，合批网格数仍12；不是GPU显存或真机耗电测量。这不是性能优化，未测帧率或温度。

运行改动限于JingfuLotusBases.js及JingfuSouthGallery.js的一次挂接和诚实的局部说明。RemainingNingshouHalls、ZoneBase、全部原始zone数据和通用物理完全不改。历史“未雕覆莲”记录保留为历史，不将其误当本轮状态。
