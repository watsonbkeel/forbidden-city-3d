## 改动和使用

- 按F3查看最近加载的CPU总时、构建、真实几何合批、碰撞/走面登记、通知及最近非空队列总时；沿用250ms可见刷新，隐藏时不读取新provider。
- 启动预构造、冷构建、预构造复用、缓存复用分别标识。build包含merge子项，不可相加；复用时两者0只描述这次入区，不代表启动免费。startup可能属于另一分区。
- 区操作才计量，最多8条短数字记录，无每帧场景扫描，不保存资源/原错误或任意用户文本。旧buildTimes保留原准备耗时语义，日志标签已明确，完整入区以新total为准。
- 现有首错本地复制摘要可附白名单时序记录，供用户自主提供。不会自动上传；lastQueue只代表最近一次非空队列，未必与当前首错/直接加载同事务。首错阶段和最近加载都只是定位线索，不是根因结论。
- 保留原失败清理、抛出对象和恢复入口；可选计时器/provider/记录写入异常不遮蔽真正错误。独审曾发现phase对象/交替getter可绕白名单，已先红后绿改成单读原始字符串校验，循环/BigInt真实主故障恢复负控闭环。
