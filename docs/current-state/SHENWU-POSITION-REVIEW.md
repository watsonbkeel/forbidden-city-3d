# 神武门定位差异：保留待核

核查日期：2026-10-14。本文记录定位依据，不更改建筑、锚点或测试阈值。

## 结论

神武门模型原点为 Z=542，独立锚点为531，相差11 m，超过原5 m容差。现有主分支有意移动建筑和北墙；旧锚点来自北墙位置的估算。两者均没有与太和殿原点联测的官方定位依据。因此本轮保留542和明确的测试失败，不把建筑移回531，也不把锚点抄成542来消除报警。

## 新找到的主要证据

1. 故宫官方[神武门条目](https://www.dpm.org.cn/explore/building/236456.html)和[顺贞门条目](https://www.dpm.org.cn/explore/building/236543.html)支持二者隔北横街相对的关系，没有给出间距或太和殿坐标。
2. 曹晓丽等《紫禁城城墙现状调查与保护初探》，故宫学刊2013，印刷343页：[官方PDF](https://www.dpm.org.cn/Uploads/File/2020/02/16/u5e490f5ea72b3.pdf)。测量的围墙尺度为963.13×752.54 m，神武门等城台为50.18×26.46 m。它们是相应构件尺寸，不能用来直接反算当前游戏坐标。
3. 黄占均等《故宫神武门门楼大木尺度设计初探》，故宫博物院院刊2013年第1期：[官方PDF](https://www.dpm.org.cn/Uploads/File/2018/06/05/u5b164a2ba5129.pdf)。基于2005年修缮测量，给出门楼柱网和构架图；柱网尺度不是城台尺寸，文中也未给出所需的全宫定位联测。

需要的下一项证据是：带明确测量对象的总平面或测量控制点，将太和殿中心、顺贞门门线、神武门柱网/城台中心和北墙内外皮联系到同一坐标系统。论文提及的《神武门现状勘测报告及维修方案》（2005）是可继续寻找的档案线索，本轮没有取得该报告。

透视照片、旅游示意图、整体宫城长度或未经精度验证的地图包围盒，都不能单独证明小于5 m的绝对定位正确。现有锚点检查仍应保留，直至可追溯的新定位依据同时更新数据和几何。
