# R41 储秀宫西侧炕体的有限补充

本批实际改变的建筑只有储秀宫。新增西次间北、南两处炕体与西梢间南部一处炕体，保留原有西梢间北部床罩轮廓、中央座屏、四道隔断、入口与外壳。不是新增整套卧房家具，也不代表89个有名称建筑已全部更新。

## 依据与时期

依据故宫博物院出版《储秀宫区域原状陈列发展沿革考》，印刷第265–266页：
https://www.dpm.org.cn/Uploads/File/2024/07/22/u669dcd8dc5647.pdf

该文引述1982年对1971年恢复后陈列的描述，明确西次间南北炕、西梢间北床及南炕的关系，并说明这是一种经过整理的风格性复原，不是完整保存下来的清代陈设。本模型只采用这些房间与南北位置关系；不宣称2026年完整陈列已经核对。

第265页图11是储秀宫东侧房间，第266页图12是体和殿，不能当成新增西侧炕体的匹配照片。本批采用文字支持的素色体量，不复制未核实的雕刻、铺陈、炕桌或梳妆器物。北床既有轮廓继续保留其未核实细节的说明。

## 模型拟合与通行

本地坐标正X为西、正Z为北。三处中心依次为(5.42,4.9)、(5.42,-3.7)、(10.84,-3.7)，宽深分别4.1×2.4、4.1×1.8、3.8×1.8米，高度均0.45米。这些数字是可回退的模型拟合，不是文献测量值。

所有新增实体均位于原有通道Z[-2,0.4]之外，并各有与可见体积一致的碰撞体。没有新楼层、额外地板登记、看不见的隔墙或额外房间登记。既有碰撞系统会将低实体顶面作为支撑面，炕顶高度与可见表面一致；不宣称可攀踏家具是现场参观许可。原有五个登记区域仍是导航分区，不代表历史上只有五个完整房间。

## 宁寿宫审查记录，不是本批几何更新

宁寿宫当前仍为待核实的通用室内。官方调查记载历史西三间万字炕已因展览拆除，不能加入默认当前陈列。2019年调查中的存留灶具也缺少可直接映射到模型的室内坐标与当前展示边界，本批不添加灶、旧寝具或楼阁。七间与偏东入口的建筑纠正需要单独处理入口、台阶、传送和院落连接，暂不实施。

旧皇极殿研究文档中混入的2017年宁寿宫石鼓馆图片已加归属纠正说明，不能作为皇极殿室内依据；没有因此改动皇极殿几何。
