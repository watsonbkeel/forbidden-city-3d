## 有限修改

主楼体高从13降到约6.9602，柱/墙高约6.1250，梁带高约0.8352；楼面12.3、横向柱网60.05×25、门高5.2和檐廊/门扇平面保持。下檐中心标高20.0011、上檐25.7483、上层瓦脊34.7138分别对应图中不同基准。

Wumen-only opt-in 控制下裙顶曲线、上层承托/檐下曲线和外观分带。上层檐下为近似的矩形承托边界到檐口的独立环面，解决保留X范围而调整Z出檐时，单一瓦面等高线不能同时代表矩形墙角的问题。四面、四角的端点与面向均有CPU检查；这不是木构梁架/椽架复原。

图中y355、380为中性承托/支承参考线；y399是内部分带，下面一层仍延至y412–414。外观模型保留到下层瓦面交接处的额外彩画带，避免把399误作全部梁带底。wood/caihua/dougong是暂定材质标签，不是黑白图纸直接证明的构件身份。

匾额外包络2.9731×3.3034，内板1.63518×2.18024；蓝板/名义上层墙宽固定为3.0%。背面z=-10.728，即暂定1.0m外挑；不靠净空自动缩小，也不自动增加外挑。实际网格净空不足会报错。

上层瓦脊34.7138与实际含饰件最高点36.5187645分别记录。后者不是建筑实测总高。旅游资料37.95m与较早博物院35m以上的取值基准/端点关系未解决；保留的楼面12.3和饰件造型不因此获得绝对标高校验。屋顶实际包围盒约x±34.82548、z±17.30048、y19.26021–36.51876；建筑世界锚点z=-419.6不变。

- 门扇、门槛、室内地板与所有walkables保持原字节。降低高度后46个墙/柱代理的底面出现Float32舍入差异，最大约0.234µm；它们的X/Z、顶面和其余碰撞体不变。保留新网格的实际包围盒，没有人为修正运行时代理。`tests/fixtures/wumen-collider-foot-roundoff.json`列出全部确切索引、前后值和原始哈希；历史比较只逆转这46个已知值，不能容忍其他漂移，也不能泛化成全局容差。因此不声称全体碰撞数据逐字节相同。
- 增加424个主楼三角形：独立上层檐下面数增加416，保留下层彩画带增加8。原389个网格和材质身份/渲染批次结构不变。材质统计按是否把匾额材质数组展开而分别为25个对象或26个实际材质，不混用口径。

## CPU与后续视觉边界

高、低两种RoofBuilder细分均检查完整匾额实体（全部外轮廓、前后面、厚度）与屋面/围脊/分带的三角形相交；下部实际最小包络净空分别约0.13061m、0.11800m，上部约0.1m。独立檐下环面检查所有面/角接缝、下向法线、非退化三角形和瓦面不低于檐下。API没有单独的medium细分分支。

原始C1局部眼点(3,30,-24)与近正南(0,30,-24)保持原位置：各有3/18个保守字形采样被椽檐遮挡，15/18可见。它们作为历史诊断保留，没有调整建筑去满足旧视点。新冻结C3为局部眼点(3,25,-40)、目标(0,26.4,-10.85)、FOV70、1280×720；主楼两版应使用同一相机。实际初始位置和C3的文字/边框CPU检查不代表普通屏幕像素可读性验收。

旧“-470一定裁掉屋脊”的断言已不适用于降低后的塔楼；当前该位置也不再裁切，实际入口仍为-494。旧模型的遮挡用未改变的通用屋顶输入另外重现。历史金样本没有重写：只串接有限、逐块匹配的逆源码迁移；所有非目标门洞、廊道、碰撞和通用屋顶检查继续运行。
