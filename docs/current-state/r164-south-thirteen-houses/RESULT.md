- 最北的第十三座主房有拟合的西侧开放接近路径，不宣称第七座历史院门。北端两间小南房、南端垂花门、北十三排、现时办公陈设/绿化与完整院落细节未做。

## 资源与故障

新增969个合批前网格、11680三角、241接触、13行走面和6个私有材质，未新增纹理文件或地图目标。旧物未删。独立统计：合批后全区CPU几何缓冲从56,282,112增至57,403,392字节，净增1,121,280字节（约1.069MiB）；几何数131→137。这不是GPU显存或帧率测量。两版几何本身已超默认32MiB缓存预算，旧贴图尺寸unknown也未被本轮修复，不能宣称本区必定缓存成功。

红测先发现第十三排被末端院墙封住、门楣正常跳跃穿头和长墙砖纹拉伸，分别以仅本组群的开放接近路径、现有明确overhead接触和物理尺寸UV修正。无通用移动/碰撞逻辑更改。UV转换最初错用返回值导致重复释放；之后独审还找到 toNonIndexed 内部中断时返回前无法登记临时几何的问题。最终先登记空 BufferGeometry 再逐属性展开，失败对象本体必须被释放；宿主不部分提交，可显式重试。展开后的每份位置/法线/UV/组与现有 BoxGeometry+applyBoxUV逐字节一致。
