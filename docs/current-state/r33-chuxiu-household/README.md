# R33 储秀宫：官方空间关系与可回滚拟合

## 本轮实现

- 仅 `west-six/储秀宫` 正殿使用专属 builder。旧五间柱网、外包、台基、台阶、屋顶和可走台面完全复用；未改丽景轩、其他六宫或院墙。
- 前檐窗门面在既有外包内后退，形成前廊；左右四间使用砖槛、玻璃与矩形棂格的支摘窗构图，中间保留入口。四个间界补齐 0.68 m 宽的拟合封闭竖框，避免后退门窗面与旧前柱列之间出现透空裂缝；可见封闭体与碰撞一致。
- 东向西四道内部边界分别表现葡萄落地罩、竹纹裙板玻璃、玉兰纹裙板玻璃、万福万寿框玻璃。各类细部纹样均为简化原创几何，非实物摹本。两道明间侧隔扇各有八扇的文献依据；本版开口状态与扇宽为拟合。
- 明间采用深木色座与五扇镜屏关系，原生字形绘制“大圆宝镜”和“寿”；西后部使用素色炕台/罩架轮廓与避风屏。没有补造某件有身份的床、柜、瓷器或寝具。
- 5 个命名分区仅供模型导航。文献说明五间内还有多种小空间，不能据此声称历史上恰好只有五个无细分房间。几何、碰撞、门位与安全点共用同一专属构建过程。

## 事实与近似

所有关键拟合量集中在 `CHUXIU_FIT`，包括前廊退距、横向通门中线/宽度、隔断高度、明间座屏尺寸、西梢暖阁尺寸和避风屏偏移。既有外包及五间等分轴距也是模型参数，不是本轮测绘成果。现状公开陈列的完整定年、精细雕刻、逐件器物身份均未完成核定。

不把有证据的回廊连接关系扩大成已经完成的院落回廊：正殿前廊应与两侧配殿前廊、体和殿后廊转角相接，实际模型的邻栋连接留给院落级工作。本轮保留周边通路，不改配殿坐标。

## 技术验收

专项：`node --test tests/r33-chuxiu-household.test.mjs`。先取得专用 builder 缺失的红测，再实现并转绿。另联合既有 `r32-six-palace-bays` 核实五间柱网未退化。

核验内容包括四分界和西端方向、5 个导航分区的门/安全点、真实 CollisionManager 双向步行、旧台基/台阶/柱/屋顶的顶点及变换签名、可走台面完全一致、FlightEnvelope 从已载入和预构建区域读取后均保留原屋顶栅格、有限几何及私有材质/文字纹理释放。

本栋旧空外壳为 1,854 三角，新构图总量 9,342 三角，净增 7,488；净增 461 个合并前网格。单栋合并为 22 个材质批次，50 个碰撞体、5 个导航分区。整场景预算由集成检查计算，不把单栋测试视为全场景性能通过。

局部截图未取得。一次本地 Chromium 截图测试在浏览器启动阶段因 sandbox socket 权限失败，未打开页面、未读场景；没有重试、提权或更换协议。开发服务器已关闭。因此此记录不宣称浏览器视觉验收或实景准确度验收已通过。
