# V3 体验方法

本轮重点为协和门、熙和门、景运门、隆宗门的五间三通道、独立台基和坡道，并保留前两轮四座建筑。工程暂定的宽深、柱网、细部坡形仍逐门标注，不是全宫测绘模型，也不代表故宫当天的开放路线。

## 已构建包

解压 `forbidden-city-r3-v3-playable.zip`，进入有 `site` 文件夹的目录，运行：

```sh
python3 -m http.server 8080 --bind 127.0.0.1 --directory site
```

Windows可用 `py` 替代 `python3`。打开 `http://127.0.0.1:8080`；Ctrl+C停止服务。不要双击 `site/index.html`。纹理已包含，不需要联网获取游戏资源。

## 源码

在新目录克隆，避免覆盖已有项目：

```sh
git clone --branch feat/r3-v3-side-gates --single-branch https://github.com/watsonbkeel/forbidden-city-3d.git forbidden-city-r3-v3
cd forbidden-city-r3-v3
npm ci
npm run dev -- --host 127.0.0.1
```

打开终端显示的本地地址。此分支由项目拥有者决定是否合并。

## 建议路线

按M打开地图，点击建筑文字可传送；WASD/方向键行走，鼠标或Q/E转向，Esc打开设置。

1. 太和门前广场东侧的协和门：从广场进入该门西侧慢道，上高台，分别走中央三条门道，到东侧坡脚。转身看完整五间立面；院内坡南边外展，不能把它当成对称矩形坡。
2. 广场西侧的熙和门：比较独立的河势外展坡形、前后端间窗墙和中线门扇。两门均保留官方2.62 m台基和17.75 m前后慢道，其他未测尺度见各自建筑卡。
3. 乾清门广场东侧景运门、西侧隆宗门：比较较低台基、礓磋坡道和靠院内一侧的门扇；每门三个通道均可体验。低门不能套用前两门的高台和白石栏。
4. 地图选择武英殿一带，走向浴德堂；建筑没有为自动测试删墙或移位，路线应沿实体之间的通道通过。
5. Esc打开设置，点击画质按钮，观察标签与实际渲染同步；手机初始仍为低画质，桌面初始为高画质。

四门外向立面分别朝东/西路，不是都朝中轴广场。游戏内打开的门扇、允许通行的区域，只是体验状态。

## 限制

神武门11 m定位分歧仍待统一测量依据，见[定位核查](SHENWU-POSITION-REVIEW.md)。各门实测面阔/进深、完整现时背立面、部分邻接屋及装饰尚未核准。全宫其他建筑仍需逐一复核。
