冻结 F2 已获 owner 与独立评审的限定接受：仅作为资料分级的钦安殿地面外观研究预览。持续输入失败、继承门禁失败及其限制保留；不等于全部控制测试、实机性能或生产验收。最终 D/R 和包校验由外部发布回执记录。


## 变更与证据边界

本版只包含钦安殿五间柱网、重檐盝顶、窄顶板与南低抱厦外观、地面观览导航，以及已独立接受的 skyline 单面化优化和示意西南日光。解析天空及铺地实验不在 V8。既有游戏 assets 不变；研究照片、PDF、裁图和字体不进入源码/公共 assets 或分发包。

实测下柱网/上柱网/柱础相对标高、图纸推读、暂定皮层/支撑/栏杆/抱厦高度分级保留。历史图纸与重建公告不是现状竣工实测。原主锚点 (0,493.1)、朝向、1×1m 玩家盒及移动规则未改。尚缺南轴复合石构、天一门、院墙、确证内金柱映射和重建细部。不接受台上、室内、穿殿北出或当前游客通行。

观览点 world (18,477)、feet 0、look-at (0,3,481.08)。传送先核实实际 resident profile、22 个支撑、落点碰撞与实体前表面视线，失败不猜另一个点。只替换一条 fixed、一条 automatic 钦安路线；另 32/58 条描述及原物理驱动不变。新路线经 z=429.7 横路转 x=18，逐帧身体扫掠避开暂缺石构；旧穿殿北出路径保留为负例。
