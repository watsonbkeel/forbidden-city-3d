# V8 体验：钦安殿地面外观


这版把钦安殿改为五间柱网、重檐盝顶、窄顶板与南面低抱厦。实测柱网和标高、图纸推读、暂定外皮/台基等分级保留。这里只接受地面外观研究预览；台上、室内和穿殿北出路线未验收，也不代表现场开放。

## 第一次打开

解压 `forbidden-city-r3-v8-playable.zip`，在含 `README.txt`、`start-local.py` 和 `site` 的目录运行：

```sh
python3 start-local.py
```

Windows 可用 `py start-local.py`。打开 <http://127.0.0.1:8080>，用完在终端按 Ctrl+C。端口被占用时加 `--port 8081`。不要直接双击 `site/index.html`。也可用：

```sh
python3 -m http.server 8080 --bind 127.0.0.1 --directory site
```

模型、纹理与解码器随包提供；文献网页另行联网打开。启动器只在本机提供文件，不安装依赖或发布网站。

## 建议先看这三处

1. 按 M 打开地图，选择“钦安殿（外观）”。到达西南侧地面 world (18,477)，脚高 0，朝向低抱厦；这是观览点，不是殿门入口。
2. 停下看低抱厦、后方重檐与窄顶板的高低关系，再缓慢转头看侧面。若从御花园走来，走南横路后绕西侧地面接近；测试路线在 z=429.7 转到 x=18，再到观览点并原路返回，避开已知暂缺的南轴石构。不要把模型空白处当成已确认的通道。
3. 回到太和殿前看石台与铺地阴影。本轮示意日光改为天文上可行的西南方向；它不是当天时间、天气或实景照片匹配，也不保证每个立面都改善。skyline 单面化优化在既定相机条件下像素中性，本来就不以画面变化为目标。解析天空、铺地实验不在 V8 中。

交付的钦安殿正面对照图，两边都用已接受的相同光照，只隔离建筑变化，左侧不是原封不动的 V7。太和殿前对照图则是已交付 V7 与 V8 的整体比较，包含日光方向变化。两种对照不要混作同一基线；诊断俯视图也不是可走位置。

WASD/方向键移动，鼠标或 Q/E 转向，Shift 加速，M 地图，Esc 设置。手机界面用摇杆与视角拖动。先慢走，转弯时松开加速。

本轮验证了编译包启动/重载、地图与说明控件，并完成各一次短脉冲键盘/触摸模拟的后退约 2.5m、停稳返回演示。另一套持续按住返回测试仍失败，不能称所有输入测试全绿；云端低帧率与输入释放延迟会使停点超走。短演示不等于完整御花园真人输入路线，触摸模拟不等于真实手机验收。具体数值和限制见 [V8 验收记录](V8-ACCEPTANCE.md)。

## 打开源码

在源码包的 `package.json` 目录运行：

```sh
npm ci
npm run dev -- --host 127.0.0.1
```

首次安装依赖需要联网。本轮独立重建使用 Node 24.19.0、npm 11.9.0。生成相对路径静态包：

```sh
npm run build -- --base ./
python3 -m http.server 8080 --bind 127.0.0.1 --directory dist
```

`R3-RELEASE.json` 记录实测运行源码 F、仅追加文档的 D 和已实际核对的远端 R；包大小与 SHA、CRC、逐文件解压校验在外部 `package-manifest.json`。参数出处见[钦安殿技术说明](../QINAN-EXTERIOR-STUDY.md)。

原神武门 11m/5m 锚点失败、23 条分区警告和历史 12 机位基线 11 项红项保留；软件 FPS 不承诺实机性能。本轮只交付新分支，main 由用户决定，未部署生产。V8 没有预览网址，另行授权的 V7 页面不代表本版。
