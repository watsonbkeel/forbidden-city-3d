## 碰撞与路线诊断
初始0.53×0.50m候选令原转弯失败；只南移路线0.25m虽通过10/60Hz，却在真实30Hz跑步仍失败。收为0.46m方形后 B/S 全矩阵通过，保留历史RED日志，不改控制器、角色半径、墙或门。三希堂路线末点由-3.5改为-3.3：独立审查在真实R90也复现旧末点30Hz步进受阻；这是诊断路线留余量，不是改旧家具。

贴墙小方几中心并不是容纳1m宽玩家的合法落点；强制放入墙内不作验收。实际 FlightState 从合法home通过输入升高/飞行/下降，在屋顶包络被阻挡，无法下机（10/30/60Hz、两桌、零位置写入）。实际地面起跳靠近两侧，逐帧身体无重叠，向南再跳均返回地面；普通退避在既有炕沿可能需再跳，独立R90/R93同输入对照确认不是新增恶化。
