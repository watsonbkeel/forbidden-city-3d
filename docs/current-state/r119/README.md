# R119 — 交泰整室组合开发版

基于完整 R118 `3d40ed95` 累计，不是要求部署的大版。R116/R117 没有采纳性能改造；R120/R126 才是下一累计大版节点，R120 包含保质性能专项。

## 本轮实际改变

- **屏框**：原上屏包络内补四条细边；红底金龙云纹为依据官方可见色域的原创示意，非照片贴图/精确雕饰复刻。牌保持原比例、位置及原“無為”文字代码，仅分层框色调整；下方铭文仍留白。
- **藻井**：已有九个 profile、方—多边—圆场及唯一悬镜并非本轮新建。在 near LOD 增三组薄口沿及笼两端圈；原 opening、镜 datum 和 far geometry 不变。
- **内檐**：原中央承框内侧与有证西侧上部增加蓝绿金分层带和有限栱臂/支点；同材质横向重复避免将一幅小图拉满整墙。南、东、北未知 perimeter 不复制此排栱，不添柱。

保留 R118 所有角色/帝妃 21:00–06:00 路线、全区预建、40m 显示、缓存策略、玩家尺寸/STEP。交泰既有钟漏、四门、低台、三列黄罩的几何和物理登记保持 exact；不补盖下宝玺库存，不把博物馆关门照改成游戏封路。

## 证据和限制

- [来源/范围/计划](PLAN.md)：官方正向、钟侧及牌近照先实看，再与实际 ready 成品对照。图片拍摄日/精确米制参数未知；所有新增尺寸、重复数和纹样均是可回退的 MODEL_FIT。
- [验证台账](VALIDATION.md)：包含先 RED、历史失败、当前必要门及构建身份，不能把旧测试全红抹成通过。
- `reports/r119-jiaotai/visual/`：同相机/FOV/光向、真实 production 几何和已解码图集的 CPU z-buffer before/after。不是 GPU/PBR/阴影/移动端验收。CPU 字体缺失导致旧牌不出字，不据此修改历史字形。
- 新增 **1 个 merged mesh/material、1,320 个 resident 三角、126,720 B geometry ArrayBuffer、524,288 B 图集逻辑像素**。这是功能质量成本，不是性能提升。near/far 共用原 central atlas；完整 mip/持有及计时见验证表，GPU实际分配/JS heap不由这些标量代表。

R112 整建筑 E1–E8/I1–I6 未完成分母继续保留。本轮没有完成屋顶/全部外檐/所有背面/精细铭文，不能称交泰全测绘复原。实际 GPU、手机外观和帧率仍 **VERIFY_PENDING**。
