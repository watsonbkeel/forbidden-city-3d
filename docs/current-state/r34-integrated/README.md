# R34 连贯游览、院落真实感与明亮夜景

本版本从已发布的 R33 开发提交 `3b9f01f1fafad61f7c23efee1f1bb0a37c2ed8fb` 继续，合并以下改动；保留 R33 回滚，不修改 main 或现有 Pages。几何参数属于基于官方空间关系和现有模型的可逆拟合，不是实测复原。

## 本轮实际改变

- **夜景**：增强全场夜间基础光和暖色补光，保留深蓝夜空、日间亮度端点和北京时间实时昼夜；四个已有御花园灯体增加可见发光，新增 48 三角、一个绘制批次，不增加动态灯。数值照明变亮不等同已验证画面观感。
- **储秀院落**：连接正殿、两侧配殿与体和殿回廊，处理角点、地面高差、可见铺地、柱与碰撞。对完整路线的检查发现翊坤宫旧侧翼位置重叠阻路，只把两座原本估算定位的侧翼南移 4 米，保留尺寸、形体和陈设，打开有可见地面的侧巷。官方耳房改通道的记载属于体和殿，不能拿来冒称翊坤侧翼新坐标经过实测。
- **乾清宫**：柱网、门窗、穿堂与暖阁边界使用同一非等距面阔模型；中央展陈和两端穿堂保留，前后廊连通。空间尺度仍为拟合。
- **太和殿**：宝座、屏风、台座、台阶、配套陈设及碰撞整体南移 2 米，改善与金柱、藻井的关系；器物尺寸、柱网、天花和既有匾联挂位不改。修复粗细两种模型侧栏表现不一致导致的视线遮挡。没有宣称整个实景透视比例已经准确。
- **性能与释放**：远景屋顶采用逐位相同三角形的索引复用，原分支测得该部分几何缓存减少 62.3%，不是整款游戏帧率提升 62.3%。修复 Environment 重复释放共享材质的所有权问题。新增常驻、预建缓存、流式区域与六座可选内景的独立预算和加载/卸载/重载检查。

## 连续路线与交互证据

最终模型上的路线/会话专项 102/102 通过。每条路线仅初始落地一次，使用真正 FirstPersonControls 连续移动；覆盖两种内景级别、正反方向、慢走/快走、10/20/60 Hz、中轴及五桥，以及经月华门、翊坤侧巷、体和殿进入储秀院落再返回中轴。沿途实际地面高度见证防止从殿堂下方穿过，禁止恢复高度或瞬移掩盖断路。

地图搜索、读卡返回、设置打断、自动/手动飞行切换、落地、下机走动、返回再登机包含桌面和触控控制器的 CPU 模拟。它们不是人工浏览器实走，也不是实体手机测试。太和殿旧观景坐标落入新台座后，测试停点改到真实新台阶前一米，未改变物理或放宽到达标准。
