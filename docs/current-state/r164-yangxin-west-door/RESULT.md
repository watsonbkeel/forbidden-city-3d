现行R53三个北边界盒体符合这一位置拓扑，但表现为一整块裸褐门框。本次只为宽西侧板和门上横板换私有浅墙饰面，前者有简化木窗格，窄东侧木门框仍是原材质。保留全部原位置、法线、索引、36三角及所有COL/可站面，只改变两个盒体的UV/材质。窗口仍为原实体墙上的不透明平面图案，不是假透明洞，不新增/放宽通行。新饰面的背面保持朴素浅墙，不复制未经核实的窗式。

原1.18m洞、0.14m深度及拟合位置保留，不扩建北佛堂/仙楼、家具、文字或地图目标。整体仍未验收；前景明间共享GLB稀格栅待另行按所有权处理。用户截图没有相机坐标，不能称逐像素识别；本轮只验证一个明确给定的可复现明间视点确能看到该对象。
