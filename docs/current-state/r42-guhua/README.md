# R42 古华轩开放亭轩的局部更新

本批实际更新古华轩一处建筑。原通用封闭厅堂改为三间敞轩，去除不适用的实墙、通用隔扇和桌椅预设，建立中央前后贯通的观览路线、周围廊、低座栏与通透内檐格架。仍不是完整测绘复原，也不代表89个有名称建筑均已完成。

## 官方依据与修缮状态

- 建筑说明：https://www.dpm.org.cn/explore/building/236431.html
- 2025年开放公告：https://www.dpm.org.cn/show/371726.html
- 本次匹配照片：https://img.dpm.org.cn/Uploads/image/2025/09/29/c2f44b867bfa08-NeYmtDOcI218985.png
- 较早的室内参考：https://img.dpm.org.cn/Uploads/Picture/dc/1501[1024].jpg

官方建筑文字支持坐北朝南、三间敞轩、周围廊、檐柱间座凳与内柱间通透花罩。2025年公告照片清楚显示红座、绿栏、黑金色内檐格架及无门中央通道。透过亭轩所见的红墙和门属于背景建筑，不能复制成古华轩自己的后墙。照片随公告发表，不等于已知精确拍摄时刻，也不证明所有内部空间当天或今天都允许游客进入。

修缮参与团队的第一手说明：https://www.ad.tsinghua.edu.cn/info/1061/32199.htm 。该说明指出恢复展示使用传统工艺复制屏罩，主要参照保存的光绪时期纹样，并非未经改动的乾隆原物。本模型采用修缮后色彩和通透关系作参考，没有精确复刻这些纹样。该伙伴说明是修缮状态的补充依据，与故宫官方建筑及照片来源分开列出。

## 已改变与仍未完成

- 保留模型位置、14.3×8.7米外廓、0.5米台面和主屋顶，仅调整为三间开放边界。所有长度与等分轴线都是模型拟合。
- 周围廊以1.8米内退作拟合；实际人物半径0.5米的路线在侧廊使用局部X±6.2米的清晰中线，不穿过座栏或框柱。
- 内檐采用简化开口格架和框柱，不宣称柱截面、雕花、原始梁架或所有侧后栏段与文物逐件一致。低座、栏条均有对应物理边界；没有把开放格架做成看不见的实墙。
- 灰色石地与素色凸格顶示意，未精确复制楠木贴雕花卉天花。旧通用桌椅预设移除，不等于声称现场或历史上从无家具。
- 只登记一个开放导航区域，保留地点与中央传送方向；不是历史房间数量或现场参观权限。
- 屋顶本批没有更新。官方记载的卷棚歇山形制与黄瓦绿剪边仍待专门更新，旧标准屋顶仅作近似，外观不标记完成。
- 阶梯位置和数量没有匹配证据，本批不增造楼梯。保留0.5米台面并验证模型实际跨入路线，不把游戏通行条件说成实测现场条件。

## 检查范围

独立检查对比原屋顶/台明的实际几何，验证新座栏支撑、真实开口、整区合并后的顶点与飞行包络，以及资源重复加载/释放。当前控制器在10/60Hz完成前后出入、四侧环廊和侧开口路线。其余121殿座和88条非目标建筑清单记录保持独立基线一致。

未进行真实GPU/WebGL生成场景视觉验收或原生手机验收。最终全量结果和保留失败见验证记录，不能把聚焦测试通过表述为全部测试通过。
