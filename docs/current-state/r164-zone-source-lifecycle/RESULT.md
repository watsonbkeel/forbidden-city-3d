# 奉先殿缓存回传与失败清理

基线为已回读的阅是楼/珍妃井累计提交 `a7a215cb32b4580c899228961ed979fe57db8da1`。本轮只修源证书的缓存生命周期和加载失败清理，不改任何落点、几何、材质、正常碰撞或接触算法。

## 可复现原因

真实 `east-six → ZoneManager → Teleport` 首次传送正常。卸载进缓存时旧 `releaseConstructionReferences()` 清空构造根组，断开奉先殿真实宿主的parent链。缓存回传重新复制可行走面时，原有私有证书正确拒绝，抛出 `Fengxian central source copy changed`。旧加载流程没有失败清理，残留2596碰撞、39可行走面、1组；再次尝试出现 `Duplicate triangle owner`。高低画质都可复现，与用户截图错误一致，但不代表所有卡死都由此引起。

## 修复边界

- 12个现有认证模块仅在成功创建真实源证书后登记需保留的构造分支，缓存释放只清无关分支。全部原认证、拒绝及移动源码通过冻结SHA逐字节检查，不删除守卫、不从公开字段伪造证书、不修复被移动或隐藏的真实源。
- 覆盖奉先中央/两侧阶、坤宁门、銮驾东/南、宝蕴、文华、箭亭、南三所前/后、文渊与主敬北阶宿主。
- 单区加载失败清理该区部分碰撞/可行走面、场景组及已经消费的缓存/prebuilt所有权，恢复silhouette；已开始的加载通知补发卸载。其他已成功区保持，既有观察者能看到的loaded与buildTimes时序保持。清理异常会与原异常一并抛出，不无限自动重试。
- 未完成构建的ZoneBase也可释放已有源几何/私有资源，正常销毁幂等。正常缓存预算仍是2项、32MiB及原TTL，不扩大生产内存上限。
