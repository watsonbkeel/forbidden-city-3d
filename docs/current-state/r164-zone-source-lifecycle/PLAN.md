# 奉先殿缓存回传与加载失败清理

基线为已回读 a7a215cb32b4580c899228961ed979fe57db8da1（含珍妃井和阅是楼）。截图错误已由真实 east-six / ZoneManager / Teleport 稳定复现：缓存释放清空构造root后，奉先殿源证书因parent被断开拒绝；随后loadZone失败留下局部物理与场景，重试出现重复三角owner。

选定方案：源证书创建成功时，明确登记仍需保留的真实构造分支；缓存只移除未登记分支，不改变任何认证谓词或恢复被外部损坏的宿主。继续按原32MiB/2项/TTL预算计入保留分支，超预算可正常释放重建。覆盖奉先、坤宁、銮驾、宝蕴及现有外朝楼梯宿主，不按地名猜测。

加载则以单区为事务，消费prebuilt/cache所有权后，构建、场景、碰撞、可行走面和通知失败均清掉该区自己的注册、组和所有权并恢复silhouette，保留其他区。已触发的生命周期通知补发卸载；清理错误不能阻止后续清理或掩盖初始原因。显式重试重新构建，不自动重试，不改传送落点/碰撞/玩家。

先红测：实际奉先缓存传送、部分注册失败、通知失败。再绿测：重复返回、高低质量、损坏源证书仍拒绝、garden及outer-east/outer-west单区复用、TTL/预算/质量/销毁、异常后重试不累积。保留累计组件和有界回归、准确Pages构建/HTTP、独立评审和上传全文回读。完整World、浏览器/GPU、手机未验。
