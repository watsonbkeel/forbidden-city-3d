## 保留的早期失败与归因

冻结源码不变。第一次实时路线报告中，默认模式南北两个完整地面往返均通过；之后在640×400短视口点击“全图”将地图滚动至scrollTop181，神武门标签落在屏外y=-51.923，测试命中检查失败。独立诊断用现有地图右侧滚动区域的真实滚轮恢复scrollTop0后，标签y129.077、canvas命中和实际点击均成功。只修正外部测试的可见性前提，保留原失败、真实滚动前后状态和原遍历/卸载断言；不修改界面或运行几何。第二次运行的默认南北往返再次通过，但神武门在garden区，其原neighbors包含axis-courts，按原政策不应触发外朝卸载。将其作为卸载目标是另一测试前提错误。实际皇极门地图落点(-293.2,142.545)属ningshou，keep集合不含axis、距外朝边界163.2m；正常RAF确实卸载外朝，20个几何、8个拥有材质、1个拥有纹理各收到dispose。保留r1/r2失败和独立诊断，后续默认模式只补生命周期与reload，复用未变化且已过的r2往返证据；all模式补完整缺项，生产包另完整运行默认与all模式，地图、两个地面起点完整往返、两轮离开返回及reload均通过，不复用开发版路线回执。开发组合证据显式绑定r2原报告SHA，r2总结果仍保留失败。

附加原12机位截图脚本对仓库历史main基线的结果仍是11/12失败，原2%阈值、tol24及基线均未改。相同脚本在已交付V6 R上复现相同11项失败；补充F对V6 R的同机位比较12项均低于2%，最大0.90567%，鸟瞰0.09780%，其余≤0.00676%，pageerror均0。此项仅将本轮新增影响与既有基线漂移分开，不把两个历史红报告改称通过，也不代替原八项门禁。
