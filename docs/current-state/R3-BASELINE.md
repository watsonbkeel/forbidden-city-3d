# R3 分支基线与范围

- 仓库基线：`4ef03b7c3315c6f75198f33bd1b40680b7c1e1b2`
- 新分支：`feat/r3-present-day-first-playable`
- 目标：现存故宫的可识别建筑及步行空间，优先纠正结构；阶段版本不代表全宫测绘完成。
- 本轮四个样板：中和殿、交泰殿、乾清门、体仁阁。其余 R2 对象不因通用代码升级自动通过。

## 继承的基线问题

基线已经将神武门移至 Z=542 m，而锚点表仍为 531 m；差 11 m，超过原有 5 m 阈值。本分支不悄悄移回城门，也不增大容差掩盖问题。城墙测量对象、宫城外缘与门楼中心应在后续独立资料核对后统一。

基线浏览器回归的四门通行采样碰到神武门后的世界边界 Z=560；必须区分边界取样问题与真正门洞阻挡。原始基线完整日志和同机位图保留在阶段验收包中。

原测试依赖特定 macOS 用户路径。本分支增加跨平台浏览器发现、明确覆盖环境变量、Node 无图像环境桩和可移植启动脚本，保留碰撞与路径断言。

## 结构参数边界

- `gateKind` 明确区分随墙门、三间门殿、五间三门殿，不再由宽度阈值猜类型。
- 旧七座宽门的当前几何被显式记录为暂定保留；这是迁移，不是新增实景验收。
- 旧锡庆门/敛禧门的 `style: triple` 曾静默落入单门模板。本版显式保留旧单门几何并标记未实现，不能称其已成为真实三门。
- `bays`、`roofH`、`roomBays`、`interior` 等已有字段完整传入；`storeys` 与 `eaveCount` 分离。多楼层必须指定专用结构，未知类型报错。
- `cuanjian` / `yingshan` 是明确屋顶别名，分别映射到攒尖/硬山；其他未知屋顶类型不再静默回退。

四个建筑的证据、近似尺寸、可玩状态和未核细节各自记录在 `cards/`。
