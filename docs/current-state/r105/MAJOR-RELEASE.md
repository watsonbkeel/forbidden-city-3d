## 部署前必须知道的限制与成本

1. Garden重载约374→556ms（+182ms）仍未优化；R98后侧/承托墙自然形体未完成。
2. R102织物约+13.829ms局部构建及2MiB像素；R103窗格约+18.118ms/+1.093MiB属性；R104门组约2.96→14.14ms及约257KiB。低档仍生成这些模型，不能称提速版。
3. R104真实竖檐上沿一个人工18m压力点在10/60Hz×8向共16/144未grounded。另24退出恢复验证10/30/60每组5/8可普通横移、落稳并再跳；不承诺原地跳或所有屋面边缘可站。病态尾p95最高6.535408ms/max13.722394ms仍存在；旧37–43ms拒绝样本保留。
4. 旧台阶/栏边/域外墙若干身体交叠未全园修复，保原差分限制；可退出不等于完全无交叠。
5. 形制来自官方图的定性依据，具体米制尺寸/格数/纹样是工程拟合，不称全宫测绘复原。
