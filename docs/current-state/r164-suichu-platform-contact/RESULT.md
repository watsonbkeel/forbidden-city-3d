# 遂初堂地面传送支撑修复

基线与保底：`1f6e583065d50eb655d66c3772fb798a25656e49`（三处入口修复累计分支）。本轮仅修遂初南阶到台明的实体支撑登记，不改main或部署，不等于整堂、现实入口或GPU验收。

## 原因和最小运行改动

原0.5m台明可见网格和行走面已存在，但南阶家具运动域的有限脚高查询未取得台明实体支撑，原五点严格传送返回null。只在 `SuichuSouthSteps.js` 加一处原生 `kit.col`：世界范围 `[-256,0,416.55]` 到 `[-250.2,.5,418.3]`，为原18.1×0.5×11.1m台明中的5.8×0.5×1.75m南片区。

宽度沿既有南阶域，片区北端在原前门位置。它完全在已有实体内，不是隐藏空中地板；不增加任何网格、材质、纹理、行走面或地图身份，不改原五点路线、公共物理或严格传送守卫。以上均为游戏原模型坐标，不是实景测绘。

初版整台明solid虽让传送通过，却堵住原后门双向通路，已撤销。最终内部南片区保留台明外缘/后口原行为，正式负控仍能复现整盒后门失败，不能只凭传送成功判断修好。
