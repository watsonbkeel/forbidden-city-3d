# V10 体验说明：限定研究预览

本轮范围是画质切换生命周期与门楼栏杆渲染修正。本文说明操作及已有专项证据；最终组合测试、精确包后检查和发行身份以配套PACKAGE-MANIFEST.json及检查包为准。V10–V12不更新Pages，公开版保留V7；V13另行验收后更新。

## 打开可玩包

1. 完整解压 playable ZIP，在解压目录运行 `python3 start-local.py`；Windows 可用 `py start-local.py`。
2. 自行打开 `http://127.0.0.1:8080/`。端口占用时加 `--port 8081`，再打开对应地址。
3. 按 Ctrl+C 停止。无需安装 npm，不要双击 site/index.html。

启动器沿用V9原文件，只监听本机127.0.0.1，不自动开浏览器、不开放局域网。另一台实体手机不能通过这台电脑的loopback地址访问。

## 建议体验

- 地图移动：进入游览，M开图，按住方向键移动后松开，再M关图。触摸界面可用左下方向盘；设置菜单会暂停游览。成功传送后先松开，再重新按键或触摸。
- 画质切换：设置内依次高→低→高→低→高，每次继续游览观察画面；留意地面、建筑与地图是否正常显示。
- 栏杆外观：上城台后观察午门马道栏杆及神武门内栏杆，尤其侧面纹样、顶部和斜向视角。本版是在现有贴图上做渲染修正，不代表栏板纹样、尺寸或现实顶部构造已经测绘复原。

## 已观察通过的限定门楼路线

下列路线来自冻结V9源码的后续gd03检查，采用原生按键和只读DEV位置反馈；不是V10编译包或实体手机的路线验收。每次转向前先松开停稳，不照抄毫秒级点按。

- 午门：按1，向北穿过地面门洞，向西到马道上城台；沿正楼西侧转入南内廊，走外檐柱内侧，经南中央门穿堂、从北中央门到北廊。8个安全截面均到达，台顶脚高12.3m。柱外狭带不是这次路线。
- 神武门：按8，向北接近城台，向西到马道上台；经南侧中央栏杆通口、南中央门穿堂，北门出，再沿北廊横向走。9个安全截面均到达，台顶脚高10.3m。

两条路线不等于四面全绕、所有门洞或连续逐帧覆盖。gd01崩溃、gd02停点及其他既有失败记录保留；gd03成功不能说明旧问题原因。

## 身份与限制

本包运行冻结与构建清单见包根目录R3-RELEASE.json；最终文档源码、附件hash及精确解压包的竖屏检查见外部PACKAGE-MANIFEST.json和检查包。没有对应回执就不能视为包后检查已通过；云端触摸仿真不等于实体手机验收。

午门2.9±0.3m为柱轴至围护轴的图纸推读退距，不是现场净宽。神武门50.18×26.46m城台的测量边界、殿基/台阶高差、屋顶标高和继承11m锚点差异仍待核。历史画面对比与软件渲染低帧率限制保留；历史持续长按停步失败记录保留，原完整复验尚未完成。模型通行不表示现实游客开放；研究照片/PDF不作为应用资产。详见[V10验收记录](V10-ACCEPTANCE.md)。
