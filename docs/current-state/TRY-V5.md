# V5 体验：三大殿腰部侧阶

这一轮补上三大殿共用台基腰部的东西两路侧阶，每侧连续三段；同时让设置面板在矮窗口和手机横屏里可以滚动，加入常驻“结构研究预览”入口。四座侧门只剔除有封闭实体遮挡证明的内部面，保留可见构件；本次实际没有删除退化面。

这是结构研究预览。侧阶中心 z=58 m、外宽 5 m，沿用的三层台基高度和若干细部仍是工程暂定值。游戏里的可走路线不等于博物院现场游客开放路线。

## 打开可玩包

解压 `forbidden-city-r3-v5-playable.zip`。进入同时放有 `README.txt` 和 `site` 文件夹的目录，在终端运行：

```sh
python3 -m http.server 8080 --bind 127.0.0.1 --directory site
```

Windows 可用 `py` 替代 `python3`。打开 <http://127.0.0.1:8080>。结束时在终端按 Ctrl+C。

不要直接双击 `site/index.html`。模型、游戏贴图和解码器已随包提供。点击说明中的官方资料链接会另外打开网站，需要联网。

## 先找到台阶，再从地面走上来

1. 按 M 打开地图，点击“中和殿”建筑文字，传送后若仍显示“点击画面开始”，点击画面进入游览。地图传送只用于找到附近位置；落在台面上不等于已经验证登台。
2. 沿中和殿侧面走向偏南的台基收腰处。找到向台基外侧下行的连续三段石阶，中间有两处平缓平台。东侧在地图东边，西侧在西边；以实际石阶和护边为准，不从栏杆或台基边缘跳下。
3. 先完整下行三段，越过最底层坡脚，继续走到外侧平地，回头看完整侧阶。此时再转身从地面上行，走完第一段、中间平台、第二段、中间平台、第三段。
4. 上到台面后，沿殿侧走回中和殿廊下。再沿原路线下到平地，检查来回衔接。建议先慢走；快走到拐角和台阶端部时松开加速。
5. 另一侧重复“先下到地面，再上行到廊下，最后返回地面”。两侧都应走完整三层，不用再次传送到上层来代替上行。

键盘操作：WASD 或方向键行走；鼠标或 Q/E 转向；Shift 加速；M 地图；Esc 设置。手机用屏幕摇杆移动、拖动视角，点常驻“结构研究预览”进入设置。

这段体验应观察到的是一条连续的侧阶路线，以及仍然存在的台基实体和护边。连续斜坡碰撞相对可见踏面的几何偏差约±0.148 m，这不是角色脚高误差上限。冲刺下坡会在重力/惯性下短暂离地，不同采样记录有约1.961 m和2.149 m的离地差，最终仍会落地，建议在阶脚与转角减速；最高踏面后还由保留的台基立板承接最后一级，台板表面比逻辑台面高 0.02 m。踏步不是任意穿墙入口；侧向撞入栏板、钻入台基或从坡外起步，都不属于正常通路。

## 试一下设置面板

点“结构研究预览”或按 Esc。矮窗口里，标题和关闭按钮留在上面，“继续游览”留在下面，中间内容可以滚动。展开资料详情，滚到末尾能看到日期、暂定值和官方链接。

- 点击画质按钮应同时改变按钮文字和实际画质。高画质的清晰度、阴影和后处理更高；低画质更省资源。
- 在菜单里滚动、点资料或切换画质时，角色应停止移动，摇杆残留输入不应继续推着角色走。
- 关闭、继续、Esc 或点背景可退出。若打开前在地图模式，退出后保留原模式；若浏览器释放了鼠标，点击画面继续。
- Tab / Shift+Tab 可在面板内移动焦点；展开资料后也可以到达资料链接。

最终实际浏览器覆盖与尚未验证项见 [V5-ACCEPTANCE.md](V5-ACCEPTANCE.md)。模拟手机视口不是 iPhone/Safari 或真实手机 GPU 测试。

## 运行源码

源码包 `forbidden-city-r3-v5-source.zip` 解压后，进入有 `package.json` 的目录：

```sh
npm ci
npm run dev -- --host 127.0.0.1
```

需要本机已有 Node.js/npm；首次 `npm ci` 需要联网下载锁定依赖。打开终端显示的本地地址。开发模式默认显示性能面板，窄屏时会盖住部分入口文字但不拦点击，可按 F3 收起；可玩生产包默认不显示该面板。构建可部署的静态文件：

```sh
npm run build
python3 -m http.server 8080 --bind 127.0.0.1 --directory dist
```

`R3-RELEASE.json` 记录最终源码 D、测试运行源码 F、远端提交 R 和源树身份。源码包是 D 的完整 Git 归档加这一份清单；运行逻辑与冻结测试版本相同，D 只补最终说明。没有进行线上生产部署。

## 证据与保留限制

侧阶拓扑参考故宫博物院所载 [1960 年三大殿资料](https://img.dpm.org.cn/Uploads/File/pdf/c7/92/ed/c792eddcdca8356377637b90520bce08.pdf)和 [2020 年刊载照片](https://img.dpm.org.cn/Uploads/File/2020/10/23/u5f9255173a228.pdf)。出版年份不等于照片拍摄日期。不同配准给出的坐标相差约 3 m，不能把暂定的 z=58 m 或 5 m 外宽写成现场实测净宽。

三层台面沿用 0、8/3、16/3、8 m 的游戏标高，殿堂和全局锚点未改。1960 年图和 2020 年文章不能证明完整的 2026 年现场状态；部分台基轮廓、层高、踏步、护边和接合细节仍待逐项核实。

游戏内开放说明按 2026-10-14 的资料核查记录撰写，引用 [2026-07-31 官方施工公告](https://www.dpm.org.cn/announce_detail/379422.html)。它不是实时开放查询，也不代替出行前核对博物院当前公告。整宫现状和当前游客通路尚未全面核准。

神武门仍在 542 m，旧锚点为 531 m，差 11 m，超过原有 5 m 容差。此项没有移动建筑或放宽阈值，整体门禁仍须明确标为失败。软件渲染的 FPS 也不能保证你的电脑或手机实际帧率。
