# V6 体验：坤宁宫偏东入口与两端穿廊


这一轮把坤宁宫改为包含两端穿廊的九间总面阔、七间室内空间。南面的入口在中心偏东的一间；中心匾额下是窗，北面中心也保持封闭。建筑围护、门窗、分隔与通路由常驻建筑层负责；可选家具层加载、失败或卸载都不应改变门洞。

这是结构研究预览。沿用的宽深、标高、柱位和部分门窗尺寸仍是暂定模型参数，游戏路线不代表博物院当天开放路线。暖阁与库房的准确分隔门位缺证，本版不添加推测内门；这不是对历史上完全封死的断言。窗格、玻璃分格与上掀板细部仍为简化表达，两座高灶的形制仍待核实。

## 打开可玩包

解压 `forbidden-city-r3-v6-playable.zip`，进入同时放有 `README.txt` 和 `site` 文件夹的目录，运行：

```sh
python3 -m http.server 8080 --bind 127.0.0.1 --directory site
```

Windows 可用 `py` 替代 `python3`。打开 <http://127.0.0.1:8080>；结束时按 Ctrl+C。不要直接双击 `site/index.html`。模型、贴图和解码器随包提供，官方资料链接另行联网打开。

## 从原台阶走到真实门位

1. 按 M 打开地图，点击“坤宁宫”文字。若出现“点击画面开始”，点击画面继续。
2. 落点在原中央台阶下的共享台面，模型脚高约 5 m；传送不等于已经爬上台阶。沿中央石阶上台，进入南廊。
3. 面对正面向右（东）走到匾额旁紧邻的一间，从木板门进入。中心窗和相邻窗槛不能通行，北面中心也没有后门。
4. 从同一南门退出。沿南廊向东端穿廊走，绕到北廊，再回到原后阶；按原路返回。西端穿廊也可按同样方式观察和返回。转角和阶脚先松开加速。
5. 暖阁和库房的内部展示视角用于检查家具；本版未提供穿过缺证内门的步行路线。不要把检查截图当作可走入口。

WASD/方向键行走，鼠标或 Q/E 转向，Shift 加速，M 地图，Esc 设置。手机使用屏幕摇杆与视角拖动。设置面板沿用 V5 的“结构研究预览”入口。

原控制器有镜头高度平滑与下坡惯性。专项记录到上坡镜头脚面比逻辑支持低 0.444118 m，下坡暂时高约 1.43 m；北端回转进入原后方下阶时也可低于 5 m。支持面存在不等于每帧脚底贴地，这些数值不是现场测量或工程安全认证。

## 运行源码

解压 `forbidden-city-r3-v6-source.zip`，进入有 `package.json` 的目录：

```sh
npm ci
npm run dev -- --host 127.0.0.1
```

需要本机已有 Node.js/npm，首次安装依赖需要联网。请使用支持 JSON import attributes 的 Node 版本；本轮实际验证 Node 24.19.0。打开终端显示的地址。构建相对路径静态包：

```sh
npm run build -- --base ./
python3 -m http.server 8080 --bind 127.0.0.1 --directory dist
```

`R3-RELEASE.json` 记录冻结运行源码 F、补最终说明的源码 D、远端 R 与源树身份。源码包必须是 D 的完整 Git 归档加这一份清单，不删掉继承的游戏测试图。线上生产部署不在本次打包范围。
