# R90：北端门墙与通路协调

## 本版变化

累计基于 R89 de4f61e4，保留时分输入、焦点恢复、皇帝跑步、乾清路线及南部水域 CPU 优化。顺贞门由一个通用门改成三座随墙门；门体、墙开口、物理碰撞和一个地图身份共用专用配置。中央北向蓝色牌匾保留，不给侧门编造新名。打开门扇有实际身体碰撞边界。

中门仍在 (0.5,518.3)，神武门中心 Z=542，外围北墙外皮 Z=547 全不移动。现有中路和北横街原本已通行，本版是形制/接口协调，不宣称修复了不存在的中央堵路。

## 资料边界

故宫官方 [顺贞门条目](https://www.dpm.org.cn/explore/building/236543.html) 支持三座随墙门形制；[从神武门看中门照片](https://img.dpm.org.cn/Uploads/Picture/dc/8401.jpg) 支持中央北面牌匾和基本配色，但未给出三门尺寸或间距。中门5m净宽保留旧模型；侧门3.6m净宽、中心间距7.1m、总宽20.6m全部是明确的工程拟合，不是测绘。普通标签字体不是历史书法复刻。

不在本版重建承光门、延和门、集福门小院，不把官网现场不开门的说明变成关闭游戏路线。现有神武门11m独立锚点差异继续保留待核，不改锚点/容差消除报警。全部可玩开放状态不表示现场开放许可。

## 验证边界

CPU全世界路线与地图测试、源文件精确差异、低帧率往返、门边界和重复加载已安排验证；最终数量、原始全量失败及构建身份见本版 VALIDATION.md。CPU诊断图只展示实际几何与替代平涂颜色，不是游戏/GPU/手机截图，不是实景验收。

专用局部组件含两段相邻墙的合批结果由10→11个mesh、1378→3502个三角面、4→14个碰撞体；不能等同全场景draw call/帧率变化。没有删除人物、关闭碰撞或改动其他宫门。

未在本版合并 main 或部署。生产包和分支上传状态另行核验。

历史 anchors 中顺贞门 w20.3/d4.5 保留；运行时拟合 w20.6/d3.5 并非与该旧锚点尺寸完全一致。游戏地图/碰撞/门墙使用同一个运行时配置。
