# 太和殿屏风冠饰：可回滚结构预览

## 当前范围

基于 ee5353ec 宝座/屏风预览，替换七扇屏风上端的实心小尖帽与过小卷边。现在是有真实空隙的开放冠饰：中央冠饰跨出本扇上缘，三对侧冠左右对称，并以连续结构接到原屏风上框。

这是原创、简化的卷草轮廓。尚未还原实际密集透雕中的龙体、须爪、云纹与精细刀工，不应称为精致复原。日光、室内灯、曝光、金色材料响应均未更改。

## 实景依据与估值

故宫博物院太和殿介绍：https://www.dpm.org.cn/explore/building/236465.html

现状陈设照片（拍摄日期未提供）：https://img.dpm.org.cn/Uploads/Picture/dc/1606%5B1024%5D.jpg

宽景照片：https://img.dpm.org.cn/Uploads/Picture/dc/14498.jpg

官方照片支持七扇阶梯形屏风、中央冠饰向两侧伸出、侧冠曲线和背景可见的透雕空隙。照片没有提供隐蔽结构、雕刻深度和测绘尺寸。本次未把照片嵌入项目，也未将生成图作为史实依据。

保留的屏风宽 4.2 米、高 3.8 米、逐级差 0.33 米、柱网内位置均为现有模型估计，未完成测绘注册。中央冠饰 1.089 米宽、主体截面 49.5 毫米等是作者试值。官方照片中冠饰与本扇宽度约 2:1 的投影关系只提供方向性参考，不能视作精确尺寸。

## 工程边界

- 从固定 0bfa52b758cb 资产中精确退役 1,736 个指定三角面，非按包围盒泛删。
- 新增 2,240 个面，净增 504，总量 17,770，仍低于原 18,000 预算。
- 原 8 个材质批次、全局屏风包络、下部表面、宝座与其他陈设、碰撞和导航均保留。
- 70 个整块旧库存条目退役，7 个只退役顶帽的框条条目重算保留部分实际边界。
- B 级粗模仍为 1,596 面 / 8 批次。
- 新冠饰只是 S 级细模，不添加地图、移动或光照功能。
