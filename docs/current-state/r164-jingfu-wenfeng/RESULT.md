- 陈玉华《景福宫前话文峰》，《紫禁城》1984年第3期，[官网入口](https://www.dpm.org.cn/building/talk/223680.html)、[第35页图文](https://img.dpm.org.cn/Uploads/pdf/2205/T00035_00.pdf)、[后续彩版](https://img.dpm.org.cn/Uploads/pdf/2205/T00035_01.pdf)。已查看实际图像；彩版文峰左缘有裁切，示意画不是测绘立面。PDF SHA256分别为d29d62b98764ad3faefec906bbed6fb9a3a6cc07453e3656210bc91856030604与29b8899df6942fd9677149f8df51fb141bf67330dfc8a0d85cdda678f78ced5b。

模型坐标(-319.8,479.5)依据现有景福宫、佛日楼和景祺阁关系拟合。立石是较强简化的穿孔体，不是照片细节或扫描复原；六孔、轮廓、隐藏面、石色、栏杆数量和座分层均为拟合。实际最高约5.54米，接近官文近似比例，不为这类无碍通行的小差异返工。未刻诗文、未补院墙/月亮门/周边景物，不声称当下参观开放状态。
