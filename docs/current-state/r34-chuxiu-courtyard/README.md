# R34 储秀宫院落连贯游览

## 已实现的范围

以 R33 原有四栋位置为约束，补齐储秀宫前廊、东西配殿前廊与体和殿后廊之间的连续覆盖路线。新增三边连廊的坡顶、内檐梁、14 根廊柱、铺地、两处北端高差过渡和三处向院心的浅阶。四角可连续转弯；储秀宫明间、两配殿门口、体和殿中通道及其两侧原有外侧通路均继续可走。

这不是移动或重建周边殿宇。`ChuxiuHall.js`、储秀宫五间隔断、西梢暖阁、储秀宫本院四栋的既有殿座坐标、屋顶、柱网、墙体、门洞、台基、碰撞体、房间和地图名字均未修改。下文另记为打通总路线而实施的翊坤宫前院估计坐标修正。原先无名的东西配殿仍不擅自指定个别名称。体和殿仍保留原模型标识“翊坤宫后殿”及“体和殿”匾额。

## 史料与拟合界线

官方储秀宫条目明确前廊、东西配殿前廊与体和殿后廊构成转角回廊；体和殿条目也明确后檐廊向两侧转北连接配殿。这是本轮实施的拓扑依据：

- https://www.dpm.org.cn/explore/building/236486.html
- https://www.dpm.org.cn/explore/building/236529.html

页面没有提供可直接用于本模型的逐段测绘尺寸。新增连廊宽度、屋面标高、曲面及转角斜接形式、柱位、铺地厚度、台阶和坡面全部为可回滚拟合，集中在 `CHUXIU_COURTYARD_FIT`。保留旧包络不等于证明旧包络精确。此版不声称完成实测复原、回廊万寿无疆赋琉璃题刻复刻、精确排水构造或宫廷陈设复原。

院心仍保持原地面 0 m。新增廊面与体和殿、配殿原台面均取 0.45 m；北端在 z=425.6→426.6 之间升至正殿原台面 0.60 m。可见铺石面采用原工程约 1 cm 的显示偏移，与已有台面一致。可见梯级与简化坡道接触面采用同一已有行走策略。坐标、标高均是模型坐标，不是测绘成果。

## 实现与回滚

- `src/scene/palace/special/ChuxiuCourtyard.js`：独立新增构建器，验证固定包络及显式拟合 profile；只追加，不修改原殿座。
- `data/zones/west-six.json`：仅增加一个顶层 `courtyardProfile`，不改任何原条目。
- `src/scene/zones/ZoneBase.js`：末遍、合并之前显式调用；其他分区不受影响。
- 移除 courtyardProfile 即撤回新增回廊层；专属功能和运行时接线分为两个提交。翊坤侧路修复还有独立 profile 和两处坐标修正，需要一并撤回才能恢复整个旧 WestSix。

模型采用三边连续斜接坡顶，不叠放两个相交硬山屋顶。没有增设会封死原外侧通路的围墙，也没有伪造不可考的壁面题字。南端及侧殿铺地边缘避开旧台面共面区域；北端坡面有 1 mm 数值接缝搭接，防止大世界坐标 Float32 缝隙。

## 后续发现与修复：翊坤前院原有断路

全轴线连续路线检查发现：旧模型中翊坤宫两座南侧配殿的估计包络与正殿前角交叠，普通半径 0.5 m 玩家不能从前院到体和殿。这是已有模型断路，不是新增储秀回廊的门洞问题。旧坐标回放明确复现失败。

故宫翊坤宫页 https://www.dpm.org.cn/explore/building/236517.html 与体和殿页的耳房改通道记录指体和殿，不据此在翊坤正殿后墙或南侧配殿山墙上开造所谓历史门洞。采用较小的可回滚坐标纠正：仅将两个原标注 estimated 的无名配殿 z=371.3 改为 z=367.3，向南 4 m；x 坐标、长宽高、屋顶、墙、柱、原门、家具及名称完全不变。`positionFit` 保留旧值和修正属性。史料支持院落连通，4 m 不是官方测量数值。

定量过程：沿转弯线 z=374.25，南退 3.0/3.25/3.5 m 仍阻挡，3.75 m 首次通过；4.0 m 多留 0.25 m 余量。正式路线用 z=374.05，居于普通地面玩家可用约 373.75–374.35 范围中央，距两端约 0.30 m。主殿台基仍有实体碰撞，未用隐藏穿透解决问题。

修正后配殿南山墙中心 z=361.7，距南院墙中心 359.5 为 2.2 m，墙面对墙面约 1.9 m。真实屋面边界为 z=361.15–373.45，所有可见构件约 z=361.13–373.47；两屋顶与翊坤门整体包络横向至少相隔 5.5 m。与院落东西侧墙的原有横向出檐关系未改，不把它描述为新完成的精确屋面复原。

`YikunSideAccess.js` 仅增加五条低铺石，60 三角、5 网格、1 已有材质、0 新碰撞体、5 个对应地面接触面；不覆盖原门槛或主殿台阶，不新增纹理/私有材质。两条侧路绕过未动的正殿，后院再接体和殿现有中通道。

追加专项：`node --test tests/r34-yikun-side-access.test.mjs`，11 项通过。涵盖两侧路线从翊坤门→体和殿→储秀完整回廊/室内→翊坤门连续实际控制器行走（10/60 FPS，冲刺）、旧坐标失败复现、局部顶点/门墙/家具完全相同而仅平移、屋顶与门包络分离、真实地面和主体墙碰撞不变。加上前述测试，本分支聚焦总计 50/50 通过。全轴线串接仍由合成版本独立复核；不据此声称浏览器视觉验收。
