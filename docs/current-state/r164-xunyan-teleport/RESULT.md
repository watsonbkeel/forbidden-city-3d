# 寻沿书屋南入口严格传送修复

基线27b8f9dcfe5d362cadea100c402ac7f806e4e0a5，保留原分支和main，不自行部署。

## 可复现根因与修正

现有五级实体石阶总高0.5m、水平延伸1.35m，但旧南向导航仍采用无阶低台基模板。旧首落点(-334.5,0,416.8)实际落在0.200000003m阶面，下一点417.8声明0m而实际为0.5m，因此严格Teleport正确返回null。这不是需要放松认证的小误差，而是玩家无法使用该地点传送的配置错配。

仅将寻沿书屋南向接近点列改为真实阶前地面(-334.5,0,415.5)，随后依次匹配五级真实顶面、平台、原门洞和室内。落点比旧候选向南移1.3m；未改原五阶、任何网格/材质/接触/行走面、地图身份、公共Teleport认证或玩家物理。其余18个profile与后门逐字段保持，包括负零。

坐标、阶尺度为已有游戏拟合，不是测绘。官源支持寻沿书屋属庆寿堂组群及五间前后廊，但不支持这些世界坐标。本轮不建庆寿堂组群甬道，也不把传送可用称整书屋或现场开放完成。
