# V7 体验：昭德门高台与单一中门

本轮将昭德门由通用小门改为高台上的三间门身、周围廊和一组中央双扇门，沿南北两条宽石慢道往返。两处直接相邻庑房接头封闭，不能从低处廊房直接穿上高台。上一版坤宁宫及 V1–V5 改进保留。

这是结构研究预览。主要形制有故宫博物院照片与出版文献支持；具体台基边界、逐间宽、前后分配、栏杆、屋面拟合和北立面仍有暂定值。南侧相邻整条庑房的朝向与门窗尚未重建，不代表整组建筑已经实景验收。游戏中开门通行不代表现场当前开放。

## 打开可玩包

解压 `forbidden-city-r3-v7-playable.zip`，进入含 `README.txt` 和 `site` 的文件夹，运行：

```sh
python3 -m http.server 8080 --bind 127.0.0.1 --directory site
```

Windows 可用 `py` 替代 `python3`。打开 <http://127.0.0.1:8080>，结束时按 Ctrl+C。不要直接双击 `site/index.html`。模型、纹理与解码器随包提供，文献链接另行联网打开。

## 从南坡脚走到北坡脚

实际编译包已验证地图入口，以及南、北两个坡脚外地面起点的完整往返。测试使用真实W键和正常应用更新，朝向有辅助；移动端菜单触摸与视口检查通过，尚不等于真实手机行走体验验收。

1. 按 M 打开地图，点击“昭德门”。地图接近点位于南慢道中段，模型脚高约2.412m，地图传送不算完整登台。
2. 先沿南慢道退到坡脚外的地面，再面对昭德门前进。经过宽石坡到台面，从中央唯一门道穿过。
3. 继续走下北慢道，到坡脚外地面后转身，沿相同路径返回南侧。坡脚和转身处先松开加速。
4. 观察南面三段较宽门身跨度、两端较窄廊间、中央双扇门和砖石高台。左右侧间、栏杆及庑房接头不是本版可走通道。

WASD/方向键移动，鼠标或 Q/E 转向，Shift 加速，M 地图，Esc 设置。手机用摇杆与视角拖动。原控制器有镜头高度平滑和下坡惯性，支持高度与镜头脚面不总是相等；测试辅助朝向与正常输入验证分开披露，云端手机视口不是实机测试。

## 运行源码

解压 `forbidden-city-r3-v7-source.zip`，进入 `package.json` 所在目录：

```sh
npm ci
npm run dev -- --host 127.0.0.1
```

需要 Node.js/npm，首次安装依赖需要联网。请用支持 JSON import attributes 的 Node 版本；本轮实际运行版本为 Node 24.19.0。构建相对路径静态包：

```sh
npm run build -- --base ./
python3 -m http.server 8080 --bind 127.0.0.1 --directory dist
```

`R3-RELEASE.json` 给出冻结源码 F、最终文档源码 D 和远端 R；源码包保留 D 的所有 Git 文件，另附这份清单。完整实测见 [V7-ACCEPTANCE.md](V7-ACCEPTANCE.md)，文献口径见[昭德门证据卡](cards/zhaode-gate.md)。

神武门原模型 542m 对旧锚点 531m，差11m超过原5m容差，整体原门禁保留失败。未经验证的整宫精度和用户设备帧率不作承诺。本次仅新分支，未部署生产站点。
