# R47 万春、千秋亭局部形制与 R46 合并候选

本批在已检查的 R46 本地备份上增加万春亭、千秋亭两座建筑形制，准备作为一份合并开发版本。R46 英华殿、咸若馆的证据、修正及独立验证保留在相邻目录。发布与最终回归结果以本目录 VALIDATION 记录为准，不把局部更新称为完整故宫复原。

## 官方依据与适用边界

- [万春亭、千秋亭官方建筑介绍](https://www.dpm.org.cn/explore/building/236521.html)：成对建筑、方形主体四面出抱厦、上圆下方的重檐关系。
- [官方学术论文，第189页图14及第190页](https://www.dpm.org.cn/Uploads/File/2020/04/08/u5e8d77d699010.pdf)：万春亭平面图区分围护、柱位、台基与台阶；较窄四抱厦形成二十转角轮廓，十二柱位，抱厦内外两重门。正文说明抱厦为庑殿顶。图无可用测量标尺，千秋亭采用成对资料支持的同类拓扑，不称为独立实测。
- [千秋亭官方全景照片](https://img.dpm.org.cn/Uploads/Picture/2020/04/20/s5e9d3ca8f21a5.jpg)及[近景](https://img.dpm.org.cn/Uploads/Picture/2020/04/20/s5e9d3cdf98a1b.jpg)：窄抱厦、圆形上檐窗鼓、槛窗与台阶；拍摄日期未知，网址日期不是现场测量日期。照片中部分门开启，不支持“所有门永久开放”。[万春亭照片](https://img.dpm.org.cn/Uploads/Picture/2020/04/20/s5e9d3c109fb73.jpg)树木遮挡较多，不据此复制室内家具。

## 实际改动

- 仅两个精确命名、精确既有坐标的目标使用专用构造。中央4.8米方形，四臂宽2.8米、深1.1米，整体围护7米；这些是图像比例与模型通行拟合，不是官方尺寸。
- 四个核心角柱与每臂两外柱，共十二柱；二十转角围护，封闭槛窗与绿釉色下部轮廓。
- 每臂有内、外两道门框及各两扇拟合开启门叶，共十六片。每层门净宽1.8米；门叶数、尺寸、折向和全开姿态均为通行拟合，不代表现场开放许可。内外门不是一个被省略分隔的空大厅。
- 四抱厦各有两片梯形长坡与两片三角端坡组成的短正脊庑殿轮廓；核心交接是简化隐蔽屋面。圆形上檐与窗鼓不增加可进入楼层，不添加楼板、楼梯或虚构家具。
- 原方形台基、压面石、六块南北阶石及原三条支撑记录逐项保留。方形台基仍是不准确的简化，尚未还原官方平面中的阶梯状台基与完整栏杆。新增东西阶石与两条坡道为拟合，宽2.4米、起高0.75米、水平长1.2米。千秋亭北阶另外保留原阶石并向模型+X方向（西侧）补0.8米可见阶翼及对应坡道，扩大局部台边开口，绕开原树而非删除景观。
- 柱顶素支承块按实际屋面片段形成接触面，不假装复原精细斗栱。瓦作、彩画、栏杆、宝顶装饰和准确屋顶曲线仍属待完善范围。
- 千秋亭北侧保留原树与树碰撞，不删景观。原北阶与树之间只有约6.4厘米的有效玩家中心转向带，不作为可用通路验收。新增西侧阶翼后，在外门之后向模型+X方向（西侧）移位，使用宽裕阶上通路下阶；这是保留环境下的通行拟合，不是现场导览路线。

## 保留范围与资源

其他三亭、地面花坛、池桥、石景、小品、34棵树的实例矩阵及相应碰撞/支撑按实际 GardenBuilder 原始阶段逐项对比，不以122座 hall 的测试代替御花园验证。122座 hall 另行全部保留检查。

台基以外未删除景观。屋面、窗鼓、支承和新增阶石纳入实际合并、飞行障碍、有限数值与资源释放检查。GardenBuilder.dispose 同时清理其 walkables，避免已销毁场景留下过期支撑。统计字段 meshObjects 是 CPU 网格对象数量，旧 drawCalls 字段仅保留兼容，均不是实际 GPU 渲染计数。

## 未完成

澄瑞、浮碧亭三间南抱厦与池桥关系、御景亭围护及堆秀山安全上下山路径均未在本批改变。没有新增御景亭可进入室内。两座本批建筑仍为 dedicated-partial，内外 accepted 均为 false；无2026完整陈设清单、真实GPU场景或原生手机视觉验收。
