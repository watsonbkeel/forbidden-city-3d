## 本轮做了什么

ZoneBase.build仍在原调用栈内完成全部工作。将原语句放在私有有序生成器内，由同步消费者立即耗尽，gate-first、item、9个条件组、136个原后处理钩子、延禧宫残址框架分离、合批、LOD安装及结果复制顺序不变。精确剥离新边界/包装后，整个旧ZoneBase逐字节等于5030；其他既有src/data/main/release没有改动。

新增getBuildStepMetrics只保存每builder的完成/失败、总时、计数、失败步骤及最多8条最慢步骤。记录只有固定phase与整数索引/有限毫秒，不含对象名称、错误消息或场景引用。现有F3和首错可复制摘要没有变，此记录供本地定位；不是新的遥测上传。索引映射见STEP-MAP.json，gate/item索引对应各区原JSON列表。

没有异步模式、setTimeout、Promise、取消半成品/跨帧发布入口；不改变玩家先移动后区域更新的既有顺序、同步传送/飞行、加载监听、碰撞认证、32MiB缓存或画质。因没有分帧，本轮并未缩短用户遇到的同步阻塞。
