# Translation provenance and scope

The original Chinese catalog contains 164 cards and 130 source records. Its original facts, source IDs, URLs, binding keys and dated review metadata are preserved. The English file is a text-only overlay, keyed by each original card ID. The descriptions and translated historical-source titles are labelled as project translations, not museum-authored English. Separately verified official names have their own naming evidence and status.

The English overlay translates every original summary, function, person/activity record, timeline, evidence/residence note, interior guide, model disclaimer, dated access notice and source title that exists in the Chinese data. Original empty optional sections stay empty. The original English overlay retains its readable pinyin-and-building-type names. A separate stable-ID registry, `data/places/official-names.json`, supplies verified official display names without rewriting that overlay or its descriptions.

Translation was checked for exact card IDs and order, optional field presence, array lengths, nonempty text, numeric/date preservation and retained uncertainty. In particular, unresolved identities, inferred names, demolished gates, intended use versus residence, and fitted model geometry versus measured reconstruction remain distinct. Structural checks alone do not constitute a complete independent historical or linguistic review.

No new review of all 130 official source pages is claimed. Existing source review dates and retrieval types refer to the original catalog research. Current museum access remains unverified; historical announcements cannot establish today's opening arrangements.

The bundled UI dictionary covers the tour's labels, accessibility text, settings, sources and model limits, help, clock, flight controls, loading and failure recovery. Four existing bridge facility groups retain their original IDs and map-only behavior. The language control itself intentionally retains the bilingual label and native language names.

Coverage of supplemental attractions, exact source-object bindings and unresolved identities is reported separately. Neither the 164 original cards nor the model source inventory number is claimed to be the total number of independent attractions.

## Official English naming

A bounded name review checked 97 page-body evidence records for 83 of the existing 286 cards. It used the official Architecture directory and a limited set of directly relevant official pages. Seventy-three cards prefer an explicitly verified official English display name. Their previous project names and all reviewed official variants remain searchable.

East and West Prosperity Gate are singular expansions of the official coordinated sentence, not standalone quoted titles. Donghua Gate and Xihua Gate therefore remain the project display names, with the expansions available for search and the distinction visible in the card.

Eight more cards retain project displays: Yongshou Palace, Jingren Gate, Yanxi Palace, Huangji Hall, Ningshou Palace, Yangxing Hall, Yihe Pavilion and Juanqin Studio. Their sourced wording has a narrower main-hall/site scope or a spelling/abbreviated-form limit. It is shown as related official wording, not declared an equivalent name for the whole card. The scope is visible in both languages. No parent name is assigned to a rear or side hall.

The remaining 203 cards and four bridge groups were not verified for official English names in this pass. That does not mean official names do not exist. Each card distinguishes its English-name status from the project-translated descriptions. A dedicated naming-source section shows original official wording, URLs, check date and scope; historical-source review dates remain unchanged.

Both Middle/Central Harmony, Valour/Valor and the independently sourced Benvolence/Benevolence palace forms remain searchable. The display follows the more specific source or the documented directory form; the other source is not silently discarded. No name evidence adds history, people, dimensions, access claims, map points or travel targets.
