1. **修复回退纹理尺度**：程序化地面回退贴图遗留 `repeat=20`，与以米为单位的 UV 再次相乘，导致约 4 米图案周期变成 0.2 米。贴图库现统一恢复 `repeat=(1,1)`；颜色资产、设计铺贴尺度、UV 和几何不改。正常文件贴图原本已是单位重复，因此不是声称所有正常地面都存在该缺陷。
2. **保守的共享材质响应精修**：减弱石板、地砖的法线凹凸响应，让红墙更哑光、彩漆木构更少粉笔感。不重绘贴图，不改原色，不改几何与碰撞。明确传入的调用参数优先；实际影响 8 种共享材质变体。部分屋顶木构和红色山花共用这些材质，因此也受影响；琉璃瓦、汉白玉、独立 GLB 材质、专用金砖等未改。参数为可逆的美术估值，不是历史测量或已通过截图校色。
3. **修复 Bloom 私有材质释放遗漏**：安装版本 Three.js r162 的 Bloom 销毁函数未释放高通材质，现补齐，覆盖画质切换和销毁路径。
