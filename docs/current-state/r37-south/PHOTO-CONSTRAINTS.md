- T：官方建筑文字事实；P：本次已目视照片可见事实；H：历史图纸；F：实现拟合。所有坐标、颜色数值、纹理频率与未给出的米制尺寸均为 F。
- 官方页面发布日期、论文出版年月、照片拍摄日互不替代；无照片拍摄日即明确未知。
- 优先级：P0 后部拓扑/屋顶类型；P1 墙基瓦口与门窗、代表器物轮廓；P2 未测室内及地下设施，宁缺不编造。

## P0 浴德堂后部组合

主文字：https://www.dpm.org.cn/explore/building/236482.html ，撰稿苏怡，页面未提供可确认发布日期。缓存 `r36-annex-evidence/yude.html`。

1. T：朝南三间前堂、黄琉璃卷棚歇山；后檐抱厦两间。堂后偏西北房两间、黄琉璃卷棚硬山。前堂不能做穹顶，北房不能复制歇山角檐；卷棚不应加直线主脊。
2. T：从前堂东次间后檐门，经曲尺砖拱通道到方形浴室。必须是有转折的连通组织，不是前堂正中直插一个圆厅。
3. H：1942-01平面图支持方形浴室位于东次间后方；烧水房紧接浴室以北；西北的服务入口/台阶区在烧水房西侧。后院西部留空，不应把前堂后部全部封成等宽大厅。
4. H：井亭独立位于更西，隔着西边界墙，南北位置约对应烧水房附近。T只说“西侧井亭一座”，故保留西侧关系；跨墙细节、精确距离和今日形式仍未核。图上的四柱不证明今日屋顶形制；词条通用井亭定义不是该亭专门照片，建议屋顶细节暂缓。
5. H与T不能机械对号：1942图中的西北服务区与今日文字“两间北房”之间缺少逐房沿革核验。可以用T做西偏两间体量，但不能称这两间已逐一在历史平面确认。
6. P：浴室外穹顶灰色亚光，有小型多边形玻璃采光罩、较宽薄檐与顶饰。照片穹顶下部被前方墙遮挡，不能用可见矮轮廓反推出完整半球高度。不得加黄瓦穹顶、巨大圆柱塔身。

外观照片：论文p51图三:1，摄影日未注明，2021出版；`r36-annex-evidence/yude-img-001.png`。
平面局部：`r37-photo-research/yude-plan-detail.png`。历史剖面：`r36-annex-evidence/yude-img-000.png`。

### 可实施比例判断（全部 F，不是测量）

- 前堂保持横向三开间；中央门、两侧窗体分开。1942立面每侧四扇竖窗、中央四扇门可作历史细节参考，不宣称今日扇数已核。
- 立面窗下有实墙裙，窗不是落地玻璃。檐口下梁枋应有厚度但不得把窗上半压没。卷棚屋面应读成单层弧脊顶，不能变成双檐大殿。
- 外观照片采光罩连薄檐宽度约为可见穹顶宽度的三分之一量级；只作为镜头匹配起点，不设“真实比例”断言。确保灯罩明显小于穹顶。
- 灰砖墙脚、红抹灰主墙、黄瓦压顶构成三个独立材料带。墙脚高低受场地高差影响，不用一个固定比例铺遍全院。

## P1 后墙近景及浴室材料

论文p52图六（本次渲染 `r37-yude-p52.png`）：
- P：升高的烧水房入口前有石阶；邻近另有低位火炕门。二者不能做成同高、同款的装饰双门。
- P：红色门扇、灰石门框/过梁、下部灰砖墙、上部红墙；外墙高位有石质渡槽，槽下石托。门上半格栅与低门百叶不同；照片不支持所有窗均复制同一格子。
- P：黄瓦墙帽清楚可见圆筒瓦端与下方尖/弧滴水，两种瓦口交错；主墙不应直接顶一根平黄色长条。
- P：图四显示大铜锅嵌在矩形砌体灶中，有石槽，不是现代浴缸或自由摆放的金属大盆。未知内部不开放比虚构更好。
- T（论文p53）：引入浴室的铜导管室内段已被齐墙切掉，原状未知。不得凭“浴室”恢复完整管道、喷头、蒸汽或热水。
- 地下火膛/火道的存在有论文依据；并不意味着现在适合可进入的游戏空间。此轮可不做地下层。

官方浴室内景：https://img.dpm.org.cn/Uploads/Picture/dc/7415.jpg （建筑页直接引用，摄影日期未知；`r36-annex-evidence/yude-interior.jpg`）。
- P：小块砖状素白/暖白釉砖，错缝横向排布并持续到穹顶；不是大块冷白浴室瓷砖或灰红裸砖。
- P：角部三角过渡/拱隅、中央尖拱门、上部圆形采光口。过渡决定方室承圆顶，不应把圆顶硬扣方墙。
- P：地面深灰；照片不足以确定全地面材料、排水口准确位置及尺寸。
- 论文称高温白釉瓷砖，并指出与普通白琉璃不同；建筑词条使用“素白琉璃面砖”。实现可标中性“素白釉面砖”，不要擅自给出化学配方或统一年代定论。
- 无摆设位置证据：不加桌椅、书架、香妃道具、浴盆或蒸纸堆。

## P1 两个代表陶瓷物件，优于批量泛花瓶

来源：2021开馆全景（目录20210517，具体摄影日未给），不是2026逐件清点。
根目录：https://ggzlquanjing.dpm.org.cn/scene/rOQSztMJ62XbrOjIj78rxu2KMZTcvyfg/20210517_wydtcg/

1. 敬思殿中轴 scene60：`panos/60.tiles/vr/pano_f.jpg`，本地 `r36-evidence/wuying-pano-60-f.jpg`。
   - P：各种釉彩大瓶，外撇宽口、较长束颈、两侧镂空耳、大腹、圈足。腹部多色竖开光，颈肩多道横环装饰。不能套细颈花瓶。
   - F：近似照片中可见正面总高/最大腹宽约2上下，口宽明显窄于最大腹宽但远非小口；透视存在，不能当实测。优先轮廓和双耳、肩环，再做克制的色带，勿伪造精确纹样。
2. 前殿西侧北柜 d102：`panos/d102.tiles/vr/pano_f.jpg`，本地 `r36-evidence/wuying-pano-d102-f.jpg`。
   - P：宽口青花缸形，敞口可见浅色内壁、唇口宽外翻、底部收窄；不是球腹罐也不是深细瓶。蓝白装饰集中外壁。
   - F：照片口宽/可见器高约1.4量级，精确数值不是文物尺寸；应优先表现真实空腔与厚口沿。
3. 两柜共同：透明罩与内部灰白织物质感墩台分离；下宽上窄两层平台，前沿独立小标签。不能做大红箱底或把柜内台当玻璃色。
4. 现代白色矩形顶部灯面属于单柜；不把反射或多个柜顶合成为全厅发光天花。原柱和古建彩画仍可见。

## 收口与验收边界

优先让一处后部组合、两件代表器物与一段墙瓦在近距离辨认出来。保留来源时期/类型元数据，照相拟合仍标F。开放参观、碰撞、进出及屋顶消隐由实现测试确认，本研究不能替代浏览器验收。未核的北房内部、井亭屋顶和当期展品继续留空或只做外壳。

补充 04:42 UTC，给实现者的抱厦限制：现行词条只证明后檐接抱厦两间，不证明偏西坐标。1942平面前堂后侧偏西确有短凸出，但未独立标“抱厦”，将之认作抱厦仅属 H→F 解释；若采用，只做浅的后檐附属体量并明确拟合，不吞没后院，不与独立西北两间北房合并。精确足迹仍可暂缓。
