- 武英殿仅细化已对应 2021 全景的两件代表器物：`scene_d102` 的敞口、厚唇和内底，`scene_60` 的瓶体、颈肩环与双镂空耳。两件均有真实内部几何，不把实体表面伪装成开口。新增两张空白标签，没有虚构藏品编号或文字。

## 审查发现与修正

独立检查在真实合并后模型中发现，最初的顶点色被既有合并器丢弃，另一个瓶口存在向下看穿底的缺陷。最终改用两张很小的私有程序化色带纹理和保留的 UV，补真实内底；没有修改共享合并器或放宽测试。合并后的颜色、内腔、标签和三次卸载重建均重新验证。CPU 几何与材质数据验证仍不等于 GPU 画面验收。

历史图纸年份同时纠正：先前 R36 笔记误读为 1932 年，放大原图后确认是民国三十一年，即 1942 年 1 月及 5 月。R36 原报告保留，R37 明确记载此勘误。历史图纸不是当前测绘。
