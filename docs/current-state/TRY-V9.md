## 打开可玩包

1. 完整解压 playable ZIP，在解压目录运行 `python3 start-local.py`；Windows 可用 `py start-local.py`。
2. 自行打开 `http://127.0.0.1:8080/`。端口占用时加 `--port 8081`，并打开对应地址。
3. 按 Ctrl+C 停止。不要双击 site/index.html；无需安装 npm。

启动器只监听本机，不自动打开浏览器、不开放局域网。另一台实体手机不能通过这台电脑的 loopback 地址访问。

## 地图移动：已覆盖的操作

- 桌面：点击进入游览 → M 开图 → 按住向上方向键约 15 秒 → 松开 → M 关图。本次观察到地图保持打开、角色标记及世界位置变化、正常回到世界画面。
