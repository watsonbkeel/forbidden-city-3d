# R45 箭亭与临溪亭围护布局

本批实际改变两处有名建筑：箭亭、临溪亭。两者旧模型都是没有围护墙、没有天花的通用敞亭，不能表达官方资料所示建筑。新模型分别建立周围廊的厅堂和无外廊的四面门窗亭，不以通用家具填满室内。

## 箭亭

- 官方建筑资料：https://www.dpm.org.cn/explore/building/236578.html
- 匹配实景：https://img.dpm.org.cn/Uploads/Picture/2020/04/20/s5e9d4c87b554a.jpg
- 当前展览用途：https://www.dpm.org.cn/pavilion/247424.html

官方记载五间主体、进深三间、二十柱、周围廊、东西山墙无窗、南五北三门组。照片可见主体五间前方的六条主柱轴，外加两端窄廊回转柱线。旧模型九间、仅前后两排恰好二十柱，数量碰巧相同不等于正确布局。

本批保留31.5×17.6米模型外廓、原近似歇山屋顶、台明和南北阶。主体前立面拟合宽27.5米、前后内退2米、侧廊2米。二十柱采用前后各八、两侧各二的外廊布置，属于照片启发的合理拟合，不是已测绘侧后柱网，也不据此认证主体进深三间的全部结构关系。没有从二十减十六而任意增造四根内部柱。

南面五组门、北面三组门，东西为无窗墙。组数不能转译成单扇数；各组采用四片简化门扇是拟合，不宣称有精确叶数证据。仅南北中央组选定打开用于模型通行，其余组选定关闭，均非现场开放许可。四周廊真实可绕行，门组与隔墙有对应可见实体碰撞。

箭亭为武备馆展览地点。历史叙述中的宝座、碑石，没有足够证据确定当前位置、陈列及保存展示状态，未增造，也不断言它们已经消失。没有编造武备展柜、兵器、床榻或祭坛。只登记一个模型观览导航区，不是完整历史房间数。

## 临溪亭

- 官方建筑资料：https://www.dpm.org.cn/explore/building/236537.html
- 明确图注的东立面：https://img.dpm.org.cn/Uploads/Picture/2020/07/15/s5f0ebf845b521.jpg
- 南北轴向实景：https://img.dpm.org.cn/Uploads/Picture/2020/07/03/s5efee59eb65f0.jpg
- 2018年天花保护研究：https://www.dpm.org.cn/building/talk/248115.html
- 官方论文：https://www.dpm.org.cn/Uploads/File/2018/12/11/u5c0f33bc7102e.pdf

官方为方形三间亭。保留9×8.4米既有矩形外廓，不说成方形测量值；照片较宽明间采用1:2:1轴间比例拟合，两向十二根周边柱。四面中央各四叶门，侧间各两叶槛窗及黄绿下墙板。没有把箭亭周围廊复制到临溪亭。

东西临水门前木护栏均有官方文字支持，东立面细部另有照片，西侧形状只是文字支持的简化拟合。南北中央门打开形成贯通通路，东西门选定关闭并有护栏；没有虚构可从临水侧直接走出。南北中心台阶有照片依据，保留0.5米台明并新增宽3.2米、跑长0.8米、三踏步的游戏拟合。先前方案0.9米跑长修正为共享台阶函数的实际0.8米，所有10/60Hz真实控制器往返通过；没有改共享常量。桥池、外围石栏不在本批完整复原范围。

2018年论文第46–47页明确天花为平面软天花绘画，制造框架与八角藻井错觉。新模型只增加平顶素面，不将画出的藻井做成实体凹顶，不复制纹样，也不把论文修复前照片的破损当当前状态。可移动家具清单未知，不增造宝座或祭坛，空白模型并非历史空置结论。

## 拟合、时间和验收边界

官方图片路径的2020日期是上传路径，拍摄日期未明确；不当作2026年全套室内陈设调查。旧近似屋顶均保留，临溪亭黄绿屋面细节、斗栱彩画和完整桥池尚未更新。原屋顶/台明/箭亭两侧台阶及旧可行走面逐件保持，新增阶梯单独验证。没有更改全局屋顶或通用厅堂函数。

所有新构件尺寸、门姿态、墙内退、柱轴、天花与通行空间均区分来源事实和拟合。两处登记为局部专用实现，不是建筑完整复原。其余120殿座和87条建筑清单记录保持；159地点目录、7项既有不确定性、航行/下机菜单和地图标注保持。两处从无房间的敞亭转为可进入建筑后，自动路线由61增至63，其中厅堂/穿行路线由40增至42；原有路线未删除。

聚焦测试包括实际全区10/60Hz、W/S及冲刺请求往返、门窗/墙与可见几何一致、原构件签名、全区合并及资源释放。最终全量结果另见验证记录，保留历史失败，不宣称全绿。尚无真实GPU/WebGL生成场景或原生手机视觉验收；已查看的是官方参考照片。

## 自动路线复核中修正的问题

新增箭亭入口触发旧验证路线规划器的最近门回退，错误地先进入南三所院落再横穿既有东墙。旧计数61/40断言起初掩盖此问题，独立展开后五项实际遍历检查均失败，因此没有发布该候选。已将箭亭专用验证路线改为从南三所门内经真实南门退出，沿南侧墙外净空向东，再转北进入箭亭中央门；保留东墙碰撞。更新当前计数为63/42并保留全部真实遍历断言，四种帧率/冲刺组合以及几何往返均通过。新回归逐一确认旧61条路线定义完全不变，只新增两处入口；此路线是模型可行走路径，不是考证的历史游览线，也未修改用户地图路线。最终验证须以修正后的第二次冻结全量运行作为依据。
