# 屋顶裁接重复计算减负

基线 adc306fcac0cff588ee2ae348ed7ae5a6c99338f。此为累计开发后继，不代表线上已更新。保留 adc、5030 和 main，未合并或部署。

## 实际改动

唯一运行改动是 `CanopyRoofSurfaceJoint.js`：在一次屋顶裁接调用内部，对已复制且之后不再改写的 polygon 点数组缓存 X/Z 四个边界数。原顺序、EPS、切分、插值、输出精度、法线/UV/索引、材质与碰撞均不改。三个实际消费者是崇敬殿、重华宫和永和宫。

不是全场景缓存，不跨调用保存源对象，不提高 32MiB 区域缓存上限，不改变认证、同步加载、队列、人物或输入。原暂存碰撞 ID 索引方案仍已撤回，本次不恢复它。

## 有证据的改善和边界

两轮预热后，十轮 AB/BA 交错实际组件构建，每轮完整比较输出。本机 Node 24.22.1 的构建中位数为：

- 崇敬殿 228.390 → 114.026ms，约减少 50.1%。
- 重华宫 60.264 → 36.060ms，约减少 40.2%。
- 永和宫 158.470 → 75.730ms，约减少 52.2%。

独立同法样本分别为 213.463→107.201、66.576→39.162、172.926→75.646ms，方向一致。计时排除材质库建立、快照和销毁；每次仍执行原生产组件并检查几何/物理完全一致。原始本轮样本在 BENCHMARK.json，脚本在测试目录。这些是组件 CPU 样本，不能换算为整区同百分比、帧率、GPU、Mac 温度或储秀宫现场崩溃已修。

确定性重复投影数：崇敬 1,430,308→9,416；重华 388,216→6,014；永和 1,097,196→12,438。原算法每个 polygon 最多 720/480/720 次数值投影，当前均为 2。红测在旧源码真实失败，当前通过。减少的是同一内部数组的重复边界计算，不减少三角面或碰撞。

每次调用增加短寿命 WeakMap 和每个已访问 polygon 的四数值记录。没有新 GPU 几何、材质、纹理或碰撞；JS 峰值额外内存未测，不称零成本。区域仍为同步构建，尚不能避免完整主帧长任务。

## 正确性与累计保护

- 三组件的 raw/合批顶点、法线、UV、索引、材质及全部接触/顶面/元数据精确相等。原 mesh/triangle 与合批数不变。
- 真实 west-six：292 合批网格、165126 三角、3223 接触、138 面及完整屋顶、地图、房间、region 摘要保持。真实控制器崇敬正负路线保持。
- 真实 east-six：113 合批网格、145521 三角、2596 接触、127 面及同类完整摘要保持。两个区 queryBox 结果一致，释放构造引用后各三轮清空/重新注册通过。
- 首次/最后 WeakMap 操作抛错保留原错误与资源清理；重复构建不复用前次 memo。变换、边缘、±0、空几何、NaN/Infinity、非法参数按旧行为逐字段/二进制比较。没有把保留旧错误行为说成新增安全验证。
- 源码全量保护证明除审定 helper 外 adc 的所有原运行源码/数据逐字节保持，包括首错本地摘要、皇帝端点、同步步骤计量、三友/玉粹/抑斋及其他累计建筑。三个历史源码保护器只接受本次完整 SHA 再还原原字节，不跳过任意变更。
- 本轮未重跑宁寿。上轮 adc 的完整宁寿/20目标累计证据仍是历史证据，本轮以原代码保持证明没有改动其构建路径，不冒称新的宁寿现场/World 验收。

独立检查 39 个不同正式用例全部通过：37 轻量、2 真实区。另 15 个合成边界探针和独立交错采样单列，不重复计数。有界252唯一文件979项976过/3旧红，加名单外真实west-six/east-six各1，去重为981不同正式用例978过/3旧红，无skip/cancel。名单见 TEST-FILES.json，准确分列见 VERIFICATION.json，不冒称全套全绿。
