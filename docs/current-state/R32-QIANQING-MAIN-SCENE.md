# R32 乾清宫主景：照片支持的局部陈设与天花改善

## 来源与界限

- 官方建筑文字：https://www.dpm.org.cn/explore/building/236472.html 。面阔九间、进深五间，以及减柱、后金柱间设屏等文字，不自动提供当前模型六个纵深站点的米制坐标。
- 官方现存内景照片：https://img.dpm.org.cn/Uploads/Picture/dc/1523%5B1024%5D.jpg 。照片拍摄日期未核；本轮采用这一陈列状态作为有限视觉参照，不声称今天临时陈列仍完全一致。
- 官方院刊林姝《皇极殿考略》印刷 p106：https://www.dpm.org.cn/Uploads/File/2019/12/15/u5df60ccd5aae1.pdf#page=6 。乾清宫与保和殿为满铺天花而无藻井；本轮继续保留该事实修正。

## 实施

1. 两侧蓝釉香亭改为地平之外的地面陈设。模型局部中心 x=±5.2、z=.2，底面为室内地面 2.16；这些数值是照片关系与现有通行净空共同约束的拟合值。没有将其描述为测绘值。
2. 六件既有主陈设改为单一常驻所有者，使加载前后均可见。四件过大黑色动物近似件已按选定官网照片的前景轮廓替换为蓝色盖器与真实镂空高架；未沿用未经核实的“仙鹤/甪端”身份。器物名称、照片日期及精确位置仍未知，不能称六件文物精确复原。四个中心仍为 x=±1.9/±3.1、z=3.5，局部 y=.70–2.35、半径≤.46，均是原占地约束内的试拟数值。
3. 中央椅背从整块长方板改成分段轮廓与局部镂空；依据选定照片增加遮挡部分椅身的覆帛前案。椅背、前案尺寸、布色与雕饰均为照片拟合/自绘近似，保留原地平、五屏、三阶和整个中央不可进入边界。
4. 天花取消大面积八圆点式花纹，使用较低反差的自绘盘绕纹、连续浅格框；23×12 格数和 .12m 深度属于工程试样，不冒充实际构造测绘。天花净高、殿顶、柱网、匾联位置未改变。
5. 金、漆、布的响应分别落在同一私有材质图集，未改全局曝光、太阳、环境光或其他殿堂金材质。
6. S 级可选 GLB 只保留地砖、六根红柱及原有 27 个代理。真正的主景常驻对象不再重复加载；当前严格绑定 SHA、逐网格可见属性摘要、变换、材料与碰撞位置，错误同面数替换仍被拒绝。

## 成本与通行

新可选 GLB：6512 三角面、4 批次；旧 R31：9024、8。转移的常驻陈设与新天花、近远主景仍须全部计入总场景成本，不能用可选层变小宣称零成本。
两侧新香亭各有常驻实体碰撞；中央地平保持原不可进入范围。针对当前 B/S 两态的左右侧线 x=±6.45 往返已通过真实碰撞 CPU 检查。该安全线是模型验收值，不是官方公布通道尺寸。

乾清纵深柱网与太和匾联挂高因配准证据不足暂未改动。本轮不得把包④写成完整尺寸校准完成。真正浏览器画面、总预算及最终普通体验在合并候选冻结后统一验收。

## 前景器物修正的边界

四座高架有可透视的真实开口，不再用整块金色圆筒；每组≤480三角面，整套常驻陈设仍≤3300、四个私有材质且无新贴图。原动物几何源文件保留作回滚与出处，不再次挂入场景。此处根据官网照片可辨轮廓修正，不宣称鉴定了馆藏器物；远处是否另有禽兽形器物未否定。固定机位新画面仍待检视。

## 合并预算修正：距离细节

原六机位第一轮的前三点超过保留的 10% 三角面门槛，失败记录保留。为减少数百米外仍绘制的殿内细件，主陈设和天花采用 90m 切远、81m 返回近景的距离层级：陈设近景 2912 面、远景 664 面；天花近景 446 面、远景 2 面。近景位置、可见属性和原永久碰撞逐字节保持；远景仍有两香亭、四盖器/开架，同一连续天花纹理。仅去掉远处亚像素线脚，不改变门窗、柱网、屋顶、步行净空或全局光照。

两级同时驻留，增加 666 面和对应几何内存，计入驻留总量；当前相机只绘制一级。不能把近景预算 3300 当作两级总量，也不能仅凭 CPU 省面宣称六点性能已通过。完整流式六点复验和远近画面检查另有回执。渲染链沿用既有 LOD 更新顺序，跨阈值时批次可能晚一帧切换；不同时绘制两级，尚未据此声称真实设备无可见跳变。
