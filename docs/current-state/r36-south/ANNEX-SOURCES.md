# R36 南区附院最小形制依据

核读日期：2026-10-21。仅研究，不改项目代码。所有未获得实测的体量、坐标、标高均为 F（拟合），不由旧 bbox 反推精确足迹。

## 可以立即纠正的错误

### 宝蕴楼：不能沿用中式双檐厅模板

- 官方修缮说明：https://www.dpm.org.cn/classify_detail/180962.html （2013-12-24）。
- 由北、东、西三座砖木西式楼组成，北楼为主楼，东西附楼相对；三楼均地上两层，下有半露地下室。不是一座占满整个院落的矩形大厅。
- 两层白柱、白栏开敞外廊连接主副楼；南侧由咸安宫遗留的咸安门围合。保持中间露天院落，保留中国式院门与西式楼的差别。
- 红色抹灰墙作矩形分格；窄长窗，白色窗线脚；双层门窗的外层为铁门铁窗。屋顶高耸四坡，覆鱼鳞状牛舌瓦，不是黄琉璃瓦飞檐重檐。
- 本文有面积但无完整足迹边长，不能把原模型 46.6 × 32 m 当单栋实测占地。
- 最小实施建议：三体块+两层开廊+空院+独立南门，红墙白边窗、灰色四坡屋顶。室内不凭空陈设；体量与门轴关系未测部分标 F。

### 浴德堂：前堂与后部浴室不得混成一个穹顶大厅

- 当前官网建筑介绍：https://www.dpm.org.cn/explore/building/236482.html
- 在武英院西北平台，前堂朝南，3间，黄琉璃瓦卷棚歇山顶；后檐接2间抱厦。
- 堂后偏西另有2间北房，黄瓦卷棚硬山顶。
- 前堂东次间后檐开门，经曲尺形砖拱通道通方形后室；后室才是穹顶浴室。四壁至顶素白釉面砖，顶部采光开口；西侧井亭是独立附属。
- 不能把前堂改为大圆顶；也不能只做普通黄瓦后屋而漏掉独立灰色穹顶。

## 西支水道接口提醒

- 官方2012排水论文配图与当前官网导览图均显示：水从武英院西侧、宝蕴/咸安门东侧向南，绕至武英门南三桥，再转断虹桥及熙和门北。
- 西华门通向武英门的宽阔南侧道路不应因为拟合水道而硬添“第4武英桥”；西北侧另有小桥，但位置与门前三桥不同。
- 河与咸安门东侧连续院墙相交处示意被墙遮挡，未获得近照；接口形式仍 F，不应声称核实某种桥或涵洞。

- 原图 https://img.dpm.org.cn/static/themes/image/xf/map3.jpg 及 https://img.dpm.org.cn/Uploads/File/2020/04/27/u5ea6a2bde2722.pdf 。均非可直接像素定米的当前测绘。
