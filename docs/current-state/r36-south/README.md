# R36：南区布局、逐殿陈设与直升机下机修复

本轮以 R35 `0d7bbf23c1d79b36170a36b27a988488554f1b9f` 为回滚基线，在独立开发分支推进。范围于 2026-10-21 02:07 UTC 确认，四小时检查点为 06:07 UTC（北京时间 14:07）；03:20 UTC 加入紧急直升机交互修复。

这是**有来源标注的南区布局校准首版**，不是整片故宫已达到测绘级 1:1，也不是全部实机验收通过。

## 本轮变化

- **文华与武英院群**：拆开前殿、穿廊、后殿，修正把组群外包尺寸误作单殿尺寸的问题。保留两院各自配殿、附院和真实连接关系，不镜像复制。四座命名单殿的地图/导航锚点改为相应模型中心，旧组群坐标保留在来源字段。
- **河道、桥与墙下通水**：从中央五桥向东西延伸，连接武英门前三桥、断虹桥、半壁桥、文渊阁池桥及东侧内桥。12 处桥梁分别具有行走支撑；涵洞保留上层墙廊。水面、地面切孔、碰撞和地图共用同一轮廓。断虹桥采用官方公布的长 18.7 米、最宽 9.2 米，其余弯折、标高等仍明确为拟合。
- **文渊阁**：按六开间、外部两层、黑瓦绿剪边及池桥入口组织；入口绕开中柱。传送须核实目的区、完整桥面支撑与实际弯折进路，缺桥或阻路时拒绝。
- **武英展陈**：按官方 2021 开馆全景的 16 个独立柜逐一对应，前殿外部 4、后殿 5、展中展 7。保留低红框、玻璃、独立灰白台座及各自器形轮廓；不是随机摆放同样的瓶子。器物纹饰未作高精复刻，未核实的墙柜藏品不虚构填充。
- **文华展陈**：依据 2026 年典则展第一期全景的 7 个关键视点，区分高展墙、仅一条直接有图证的前岛低柜、长廊高柜、可穿行前圆门和不可穿行后圆形展示。没有把第一期作品杜撰成第二期现存库存。
- **宝蕴楼**：用有来源的三座西式楼、两层及半地下外露基部、白柱廊、红墙白边窄窗和四坡屋顶替代通用中式双檐大厅。未建模的室内关闭，不摆通用宫廷家具。
- **太和殿**：核对现有七扇背屏、六金柱、四座前排高足器架及成对主景；本轮没有重复改动其已拟合资产或 GLB。

## 紧急直升机修复

- 按 H 与点击下机统一恢复步行、头部起伏、鼠标控制，清空飞行及步行遗留输入和飞行焦点。
- 普通步行不再常驻完整飞行面板；只有靠近停稳直升机时出现轻量登机入口，走远隐藏，不自动登机、不自动解锁或抢焦点。
- 浏览器拒绝/延迟 pointer lock 时仍保持步行状态并显示明确的点击恢复入口，不假装已恢复鼠标。
- 再次登机、原生 Esc 通知顺序、地图/设置占用、移动端触控、恢复成功后正常 Esc 均有事件链回归。
- 原生 DOM / pointer-lock 边界由测试装置模拟；运行的 FirstPersonControls、Three PointerLockControls、FlightTour 和 main 回调是真实代码。这不是原生浏览器现场操作证据。

## 验证如何阅读

[最终命令、计数、退出码与字节身份](FINAL-VALIDATION.json) 是最终结果入口。[逐断言分诊](REGRESSION-TRIAGE.md) 区分已复现基线失败、旧版本身份链阻断和本轮有意范围变化。**未通过的旧检查不会被计作通过**；没有删除历史夹具或抬高容差来制造全绿。

- 新南区、展陈、桥涵、真实控制器地面往返、地点目录及资源所有权均直接检测当前代码。
- 几何检查器仅为文渊阁和文华穿廊增加明确的实际路线适配，不再把中柱/圆形展示当成可直穿空地；实路堵塞、缺桥、缺楼面均有负向测试。其他泛型规则保留。
- 159 地点身份和 7 疑点保留。33 条固定路线保留名字与数量；61 条当前自动路线包含新增的文渊阁实际入口。
- 两条泛型绕行算法回归使用明确标注的 R35 四构件输入，执行的算法仍为当前代码；它们不被当作当前武英几何验收。
- 四殿 anchor 的 0 偏差只是同源模型、地图和导航一致，不是独立外部测绘精度；原神武门锚点 11 米差异未抬容差掩盖。

## 明确保留的缺口

1. 云端浏览器实测 WebGL Disabled，本地 HTTP 候选与该浏览器不连通。因此没有本轮真实游戏画面截图、原生人工完整走线、真实 GPU/FPS 或实体手机验收。
2. 官方导览图是绘制图，不是带控制点的正射测绘总平。多数建筑单体尺寸、院墙/河岸坐标、展柜间距与标高仍为可逆拟合；米制单位不等于已验证 1:1。
3. 武英全景为 2021 开馆记录；文华为 2026 年第一期展陈构造证据。今日第二期作品位置、2026 武英藏品是否替换，没有冒称已核实。
4. 浴德堂后部抱厦、曲尺拱道与浴室穹顶、文渊阁历史内层/书架、宝蕴楼室内和精细瓦作/雕饰仍未还原。没有把这些留白称作完整复刻。
5. 本轮没有更改 main 或发布 GitHub Pages。R35 基线保留；开发分支与线上体验是不同交付状态。
