## 结论与使用边界

可立即实施的是：以官方建筑文字和实景照片约束南区拓扑，以明确公布的米制数值校核局部尺度；其余足迹、院墙折点和河岸折点保留为待拟合。已取得的两张官方地图都是立体绘制导览图，不是正射测绘总平，不能直接以像素换算真实米数，更不能把它们称为“测绘级1:1”。

当前层应以现存建筑群为对象，不把明初、清代或民国原状图自动当作当前总平。文章中历史推论与现存照片/尺寸必须分开。

## 可直接作为验收程序的拓扑约束

项目实际采用西X正、北Z正的本地坐标；以下只是方向/次序，不含绝对米坐标。

1. 中轴：午门北侧广场，经五座内金水桥到太和门；太和门北侧为太和殿前庭及太和殿。每座桥均有水体在下且两端落到可走岸上。
2. 东西边界：西庑中设熙和门、东庑中设协和门；它们是贯通中路与外朝东西路的门，不是贴墙装饰。
3. 西院主序：武英门→月台/甬路→武英殿→穿廊→敬思殿；武英门南有三桥；断虹桥在武英院东，桥向南北。
4. 东院主序：文华门→月台/甬路→文华殿→穿廊→主敬殿；北部接文渊阁及方池、池中桥、东碑亭和北假山。
5. 东西配殿按独立命名、独立方位检查，不以镜像生成替代资料。
6. 河道在西路、太和门前、协和/半壁桥、文华/文渊阁及东侧下游之间连续。暂未核定的折点标F，曲线拟合不得宣称是官方坐标。
7. 河岸、桥、慢道、院墙以碰撞/交穿测试核对；尤其协和/熙和慢道与河岸的夹角，武英门前4.8m净距，不能用统一宽路盖掉。

## 必须排除的误用

- S12论文p202图7明确是“南京紫禁城金水河流向图”，不是北京南区底图。
- 同论文讨论元大内位置、断虹桥迁移年代属于学术主张；官方断虹桥建筑页仍标建造年代未定，R36不应把单篇推论转成确定史实。
- M01的left/top百分比只是导览标注定位，且标注有视角偏移；不应导入3D场景当现状建筑中心坐标。
- M02/M04为绘制导览图，即使以全城961×753m拟合，也只能得到粗定位，不是独立验证过的局部米制尺度。
- “1单位=1米”是场景单位约定，不等于“全场景已1:1验证”。
