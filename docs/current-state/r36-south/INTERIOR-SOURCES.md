# R36 南区室内陈设证据

核验时点：2026-10-21 UTC。范围：太和殿、文华殿、武英殿与敬思殿。用途：区分建筑与陈设类型，并以可追溯官方实景支持建模。以下为来源研究记录，不等于实机验收；研究用原图未作为项目贴图再分发。

## 结论与实施优先级

1. **三馆不得共用一种家具填充规则。** 太和殿为原状陈列型；文华殿为现代书画展厅；武英殿、工字廊及敬思殿为2021开馆陶瓷通史展厅。
2. **武英独立柜已由落成全景逐柜复核。** 后殿横排5柜、前殿东西各2柜、前殿展中展北排4柜/南排3柜，共16柜。不是2020设计中的“展中展5柜、外部11柜”。实际位置组织以全景优先，尺寸仍只能引设计。
3. **文华已核7个关键实景点。** 除沿墙通柜外，前殿有自由立展墙及低玻璃平柜、格栅圆洞隔屏；穿廊两侧为高玻璃通柜；后殿中轴圆形框是作品展示，不是可穿行门洞。不能简单复制武英工字形柜。
4. **今日不等于资料上传日。** 文华当前为典则第二期（2026-09-30至11-01）；所见完整全景为第一期9月资料。武英完整现场为2021开馆期。太和图片拍摄日期未给。可按对应时期复原构造，不可宣称2026全部物件、位置已经现场核验。
5. 禁止根据单件藏品网页倒推摆位；禁止将历史宫廷家具填进今日展馆；禁止把未核验书画写成当期作品。官方照片未查得可再分发许可，仅作研究参考，不直接提交为项目贴图。

## 证据等级

- **P：实景可见**。官方照片/全景已经下载且目视；支持可见形态、相对组织，不自动支持尺寸与遮挡部分。
- **T：官方文字**。支持名称、用途、日期、设计数值。
- **D：设计/策划**。有明确数值或平面方案，但不是落成实测；与P冲突时以P为准。
- **F：实现拟合**。为适配项目尺度决定的坐标、间距、简化轮廓。必须保留此标签，不应被source字段包装为实测。

### 可实施特征与边界

- P：中心高台、左右红色阶梯、中央彩绘龙纹斜面、两侧栏杆构成层次，宝座置于上层中轴。不要压扁成普通桌椅组合。

- P：前方能数出**四个高足架台上的青绿色有盖器**，左右各二。其后仍有金色高耸香亭、立鹤等陈设；不应把所有器物缩成8件普通花瓶。
- T：官方建筑正文写宝座两侧六根金龙柱，陈设包含成对的宝象、甪端、仙鹤和香亭。该概括不是现场全部物件总清单。
- P：宝座为宽座、雕龙高背/扶手、复杂透雕底座及前脚踏，不宜用普通皇座模型替代。七扇屏、宝座与礼器须分别建模。

### 可用结论

- 紫褐背板、灰/深色底柜、轻薄浅色案台、全高透明玻璃，与武英红框厚墩陶瓷柜显著不同。
- 前殿有“高展示墙+低平柜”和格栅隔屏；廊为连续双侧通柜；后殿有中央圆形展示面及周边折角柜。三部位必须分型。
- 保留古建彩画顶和红柱，不加现代全覆盖吊顶。部分前殿地面呈彩色纹样铺面，廊为深灰石/砖地；未证材料与尺度，不应硬说同一种地砖遍布所有厅。
- 目前**没有官方柜高、深度、条数总表或实测尺寸**。实现3.45m高、1.05m深等只能标F，不能套用武英的D。
- 第一期全景的柜体结构作为最接近当期的参考，仍应标“2026-09第一期实景；第二期物件未核”。两期合计107件绝不能作为单期柜数/作品数。
- 2026年5月“神骏”以及2024年其他书画全景确实存在，但均已退出当前陈设证据集，避免跨展拼接。

## D. 对已读实现的证据审核

只读审核了 `SouthGalleryDisplays.js` 的早期版本；已将以下项逐条通知唯一实现负责人，未直接改代码。

1. 删除前殿/穿廊手排碗罐是正确方向；如重新加入，应按16个实景柜的ID建立一对一来源，不使用随机/循环泛类别填充。
2. 后殿轴心大瓶位置有实景，但代码`cz=1.8`及`.86m`不因附了设计URL就成为实测。瓶轮廓应匹配可见的大腹、宽口、双耳，不复用细瓶。
3. 独立柜应分离“低框玻璃外壳”和“内部灰白墩台”，而非大红底箱。
