# R9 central ceiling frame candidate

The official throne photograph https://img.dpm.org.cn/Uploads/Picture/dc/1606%5B1024%5D.jpg and caisson photograph https://img.dpm.org.cn/Uploads/Picture/dc/1602%5B1024%5D.jpg visibly establish thick coffer frames, recessed decorated panels and exposed frame sides. The building page https://www.dpm.org.cn/explore/building/236465.html describes the decorated interior. These photographs do not establish current capture dates, exact frame width/depth or installation heights.

The R8 panel surface is four flat planes. This bounded candidate adds 28 frame segments in the central column strip only, reusing the existing 1.6 m tile cadence. Width0.12 m and drop0.18 m are visual estimates. Panel/caisson heights, opening, column grid, plaque/couplets, furniture, lights, exposure and FOV remain unchanged. Other ceiling areas remain flat and require later evidence-led work. Museum imagery is reference only, not runtime artwork.

Cost is explicitly additive: 280 visible triangles, 23,184 unmerged index/attribute bytes, no new texture or material batch. Shared mesh batching can change final buffer allocation; actual merged memory and whole-scene calls/triangles must be measured before release. The unchanged S core remains17,924 triangles plus60 existing main-beam triangles. Counting the new frames too gives18,264, so this is not a claim that total interior geometry stayed below18,000. The existing18,000 core limit and original whole-scene +10% performance gates are not raised. Original gold shaft end caps were already removed in R7 and provide no additional savings.

No new collision, walking surface or lighting is introduced. Initial focused CPU tests7/7 pass. Two identical-camera R8/candidate views were actually reviewed: frame relief is visible but modest, so it is not a standalone overall-realism success. With the separately reviewed rear enclosure, merged hall geometry changes by +212 triangles, +1 material batch and +20,640 buffer bytes. Final original whole-scene performance and regression acceptance are recorded in the integrated release notes.
