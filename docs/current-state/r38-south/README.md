## 本轮实际改变

1. 依据官方照片中可定位的树干，在文华殿正面两侧补四株，在武英殿前院两侧补两株。它们是照片支持的部分呈现，不表示这两处实际只有六棵树。树干、倾斜和分层树冠使用有差异的局部拟合，不借用御花园随机散点，不把庭院铺满同样的树。
2. 武英殿两株树增加薄的土面和石边树池轮廓，未把未知高度的池边虚构成障碍。文华殿完整种植地边界、低枝和每根细针叶尚未复刻。
3. 太和门南侧原通用单梯改为两条台阶夹中间实体御路石，两侧斜栏杆分别构建。北侧台阶、殿体和屋顶不改。中间御路石不是步行坡道，既有“午门→太和门”路线改从真实模型西侧梯道上行后绕过原柱排再回到中轴，没有删柱或降低碰撞来制造通行。
4. 没有新增午门—太和门—太和殿中央铺地庭院的树。单独有资料的十八槐、文华门前海棠不等于本轮六株殿旁树，未按名称臆造整齐十八棵槐树。
