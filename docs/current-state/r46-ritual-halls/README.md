# R46 英华殿与咸若馆的佛堂关系局部更新

本批只更新两座已绑定建筑：英华殿 outer-west/items43，咸若馆 outer-west/items19。保留旧整体尺寸、台明、南台阶和原可行走面，替换通用办公家具与不符建筑类型的壳体。其他120殿座、87建筑记录保持，159地点/7既有不确定性不变。两处均为局部实现，不是完整复原。

## 英华殿

来源：https://www.dpm.org.cn/explore/building/236568.html
实际外景：https://img.dpm.org.cn/Uploads/Picture/dc/8416.jpg

官方五间、单檐庑殿、明间四叶门及四个侧间的槛窗，取代旧九等分歇山通用厅。保留32.7×18.2米既有拟合外廓和0.9米台明，不将等分轴间、屋顶曲线或选定打开门姿态称为测量。没有把耳房也改为庑殿。

官方七座佛龛只有数量，缺少可靠摆位/当前库存依据，因此没有按七个盒子猜摆，不增造佛像；撤去通用办公桌椅并非断言实际殿内为空。天花和墙面为素面拟合，精确彩画、后檐开口和内柱关系尚未完整核验。

替换庑殿网格发现共享生成方式的屋脊零面积三角形，仅对本目标新屋顶过滤零面积面，不改共享RoofBuilder或其他建筑。实际非退化几何、合并和释放另有独立测试。

五间、三进深主体，南向三间封闭抱厦，周围廊。不是永和宫式敞抱厦。官方照片可见外柱与其内侧窗墙，采用保留26.7×20.6米整体外廓内的分带拟合：主体外柱带Z−5.3..10.3，三间抱厦Z−10.3..−5.3，廊内退1.5米。主体围护X±11.85、后Z8.8、前肩Z−3.8；抱厦围护X±6.51、前Z−8.8。中央衔接开放，无虚构封死隔墙。地方坐标+Z北，−X东。

高歇山主屋顶与低圆弧抱厦分别建模，隐蔽交接为非共面拟合遮盖；圆弧体量不是完整卷棚歇山端部复原。未获测绘屋顶图，不把柱轴/屋顶交接/深度当已知尺寸。四根抱厦前柱顶部另加0.4×0.4米素面承托，底部接原柱顶6.4米、顶部随实际离散屋面底面裁切，补足约0.67米承托区；不是考证复原的斗栱花样。素面平天花不复制花卉绘画，也不做实体凹藻井。

东西北三面连续阶梯龛柜来自官方文字与照片。采用素面非具象三层轮廓，最大深1.6米、高3.6米，侧带Z−1.8..7、后带Z7..8.6，三层高0.8/1.2/1.6米、深1.6/1.05/0.55米，全部是拟合而非史料层数/测量值。低柜与墙面、窗、中央通路分开；不增造佛像、中央供案物件、唐卡、七层塔或密集小龛细节。

重要年代界限：2017图片路径不是拍摄日期，同一外景已见2011创建的研究PDF。2004陈列页面、旧照片与明确写作1980年代以前的物件描述不能认证2026完整陈设。没有找到龛柜被移除/改组的证据，不能据拍摄日期不详宣称已消失；本批是有年代界限的官方参考解释，不是当代库存验收。2015公告是修缮及陈列计划，不证明每个部件原样保留。
