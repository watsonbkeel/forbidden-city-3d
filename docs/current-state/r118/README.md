## 已实现的限定行为

- 游戏时间 **21:00**，皇帝从太和龙椅原接触位站起，沿实际连续通路以原 **12 m/s** 跑向储秀；最大 dt `.1s`、水平子步不超过 `.15m`。
- 储秀后妃从白天西次间北炕出发，保持 `.65 m/s`。两人各占现存西梢间北罩床的固定独立睡位，普通完整服装、闭眼；没有另造床，也没有缩小身体。
- **06:00** 启动醒身及连续返程，最终回原太和龙椅/原后妃白天座位，不在 06:00 瞬间传送到终点。午夜保持睡眠；中途手动调时沿当前路线段反向，不重置至起点。
- 玩家堵住床南入口时等待，移开后继续。两角色按原 capsule 做彼此完整扫掠，固定两 slot 不共享中心；不宣称有平滑爬床动画。
- 保原 40/45m 显示迟滞和 60/70m 模型资源兴趣窗。离区只保两人的数值作息状态与必要导航；不向玩家 cm 写假地板或隐形近身身体、不永久 loadAll。
- 两人新路线的踏步、地坪覆层和木槛使用真实 F32 向上三角接触，完整足部/衣袍包络；当前三角裸数值变异也先停。乾清玉路侧缘和一处旧箱体切角只作局部安全绕行。原乾清低台使用实际 Float32 成品顶/有限域交接；承乾西配原木槛登记同源实体。无全局 body、STEP、SAT 改动。

## 来源与生命周期合同

- 完整现存床六面/十二三角、朝外绕序、顶沿副本、真实顶面覆盖以及两 slot/入口净空一起验证。替换同数属性/array、改版次、改 frame、缺 mesh、错误朝面或第三人均不能沿用旧证明。
- 初始座位由真实成品和 Kit 座位接触指标验证；既有预建数据只提取两条路的数值邻域（703 collider / 106 walkable 的本次实测），远区渲染几何仅有 WeakRef 证据，不被本功能强持有。
- ZoneManager 正常 unload/cache/evict 可继续离线逻辑；重载重新绑定当前实体，并核床和白天座位。意外 detach、当前几何/owner 变更先停，不当正常卸载。睡眠状态的 source identity 随重建更新。
- 每帧只检查两人当前完整身体和该帧最多 1.2m 的扫掠邻域（3m 包络），未来段在使用前检查；不每帧扫全园或哈希全部 mesh。公开 CollisionManager add/remove/update 驱动当前空间索引；当前 owner 同数替换由原 array/index 身份检查。
- 合法 Three.LOD level 切换与 OcclusionByWall 官方离屏隐藏不等同源删除；几何身份仍检查。普通 lamp 显隐不是建筑支撑。缓存重入先清旧视角剔除状态，显示前当前源必须可用。
- 未通知的远处对象直接搬入近处、非当前接触面的未按 Three 协议标记 needsUpdate 裸 buffer 写入、未声明手写矩阵不属于快速变更合同；不为这些非产品路径增添每帧全园扫描。

## 成本与边界

新路线 2077 点、水平 861.278847m，JSON 133767 bytes；未为了文件小而简化拐角。JSON 的 `sourcePrefix` 是保留的原1051点输入来源留档，不代表修后1051点逐值相同；与当前HEAD路线真正逐值相同的共同前缀为333点，乾清侧梯与箱角的有限改点另有测试与oracle。路线长度是功能成本，不与旧中和短线冒称同功能性能提升。

最终完整 60 Hz 去返、两角色 routine 共 **8616 帧**：新增路线区间 P50 `.098ms` / P95 `1.984ms` / 最大 `10.414ms`，出程 P95 `1.795ms`、返程 P95 `1.817ms`；冷启动段最大 `13.697ms`。私有导航初始化约 `448ms`，CharacterSystem构造约 `452ms`。这是本地两 routine 的 CPU 更新，不是整帧、GPU或手机性能承诺。见 [完整 raw 与源绑定](../../../reports/r118-nightlife/final-route-cost.json)。

703 colliders / 106 walkables 的数值字段粗估 122656 bytes；1331 个真实接触三角另含34606个 owned numeric scalars，按Float64等价 **276848 bytes**，796个索引cell、5737个cell行引用、30个大面引用。对象/Array/Map/WeakRef开销未计，**不是 JS heap 或峰值内存**；模块内旧22数/tri计数只是偏低粗估，最终外部逐字段26数/tri账为准。原100帧 `.834ms` 测在新增实际接触通道之前，不再冒充最终成本。全签名版 P95 18.06ms/初始化3717ms已拒；中间3分钟长测中止，绝不当PASS。
