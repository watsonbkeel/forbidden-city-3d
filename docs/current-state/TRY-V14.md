# V14 体验说明：地面门扇与出口指引研究预览

本版以V13最终源码为基线，范围为地面门扇碰撞、模型相对神武门地面出口指引及初始分区覆盖/诚实回退警告。V14最终运行冻结已完成1249/1249串行CPU；封包时浏览器、原生行走、性能和实际ZIP验收为PENDING。后续结论以绑定对应ZIP哈希的配套LOCAL-RELEASE-RECEIPT.json/发布说明为准，正式组合交付时另见PACKAGE-MANIFEST.json与检查包；本文不预先宣告通过，也不因后续结果重写或重压已测试ZIP。

## 打开可玩包

1. 完整解压playable ZIP，在解压目录运行`python3 start-local.py`；Windows可用`py start-local.py`。
2. 自行打开`http://127.0.0.1:8080/`。端口占用时加`--port 8081`，再打开对应地址。
3. Ctrl+C停止。无需npm，不要双击site/index.html。

启动器沿用前版1945字节原件，只监听127.0.0.1，不自动打开浏览器、不开放局域网。实体手机不能通过电脑的loopback地址访问。运行/构建身份见R3-RELEASE.json，实际ZIP的大小、SHA-256和检查结论见外部回执。

## 本轮查看什么

- 为模型中12片既有可见地面门叶补齐碰撞代理，横向bounds对齐既有mesh，垂直采用既有0–3m身体代理约定；这只是模型碰撞修补，未核现实门叶当前开合角度或门洞开放现状，不构成新的测绘真实性验收。不是封闭整个门洞、所有建筑碰撞重做，或完整穿门路线通过证明；精确门扇集合与范围须与批准的源码一致。
- 神武门地面出口采用玩家可到达的模型相对指引。它不声称现实位置、真实游客开放、建筑标高校准或原11m锚点误差修复。
- axis-courts分区覆盖初始位置`(0,1.7,-494)`。区外情况仍需准确说明回退到第一个已注册分区并按正常流程加载该区/排队邻区；只有独立的loadAll或`?zones=all`分支才立即加载全部分区。不能从历史警告文字推断加载数量或性能变化。
- 继承V13初始视点、限定屋脊/宝顶精确同值批次修复和V12紧凑地图。视点是选定的游戏视点，不是实测摄影位置；窄竖屏不承诺完整午门组群入镜。

按正常提示进入，使用WASD/方向键或触摸方向盘。持续按住约2秒仍会自动奔跑；松开有原控制器减速。M或触摸预览打开完整地图；“收起到角落”进入紧凑地图，“展开地图”返回；紧凑状态可平移/缩放而不点击传送。具体输入与界面覆盖仍以本版实际测试范围为准。

## 两项模型自测

以下是供用户检查的目标，不是已经完成的浏览器验收，也不代表现实开放。

- 在午门/神武门地层门洞贴着可见门叶移动，检查身体不能穿叶，而中间仍可通行。
- 沿神武门地层中门向地图北侧走出城台，检查位置提示从“神武门”变为“神武门外”，在门外跳跃不应闪回。

## 如何看验收结论

V13的1147项CPU、cp03六点结构预算及en02四例13张图/短按住观察只属于原V13输入；cp03还有6项软件FPS警告，cp02午门调用超预算仍是失败历史，均不能自动算作V14通过。V14须绑定自己的F、构建、实际ZIP和原始结果；未运行、失败、局部通过分别记录。

若沿用原六机位性能测试，仍为原机位各60帧、原基线与阈值。任何在正式入口原字节后仅追加两个访问入口的TEST-ONLY副本，须单独绑定；其结果不是原样交付ZIP或实体GPU的性能证明。普通浏览器观察与有钩子的性能副本不能互相替代。

神武门上层满汉匾及黄色门罩仍缺失；系统字体不是原书法，模型尺寸未校准，11m锚点偏差超过5m容差。窄竖屏历史裁切/提示重叠和软件FPS限制保留至本版有明确对应证据；桌面窄视口不等于实体手机或触摸验收。两门完整编译包原生路线尚未验收；短行走、受控机位、CPU段落和V9 DEV旧路线不能替代。
