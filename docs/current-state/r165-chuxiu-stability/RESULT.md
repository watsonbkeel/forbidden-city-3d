## 用户可见改变

1. 主帧异常后仍停止游览并提供重新加载。新增可手动复制的首错摘要：阶段、限定区域、构建身份、允许的异常类型、固定原因类别和故障分类码。不会自动发送、持久化或循环刷新。复制不可用时保留文本选择与重载。
2. 皇帝按游戏北京时间定点：06:00–20:59 在原太和殿龙椅，21:00–05:59 在原储秀宫皇帝床位。首次进入、调时、从后台恢复、关闭再开启人物都按当前时间决定，不补跑跨宫行程。
3. 玩家或共享床位的另一角色占据目标时，皇帝留在当前安全状态等待；来源缺失/变更则停用显示或暂停，不强制加载远区，不落到虚拟地面。妃子继续原局部活动。
