# R383：御花园北口、顺贞门与神武门

[故宫博物院顺贞门资料](https://www.dpm.org.cn/explore/building/236543.html)区分园内承光门、延和门、集福门与园墙上的顺贞门三门洞。顺贞门外隔北横街才是神武门；今人路线与游戏双向漫游是两回事。参考馆方[从神武门看顺贞门](https://img.dpm.org.cn/Uploads/Picture/dc/8401.jpg)辨认独立铺地与门墙，不从照片倒推绝对尺度。

R382 将北横街中段误标为「神武门」，园内靠近矮墙也缺少去向提示。东侧沿名义甬路 x≈−17 直接向北会碰到堆秀山边缘；从模型中实测可通行的相邻走廊按 x≈−15.4 向北，可以转进延和门。这不是在假山上开路。

R383 在园内给两个可通行的转弯补了平铺路线；在顺贞门外至神武门城台南侧补出可区分的北横街铺地，并按地段显示位置及去向。铺装和尺寸只是现有模型上的工程拟合。矮墙、门洞、假山、城墙、建筑锚点、碰撞与已通过的三佛贴图均保留。中线可通是保留的游戏改编，并非实际承光门开放的声明。

回归覆盖：站立玩家从御花园相邻甬路，经双侧门或游戏中线，出顺贞门、过北横街、穿神武门到城台北侧再原路返回；低墙仍然不能直穿，铺地不引玩家进东侧假山。
