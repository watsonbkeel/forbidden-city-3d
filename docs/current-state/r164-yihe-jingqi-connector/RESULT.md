## 有依据的范围与拟合

故宫颐和轩、景祺阁官文明确两建筑间有三间穿廊，中央东西开门。官方《紫禁城》2025年第1期印刷108页平面支持颐和轩后口；《“迷楼”—符望阁》印刷19页下图可见低瓦顶和红色窗门侧面，但有遮挡。来源、原始文件摘要及证据限度见 SOURCE-MANIFEST.json。

本轮新增可辨认三间低檐穿廊、两端窗面、中央东西出入口和实体南阶，打开准确识别的旧颐和轩闭门面，补两片全开红板门。位置、宽度、开间分配、窗格、颜色、屋顶接缝与全开姿态是适应现有布局的拟合；未做小院园石、家具、原彩画、精确测绘或现时参观权限。两原建筑轴线相差0.4m，不移动原建筑。

中段采用原地面0m，南端九级实体阶接既有颐和轩1m平台，北端保留景祺阁原五级阶及0.8m平台。这个高差处理是游戏通行拟合，不是历史地坪测量。没有新增地图对象、房间或传送目标；I29仍29个原ID，分类不变，只有颐和轩/景祺阁增加局部代码证据，整项验收新增0。

## 改动边界及保护

运行改动仅 YiheJingqiConnector.js 与 ZoneBase 的一个 import、一次挂接。只移除唯一旧闭门面及对应普通接触；原颐和轩后门楣几何不动，仅给同一形状接触增加原生 overhead，使新开放通路跳跃头部被实际门楣截停。Teleport、公共物理、数据、原两殿及26排组件源码均未更改。

来源守卫要求准确宿主、可写数组/父级、自动矩阵、标准旧门 position/normal/UV/index/groups 实际载荷及单一几何引用。异常在提交前释放暂存资源，不误删漂移目标或释放其他网格共享几何。
