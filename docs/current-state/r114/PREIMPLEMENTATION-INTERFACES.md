## 施工前阻断：全宽延伸新增前配交叠（不能漏检）

上述8mesh替换是**接口算式，不是已批准可通行几何**。两前配台基z364.5..376.7贯穿新扩展条；新全宽平台条x[-108.25,-78.95],z[372.15,373.75]，与西前配交叠x[-81.14,-78.95]（2.19m宽）、与东前配交叠x[-108.25,-106.06]（同宽）。旧平台在更北处已有同角交叠，但新条把它往南延长1.6m，ph.6可能覆盖ph.45的配殿前缘/内部/门旁。**writer必须先核新条变化域里的前配真实墙、门叶、room-floor和通路**，不可称“原问题不归本轮”后把新增部分隐藏。

若要只建中央窄月台避两角，南伸条宽最多24.92m（两前配台基内缘之间；还须留身体/石板余量），如约24m宽才有几何余量。但这变为阶梯平面，不可继续把全宽owner/顶面统一南扩，否则出现无可见台面的幽灵碰撞/支持。窄月台必须有准确分块owner和R109源绑定设计；这已不同于上方最简单原位单盒方案。优先先用真实前配剖面裁定全宽候选能否保留，再决定是否需要窄月台；不要为赶时间改角色尺寸、全局步高或身体数学。
