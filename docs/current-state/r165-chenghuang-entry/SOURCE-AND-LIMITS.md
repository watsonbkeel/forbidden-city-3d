# 城隍庙入口琉璃门：来源与有限实现

本次只增加城隍庙山门前东侧院墙上的一座闭合琉璃入口、短自有墙段及可达低阶，不代表三间山门或完整城隍庙。原整组对象FC-B3FB517883未宣称完整复原、测量、室内完成或现行开放。

故宫博物院苏怡署名建筑页 https://www.dpm.org.cn/explore/building/236481.html 将“山门面阔3间，灰瓦硬山顶”和“门前东侧院墙辟琉璃门一座”分开描述。“硬山顶”不借给这座琉璃门。东向/-X仅是与“东侧院墙”相容的游戏拟合，非一手独立方位证据。
