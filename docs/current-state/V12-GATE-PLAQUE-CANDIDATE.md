## 结构、资源与有限回归

- 每个新匾额均是独立有名语义网格，正面为局部+Z，午门整体旋转π朝南。
- 只有正面三角形使用文字Canvas材质。背面、侧面为无字材质；UV正向，不让六面共用字图。
- 缓存键包含文字、横竖布局、样式、脚本、宽高厚和系统字体栈。不是仅凭文字复用。
- 两块旧网格各替换为一块新网格；午门增加112三角形，神武门三角形数不变。每块从一种材质变为两种、两个绘制组，合计增加两种材质和两个绘制组。未声称实测FPS变化。
- 碰撞体、可行走面、城台、洞口、门扇、马道、栏杆及所有无关几何保留。
- 历史几何金标准没有刷新。测试仅将两个精确身份、位置的候选插槽恢复为旧匾，再执行既有栏杆有限恢复和原始V9/V10指纹比对。
- PalaceBuilder和RoofBuilder具有固定历史SHA-256与逐段精确字节替换守卫；缺失、重复、修改替换段或其他字节漂移都会失败。

已执行的集中CPU检查包括语义身份、正反面/侧面材质、Canvas实际绘字顺序、UV、缓存隔离、资源释放、屋面射线分离、城台净空、合并后元数据、固定碰撞/支撑及历史几何守卫。目标浏览器字体、阴影、抗锯齿、实际可读性和斜视遮挡尚未验收。
