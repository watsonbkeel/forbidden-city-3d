1. 最终累计输出确认负X近路线owner2051，168个原cell完整不重叠铺满同高10.5的矩形实体，无跨界cell。原四项初步结构测试通过：联合体网格、坏输入拒绝、旧cap全部属性与其它geometry/owner保留、生成折面/简化cap点位对应。
2. 为避免R98原单owner2320tri的代价，保旧render cap属性，但以相同平面域简化物理cap；唯一候选原12→70physics tri、原168cell合计2016→738render tri。只向内宽尺度斜折、顶面/外缘保持，没有加外贴皮或旧box假碰撞。
3. 同实际Garden生产导出、同route/side相机和光照的CPU图显示：路线近景确实可见变化，但仍像数块贯通高度的大三角内折支挡板，侧视像规则锯齿，不像自然叠石。writer与独审一致拒绝，不向其它四组推广，不做第二档参数。
4. **没有运行候选闭合/最终合批同源独检、落脚退出矩阵或正式成本。** 四项初步结构绿不是物理/性能通过；70tri也是规模，不是成本通过。未采纳候选不进入后续R112–115运行树。
