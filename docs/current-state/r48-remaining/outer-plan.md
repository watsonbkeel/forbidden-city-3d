# R48 Outer 27 逐项实施计划

基线 56fd3e9。模块独占 RemainingOuterHalls.js；只由集成 owner 接线。

先实现宝相楼、吉云楼、慈荫楼、慈宁宫、大佛堂、寿安宫，再含清/延寿与南薰/延春，最后已专用南部增量；11个证据条件项持续调查，不把记录更新当实际改模。

## 1. 主敬殿 (place-outer-east-b7c67c602b)

- 模式：augment
- 几何：保留既有2026年9月第一期展厅；据官方后殿全景补可见展柜/灯带细部，外门窗只在照片证实时调整。
- 边界：后殿略似前殿不等于门窗扇数全部相同；不得复制前殿单项到后殿。
