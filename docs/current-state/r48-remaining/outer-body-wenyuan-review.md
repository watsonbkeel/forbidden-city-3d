# R48 文渊阁：真实入口可达穿体复核

## 结论

- 固定基线模块：`2ffeaf1fa9be545335ccb5eda0a092845dd750e8935655ab2551dddfaef572a9`。
- 固定修复候选：`60b02f3aa8c8fc9b5be7fc50cd841b657af32b90327d158526fc45abcdfbf80d`。
- 基线主测试为 1 个入口/两梯可达通过、8 个实际穿体失败；补充测试为 3 个可达/绕行通过、4 个方向攻击失败。不是把静态候选直接当作实际错误。
- 修复候选：主测试 9 项、补充 7 项，分别经过 10/60 fps × 步行/冲刺 × 正向/倒行，合计 128/128 通过。
- 同候选另与原 `r48-outer-wenyuan.test.mjs` 联跑：28/28 通过。未替代全项目测试、构建或发布检查。

## 测量边界

实际 FirstPersonControls，只有 DOM 事件目标和 performance.now 被桩化。碰撞世界来自完整 outer-east Preview 构建。每次从池前 world `(-186.5, 0, -156.3)` 出发，经原入口进入，需实际到达相应楼层与攻击前位置，禁止从上层生成角色。所有已验路线均无 rescue / unverified 地面来源。

穿体判定使用场景 mesh 经 matrixWorld 变换后的实际三角形，不是只有 AABB。完整头高使用 `feet + PLAYER.HEIGHT - 0.000001`，即 1.7 m，不采用生产碰撞体裁短的 5 cm。相切容差仅 XZ 内缩 1 mm、脚底 STEP_CLEARANCE 上方 1 mm、头顶 1 微米。只检查稳定脚面帧（feet/ground 差不超过 .02 m）及真实攻击阶段；完整 mesh 顶面不高于该脚面 + STEP_UP 的接触另列为低踏步，不混入高实体穿体。补充测试在攻击/绕行阶段检查所有实三角，不只检查已知梯面。

原静态候选底层 51、暗层 33、三层 281 点。这里逐类建立真实路线，没有声称 365 个采样点都逐点到达。没有浏览器截图检查。

## 基线实锤与路线

以下 x,z 为阁内局部坐标，世界坐标偏移为 (-186.5,-132.8)。每条路线前均有池前入口与必要楼梯。首个命中处为连续控制器帧，不是人工传送点。

1. 底层折门：入口后向 (-6.2,-7.95)；首命中约 (-5.7905,-7.9428)，feet=.5，lattice_doors。真实叶片绕 Y 轴转了 90°，原来无对应实体代理。
2. 底层屏风横档：经 x=-1.1 内柱间，转至 (-.5,3.5)，向 (-.5,4.4)；首命中约 (-.4830,4.1598)，feet=.5。横档 y=1.165–1.235 原无代理。
3. 第一梯下：从 (14.3,-2) 向 (15.5,-2)，首命中约 (14.6331,-1.9639)，feet=.5。右侧从 (18.5,-2) 向 (16.5,-2) 也可穿入；高端从 (16.05,1.1) 向 (16.05,-2) 也可穿入。
4. 暗层旧额枋/墙带：第一梯平台 → (10,.85) → (10,-6.46) → (-3.375,-6.46) → (-3.375,-8.4)。首额枋约 (-3.3773,-8.2928)，首墙带约 (-3.3755,-8.3762)，feet=3.15。穿体发生在脚点仍由暗层楼板支撑时，不是掉楼后误报。
5. 第二梯下：第一梯平台 → (10,.85) → (10,-7) → (18.12,-7) → (18.12,-4.1)，首踏板约 (18.1264,-4.4999)，feet=3.15。高端靠左 x17.8 / 靠右 x18.5 亦复现。较小 x 侧被既有第一梯洞栏挡住，较大 x 侧被旧扶手/外墙边界挡住，未把这两条不可达侧路算作红例。
6. 三层前檐窗/外柱：从第二梯上口转至前廊，向 z=-7.4；外柱及隔扇实际三角原无代理。
7. 三层山墙：三层内廊 (13.1,-3.4) 向 (-18.9,-3.4)；首砖墙约 (-18.6497,-3.3999)，feet=5.5。
8. 三层后檐窗/外柱：沿柜端外绕至 x14.2 再向 z=7.4；实际三角原无代理。

单独记录的小问题：新内柱 CylinderGeometry 底部半径为 1.05r，原 collider 为 ±r，可产生毫米级柱脚/锥面擦入。它与上述大面积穿体分开报告，候选已扩大至实际柱底范围。

## 修复可通行性与中途回归

候选低栏明确标记 `MODEL_ACCESS_SAFETY_FIT_NOT_HISTORIC_OBJECT`、`source:null`，不是考据历史陈设。第一梯的左右及高端低净空入口被可见低栏阻止，第二梯高端低净空入口被阻止；两梯原上行/下行路线保持可通。

保留的真实绕行包括：
- 底层第一梯外围：(14.3,-4.5) → (14.3,1.1) → (18.5,1.1) → (18.5,-6.8)。
- 暗层第二梯高端外围：第一梯平台 → (10,.85) → (10,-7) → (18.12,-7)。

中途 cf81aa 候选按材质收集旧立面代理，误把 0.5 m 台明收成实体，使池前角色在 world(-189.8756,-142.78365)、feet=0 卡住，9 项全因前置不可达失败。父任务随后只为高于 g.y+STEP_UP 的原立面件添加代理，保留原低台基/低门槛可迈规则。最终 60b02f3 候选的真实入口与两梯前置已恢复。

前置路线不是测试漏洞：为避免低帧冲刺在原约 8 cm 容差前廊中擦柱，主测试从入口走 (-3.375,-4.5) → (12,-4.5) → (12,-6.8) → (16.05,-6.8)，然后按原两梯路线；攻击末段不变。三层后廊从 x14.2 绕柜端，避免低帧 waypoint 转弯误差导致未到攻击区。
