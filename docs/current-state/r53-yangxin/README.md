## 来源尺寸与兼容拟合

详见 [注释平面](visuals/annotated-plan.png) 与 [机器可读几何 delta](white-model-delta.json)。项目坐标 **+X 为西、+Z 为北**。来源局部坐标原点取西暖阁东南角，u 向西、v 向北：

`x = 6.32 + u × (11.18 / 10.15)`；`z = -5.55 + v × (5.4 / 5.15)`。

这是一组可逆、非等比的兼容变换，不是测绘。总宽模型比来源宽 1.03 m；南部深度加 0.25 m。三个来源净宽合计 9.30 m，与总宽的 0.85 m 差额来源未明。本白模将其变换后均分为两条 0.468128 m 隔带，**不声称这是真实墙厚**。三希堂 6−5.15=0.85 m 与 p123 北伸 0.77 m 的 0.08 m 差异也单独保留，没有静默修平。

原 x=6 GLB 门洞不另加墙。原实净宽为 z[-1.44, 1.44]，通行采用 z=-0.84；该入口位置属于旧模型兼容，并非历史门位的测量结论。前缘 z=-5.55 与保留前窗 z=-6.3 之间的 0.75 m 也标记为兼容余量。
