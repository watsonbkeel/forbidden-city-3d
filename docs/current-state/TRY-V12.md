# V12 体验说明：紧凑地图限定研究预览

本轮在已打开的地图中增加“收起到角落”和“展开地图”，方便边走边看地图；另调整持续位置提示与地图的布局。建筑、出生点、天空、碰撞和玩家边界沿用V11。CPU和构建已有对应记录；普通浏览器、触摸仿真及实际ZIP结果见配套PACKAGE-MANIFEST.json和检查包，本说明不预先宣告待验项通过。公开Pages继续保留V7，V13首屏/性能另行验收。

## 打开可玩包

1. 完整解压playable ZIP，在解压目录运行 `python3 start-local.py`；Windows可用 `py start-local.py`。
2. 自行打开 `http://127.0.0.1:8080/`。端口占用时加 `--port 8081`，再打开对应地址。
3. Ctrl+C停止。无需npm，不要双击site/index.html。

启动器沿用已交付版本的原始字节，仅监听本机127.0.0.1，不自动开浏览器、不开放局域网。另一台实体手机不能通过这台电脑的loopback地址访问。

## 地图操作

- 桌面按M、触摸界面点右上角预览，先打开完整地图；点击“收起到角落”进入紧凑状态。关闭地图后再次打开仍从完整地图开始。关闭时的118px触摸预览与紧凑地图是两个状态。
- 紧凑地图设计宽度为桌面240px、触摸220px，显示八方向朝向和“展开后可传送”。可拖动平移，使用滚轮或双指缩放；点击紧凑画布不触发传送。
- 点击“展开地图”返回完整地图，保留切换前的缩放和平移。建筑标签和快捷传送按钮在完整地图中使用；成功传送后先松开再重新输入。
- 收起/展开只切换地图展示，不调用地图开关或重置行走输入。可按住W/方向键或左下方向盘再切换；实际设备上的持续移动、松手停止及多指衔接仍须按配套检查记录阅读。
- “结构研究预览”、展开和关闭三个操作保留在紧凑地图中，样式按最小44×44 CSS像素设置。原披露入口仍打开设置并暂停游览；恢复后需要新的移动输入。
- 触摸横屏为左右控制区各预留164px。高度不足时，紧凑地图隐藏画布，留下朝向和操作条；恢复足够高度后重新显示画布。左上角位置文本允许换行，窄屏改用上下排列以避开地图。这些布局需由实际浏览器画面和命中检查确认。

## 已知边界

普通浏览器的限定检查覆盖1280×720桌面、390×844触摸竖屏、844×390触摸横屏及844×240短横屏，另检查恢复竖屏；最终是否完成以及每项结果以外部回执为准。触摸仿真不等于实体手机。320px窄屏、安全区、全部朝向和所有焦点/手势组合不能由这四种尺寸推定通过。

午门原出生点仍被下檐遮住“午門”，单纯抬头不能消除几何遮挡，较远首屏属于V13。神武门北面上层满汉匾和黄色门罩仍缺失，系统字体、牌匾尺寸及建筑尺度沿用前版研究近似。V11受控图的神武门南立面仍为部分覆盖，城外机位不代表玩家可达；V9 DEV限定路线也不是V12包全路线复验。
