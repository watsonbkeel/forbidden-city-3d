# V11 体验说明：门楼匾额限定研究预览

本轮调整午门南面门名和神武门北面院名；不改变通行、碰撞、建筑锚点或天空。最终CPU、视觉、性能及实际可玩包结果见配套PACKAGE-MANIFEST.json和检查包，不能从本说明推定通过。V11匾额、V12紧凑地图、V13首屏/性能及Pages；公开版在此期间保留V7。

## 打开可玩包

1. 完整解压playable ZIP，在解压目录运行 `python3 start-local.py`；Windows可用 `py start-local.py`。
2. 自行打开 `http://127.0.0.1:8080/`。端口占用时加 `--port 8081`，再打开对应地址。
3. Ctrl+C停止。无需npm，不要双击site/index.html。

启动器沿用已交付版本的原始字节，仅监听本机127.0.0.1，不自动开浏览器、不开放局域网。另一台实体手机不能通过这台电脑的loopback地址访问。

## 看什么

- 午门南面：竖排“午門”在两层屋檐之间，蓝底金字、自绘简化红金框。原gp01近景曾有“午”字被上檐遮挡，本次只修正牌匾挂点与尺寸。当前默认出生点仍被下檐遮住两字，单纯抬头不能消除几何遮挡；较远首屏位置属于V13另行验证。近景可读性和普通首屏必须分别记录，不以换机位画面替代。
- 神武门北面：浅底深字的“故宫博物院”横匾位于城台墙面上段。上层满汉文门名匾仍未复原，模型亦缺中央黄色门罩；两者均是明确缺项。
- 午门北面没有复制新门名，神武门南面旧低位“神武门”已撤去。系统字体只是语义文字近似，不是原书法或雕刻复原。
- 地图和移动沿用上一版：M开关地图，按住方向键后松开；触摸界面用左下方向盘。设置菜单暂停游览，成功传送后先松开再重新输入。
