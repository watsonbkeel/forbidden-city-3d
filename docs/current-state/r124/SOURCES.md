# R124 source boundary

Primary official relation: [储秀宫](https://www.dpm.org.cn/explore/building/236486.html). Official panorama API metadata and independent images, reverified by the source agent and reviewer, bind main group58, east Yanghe group62 and west Suifu group59. Cache manifest remains private under `r123-r126-source-preflight` and `r124-independent-review/source-preflight`; original official bitmaps are not redistributed in this project.

- Main group58 photographs8/9: recessed front enclosure, glass/wood-skirt door assembly, side upper red rectilinear lattice/lower glazing, pale continuous front beam field. Photograph file paths include2025/08/19, but that is not asserted as the photographic date.

Modern displays/signs/fire equipment are not modelled as historical inventory.
- Main interior2017 photographs314×400 and313×400 were separately viewed, supporting broad fixed wooden partition/screen relationships but not exact all-face carving or a reliable five-panel mirror remap. The existing central composition was preserved, not claimed newly complete. Native existing inscriptions unchanged.
- [2024故宫学刊论文](https://www.dpm.org.cn/Uploads/File/2024/07/22/u669dcd8dc5647.pdf), printed258Fig1, retains the inherited R123 topology context. Unscaled plan, no new measurement or courtyard refit is inferred.

## Evidence classification

**Fact/photo-observed:** named side assignment from independent metadata; door/window/column/beam composition and broad colour zones visible in selected photos.

**Engineering/photo-fit:** retained model dimensions, equal bays, schematic nested rectangles and connector bars, material colours, beam field subdivisions, game-open door pose. These are not exact carvings, measured sections, historic open-state or current visitor access claims.

**Unknown/unimplemented:** full reverse-face partitions, precise dense window pattern, floral hanging-bracket carving, complete painted-beam motifs, unverified inscriptions, other western-room furnishings, full panorama/WebGL navigation. No imitation full inventory is added to fill these gaps.
