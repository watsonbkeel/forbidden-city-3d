# R124：储秀正殿门窗与前院三立面组合

**当前：本地限定开发候选 / PARTIAL；必要功能/资源/旧门对比已终态，精确干净build见外部交付manifest。** 基于已冻结R123 `0aab5f4c`，累计R118同床作息、R119交泰、R120乾清与R123后院/父frame。R116/R117无采纳性能改动，R120 NR1/NR1b已拒绝恢复；R121/R122石山三案未交付。下一累计major为R126。

## 实际改变
- 主殿原凹入门面：两个固定侧光和两个保持开放的门叶，在旧实体包络内分成木裙、上下玻璃、木框；四侧窗上部由粗梯格变为有实际连接的简化嵌套矩形，下部增原域内分竖。
- 主殿与两前配的朝院前梁：保持旧梁体/底标高，改为浅色主框域、灰绿端区和窄边的连续组合；不是新增整套斗栱/挂落，未复刻花卉彩画。
- 两前配同原面上的整高通用隔扇，改为砖槛、下玻璃、上红格窗；既有开放叶作同域木裙/玻璃分段，仅前排柱改绿。两侧分别有官方养和/绥福独立立面支持，不复制现代商店陈列、海报或未核牌文。
- 不动R123父frame、外墙/屋顶/回廊地面/14柱位置、门洞、室内范围、接触owner/rooms、床/隐私屏/人物路径。**中央四罩五屏只对照保留，本版没有完成全部中央内装修。**

## 来源与拟合
主门窗来源为官方储秀宫group58的8/9号照片；养和东配与绥福西配分别来自group62与59的独立官图和实名元数据。原图仅私有研究缓存，不入产品。位置/尺寸沿用已批准模型；格纹、色区、门的游戏开启状态是合理示意拟合，**非测绘或精确纹饰复原**。

## 已知边界
- 真实图库准备好后再进入的策略不变，0新增atlas/texture请求；并非性能优化版。
- 第一版孤立格环视觉拒绝，修正为接到总框的有限短接；第一版图片/测试保留，不把预算PASS当视觉PASS。
- 27条门面局部门进出能完成，旧完整后院连接9例能完成；但新试的外院直行/部分短转角会停滞，已在冻结R123同输入逐帧复现。没有为了本版“全绿”改物理或删除原记录。旧接触穿入、太和前缀问题仍保留，**不宣称全程零穿或全部路径畅通**。
- 1.1m窄侧带仍是1m方形全身的紧通道。无新空间损失不等于旧模型通路已全部修好。
- CPU真RGBA/成品三角和控制器是所测范围；没有实际GPU、手机、完整heap/VRAM或真实玻璃反射验收。
