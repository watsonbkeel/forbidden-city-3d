# 午门马道：三段折返拓扑证据卡

研究结论：当前模型的单段直坡与官方图纸不符。已具备下一轮午门专属“三段折返登城”候选的拓扑依据；尚不具备现状测绘精度的施工参数或 2026 公众开放状态依据。本卡未改项目源码、碰撞、导航、锚点或 main，未运行浏览器/GPU，未发布。

## 最强差异

`src/scene/palace/gateAscent.js:71–103` 为每端仅造一条沿 X 的坡面。`PalaceBuilder.js:919–928` 给午门使用该通用函数：W=120，顶面12.3，默认水平长24.6；坡脚位于 x=±84.6，坡顶 x=±60，整个马道位于午门局部 z=12.6..18.6。行走者从外围向内沿同一直线抵达北缘城台。

官方展陈平面显示的路径却是：从城内北侧向南接近墩台的一跑 → 转向侧外的东西向一跑 → 在外端折返，沿邻接的上部一跑返回午门城台。两侧都画有折返平台、相邻两条东西向跑及南北向起步跑。保留单条直坡、仅换纹理或墙色，不能修复这一空间关系。

## 已知、未知与现代通行

- 高可信：双侧三段折返，北侧起步，外转后返回城台，分隔/挡土体必须随此拓扑组织。
- 尚未知：现状每段的准确起终点和标高、净宽、转台尺寸、墙体收分/厚度、踏步与礓嚓的现存分界、现代围栏的完整样式。旧文13m与官方建筑页12m的口径不能直接合并。
- 上述15.3/25.59/25.5是文献数字，不是已经注册到当前120m模型墩台的坐标。2021展陈图也不宜按像素作精确测量。
- 2020-12-14官方“远行与归来”公告明确当次展览入口在西马道，并说明入午门后左转约50m。它能支持“现代展览使用该路线”，不能证明2026年仍同方向、无限制、双向开放。2015和2020流线不同，正说明运营规则会变。
  https://www.dpm.org.cn/show/254952.html

## 最小后续源码范围建议

1. 新增午门专属 `special/WumenAscentProfile.js` 与 `special/WumenAscent.js`，先冻结来源层级、三跑及转台关系、旧文尺寸与工程拟合值的区别。
2. 只替换 `PalaceBuilder.js` 午门的 ascent 构建块。保持神武门使用原 `gateAscent.js`；`gateRailFacade.js` 的材质/三角形处理无需因拓扑而改动。午门上口的局部栏杆开口须与最终上口一致。
3. 实施前核对 `Enclosure.js:82–86` 的午门邻接南墙接口。现有外墙顶10m而午门台顶12.3m；不能用隐藏水平桥或擅开整条城墙通行来掩盖高差。若接口需要修改，应单独列出局部墙段范围，不能扩大为全宫墙体重建。
4. 后续真正实施必须让可见几何、挡土/栏墙碰撞、两侧三跑与转台支持面一致；新增左右全程/折返控制器测试，保留主楼、门洞、翼楼、其他门及移动算法。旧直坡路线和保留指纹不能靠放宽容差强行通过，应保留历史金样并添加有限来源迁移。

建议先做参数审阅与几何候选，不直接称为“2026实景复原”。无须为了这次研究改变现有导航。
