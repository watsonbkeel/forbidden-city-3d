# R8 four incense tables and censers: bounded silhouette trial

Official comparison image: https://img.dpm.org.cn/Uploads/Picture/dc/14498.jpg (also embedded in https://www.dpm.org.cn/explore/building/236465.html). The enlarged user copy depicts the same scene, not independent dating evidence. The photograph visibly supports four tall stands, spread feet, broad waisted aprons, rounded vessel shoulders and high open handles. It does not establish exact dimensions, alloy/finish or the date of current temporary carpets/barriers.

This candidate changes only the four existing estimated table/censer shapes. Position, height, collision envelope, dais steps, railings, cover, six columns, plaque, throne and screen registration are unchanged. All non-table generated components are compared against the frozen R7 ordered material/vertex hashes. No source photograph is included in product textures.

Fine S: 112 triangles per stand instead of 114. Generated front-dais detail 728 instead of 736; integrated S 17,924 plus 60 permanent beam triangles = 17,984, within the unchanged 18,000 ceiling. Coarse B remains 1,600 triangles. Eight batches and all material/texture definitions stay unchanged. Reusing the existing neutral gold batch adds 8,640 S / 1,728 B bytes of runtime response buffers (declared totals 493,368 / 13,248); this is an allocation change, not a raised performance threshold.

The bright apron/base/handles are a visual material trial. They are not a measured conservation-material claim. The low-sided bowl, two-sided slender handles/feet, and simplified straight splayed legs remain stylized. No claim of complete or exquisite restoration is made. Actual same-view image review is required before release, followed by the consolidated necessary runtime checks.

Focused CPU coverage: exact retained old GLB attribute/index prefixes, no new materials/images/textures, neutral UV on appended gold, unchanged column response ownership, bounded closed/outward apron geometry, unchanged navigable profile, 120 tests passed after correcting fixture expectations for this explicit asset revision. Initial failed test log is preserved separately.
