# V13 体验说明：首屏与限定批次修复研究预览

本轮是首屏与限定批次修复研究预览，集成V11修正后的匾额与V12紧凑地图代码，把初始视点向南移24m，并加入经审阅的屋脊/宝顶精确同值渲染批次修复。运行与构建身份见R3-RELEASE.json，CPU证据及其归属见V13验收范围；普通浏览器A/B、原生按住行走、原六机位性能和实际ZIP的验收状态见外部PACKAGE-MANIFEST.json及检查包。本文不预先宣告待验项通过，也不证明Pages已更新。

## 打开可玩包

1. 完整解压playable ZIP，在解压目录运行 `python3 start-local.py`；Windows可用 `py start-local.py`。
2. 自行打开 `http://127.0.0.1:8080/`。端口占用时加 `--port 8081`，再打开对应地址。
3. Ctrl+C停止。无需npm，不要双击site/index.html。

启动器沿用前版原始字节，只监听本机127.0.0.1，不自动开浏览器、不开放局域网。另一台实体手机不能通过这台电脑的loopback地址访问。最终身份见R3-RELEASE.json；实际不可变ZIP的大小、hash及检查结论见配套PACKAGE-MANIFEST.json。

## 首屏与操作

- 初始视点为`(0,1.7,-494)`，位于既有地面上，面朝午门。相机、控制器和分区初始加载使用同一位置；原性能锚点`LAYOUT.START_POSITION=(0,1.7,-470)`保持不变。
- 视高1.7m、垂直FOV70°及初始俯仰不改。16:9中央屋顶的CPU投影不再越框，但这不证明浏览器画面、UI遮挡或匾额可读性已经通过。窄竖屏仍可能横向裁切屋顶及两翼；不承诺完整组群入镜。
- 这是为游览选定的游戏视点，不是实测摄影机位、照片标定或建筑尺寸复原证明。天空、光照、建筑比例、地面、碰撞、玩家边界和控制方式沿用前版。
- 按正常提示进入，使用WASD/方向键或触摸方向盘行走。持续按住约2秒仍会自动奔跑；松开后仍有原控制器的短暂减速。
- M或触摸预览打开完整地图；“收起到角落”进入紧凑地图，“展开地图”保留缩放/平移后返回完整地图。紧凑状态可平移/缩放，点击不传送；关闭后再次打开从完整状态开始。短屏操作条、八方向提示及位置文本避让沿用V12。

## 限定渲染批次修复

修复仅让符合完整安全条件、原始线性颜色/粗糙度/金属度完全相同的 roof_ridge_glaze 与 roof_finial_gold 共享渲染批次；源几何、匾额、源材质对象和shader均不改。非默认材质或钩子、特殊几何/变换等回退原UUID分组，材质/几何身份及受支持的属性修订改变时重建。CPU夹具的11组归为2批只是分组证明，不是GPU调用节省或预算已通过的证明。
