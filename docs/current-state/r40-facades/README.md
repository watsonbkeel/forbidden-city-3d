# R40 三处正殿前后檐的差异化更新

在 R39 的89个有名称建筑清单上继续推进。本批实际更新景仁宫、钟粹宫、永和宫三座正殿，并不是所有建筑已完成；原有后殿更新和其他专属模型保留。

- 景仁宫：按官方文字开放后部中央入口，不把前檐菱花直接镜像到后檐。后部矩形玻璃框参考修缮文献作简化示意，精确现状仍待核；后阶和通用宝座前移只为模型通行留量，不是历史坐标。
- 钟粹宫：保留外柱、主屋顶、台明和外部台阶，将门窗围护退到柱列后方，形成可进入前廊。侧窗具有槛墙、上格和下部浅色区。2米后退是模型人物通行拟合，不是实测廊深；中央冰裂纹、苏式彩画和画片未精确重建。
- 永和宫：三间抱厦为开放柱廊，前方四柱承托圆弧屋面，檐下露曲椽，不增加封闭附室或第二套家具/房间。屋面隐蔽接缝与深高为拟合。正殿室内采用白樘箅子素格示意，不能把这一平天花伸到抱厦下面。

照片网址中的2020年路径是上传组织方式，拍摄日期未知。官方照片是建模参考，不是对生成场景的实机视觉验收。

## 验证边界

新专属测试覆盖实际门口、廊内行走、平台/台阶接续、全区原始和合并后有限几何、飞行包络及材料释放。其他119个殿座记录与86个建筑清单记录保持独立 R39 基线一致。初始钟粹廊深不足和屋面未设变换的问题已由测试发现并修正；不能只检查元数据就宣称模型正确。

全量测试与旧冻结断言的差异见最终验证记录。没有真实 GPU / WebGL 或原生手机验收；不宣称1:1测绘还原。地点仍为159项，七项原有身份不确定性未新增为确定事实。
