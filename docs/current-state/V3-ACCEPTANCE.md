四门各有独立记录，不再落到旧三间门或深砌体隧洞模板。门体、墙洞、小地图和三条通行中心共用同一参数。只调整直接紧邻协和/熙和的四个廊端点，不把这些接口修订当成全部庑廊验收。

梯形坡道有实际封闭楔体、内部切片碰撞及随坡变化的边界；不在包围盒空角产生虚假可走面。高台不依赖把玩家从底部自动托上去的补救。门叶、柱和封闭窗墙保留碰撞，支持三条真正的地面到地面通行。

所有参考照片只作研究。没有把博物院照片/论文复制进运行时，没有生成图片冒充实景证据；四座原有坐标、神武门与城墙位置均未移动。

## 路线与设置修复

- 浴德堂自动路线先在旧生产控制器中复现。测试规划器错误的五间门平台深度，加上过早转弯，导致撞到武英门后柱。改为读取实际门型尺寸，并在两个简单折线路径都不可行时，从附近殿台边界生成有限的三段路径。没有删墙、移建筑、放宽到达半径或跳过失败。
- 自动路线由39条增为51条，新增四门各三通道的完整坡脚/坡顶往返。原有33条固定路线全部保留，只将协和/熙和的四段跨门过程补到真实坡脚外地面再转弯；原固定路线本来就能通过，不虚构旧栏杆阻挡。
- 旧设置菜单把用户选择的画质赋值后又反转一次，真实按钮点击会应用相反档位；本轮直接应用所选值，并同步标签。桌面设置层提升到欢迎层之上、加载层之下，按钮无需隐藏欢迎层才能操作。
- V2额外观察的“初始高画质标签”来自尚未打开的隐藏按钮；打开菜单时原本会刷新。这个观察不等于用户打开菜单仍错标。真正的按钮反向应用和桌面遮挡已分别在旧开发版、旧生产包复现。
