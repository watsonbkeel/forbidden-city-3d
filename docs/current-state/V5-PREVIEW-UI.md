# V5 设置与结构预览说明

日期：2026-10-14 UTC。此项只调整 UI 生命周期与研究说明；不修改建筑定位、碰撞、路线、性能机位或容差，不代表全宫 2026 年现状与游客开放情况已验收。

## 行为

- 常驻小型“结构研究预览”按钮同时提供触屏设置入口；游戏路线不代表现场游客开放路线。摇杆被一指按住时，入口直接响应第二指的 touchstart，并在事件可取消时阻止延迟兼容 click；菜单内现有按钮、详情和链接在非主触点未拖动、未取消且 600ms 内结束时激活一次，超过 10px 的移动不触发控件。单指轻点、鼠标和键盘继续使用原生 click，菜单内部仍保留原生触摸滚动。两个触摸处理点仅在事件可取消时调用 preventDefault；不可取消事件仍执行同样的一次激活，不触发浏览器取消警告。
- 地图展开时，同一个预览入口进入现有地图的流式顶部，随地图滚动保持 sticky，并为聚焦滚动留出顶部空间；关闭地图移回原位置，不覆盖地图快捷按钮，不改变画布尺寸和导航坐标。菜单打开期间程序切换地图只更新恢复后的模式，入口移动仍保持 inert 与焦点限制。
- 设置面板受动态视口和安全区约束。标题／关闭与底部“继续游览”固定在面板内，仅中间内容滚动。640×400 与横屏不再依赖超出屏幕的固定高面板；真实点击、滚动和尺寸仍须通过下述浏览器验收。
- 初始焦点在标题；Tab／Shift+Tab 限于当前可用控件，关闭的资料详情内链接不参与 Tab。滚动区可聚焦，保留原生箭头、PageDown、Space 和触摸滚动；展开资料后可用键盘到达所有链接。关闭恢复之前焦点。
- 关闭、继续、背景点击、Esc 都只触发一次恢复；重复打开或隐藏不重复触发回调。持住 Esc 不重复切换。画质按钮保留一次点击只应用一次所选值，音效有对应按下状态。
- 菜单打开时清除按键、残留摇杆／视角触点及排队跳跃；暂停控制器更新，脚步音效输出归零。设置事件不传到 body／document／window 的行走、地图或传送处理器，默认滚动与控件行为保留。
- 关闭恢复原来的地图／freeMove 状态和实际指针锁定状态。若打开时在欢迎页或已解锁，关闭后仍保持原状态。若浏览器原生 Esc 在应用收到按键前已解锁，则保留普通“点击画面开始”入口；不猜测更早的锁定状态。实际锁定状态下打开菜单才尝试恢复锁定，浏览器拒绝时保留点击入口。
- 销毁恢复此前的 inert 状态，并移除全部菜单 DOM 与事件监听，不触发重新锁定。普通游览、画质渲染链和玩家物理实现保持原有实现。

## 三项资料层级

1. 有来源的结构：弘义阁、体仁阁分别依据[杨新成 2006 年测绘研究](https://www.dpm.org.cn/Uploads/File/2019/11/14/u5dcd2fd72ceee.pdf)。三大殿共用台基东西腰部台阶的拓扑参考[1960 年资料](https://www.dpm.org.cn/building/talk/223358.html)与[2020 年刊载照片](https://img.dpm.org.cn/Uploads/File/2020/10/23/u5f9255173a228.pdf)。刊载年份不是照片拍摄日期。
2. 暂定几何：部分屋面、构件细节与台基接口仍为近似；侧阶中心 z=58 m、外宽 5 m，以及沿用台基层高、轮廓和踏步细节是工程暂定值，不是现场实测。既有全局定位不变。
3. 独立的游客开放状态：[2026-07-31 官方公告](https://www.dpm.org.cn/announce_detail/379422.html)说明太和门自 2026-08-03 起封闭施工。2026-10-14 资料检索未找到官方重新开放确认，未作当日现场核实；不能外推其他建筑、桥或侧阶的开放情况。游戏通路不被这条说明强制封锁。

UI 只含文本和普通官方链接，不自动读取外部状态、不加图片／纹理或追踪。链接以新窗口打开，含 noopener noreferrer。

## 自动化与浏览器边界

专项命令：

```sh
node --test tests/settings-menu.test.mjs tests/settings-tour-session.test.mjs tests/settings-inputs.test.mjs
```

首轮 14 项新增行为在原实现上失败；保留的 4 项画质／层级测试通过。独立评审补充的 3 项原解锁状态恢复测试先失败再修复。现有 37 项专项测试包括真实 FirstPersonControls、VirtualJoystick、CollisionManager 的输入与恢复回归；DOM fixture 仅模拟事件传播、焦点和属性。CSS 约束测试不是实际排版、触摸滚动、浏览器指针锁或屏幕阅读器验收。独立手机遥测曾确认第二指事件到达入口但不合成 click；保留该失败与单指对照，再以两项先失败的回归补充入口处理。第二步遥测确认旧第一指仍按住时菜单按钮也无 click，新增先失败的控件激活回归与拖动／取消／长按／旧触点恢复保护测试后补齐。

## 浏览器验收矩阵（交由独立 QA 执行）

所有操作须使用可见真实控件，不遮掉欢迎层、不强制点击、不用脚本直接派发按钮回调。开发版和冻结后的可移植生产包均需复查。

| 设备／CSS 视口 | DPR | 必做操作与断言 |
| --- | --- | --- |
| 桌面 1600×1000 | 2 | 欢迎页打开按钮；初始焦点与层级；高→低→高实际像素比 2→1→2，标签／SSAO／阴影同步；关闭后仍停欢迎页。进入游览后再开关。 |
| 短桌面 640×400 | 2 | 标题、关闭、继续全在视口内；展开详情后滚轮／PageDown／Tab 可达所有说明和 5 个官方链接，无横向裁切；按钮各真实点击一次；高→低→高 2→1→2。 |
| 手机竖屏 390×844 | 3 | 常驻标签、地图与摇杆不互相挡住；点标签进入；手指滚动可达全部详情，标题／继续保持可点；低→高→低 1→2→1；旋转后再检查。 |
| 手机横屏 844×390 | 3 | 展开详情后实际触摸滚动；标题与继续不裁切；近摇杆区域的菜单拖动不走路／转视角；低→高→低 1→2→1。 |

四组共同覆盖：

- Tab／Shift+Tab 首尾回绕，合拢与展开详情的焦点顺序正确；焦点可见，关闭回原入口。
- 关闭按钮、继续、Esc、背景点击分别只关闭一次；按住 Esc 不抖动、不重新弹回。菜单里点正文／标题不锁鼠标。
- 打开地图并持住移动时开菜单：按键／Q/E／M／1–8／Space 不影响角色；关闭恢复原地图模式，新输入能移动。
- 手机摇杆推住时开菜单：立刻停止；滚动、展开与画质按钮不重启摇杆；关闭后新触摸能正常走动与转向。
- 点击资料链接只打开所选官方页面，返回游戏时菜单仍在；没有自动外网请求或游戏路线封锁。
- 正常进入后的无菜单帧不改变性能口径；检查 pageerror、重复开启／销毁后的孤立 DOM 和监听增长。

关键选择器：#structural-preview-button、#settings-title、#settings-content、#settings-close-btn、#quality-toggle-btn、#sound-toggle-btn、#preview-details、#resume-btn。
