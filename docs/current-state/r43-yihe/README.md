# R43 颐和轩地面布局的局部更新

本批实际更新颐和轩一处建筑。主殿七间、前抱厦五间、后抱厦三间不再用一个通用九间厅堂代替；前抱厦中央三间开放，两端围合。东侧主殿隔断延续到东南随安室，西向门进入北部过渡空间后向南转入两个相通的小空间及南端床位轮廓。没有添加被褥、摆件或猜测的完整陈设，其他88个建筑记录不作修改。

平面图署名清华大学建筑设计研究院陶金绘、许彤提供。它是无比例尺的示意平面，不是本模型可直接套用的实测尺寸表。图中东南间与放大图北墙标注共同确定北向在上、东向在右；场景东向为负X，因此随安室在模型负X、负Z方向。

入口在北部过渡空间的西侧边界，不是北墙夹纱窗。模型保留西向开口及向南转折，北墙窗保持阻隔。两个空间之间和床位前是短框形成的相通颈口，不是完全封死的横墙。主殿端间的南向前凸是围护线，不能与更外侧的平台轮廓混淆。

## 拟合和未完成部分

- 保留既有34.1×22.9米模型外廓、位置、台明、前阶和近似连续屋顶。不宣称这些尺寸为实测或1:1复原。
- 等分七间轴线及前五间、后三间对应关系是拟合。南至北的深度段为6.2、11.65、5.05米；主殿端间额外向南前凸2.5米。该分配是示意图归一化后的模型选择。
- 西向门洞宽1.6米、北窗旁转入通道宽1.55米、内部颈口宽2.4米为人物通行拟合，门扇选定姿态不是历史状态或现场参观许可。
- 北接廊超出原模型外廓的部分未建。北中央门以关闭姿态表达边界，不虚构已经通往景祺阁的完整通道；主殿与后三间之间保持开放连接。平面中未标名的中央短构件暂不猜为屏风或家具。
- 西部主殿细分仍待专门更新。当前登记三个观览导航区域，并非声称全殿恰好只有三个历史房间。
- 屋顶本批未改。连续旧屋顶与新阶梯式围护之间只是过渡近似，抱厦屋顶形制、交接和完整屋面轮廓仍未重建；不能标记外观完成。
- 素格门窗、素色高顶、框口和床位低轮廓仅表示已核实的关系与拟合空间；未复刻夹纱刺绣、宣石山景、精细彩画或占用床铺。官方照片网址日期不是已知拍摄日期，2025年出版平面也不是2026年陈设清单。

## 检查

真实控制器在10/60Hz重复前阶、中央门、向东进入西向侧门再向南转入随安室，反向退出；窗不可作为捷径。独立冻结基线覆盖所有121处非目标殿座和88条非目标记录。完整测试、构建及保留失败将在验证记录中分别列出，不将聚焦通过表述为全量通过。
