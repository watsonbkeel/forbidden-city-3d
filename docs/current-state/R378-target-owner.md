## 产品修复

奉先门原始目标中心与首选落点位于所属区域 bounds 之外。此前仅按坐标查区域可能未加载目标的碰撞实体，便开始验证和写入落点。现在保留原始目标与所属区域的准确关联，传送安全检查之前加载该所属区域及其声明邻区；加载失败或关联失效不得先移动玩家。静态与 map-only 目标不按名称或最近坐标猜造 owner。

保持原落点候选顺序、空间预取、碰撞检查、回退逻辑及历史三佛资源清理修复。具体实现和负例见 `tests/r378-target-owner/owner.test.mjs`。新增需求/bug单独登记，不重复计入原397项。
