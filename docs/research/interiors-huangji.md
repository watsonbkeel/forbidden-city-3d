# 皇极殿 室内资料（interiors-huangji）

> 任务 P1-D / D-3。坐标约定：原点 = 太和殿中心，+Z 北，−X 东，单位 m。
> 主来源：A14 故宫博物院官网 https://www.dpm.org.cn/explore/building/236476.html （访问 2026-10-11）；Commons 分类 "Palace of Tranquil Longevity"。
> 置信度：高 / 中 / 低；未查到的字段显式写"未查到"。
