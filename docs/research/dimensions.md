## 0. 坐标换算附录（D-2）

### 0.1 换算方法

1. 原始数据：OpenStreetMap 0.6 API，`map.json?bbox=116.3855,39.9105,116.3965,39.9230`（2026-10-11 下载，501 个带名称 way），见 D1–D3。
2. 太和殿 OSM 轮廓 bbox 中心 → (lat 39.915 9°, lon 116.390 6°) 定为原点。
3. 局部米制：Δz_raw = Δlat × 111 034 m/°；Δx_raw = −Δlon × 85 499 m/°（lat 39.916° 处 cos 修正）。
4. 轴线旋转：午门中心 → 神武门中心 的方位角相对正北偏 **−2.13°**（紫禁城中轴实际约 2° 偏西北，OSM 数据+本地投影合成），对全部点做 −2.13° 旋转后，中轴上各门殿 |x| < 2 m，验证通过。
5. 建筑中心 = 轮廓 bbox 中点；面阔/进深量算值 = bbox 宽/高（含出檐）。
