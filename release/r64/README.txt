R64 G区御花园阶段累计生产包

累计包含此前108人物、24路线及A至F全部阶段更新，人物默认开启，可在设置一键关闭，不是108人同时显示。
本轮有界改进：钦安殿原台面改白石表面、五片南面门窗细分；浮碧亭与澄瑞亭各自天花格框，澄瑞独立八方藻井轮廓；实际新增天一门拱券、台阶、平台与素影壁；千秋亭分段宝顶；御景亭仅照片可见南侧通透栏。
天一门向外开启是可游览拟合，不代表博物馆常态开放；尺寸、未知纹样与满文省略均明确标记。只撤除实际穿新影壁的两盏旧程序灯和对应碰撞，其余树木、路径和角色保留。
G区29对象、400细项及10声明完成逐项差异/可实施性审查，不是整园完成。浮碧实拱、完整顺贞三门、缺失配套建筑、堆秀山洞/蹬道/水法及各室内仍保留明确残余，A至F未闭合项不清零。

需要 Node.js。解压后在此目录运行 node start.mjs，再打开终端显示的本地地址。不要直接双击 dist/index.html。
页面显示R64构建号；设置内可复制诊断核对实际载入版本，不需清除全部浏览器数据。
构建信息见 dist/build-info.json，完整包文件及SHA见 SHA256SUMS.json。

实际CPU几何/控制/绑定测试不是浏览器WebGL、手机或GPU验收。官方参考照片不随包再分发。
