# R64-G cumulative production package

This package includes the previously delivered cumulative R63 and bounded R64-G garden corrections. It is an executable stage, not acceptance of every garden requirement.

Run `node start.mjs` and open the local address it prints. The package identifies itself as R64 with a build fingerprint. Character presentation remains on by default and may be switched off in Settings. The logical registry remains108, with24 routes and unchanged simultaneous display limits.

R64 addresses Qinan's exposed support finish/front panels, distinct bridge-pavilion ceiling structures, one newly instantiated Tianyi gate, Qianqiu's fitted layered finial and the photo-visible southern Yujing rail. Tianyi's open-door pose is a navigation fit, not a statement that the museum gate is normally open. No official reference photograph is bundled.

Fitted dimensions, unseen ornament and rear surfaces remain qualified. The full G29 review and all A–F residuals remain in the source reports. Browser/WebGL, GPU performance and physical-phone acceptance have not been performed; offline CPU images do not replace them. The photographed Fubi bridge opening, Shunzhen's full three-gate ensemble, missing side buildings, rockery/grotto/stair/water geometry and other identified omissions remain explicitly pending.

No account credentials, main-branch merge or Pages deployment is performed by this package.
