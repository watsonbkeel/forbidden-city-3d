故宫 3D · R53 统一版本 · 本地生产包（不是部署）

1. 完整解压，保留 dist 文件夹与 start.mjs 在同一目录。
2. 运行 node start.mjs（已安装 Node.js 18+，不需要 npm install）。
3. 浏览器打开 http://127.0.0.1:4173 。Ctrl+C 停止。
不要直接双击 dist/index.html，浏览器的本地文件限制会阻止模块或模型加载。

加载界面和游览设置显示本包实际构建编号。dist/build-info.json 记录同一版本、构建编号、源码内容指纹、构建时提交及是否有未提交输入。
游览设置可复制当前构建与人物已注册、数据就绪、当前可见、准备中和失败数量；不会复制浏览器地址、查询参数、位置或错误详情。
只有点击“检查服务器版本”才请求同一站点的版本信息，无后台轮询。版本不同后仍须主动点击刷新，刷新会重置当前游览位置。不自动刷新、清理缓存、删除保存数据或注销服务工作线程。
在本地包中，服务器指运行本包的本地服务，不会检测 GitHub Pages 或其他网站。

本包累积保留R49B、R49D、R49E及R51的已交付修正，并保留 R52 武英殿四件展品轮廓改善及南月台/侧阶。本版77个不具名宫廷演绎人物，新增咸福宫、太极殿、景阳宫共6人，并加入养心殿西暖阁与寿康宫东暖阁的有限基础构架、形制和材质。后两项仍是来源约束的 partial，不是完整精修、测绘复刻或清代原状复原，未知纹样、书法、佛像与供器不补造。未接受的景运门实验不包含在内。
人物默认开启，游览设置可一键关闭。77为全场逻辑人数，不是同屏人数；高档同屏最多64、低档32、复杂近景最多2。太和及生活场景白天活动，夜间保留18名宫门与长街守卫；低档太和官员固定12。室内后妃和皇帝在原室内座位，不移到庭院。人物数据就绪不是 GPU／手机性能或史料验收通过。
SHA256SUMS.json 列出包中所有文件的 SHA-256，并保留实际构建来源；打包时源码指纹不符会拒绝旧 dist。此包不覆盖旧版本，保留旧包即可回滚。

本版另修储秀宫旧人物鞋底约2厘米压入可见地面的接触问题：宫女改绑真实地面，坐姿后妃只调整低炕姿态脚/下袍，臀与座面不抬高。其低炕变体的几何字节有变化，其他姿态不变。
