R62 E区阶段生产包

累计包含此前108人物及A至D阶段更新。人物默认开启，可在设置一键关闭；不是108人同时显示。
本轮有界改进：奉先前殿九间双檐及四端窗、后殿九间；永和抱厦曲肩；景阳后殿五间与槛窗；景仁前后殿局部窗格；景仁与钟粹低模屋角五兽列；五处无据通用宝座及24个既有附属建筑预设家具撤下并标UNKNOWN。
这些是有来源边界的局部改进。E区61对象/854细项已逐项扫描，不是整区实景验收；未核房间、陈设、布局、细雕和铭文等仍有明确残余，空陈设不表示历史上为空房。

需要 Node.js。解压后在此目录运行 node start.mjs，再打开终端显示的本地地址。不要直接双击 dist/index.html。
页面显示R62构建号；设置内可复制诊断核对实际载入版本，无需清除全部浏览器数据。
构建信息见 dist/build-info.json，完整包文件及SHA见 SHA256SUMS.json。
