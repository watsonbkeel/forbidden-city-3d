R65 人物体验修正累计生产包（不是 H 区版本）

保留 R64 及之前所有累计内容、108 个逻辑人物、24 条路线。高档最多同时提交64人，低档32人，不是108人始终同屏。
人物全天保持可展示，17:25不再按日照阈值消失。夜间增加冷色模拟月光和柔和补光，保留夜空、太阳和曝光；这是游览可读性处理，不代表真实历史夜间作息或实测月相。
玩家与人物按姿态/高度互相阻挡。巡逻遇玩家停止，空间允许时沿原已验证路线退让，玩家离开后继续；不瞬移、不推开玩家，不把人物当建筑地面。被关闭、卸载或低档省略的人物不会留下近处隐形障碍。
底部设置入口按指定位置改为两行：“作者”“陈华山&陈诺”，点击仍打开设置。人物可以一键关闭。

需要 Node.js。解压后在此目录运行 node start.mjs，再打开终端显示的本地地址。不要直接双击 dist/index.html。
设置内显示 R65 构建号，可复制诊断，避免误认旧页面。无需清除全部浏览器数据。
完整文件校验在 SHA256SUMS.json；构建来源在 dist/build-info.json。

本版本交付累计开发分支供用户自行合并 main。未修改用户 main 部署工作流或 vite 配置，不宣称合并无冲突，也未直接部署 Pages。
CPU 实际几何、输入、碰撞、流式加载与生产接线检查不是浏览器 WebGL、实体手机或 GPU 性能/夜景观感验收。A–G 历史资料与工程残余全部保留；H 后续顺延为 R66，尚未开发。
