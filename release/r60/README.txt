R60 C区阶段生产包

包含此前累计的108人物与A/B阶段修改。人物默认开启，可在设置一键关闭；不是108人同时在屏幕显示。
本轮修改武英门端窗及南台素栏、浴德既有内穹顶砖缝、南薰无据道具与藻井基础色、西华外向上带窗面。
C区17个对象已扫描，但不是整区实景验收；细纹、雕塑、未知房间和时点仍有明确残余。

需要 Node.js。解压后在此目录运行 node start.mjs，再打开终端显示的本地地址。不要直接双击dist/index.html。
页面显示R60构建号，可用设置内复制诊断核对实际载入版本；无需清除全部浏览器数据。
构建号见dist/build-info.json，完整包清单和SHA见PACKAGE-MANIFEST.json。

本地CPU几何/控制/绑定测试不是浏览器WebGL、手机或GPU性能验收。参考图不作为游戏贴图再分发。
