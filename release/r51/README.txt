故宫 3D · R51 统一版本 · 已构建生产包

本包包括此前已交付的 R49B、R49D、本仁小修、R49E 文渊牌位、R50 人物与后续修正。不包括未接受的景运门实验。

运行：
1. 完整解压，保留 dist 文件夹与 start.mjs 在同一目录。
2. 在该目录运行 node start.mjs（需要已安装 Node.js 18 或更新版本，不需要 npm install）。
3. 浏览器打开 http://127.0.0.1:4173 。停止时在终端按 Ctrl+C。
也可用已有静态 HTTP 服务托管 dist。不要直接双击 dist/index.html，浏览器的本地文件限制会阻止模块或模型加载。

人物现在在普通生产版本中默认开启，不需要 DEV、控制台或实验按钮。
出生视角可以看到较远的午门守卫；靠近后模型更清楚。前往太和殿可看朝会人物，宫廷生活人物分布在后宫。
人物逐步准备并淡入。打开游览设置可看已注册、已加载、当前可见、准备中与失败数量，以及一键关闭/再开。
夜间朝会和生活人物按计划休息，守卫仍在；没有为截图改动游戏默认时间或成人尺度。

外观方向已由用户确认。GPU、手机性能及具体女性发式/服制史料仍未完整验收，不能把“可用”当作全体验收通过。
这是可本地运行的开发交付，不是已经部署到 GitHub Pages。

包中模型和建筑材质/纹理均来自当前生产构建。另附的 CPU 几何核查图省略贴图、运行时光照和阴影，因此建筑呈白模；那不是本包游戏材质被删除，也不是浏览器/GPU截图。
SHA256SUMS.json 列出包中每个 dist 文件的 SHA-256，可用于完整性核验。
