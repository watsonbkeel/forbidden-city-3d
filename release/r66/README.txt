需要 Node.js。解压后在此目录运行 node start.mjs，再打开终端显示的本地地址。不要直接双击 dist/index.html。设置内显示 R66 构建号并可复制诊断；人物可一键关闭，无需清除全部浏览器数据。

完整文件校验在 SHA256SUMS.json；构建来源在 dist/build-info.json。源码报告包含四个独立完整世界的重新绑定、真实加载/卸载和 CPU 几何检查。它们不是单一连续浏览器会话、WebGL、实体手机、GPU 性能或夜景观感验收。
