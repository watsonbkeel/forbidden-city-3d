累计包含此前R57的全部更新和108名逻辑人物。人物默认开启，设置中可一键关闭；108不是同屏人数。高档最多64、低档32，近景高细节最多2。日间与夜间计划不同，夜间保留全天守卫。人物是可切换匿名宫廷演绎，不对应史实人数、岗位、日程或现代工作人员。

完整待办仍包括未定位的保和东联庑防火墙、缺乏尺度配准的中和内柱、需要支承物理方案的桥帽、需要扩大拟合并核屋檐净空的太和外匾，以及各对象未见侧背面、隐蔽空间、纹饰和时代核对。新13分区队列不删原范围；后续进入B区时保留这些A区待回访事项。

运行：需安装Node.js。在解压目录运行 node start.mjs，再打开终端显示的本机网址。不要直接双击 dist/index.html。此包不会自动部署或修改浏览器数据。

左上/设置可查看R58构建标识。若看到旧版，先核对网址和版本，不必清除全部浏览器数据。
