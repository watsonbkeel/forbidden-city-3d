故宫 R56 累积生产包

包含此前 R55 及更早已交付更新，新增寿康宫、慈宁宫、寿安宫、养心殿院落的8名匿名人物。逻辑总人数101，不代表同屏人数；高档最多64、低档32，近景高细节最多2。全部人物可在设置中一键关闭。

运行方法：需已安装 Node.js，在解压目录运行 node start.mjs，再打开终端显示的本机网址。请不要直接双击 dist/index.html。此包不会自动部署或修改浏览器数据。

左上/设置可查看 R56 构建标识。若看到旧版，请先核对网址和版本，不必清除全部浏览器数据。

人物为匿名宫廷氛围演绎，不对应史实人数、确切职务或现代展厅工作人员。养心两人位于模型内院，不称养心门外值宿岗位。现有建筑仍有部分简化。GPU/WebGL画面与帧时、实体手机及完整史实验收未完成。人物默认可见不代表整体验收通过。

SHA256SUMS.json 给出全部包文件哈希及实际构建来源；此前版本保持回滚。
