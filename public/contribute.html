参与改进 / Contribute

欢迎提交可复现的问题、可靠资料和小范围改进。作者：陈华山、陈诺。先核对当前构建版本，再描述问题。

Contributions are welcome: reproducible bugs, reliable sources and focused improvements. Record the exact build first. This page does not require the game or JavaScript.

报告问题 / Report an issue

  1. 记录版本或构建标识、浏览器与设备、宫殿名、地图位置或路线。
  2. 说明预期与实际结果；人物或光照问题附北京时间，碰撞问题附进入和退出方向。
  3. 可附不含私人信息的截图。不要提交密码、令牌或账号凭据。
  4. 通过GitHub Issues提交，或先查看是否已有同类问题。

Include the build ID, device/browser, palace/location, reproduction steps, expected and actual results. Add Beijing time for lighting/routine issues and travel direction for collisions. Never include credentials or private data.

资料与模型修正 / Evidence-led corrections

优先提供官方页面、可核对照片或论文的具体出处、日期与页码。区分已知事实、照片拟合、工程/游戏适配与未知细节。不要把估算写成测绘，不上传来源不明的整本资料或无权分发的素材。

代码贡献 / Code contributions

  1. 从明确的累计版本建立独立分支，保留之前的完整功能。
  2. 运行安装、构建和受影响测试；旧失败必须保留和说明，不能通过删除测试隐藏。
  3. 碰撞或公共几何修改扩大路线验证，检查地图、飞行、人物和夜景。
  4. 提交小范围Pull Request，说明来源、改动、证据、未验项及回滚办法。

Use an isolated branch and a focused pull request. Preserve cumulative functionality, document evidence and unknowns, and run affected tests. Shared geometry/collision changes require broader route checks. Do not hide legacy failures or claim GPU/mobile validation from CPU tests.
