项目、资料与引用 / About

这是一个基于Three.js与Vite的故宫第一人称浏览器漫游项目。基础建筑主要由代码生成，部分细化内景使用仓库随附的GLB模型。玩家可步行、查看地图、体验飞行与昼夜场景。

Forbidden City 3D Tour is an independent browser-based exploration project built with Three.js and Vite. Its base architecture is largely procedural; selected interiors use bundled GLB models. It supports walking, map navigation, flight and a day/night scene.

准确性与资料 / Evidence and accuracy

米制坐标不等于实测精度。项目区分官方资料支持的事实、照片或既有外包的合理拟合、游戏适配，以及尚未核实的细节。人物作息、床位、隔屏与照明是游戏设计，不是历史生活复原。

Metric coordinates are not a claim of survey accuracy. Official facts, photo/model fits, gameplay adaptations and unknown details are separate categories. Character routines, beds, privacy screens and lighting are game design, not a reconstructed historical household.

版本与验证 / Version and validation

本页属于R79文档改进候选。已核验的累计源码为R78；分支上传、合并主线、公开部署是不同状态。请在游戏设置中查看实际加载的构建标识，不要只凭网页文案判断部署版本。

R78记录108个逻辑人物、28个唯一占用床位。专项17项、累计133项及4种完整夜间CPU场景检查通过；旧检查仍有151个失败，不能称为全套测试全绿。真实GPU、手机及完整视觉路线验收仍有缺口。

Version labels do not prove deployment. Check the loaded build identity in game settings. R78 retains 108 logical actors and 28 assigned occupied beds. Its documented CPU checks do not replace GPU, mobile or complete visual acceptance; 151 legacy failures remain disclosed.

常见问题 / FAQ

这是官方数字故宫吗？

不是。这是陈华山与陈诺的独立项目，不代表故宫博物院。

能把模型尺寸当作建筑测绘数据吗？

不能。请查看每项来源和拟合标记；需要测绘依据时应使用相应权威原始资料。

页面能在不运行游戏时阅读吗？

可以。本说明和贡献页面是普通HTML，不依赖WebGL或JavaScript。

Is this an official or survey-accurate digital twin?

No. It is an independent interpretation. Use the cited original sources for historical facts and measured architectural work, and cite this repository only for its own software and modelling choices.
